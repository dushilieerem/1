# 四个通道位置与宽度因子说明

> 对应实现：`Factor/libraries/classic_indicators.py`
>
> 本文档说明唐奇安通道与肯特纳通道的四项衍生因子。它们均返回“日期 × 标的”的 `pandas.DataFrame`，只使用当期及历史行情，不使用未来数据。

## 1. 唐奇安通道位置

### 用途

衡量收盘价在最近一段时间高低价区间中的相对位置，适合刻画突破方向和趋势强弱。数值通常位于 `0` 到 `1` 附近，越接近 `1` 表示越靠近区间上沿。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `donchian_position` |
| 默认参数 | `window=20` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
Upper = RollingMax(High, n)
Lower = RollingMin(Low, n)
Donchian Position = (Close - Lower) / (Upper - Lower)
```

实现对分母增加极小值保护；当价格接近通道下沿或上沿时，因子分别接近 `0` 或 `1`。

## 2. 唐奇安通道宽度

### 用途

衡量最近高低价区间相对价格的扩张程度，可用于识别突破前的收缩与趋势中的波动扩张。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `donchian_width` |
| 默认参数 | `window=20` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
Donchian Width = (Upper - Lower) / |Close|
```

使用收盘价绝对值归一化，便于比较不同价格水平的标的。

## 3. 肯特纳通道位置

### 用途

衡量收盘价在 EMA 中轨与 ATR 波动带中的位置，兼顾趋势方向和近期真实波动范围。数值高于约 `0.5` 表示价格位于通道中线之上。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `keltner_position` |
| 默认参数 | `window=20`、`atr_window=10`、`multiplier=2.0` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
Middle = EMA(Close, window)
TR = max(High - Low, |High - PrevClose|, |Low - PrevClose|)
ATR = SMA(TR, atr_window)
Upper = Middle + multiplier × ATR
Lower = Middle - multiplier × ATR
Keltner Position = (Close - Lower) / (Upper - Lower)
```

当前实现采用常见的 EMA 中轨、ATR 波动带口径；分母使用极小值保护。

## 4. 肯特纳通道宽度

### 用途

衡量 ATR 通道相对于 EMA 中轨的宽度，反映价格波动水平的相对变化。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `keltner_width` |
| 默认参数 | `window=20`、`atr_window=10`、`multiplier=2.0` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
Keltner Width = (Upper - Lower) / |Middle|
```

宽度越大表示 ATR 反映的波动越高；使用中轨绝对值归一化后可用于不同价格水平标的的横向比较。

## 使用边界

- 四个因子是研究信号，不构成交易指令或收益承诺。
- `window` 或 `atr_window` 的前置样本不足时会产生缺失值；回测前应统一处理缺失值、停牌、涨跌停和股票池。
- 唐奇安通道直接使用滚动最高/最低价，极端价格会影响窗口内的通道边界；肯特纳通道的结果会随 ATR 和乘数设定变化。
- 价格应采用一致的复权口径；跨数据源比较前应核对交易日历、复权规则和字段单位。
