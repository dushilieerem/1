# 四个技术振荡与量价因子说明

> 对应实现：`Factor/libraries/technical_lib.py`
>
> 本文档说明终极振荡器、费舍尔变换、移动容易度和相对活力指数的当前实现口径。四项因子均返回“日期 × 标的”的 `pandas.DataFrame`，只使用当期及历史行情，不使用未来数据。

## 1. 终极振荡器（Ultimate Oscillator）

### 用途

用短、中、长三个周期同时观察买压相对真实波幅的强弱，降低单一窗口动量指标在趋势延续阶段过早钝化的问题。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `ultimate_oscillator` |
| 默认参数 | `short=7`、`medium=14`、`long=28` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
PrevClose = Close.shift(1)
BP = Close - min(Low, PrevClose)
TR = max(High, PrevClose) - min(Low, PrevClose)
Average(n) = Sum(BP, n) / Sum(TR, n)
Ultimate Oscillator = 100 × (4 × Average(7) + 2 × Average(14) + Average(28)) / 7
```

窗口参数可调整，但保持短、中、长窗口的递进关系更容易解释。

## 2. 费舍尔变换（Fisher Transform）

### 用途

把滚动价格位置映射为更容易观察极值的非线性振荡值，用于捕捉趋势转折和价格处于窗口极端位置的情况。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `fisher_transform` |
| 默认参数 | `window=10` |
| 字段依赖 | `high`、`low` |

### 公式

```text
Midpoint = (High + Low) / 2
X = 2 × (Midpoint - RollingMin(Midpoint, n))
    / (RollingMax(Midpoint, n) - RollingMin(Midpoint, n)) - 1
Fisher Transform = 0.5 × ln((1 + X) / (1 - X))
```

实现将 `X` 限制在 `[-0.999999, 0.999999]`，避免价格位于滚动边界时出现无穷值；平坦窗口的 `X` 设为 `0`。

## 3. 移动容易度（Ease of Movement，EOM）

### 用途

结合价格中点位移、日内振幅和成交量，衡量价格上涨或下跌所需的成交量压力。正值表示价格相对容易上行，负值表示相对容易下行。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `ease_of_movement` |
| 默认参数 | `window=14`、`volume_divisor=100000000.0` |
| 字段依赖 | `high`、`low`、`volume` |

### 公式

```text
Distance Moved = ((High + Low) / 2).diff()
Box Ratio = (Volume / volume_divisor) / (High - Low)
One-period EOM = Distance Moved / Box Ratio
EOM = SMA(One-period EOM, window)
```

`volume_divisor` 用于控制不同成交量单位下的数值尺度；跨数据源比较时应保持一致。

## 4. 相对活力指数（Relative Vigor Index，RVI）

### 用途

比较收盘价相对开盘价的动量与日内高低价区间，观察趋势方向和潜在背离。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `relative_vigor_index` |
| 默认参数 | `window=10` |
| 字段依赖 | `open`、`high`、`low`、`close` |

### 公式

```text
NumeratorBar = (Close - Open)
    + 2 × (Close - Open).shift(1)
    + 2 × (Close - Open).shift(2)
    + (Close - Open).shift(3)
    -------------------------------- / 6

DenominatorBar = (High - Low)
    + 2 × (High - Low).shift(1)
    + 2 × (High - Low).shift(2)
    + (High - Low).shift(3)
    -------------------------------- / 6

RVI = SMA(NumeratorBar, window) / SMA(DenominatorBar, window)
```

实现对分母增加极小值保护，不额外输出信号线。

## 使用边界

- 四个因子是研究信号，不构成交易指令或收益承诺。
- `window` 及多周期窗口的前置样本不足时会产生缺失值；回测前应统一处理缺失值、停牌、涨跌停和股票池。
- EOM 对成交量单位和 `volume_divisor` 敏感；RVI 需要可靠的开盘价，复权口径应与高低收保持一致。
- 费舍尔变换在滚动极值附近更敏感，应结合独立样本、交易成本和稳健性检验使用。
