# 四个趋势拐点与波动确认因子说明

> 对应实现：`Factor/libraries/technical_lib.py`
>
> 本文档说明科波克曲线、真实强度指数、相对波动指数和涡旋指标差的当前实现口径。四项因子均返回“日期 × 标的”的 `pandas.DataFrame`，只使用当期及历史行情，不使用未来数据。

## 1. 科波克曲线（Coppock Curve）

### 用途

结合两段中期收益率并进行线性加权平滑，用于观察中长期趋势拐点和动量方向。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `coppock_curve` |
| 默认参数 | `short=11`、`long=14`、`smooth=10` |
| 字段依赖 | `close` |

### 公式

```text
ROC(n) = (Close / Close[n] - 1) × 100
Coppock Curve = WMA(ROC(short) + ROC(long), smooth)
```

实现使用线性权重 `1, 2, ..., smooth`，越近的数据权重越高。值在零线上方表示两段收益率合计为正的趋势背景。

## 2. 真实强度指数（True Strength Index，TSI）

### 用途

通过双重 EMA 平滑价格动量和绝对价格动量，降低短期噪声后衡量趋势方向与强度。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `true_strength_index` |
| 默认参数 | `long=25`、`short=13` |
| 字段依赖 | `close` |

### 公式

```text
Momentum = Close - PrevClose
TSI = 100 × EMA(EMA(Momentum, long), short)
            / EMA(EMA(|Momentum|, long), short)
```

TSI 通常围绕零线波动；正值表示平滑后的上涨动量占优，负值表示下跌动量占优。

## 3. 相对波动指数（Relative Volatility Index，RVI）

### 用途

将滚动波动率按价格上涨和下跌方向分组，形成类似 RSI 的 0–100 振荡值，用于确认波动方向。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `relative_volatility_index` |
| 默认参数 | `window=10`、`smooth=14` |
| 字段依赖 | `close` |

### 公式

```text
Volatility = RollingStd(Close, window)
UpVolatility = Volatility，若 Close > PrevClose，否则 0
DownVolatility = Volatility，若 Close < PrevClose，否则 0
RVI = 100 × EMA(UpVolatility, smooth)
            / (EMA(UpVolatility, smooth) + EMA(DownVolatility, smooth))
```

较高读数表示上涨方向的波动贡献更大，较低读数表示下跌方向的波动贡献更大。当前实现使用收盘价滚动标准差这一明确口径，便于在因子库中复算。

## 4. 涡旋指标差（Vortex Indicator Spread）

### 用途

比较滚动上行与下行涡旋运动，刻画趋势方向和潜在趋势反转。正值表示上行涡旋线占优，负值表示下行涡旋线占优。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `vortex_indicator` |
| 默认参数 | `window=14` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
TR = max(High - Low, |High - PrevClose|, |Low - PrevClose|)
VM+ = |High - PrevLow|
VM- = |Low - PrevHigh|
VI+ = Sum(VM+, n) / Sum(TR, n)
VI- = Sum(VM-, n) / Sum(TR, n)
Vortex Indicator = VI+ - VI-
```

标准涡旋指标通常绘制 `VI+` 和 `VI-` 两条线；因子库需要单一宽表输出，因此当前实现返回二者的差值。

## 使用边界

- 四个因子是研究信号，不构成交易指令或收益承诺。
- 滚动窗口和 EMA 的前置样本不足时会产生缺失值；回测前应统一处理缺失值、停牌、涨跌停和股票池。
- 科波克曲线与 TSI 对窗口较敏感，RVI 与涡旋指标应结合价格趋势、成交量和交易成本做独立样本检验。
- 复权口径、成交量单位和交易日历需要在同一研究样本内保持一致。
