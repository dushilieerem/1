# 四个趋势质量与路径风险因子说明

> 批次日期：2026-08-14
>
> 对应实现：`Factor/libraries/technical_lib.py` 的 `TechnicalLib`。
>
> 本批次新增 4 个只使用收盘价的日频因子，重点补充“趋势是否有方向、趋势是否稳定、下行回撤是否持续”三类研究信息。所有因子均返回“日期 × 标的”的 `pandas.DataFrame`，不使用未来数据。

## 1. 批次目标与因子总览

现有因子库已经覆盖均线、振荡器、经典波动率和量价关系。本批次不再增加另一组相似的方向指标，而是引入路径效率、回归质量和下行风险三个互补维度，服务于趋势筛选、信号过滤和风险分层。

| 因子名 | 类别 | 输入字段 | 默认窗口 | 主要回答的问题 |
|---|---|---|---:|---|
| `kaufman_efficiency_ratio` | 趋势质量 / 路径效率 | `close` | 10 | 价格移动是否沿着单一方向前进？ |
| `normalized_linear_regression_slope` | 趋势方向 / 相对速度 | `close` | 20 | 价格趋势方向和相对斜率是多少？ |
| `regression_r_squared` | 趋势质量 / 稳定性 | `close` | 20 | 价格是否稳定贴合一条线性趋势？ |
| `ulcer_index` | 下行风险 / 回撤路径 | `close` | 14 | 回撤的深度和持续性有多大？ |

参数边界统一为 `window >= 2` 的整数；不满足时实现抛出 `ValueError`。滚动窗口采用完整窗口语义，不用静默填充值补齐缺失样本。

## 2. Kaufman 路径效率

### 定义与经济直觉

`kaufman_efficiency_ratio` 衡量“净位移”相对于“实际路径长度”的比例。价格持续单向移动时，净位移接近路径长度，因子接近 1；价格来回震荡时，路径很长但净位移较小，因子接近 0。它只取 Kaufman Efficiency Ratio（ER），不包含 KAMA 的自适应均线递推部分。

### 数学公式

```text
ER_t = |Close_t - Close_{t-n}|
       / (Σ_{i=0}^{n-1} |Close_{t-i} - Close_{t-i-1}| + ε)

ε = 1e-10
```

### 实现参数与返回值

- 默认 `window=10`；允许覆盖为不小于 2 的整数。
- 返回范围按实现裁剪为 `[0, 1]`；完整平坦窗口返回 0。
- 直接字段：`close`。
- 默认预热期为前 `window` 个交易日；缺失数据导致窗口不完整时返回 NaN。

### 使用建议与局限

适合用作趋势信号的质量过滤器，例如只在 ER 较高时采用方向性信号。ER 不提供涨跌方向，也不区分上涨趋势和下跌趋势；价格跳跃、复权切换和停牌会显著改变路径长度。不要把 ER 直接解释为收益预测概率。

## 3. 归一化滚动线性回归斜率

### 定义与经济直觉

`normalized_linear_regression_slope` 在长度为 `n` 的滚动窗口内对收盘价做普通最小二乘线性回归，并将斜率除以滚动均价绝对值。归一化后，不同价格水平的标的更容易进行横截面比较。正值代表上行斜率，负值代表下行斜率，绝对值越大表示相对价格变化越快。

该因子是 SVQuant 的自研定义：标准线性回归斜率通常保留价格单位，本实现为了因子横截面使用增加了“除以滚动均价”的归一化约定。

### 数学公式

```text
x_i = i, i = 0, ..., n-1
b_t = Σ[(x_i - x̄)(Close_i - Closē)] / Σ[(x_i - x̄)^2]
NormalizedSlope_t = b_t / (|Closē| + ε)
```

### 实现参数与返回值

- 返回值无固定上下界，量纲近似为“每日相对价格变化”；平坦价格返回 0。
- 直接字段：`close`；内部使用滚动 `numpy.dot` 完成加权求和。
- 默认 `window=20`；允许覆盖为不小于 2 的整数。
- 首个完整回归窗口在第 `window` 个观测（位置 `window - 1`）出现；窗口内存在缺失值时返回 NaN。

### 使用建议与局限

可用于排序趋势方向、构造趋势强度或与 R² 组合过滤弱趋势。它对窗口长度和价格复权口径敏感；极低价格或异常价格会放大归一化结果。该实现不含截面去极值、中性化和年化处理，研究前应自行决定这些步骤。

## 4. 滚动线性回归拟合优度 R²

### 定义与经济直觉

`regression_r_squared` 使用与上一因子相同的滚动线性回归，返回价格变化被线性趋势解释的程度。R² 越接近 1，说明价格路径越贴近一条直线；越接近 0，说明线性趋势解释力弱。R² 不提供方向，所以需要与回归斜率或收益因子配合。

### 数学公式

```text
SST_t = Σ(Close_i - Closē)^2
SSR_t = b_t^2 × Σ(x_i - x̄)^2
R²_t = SSR_t / (SST_t + ε)
```

实现将结果裁剪在 `[0, 1]`；完整平坦窗口定义为 0，预热期仍保留 NaN。

### 实现参数与返回值

- 返回范围 `[0, 1]`。
- 直接字段：`close`。
- 默认 `window=20`；允许覆盖为不小于 2 的整数。
- 首个完整回归窗口在第 `window` 个观测（位置 `window - 1`）出现；缺失或窗口不足返回 NaN。

### 使用建议与局限

R² 适合作为趋势信号的置信度或状态过滤器，例如要求 R² 达到阈值后才使用斜率方向。高 R² 只说明线性拟合稳定，不说明未来仍延续，也不代表收益为正；强烈的非线性趋势可能得到不高的 R²。

## 5. Ulcer Index（痛苦指数）

### 定义与经济直觉

`ulcer_index` 只关注从近期高点回撤的下行风险，并同时考虑回撤深度和持续时间。回撤越深、恢复越慢，因子越大；价格持续创新高时因子接近 0。它与标准差不同，不会因为向上波动本身增加风险读数。

### 数学公式

```text
M_t = max(Close_{t-n+1}, ..., Close_t)
D_t = 100 × (Close_t - M_t) / (|M_t| + ε)
UI_t = sqrt(mean(D_{t-n+1}^2, ..., D_t^2))
```

### 实现参数与返回值

- 默认 `window=14`；允许覆盖为不小于 2 的整数。
- 返回范围 `[0, +∞)`，单位是百分比点；无回撤时为 0。
- 直接字段：`close`。
- 需要先形成滚动高点，再形成回撤平方的滚动均值，默认预热期为 `2 × window - 2` 个交易日。

### 使用建议与局限

可用于剔除回撤路径过差的标的、构造下行风险分层，或与收益率结合进行风险调整比较。窗口高点只使用当期及历史收盘价；该因子不考虑成交量、流动性、涨跌停和组合层面的相关性，也不应单独作为止损或交易指令。

## 6. 来源说明

- Kaufman ER：参考 StockCharts 对 KAMA 中 Efficiency Ratio 的说明，尤其是 ER 衡量净价格变化相对每日波动路径的效率；本库只实现 ER，不实现 KAMA 平滑常数和递推均线。<https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/kaufmans-adaptive-moving-average-kama>
- 滚动线性回归 R²：参考 StockCharts 对 Linear Regression R2 的指标定义，R² 在 0 到 1 之间衡量线性趋势强度；本库的 `normalized_linear_regression_slope` 在此类滚动回归基础上增加了价格均价归一化，属于自研工程口径。<https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/linear-regression-r2>
- Ulcer Index：参考 StockCharts 对百分比回撤、回撤平方均值和平方根计算的说明。<https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/ulcer-index>
- `normalized_linear_regression_slope` 的归一化分母、参数校验、NaN 预热语义和 `1e-10` 数值保护均为 SVQuant 自研定义，不宣称与任何第三方平台逐值一致。

## 8. 组合使用提示

- ER 判断路径是否有方向，回归斜率提供方向和速度，R² 评估线性趋势稳定性，Ulcer Index 补充下行回撤风险；四者可以组合成“方向 × 质量 × 风险”的研究筛选框架。
- ER、回归斜率和 R² 在单边趋势中可能高度相关；加入同一组合前应查看相关性矩阵，避免把同一价格路径重复计权。
- Ulcer Index 与波动率并不等价；它偏向下行回撤，可能与下行波动率、最大回撤等现有因子共线。
- 使用时应统一复权价格、交易日历、停牌处理和收益确认区间，明确去极值、标准化和交易成本假设。
- 这些因子是研究信号，不承诺收益、风险或跨市场逐值一致性；最终结论应通过独立样本和真实数据回测验证。
