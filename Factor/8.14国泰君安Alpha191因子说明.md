# 国泰君安 Alpha191 因子库迁移说明

> 批次：2026-08-14
> 实现：`Factor/libraries/gtja_alpha191.py`
> 索引：`Factor/libraries/index.yaml`

## 1. 批次目标

将公开的国泰君安 Alpha191 公式迁移为 SVQuant 原生 `FactorLibrary`，让研究员可以
通过 `gtja_alpha191` 库按 `alpha191_001`–`alpha191_191` 枚举和回测。实现不调用聚宽
SDK/API，不保存或分发第三方因子值。

## 2. 因子总览

| 范围 | 主题 | 典型输入 |
|---|---|---|
| 001–024 | 短周期量价、收益、平滑与波动 | OHLCV、VWAP |
| 025–048 | 动量/反转、成交量确认、区间位置 | OHLCV、VWAP |
| 049–072 | 真实波幅、资金流、趋势与相对强弱 | OHLCV、amount、VWAP |
| 073–101 | 长周期量价、行业/基准相对信号 | OHLCV、amount、VWAP |
| 102–128 | 量能、价格位置、回归与资金流 | OHLCV、amount、VWAP |
| 129–153 | 下行波动、均线、回归、基准过滤 | OHLCV、amount、VWAP、基准 |
| 154–176 | 趋势平滑、方向运动、波动率 | OHLCV、amount、VWAP |
| 177–191 | 高低点、趋势、基准相对强弱 | OHLCV、amount、VWAP、基准 |

完整公开调用名为：

```text
alpha191_001 … alpha191_191
```

每个调用名对应源码中的同编号方法，方法 docstring 显示“国泰君安 Alpha191 #NNN”。
固定窗口按照公式执行；带小数的窗口向下取整。SMA 使用递推平滑
`Y[t] = (M * X[t] + (N-M) * Y[t-1]) / N`。

## 3. 统一数据契约

必需字段：`open`、`high`、`low`、`close`、`volume`，均为日期×标的宽表。

可选字段与回退顺序：

- `amount`：优先使用；缺失时按 `close * volume` 近似。
- `vwap`：优先使用；缺失时按 `amount / volume`，再缺失时按
  `(high + low + close) / 3`。
- `benchmark_close`、`benchmark_open`：优先使用；其次尝试 CSI300 指数；均缺失时
  使用全股票等权均值作为明确的研究代理。

所有除法对零分母返回 `NaN`；滚动统计保留缺失值，不以零值掩盖预热期。输出始终
与 `close` 的索引和列对齐，结果中的无穷值会转换为缺失值。

## 4. 代表公式说明

### Alpha191 #001：成交量变化与日内收益秩相关

`-CORR(RANK(DELTA(LOG(VOLUME),1)), RANK((CLOSE-OPEN)/OPEN), 6)`。
负值表示成交量变化与日内收益排名的正相关更强。需要 6 日相关窗口和 OHLCV。

### Alpha191 #002：区间位置变化

`-DELTA(((CLOSE-LOW)-(HIGH-CLOSE))/(HIGH-LOW), 1)`。
高低价相等时该位置返回缺失，避免除零。

### Alpha191 #041：VWAP 短期极值反转

`-RANK(TSMAX(DELTA(VWAP,3),5))`。VWAP 按统一回退规则得到。

### Alpha191 #149：下跌基准日回归斜率

`REGBETA(FILTER(stock_return, benchmark_down), FILTER(benchmark_return, benchmark_down), 252)`。
过滤日按有效配对观测计算滚动回归；没有基准字段时使用等权市场代理，不能宣称与
第三方平台逐值一致。

### Alpha191 #190：收益偏离阈值的对数比率

使用 20 日计数和条件平方误差构造正比率后取对数；非正比率返回缺失。

其余因子按同一编号的公开公式实现，包含 `RANK`、`TSRANK`、`SUM`、`STD`、`CORR`、
`COV`、`DECAYLINEAR`、`SMA`、`REGBETA`、`LOWDAY` 和 `HIGHDAY` 等算子。

## 5. 已知边界与使用建议

- Alpha030 的原始公式依赖 Fama-French 市场因子；当前平台没有该字段，返回全缺失值，
  但仍保留可发现的方法以维持 191 项编号完整性。
- Alpha075、149、181、182 会使用基准代理；正式研究应提供同口径的指数行情并记录
  证券池、复权和交易日历。
- 公式迁移验证的是计算口径和可复算性，不代表 IC、收益或交易有效性。
- 大窗口因子（例如 149、181、184）需要足够的历史预热数据；回测应遵循
  `ADR-018` 的“先完整计算、再裁剪收益区间”约定。

## 7. 组合使用提示

191 个因子覆盖大量相同的 OHLCV 信息，短窗口动量、区间位置和成交量类因子之间可能
高度相关。组合回测前应做缺失率、截面标准化、相关性和换手检查；不要把未验证的
代理基准结果与同源供应商值混合比较，也不要根据单个因子直接形成投资建议。
