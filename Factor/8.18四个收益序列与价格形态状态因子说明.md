# 四个收益序列与价格形态状态因子说明

> 批次日期：2026-08-18
>
> 本批次新增 4 个自研定义的日频 OHLCV 因子，分别观察收益延续/反转、上涨下跌贡献不对称、K 线影线压力和隔夜跳空在真实波动中的占比。所有因子返回“日期 × 标的”的 `pandas.DataFrame`，只使用当前及历史数据，不使用未来数据。

## 1. 批次目标与因子总览

最近几批因子已经覆盖均线、振荡器、趋势拟合、波动扩张、日内方向和成交额冲击。本批次继续放在 `technical_lib`，但不重复增加同类指标：

- 用收益自相关补充“收益序列是否延续或反转”的时间依赖；
- 用收益非对称性区分上涨收益和下跌损失的贡献结构；
- 用影线压力保留单日 OHLC 形态中的反转信息；
- 用跳空占比拆分总波动中的隔夜与日内来源。

| 因子名 | 类别 | 输入字段 | 默认参数 | 主要回答的问题 |
|---|---|---|---|---|
| `return_autocorrelation` | 收益序列 | `close` | `window=20, lag=1` | 短期收益更偏延续还是反转？ |
| `gain_loss_asymmetry` | 收益分布 | `close` | `window=20` | 上涨与下跌收益贡献是否对称？ |
| `wick_reversal_pressure` | 价格形态 | `open/high/low/close` | `window=10` | K 线的上下影线哪一侧更占优？ |
| `overnight_gap_share` | 日内结构 | `open/high/low/close` | `window=20` | 总真实波动中有多少来自隔夜跳空？ |

## 2. `return_autocorrelation`

### 定义与经济直觉

先计算日收益 (r_t = close_t / close_{t-1} - 1)，再计算窗口内 (r_t) 与 (r_{t-lag}) 的相关系数。正值表示相邻收益方向更容易延续，负值表示更偏短期反转；它描述的是收益序列的时间依赖，不是收益大小或趋势斜率。

### 数学公式

令窗口长度为 (w)，滞后为 (l)，则：

\[
AC_t(l) = \frac{Cov(r_t, r_{t-l})}{\sqrt{Var(r_t)Var(r_{t-l})}}
\]

窗口内任一收益无效时不输出有效结果。分母低于数值阈值时视为零方差窗口并返回 0，避免把“没有可识别的相关关系”误报成无穷值。

### 实现参数与预热期

- `window`：不小于 2 的整数，默认 20。
- `lag`：不小于 1 且严格小于 `window` 的整数，默认 1。
- 默认首个有效位置为 `window + lag`（从 0 开始计数），需要同时形成当前收益和滞后收益的完整配对窗口。

### 返回范围、边界与缺失值

- 返回范围为 `[-1, 1]`。
- 收盘价为 0 导致的无穷收益会转成缺失值，随后由滚动窗口自然传播；不会用 0 填充缺失收益。
- 平坦收益窗口的方差为 0，因子返回 0；窗口不足、缺失值或非法参数分别保留缺失或抛出 `ValueError`。

### 使用建议与局限

可用于区分短期动量和短期反转状态，或作为趋势信号的 regime 过滤器。它对窗口长度、交易价格复权、涨跌停和离散报价敏感；自相关不代表未来收益方向，也不替代交易成本和容量分析。

## 3. `gain_loss_asymmetry`

### 定义与经济直觉

将窗口内正收益之和与负收益绝对值之和进行对数比较。正值表示上涨收益贡献较大，负值表示下跌损失贡献较大，使用对数后正负方向具有对称解释，避免简单比值在没有下跌日时无限放大。

### 数学公式

\[
G_t = \sum_{i=0}^{w-1} max(r_{t-i}, 0),\qquad
L_t = \sum_{i=0}^{w-1} max(-r_{t-i}, 0)
\]

\[
GLA_t = log\left(\frac{G_t + \epsilon}{L_t + \epsilon}\right),\qquad \epsilon=10^{-10}
\]

### 实现参数与预热期

- `window`：不小于 2 的整数，默认 20。
- 日收益的首个观测需要前收盘，因此默认首个有效位置为 `window`。
- 只对完整收益窗口求和；缺失收益会使受影响的滚动结果保持缺失。

### 返回范围、边界与缺失值

- 返回值没有固定上下界；完全平坦窗口返回 0。
- `epsilon` 只用于零收益贡献的对数保护，不会把缺失值变成有效收益。
- 只有上涨没有下跌时读数为较大的正数，只有下跌没有上涨时读数为较大的负数；应结合样本覆盖率解释。

### 使用建议与局限

可用于风险分层、收益路径筛选和上涨/下跌贡献的横截面对比。它与偏度、下行波动率和夏普类因子可能相关，不能单独解释尾部风险，也不代表未来收益必然延续。

## 4. `wick_reversal_pressure`

### 定义与经济直觉

对每根 K 线计算下影线与上影线的差，再除以当日高低价区间并滚动平均。较长的下影线通常表示盘中下探后被收回，读数偏正；较长的上影线表示冲高后被压回，读数偏负。因子保留连续强度，不把形态压缩成单一的 0/1 标签。

### 数学公式

\[
Upper_t = High_t - max(Open_t, Close_t)
\]

\[
Lower_t = min(Open_t, Close_t) - Low_t
\]

\[
WRP_t = Mean_w\left(\frac{Lower_t - Upper_t}{High_t - Low_t + \epsilon}\right)
\]

### 实现参数与预热期

- `window`：不小于 2 的整数，默认 10。
- 当前 OHLC 形态本身不需要前一日数据；默认首个有效位置为 `window - 1`。

### 返回范围、边界与缺失值

- 在合法 OHLC（`high >= max(open, close)` 且 `low <= min(open, close)`）下，返回范围为 `[-1, 1]`。
- 零高低价区间返回 0；非法价格区间和缺失 OHLC 保留缺失值。
- 影线长度会先按非负值处理，避免异常输入产生反向的影线贡献；异常数据仍应在数据质量层处理。

### 使用建议与局限

适合做日线反转压力、突破失败和趋势确认的辅助特征。它依赖开高低收复权口径，对集合竞价、涨跌停、停牌和极端行情敏感；长影线可能来自消息冲击或流动性不足，不能直接视作买卖信号。

## 5. `overnight_gap_share`

### 定义与经济直觉

隔夜跳空是前收盘到当日开盘的绝对价格变化。该因子将窗口内隔夜跳空绝对幅度之和除以真实区间之和，回答“观察期内的总价格活动有多少发生在收盘到开盘之间”。读数高表示隔夜风险来源更突出，读数低表示波动更多发生在日内。

### 数学公式

\[
Gap_t = |Open_t - Close_{t-1}|
\]

\[
TR_t = max(High_t-Low_t, |High_t-Close_{t-1}|, |Low_t-Close_{t-1}|)
\]

\[
OGS_t = clip\left(\frac{\sum_{i=0}^{w-1}Gap_{t-i}}
{\sum_{i=0}^{w-1}TR_{t-i}+\epsilon}, 0, 1\right)
\]

### 实现参数与预热期

- `window`：不小于 2 的整数，默认 20。
- 首个观测没有前收盘，默认首个有效位置为 `window`。
- 真实区间和跳空都必须形成完整窗口；缺失数据不会被静默填充。

### 返回范围、边界与缺失值

- 在合法日线 OHLC 下返回范围为 `[0, 1]`。
- 真实区间总和为 0 时返回 0；分母保护仅处理零区间，不改变缺失值语义。
- 由于 `high/low` 通常包含开盘价，合法数据下跳空占比不会超过 1；实现仍做边界裁剪以防异常输入破坏范围。

### 使用建议与局限

可用于区分隔夜驱动和日内驱动的波动状态，或作为开盘交易风险、事件风险和持仓隔夜暴露的过滤维度。它与 `overnight_gap_follow_through` 共享跳空信息，二者分别关注幅度占比和方向延续，不应视为独立信号；该因子不包含成交量、盘口或事件语义。

## 8. 组合使用提示

- `return_autocorrelation` 与 `gain_loss_asymmetry` 都基于收盘收益，组合前应检查与既有动量、偏度、下行波动率的相关性。
- `wick_reversal_pressure` 提供单日价格形态，适合与收益序列状态结合；不要把长影线直接解释为反转必然发生。
- `overnight_gap_share` 和 `overnight_gap_follow_through` 共享隔夜跳空来源，但一个关注波动来源占比，一个关注跳空后的方向确认，仍可能存在共线性。
- 四个因子的窗口不同，回测前应统一预热期、缺失处理、去极值和标准化口径，并在独立样本中加入交易成本、停牌、涨跌停和复权检查。
- 这些因子是研究信号，不构成交易指令、收益承诺或风险保证。
