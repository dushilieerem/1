# 8.19 四个波动结构与尾部风险因子说明

> 批次日期：2026-08-19
> 主题：波动规模、波动状态、日内/隔夜波动拆解与亏损尾部集中度
> 实现库：`Factor/libraries/volatility_lib.py` / `VolatilityLib`

## 1. 批次目标与因子总览

本批次补齐 `volatility_lib` 中对“波动有多大、当前处于什么状态、波动来自哪里、损失是否集中在少数极端日”的研究信号。4 个因子均使用历史及当日 OHLC 数据，不使用未来价格，不改变 `FactorLibrary`、`FactorLoader` 或回测 API 契约。

| 因子 | 类别 | 输入字段 | 默认参数 | 方向/范围 |
|---|---|---|---|---|
| `atr_percent` | 波动规模 | `high`、`low`、`close` | `window=14` | 非负；越高表示单位价格对应的真实波动越大 |
| `atr_percentile` | 波动状态 | `high`、`low`、`close` | `window=14`、`rank_window=60` | [0, 1]；越高表示当前波动处于更高历史分位 |
| `intraday_to_close_vol_ratio` | 波动来源 | `high`、`low`、`close` | `window=20` | 非负；越高表示日内区间相对收盘到收盘波动更突出 |
| `tail_loss_concentration` | 尾部风险 | `close` | `window=20`、`tail_fraction=0.2` | [0, 1]；越高表示总亏损更多集中在少数最差交易日 |

## 2. 共同实现约定

- 所有结果保持输入的日期索引和标的列，输出为 `日期 × 标的` 的 `pandas.DataFrame`。
- `window` 和 `rank_window` 必须是大于等于 2 的整数；`tail_fraction` 必须满足 `0 < tail_fraction <= 1`。
- 真实波幅第一天因缺少前收盘价而为空；滚动窗口默认要求完整有效观测，因此预热期会保留为空。
- 价格为零、非正或除数为零时返回缺失值，不用静默填充掩盖无效数据；无穷值会转为空值。
- 因子只描述风险和市场状态，不是买卖指令，也不承诺收益或风险结果。

## 3. `atr_percent`：归一化平均真实波幅

### 定义与经济直觉

使用真实波幅同时考虑当日高低区间和隔夜跳空，再除以收盘价绝对值，得到跨价格水平可比较的波动规模。相比单纯的收盘收益波动，它能保留日内高低价和跳空信息。

### 数学公式

```text
TR_t = max(H_t - L_t, |H_t - C_{t-1}|, |L_t - C_{t-1}|)
ATR_t = mean(TR_{t-window+1}, ..., TR_t)
atr_percent_t = ATR_t / |C_t|
```

### 参数与输出

- 默认 `window=14`，允许调用时覆盖。
- 输出理论上非负，没有固定上界；正常股票日频数据通常是较小比例。
- 第一条有效真实波幅需要前收盘，滚动 ATR 还需要 `window` 条有效真实波幅，因此首个有效位置约为输入第 `window` 行。

### 边界、缺失值与使用建议

- 高、低、收盘任一关键观测缺失时，涉及该观测的窗口保留缺失。
- 收盘价为零时不计算比值。
- 适合做波动规模排序、风险暴露控制或与收益信号做风险调整；跨股票比较前仍应检查复权和停牌处理。

### 局限

真实波幅把跳空和日内区间合并为一个尺度，无法单独判断波动是由消息跳空、盘中交易还是流动性不足造成的；它也不是隐含波动率估计。

## 4. `atr_percentile`：ATR 波动状态分位

### 定义与经济直觉

先计算 `atr_percent`，再观察当前值在最近 `rank_window` 个有效 ATR 观测中的百分位。它将绝对波动规模转换为相对自身历史的状态信号，便于识别波动扩张或收缩阶段。

### 数学公式

```text
x_t = atr_percent_t
atr_percentile_t = percentile_rank(x_{t-rank_window+1}, ..., x_t; x_t)
```

并列值使用中间秩，因而完全平坦的窗口返回 0.5，而不是人为判定为最高或最低状态。

### 参数与输出

- 默认 `window=14`、`rank_window=60`。
- 输出范围为 [0, 1]；值越大表示当前波动在自身历史中越高。
- 首个有效位置约为 `window + rank_window - 1` 行，具体仍取决于输入缺失情况。

### 边界、缺失值与使用建议

- ATR 预热或 rank 窗口不足时返回缺失值。
- 不对缺失观测做前向填充；缺失会使相关滚动窗口暂时无效。
- 可作为波动状态过滤器，与趋势或动量因子组合时区分“趋势信号发生在低波还是高波环境”。

### 局限

分位数是相对于单只股票自身历史的状态，不等价于全市场横截面分位；`rank_window` 较短时容易受个别极端事件影响。

## 5. `intraday_to_close_vol_ratio`：日内区间/收盘波动比

### 定义与经济直觉

比较同一窗口内的高低价对数区间波动和收盘到收盘对数收益波动。高比值表示价格在日内曾有较大摆动，但收盘变化相对有限，可能对应盘中震荡、消息消化或收盘回归。

### 数学公式

```text
range_vol_t = sqrt(mean(log(H / L)^2, window))
close_vol_t = std(log(C_t / C_{t-1}), window; ddof=0)
intraday_to_close_vol_ratio_t = range_vol_t / close_vol_t
```

### 参数与输出

- 默认 `window=20`。
- 输出非负，但没有固定上界。
- 收盘收益波动为零、价格非正或滚动观测不足时返回缺失值；不会将零分母转换成一个虚假的大数。

### 边界、缺失值与使用建议

- 高低价需为正值才能计算对数区间。
- 推荐与 `atr_percent` 配合：前者描述总波动规模，本因子描述日内区间相对收盘波动的结构。
- 使用前应确认 OHLC 是同一复权口径；高低价与收盘价口径不一致会扭曲比例。

### 局限

日线 OHLC 无法识别盘中路径和成交顺序；该因子也不区分买卖方向，不能单独解释波动对未来收益的影响。

## 6. `tail_loss_concentration`：尾部亏损集中度

### 定义与经济直觉

在收益窗口中提取负收益，将最差 `tail_fraction` 比例的负收益绝对值之和除以全部负收益绝对值之和。值越高，说明窗口内的总亏损更依赖少数极端下跌日，而不是均匀分布的连续小幅损失。

### 数学公式

```text
r_t = C_t / C_{t-1} - 1
L = {-r_t | r_t < 0}
k = max(1, ceil(len(L) × tail_fraction))
tail_loss_concentration = sum(largest_k(L)) / sum(L)
```

窗口内没有负收益时定义为 0。

### 参数与输出

- 默认 `window=20`、`tail_fraction=0.2`。
- 输出范围为 [0, 1]；接近 1 表示亏损集中在最差的少数观测，接近 0 表示没有明显负收益或亏损较分散。
- 需要 `window` 条有效收益观测；首个收益因缺少前收盘而为空。

### 边界、缺失值与使用建议

- `tail_fraction` 越小，信号越聚焦于极端损失，但样本噪声也越高。
- 价格无效或收益窗口含缺失时返回缺失；不把缺失当成零收益。
- 适合用于风险分层、组合约束和回撤归因；不应把低集中度误读为低总风险。

### 局限

该指标只看亏损在时间上的集中程度，不直接衡量亏损绝对大小；需要与波动规模、最大回撤或 CVaR 等指标联合分析。

## 7. 来源说明

本批次 4 个因子均为**自研定义**，没有复制第三方平台的名称或运行时实现。设计依据是 OHLC 真实波幅、滚动对数收益波动和负收益尾部统计这几类通用研究概念；代码中已明确写出计算公式、零分母保护和缺失值语义，因此不声明与任何第三方平台逐值一致。

## 9. 组合使用提示

- `atr_percent` 与 `atr_percentile` 都来自真实波幅，可能具有较高相关性；组合时可保留一个原始规模信号和一个状态信号，避免重复加权。
- `intraday_to_close_vol_ratio` 与 ATR 的信息互补：一个看波动总量，一个看日内/收盘波动结构，但二者仍可能受同一极端行情共同驱动。
- `tail_loss_concentration` 侧重损失形状，不代表总风险大小，适合与波动规模或回撤指标联合评估。
- 回测前应按项目统一流程处理复权、停牌、涨跌停、去极值、标准化和交易成本，并遵守 `ADR-018` 的完整历史预热语义。
- 以上信号仅用于研究和风险刻画，不构成投资建议或收益承诺。
