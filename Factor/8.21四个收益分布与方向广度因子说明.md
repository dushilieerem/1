# 8.21 四个收益分布与方向广度因子说明

> 本批次新增 4 个自研定义的收盘价收益因子，观察窗口内的上涨/下跌方向广度、收益尾部平衡、方向切换和极端波动出现频率。所有因子返回“日期 × 标的”的 `pandas.DataFrame`，只使用当前及历史收盘价，不使用未来数据。
>
> 实现位置：`ResearchEngine/app/assets/factors/libraries/technical_lib.py` / `TechnicalLib`

## 1. 批次目标与因子总览

本批次补充一组不依赖成交量和 OHLC 区间的收益分布信号。它们分别回答：

1. 最近一段时间上涨日是否多于下跌日；
2. 收益分布的上尾与下尾谁更占优势；
3. 收益方向是否频繁切换；
4. 大幅收益日是否经常出现。

| 因子 | 类别 | 输入字段 | 默认参数 | 返回范围 | 方向解释 |
|---|---|---|---|---|---|
| `up_down_frequency_imbalance` | 方向广度 | `close` | `window=20` | `[-1, 1]` | 越高表示上涨日数量相对更多 |
| `return_tail_balance` | 尾部结构 | `close` | `window=20`、`tail_fraction=0.2` | `[-1, 1]` | 越高表示上尾收益相对下尾更强 |
| `return_sign_flip_rate` | 路径状态 | `close` | `window=20` | `[0, 1]` | 越高表示相邻收益方向切换更频繁 |
| `return_shock_frequency` | 冲击状态 | `close` | `window=20`、`shock_multiple=2.0` | `[0, 1]` | 越高表示相对自身典型波动的冲击日更多 |

共同约定：

- 日收益定义为 `close.pct_change(fill_method=None)`；无穷值会转换为缺失值，不用静默填充值掩盖异常价格。
- `window` 必须为不小于 2 的整数；`return_tail_balance` 为保证两侧尾部有足够观测，要求 `window >= 4`。
- 滚动窗口默认要求完整有效样本；窗口不足、价格缺失或价格跳变导致的无效收益保留为 `NaN`。
- 首个价格没有可计算的日收益，因此无缺失数据时首次有效位置通常需要 `window` 个有效收益观测。

## 2. `up_down_frequency_imbalance`：涨跌频率失衡

### 定义与经济直觉

该因子只统计收益方向，不比较上涨和下跌的幅度。它用来区分“上涨日更常见”与“下跌日更常见”的路径广度，适合作为收益方向持续性的基础状态变量。

### 数学公式

令日收益为 (r_t)，方向得分为：

\[
s_t = \mathbf{1}(r_t > 0) - \mathbf{1}(r_t < 0)
\]

窗口 (W) 内的因子为：

\[
UDFI_t = \frac{\sum_{i=t-W+1}^{t}s_i}{\text{有效收益数量}}
\]

平盘日的方向得分为 0，但仍计入有效收益数量；因此结果稳定在 `[-1, 1]`。

### 实现参数与边界

- **默认参数**：`window: int = 20`。
- **字段依赖**：`close`。
- **预热期**：默认需要 20 个有效收益；在连续日线数据中通常从第 21 个价格观测开始有效。
- **异常行为**：无穷收益、缺失收益或完整窗口不足时返回缺失值；全窗口为平盘收益时返回 0。
- **方向解释**：接近 1 表示窗口内几乎都是上涨日，接近 -1 表示几乎都是下跌日。

```python
def up_down_frequency_imbalance(self, window: int = 20):
    returns = self.close.pct_change(fill_method=None).replace(
        [np.inf, -np.inf], np.nan
    )
    direction = (
        returns.gt(0).astype(float) - returns.lt(0).astype(float)
    ).where(returns.notna())
    numerator = direction.rolling(window).sum()
    valid_days = returns.notna().astype(float).rolling(window).sum()
    return (numerator / (valid_days + 1e-10)).clip(-1.0, 1.0)
```

## 3. `return_tail_balance`：收益尾部平衡

### 定义与经济直觉

该因子比较窗口内最大的一段收益和最小的一段收益，强调收益分布的尾部，而不是只看均值或标准差。它可用于识别“正向大波动占优”与“负向大波动占优”的状态。

### 数学公式

窗口内将收益从小到大排序，取两侧各 (n=\lceil W\times p\rceil) 个观测：

\[
L_t = \operatorname{mean}(\text{下尾收益}), \quad
H_t = \operatorname{mean}(\text{上尾收益})
\]

\[
RTB_t = \frac{H_t + L_t}{|H_t| + |L_t| + \epsilon}
\]

其中 `p=tail_fraction`，要求 `0 < p <= 0.5`。当两侧均接近 0 时返回 0。

### 实现参数与边界

- **默认参数**：`window: int = 20`、`tail_fraction: float = 0.2`。
- **参数边界**：`window >= 4`；`0 < tail_fraction <= 0.5`。
- **字段依赖**：`close`。
- **预热期**：需要一个完整的收益窗口；滚动排序只使用当前窗口及更早数据。
- **返回范围**：`[-1, 1]`。正值表示上尾均值相对更占优，负值表示下尾均值相对更占优。
- **已知局限**：尾部观测数随窗口和 `tail_fraction` 变化；短窗口下信号离散，不能与不同参数的结果直接视为同一量纲。

## 4. `return_sign_flip_rate`：收益变号率

### 定义与经济直觉

该因子统计相邻两日收益方向是否发生正负翻转，描述价格路径的“来回摆动”程度。高变号率表示趋势路径更容易被反向日打断，但它本身不判断下一日涨跌方向。

### 数学公式

令 (d_t=\operatorname{sign}(r_t))，相邻收益变号指示为：

\[
f_t = \mathbf{1}(d_t d_{t-1}<0)
\]

窗口内变号率为：

\[
RSFR_t = \frac{1}{W}\sum_{i=t-W+1}^{t}f_i
\]

零收益不被视为正负翻转；无法形成相邻有效收益的观测保留为缺失值。

### 实现参数与边界

- **默认参数**：`window: int = 20`。
- **字段依赖**：`close`。
- **预热期**：除完整窗口外还需要相邻收益，因此连续数据通常比其他本批次因子多一个价格观测的预热。
- **返回范围**：`[0, 1]`；0 表示窗口内没有正负方向切换，1 表示每个可比较的相邻收益都发生翻转。
- **已知局限**：该因子与收益自相关、短期反转等信号可能相关；组合使用前应做相关性检查。

## 5. `return_shock_frequency`：收益冲击频率

### 定义与经济直觉

该因子不使用固定的绝对收益阈值，而是在每个滚动窗口内以收益绝对值的中位数作为“典型波动”基准，再统计超过该基准若干倍的收益日比例。这样可以降低不同价格波动水平之间的不可比性。

### 数学公式

窗口内典型波动为：

\[
m_t = \operatorname{median}(|r_i|), \quad i\in[t-W+1,t]
\]

冲击指示和因子为：

\[
h_i = \mathbf{1}(|r_i| > k m_t), \quad
RSF_t = \frac{1}{W}\sum_{i=t-W+1}^{t}h_i
\]

当窗口内 (m_t) 接近 0 时，冲击频率定义为 0，避免零分母和无意义的无限值。

### 实现参数与边界

- **默认参数**：`window: int = 20`、`shock_multiple: float = 2.0`。
- **参数边界**：`window >= 2`；`shock_multiple` 必须是大于 0 的有限数。
- **字段依赖**：`close`。
- **预热期**：需要完整的有效收益窗口。
- **返回范围**：`[0, 1]`；值越高表示窗口内相对自身典型波动的较大收益日越多。
- **已知局限**：窗口内中位数会随极端值变化；该指标是状态描述，不应直接当作风险预测概率。

## 6. 来源说明

本批次 4 个因子均为“**自研定义**”，不是对某一篇论文、平台指标或第三方公式的逐字复刻。设计依据是将日收益的方向计数、尾部排序、相邻符号关系和滚动中位数基准组合成可解释的面板信号；公式、参数边界和异常处理以本说明及源码为准。

实现使用的通用滚动与收益变换接口可核验于 [pandas `DataFrame.rolling` 文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.rolling.html) 和 [pandas `DataFrame.pct_change` 文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.pct_change.html)。这些链接是工程 API 依据，不代表本批次因子具有文献结论或收益保证。

## 8. 组合使用提示

- `up_down_frequency_imbalance` 偏向方向广度，`return_tail_balance` 偏向收益分布两端，二者信息来源不同但可能在单边行情中同向。
- `return_sign_flip_rate` 描述路径是否来回切换，可能与 `technical_lib.return_autocorrelation` 和短期反转因子存在相关性。
- `return_shock_frequency` 描述冲击状态，可能与 `risk_indicators` 中的方差、偏度、峰度以及 `volatility_lib` 中的波动状态因子重叠。
- 回测前应统一预热期、缺失处理、去极值、标准化、复权口径和交易成本；组合相关性与分层单调性需要在独立样本中验证。
- 4 个因子都是研究信号，不构成交易指令，也不承诺收益或风险结果。
