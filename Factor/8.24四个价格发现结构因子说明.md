# 8.24 四个价格发现结构因子说明

> 本批次新增 4 个自研定义的 OHLCV 因子，观察收盘价相对成交量加权价格的位置、收盘在日内区间中的持续位置，以及真实区间与收益/成交量变化的协同关系。所有因子返回“日期 × 标的”的 `pandas.DataFrame`，只使用当前及历史数据，不读取未来行。
>
> 实现位置：`ResearchEngine/app/assets/factors/libraries/price_discovery_lib.py` / `PriceDiscoveryLib`

## 1. 批次目标与因子总览

现有因子库已经覆盖均线、振荡器、收益分布、成交量时序和波动率。本批次单独建立 `price_discovery_lib`，补充一组以“价格在交易区间中如何被成交确认”为核心的结构信号：

1. 收盘价是否偏离近期成交量加权的典型价格；
2. 收盘价是否持续落在日内区间的高位或低位；
3. 较大的真实区间是否更常伴随上涨或下跌收益；
4. 区间扩张是否与成交量变化同步。

| 因子 | 类别 | 输入字段 | 默认参数 | 返回范围 | 方向解释 |
|---|---|---|---|---|---|
| `volume_weighted_price_deviation` | 价格发现 | `high/low/close/volume` | `window=20` | 通常为小数比例，理论上不设固定上界 | 正值表示当前收盘高于窗口成交量加权典型价格 |
| `close_location_persistence` | 收盘位置 | `high/low/close` | `window=10` | `[-1, 1]` | 越高表示收盘更持续地靠近日内高位 |
| `range_return_alignment` | 区间方向协同 | `high/low/close` | `window=20` | `[-1, 1]` | 正值表示大区间更常与上涨收益同步 |
| `range_volume_alignment` | 区间成交确认 | `high/low/close/volume` | `window=20` | `[-1, 1]` | 正值表示区间扩张与成交量变化更同步 |

共同实现约定：

- 所有结果保持输入的日期索引和标的列；`window` 参数可以通过因子调用覆盖。
- 滚动运算采用完整窗口语义；窗口不足、必需字段缺失或无效值会保留为 `NaN`，不使用填充值制造早期信号。
- `volume` 中的负数和无穷值视为无效；零成交量不参与成交量加权价格计算。
- 除法使用 `1e-10` 数值保护。相关性窗口任一序列没有可识别方差时返回 0，表示该窗口无法给出方向协同，而不是人为推断涨跌。
- 真实区间使用当日高低价区间和前收盘跳空的最大值；首日没有前收盘时仍可使用当日高低价区间。

## 2. `volume_weighted_price_deviation`：成交量加权价格偏离

### 定义与经济直觉

该因子用成交量对典型价格加权，形成一个滚动的成交量加权典型价格基准，再观察当日收盘价相对该基准的比例偏离。它把“价格在什么位置”与“哪些日子的成交更活跃”结合起来：放量日形成的价格基准权重更高。

该因子只描述当前价格相对近期成交基准的位置，不等同于交易所逐笔成交口径的 VWAP，也不直接预测下一期收益。

### 数学公式

令典型价格为：

```text
TP_t = (high_t + low_t + close_t) / 3
```

窗口成交量加权典型价格为：

```text
VWTP_t = sum(TP_i × volume_i) / sum(volume_i)
```

因子为：

```text
VWPD_t = (close_t - VWTP_t) / (abs(VWTP_t) + ε)
```

其中 `i` 覆盖当前日及其之前的 `window - 1` 个观测，`ε=1e-10`。

### 参数、预热期与边界

- 默认 `window=20`，要求为不小于 2 的整数。
- 需要 `high`、`low`、`close` 和非负 `volume`。
- 连续有效数据下，首次有效位置通常为第 `window - 1` 行。
- 完整窗口成交量总和为 0 时没有可定义的成交量加权基准，结果返回 `NaN`；部分零成交量日可以参与窗口，但权重为 0。
- 结果没有固定理论上界；真实正价格数据下通常表现为比例偏离。价格接近 0 时应谨慎解释。

### 使用建议与局限

可与趋势或成交量确认因子结合，区分“价格远离近期活跃成交基准”和“价格变化得到成交参与”的状态。它与滚动均线偏离、VWAP 类特征以及成交量趋势可能相关；回测时应检查截面相关性和换手成本。

## 3. `close_location_persistence`：收盘区间位置持续性

### 定义与经济直觉

该因子先计算每日收盘价位于当日高低区间的位置，再取滚动均值。持续收在区间上沿，说明收盘压力偏向买方；持续收在区间下沿，说明卖方压力更强。与只比较收盘涨跌不同，它保留了日内高低价提供的路径信息。

### 数学公式

日内收盘位置为：

```text
CLV_t = (2 × close_t - high_t - low_t) / (high_t - low_t)
```

当 `high_t == low_t` 时，定义 `CLV_t=0`；单日位置限制在 `[-1, 1]`。窗口因子为：

```text
CLP_t = mean(CLV_i), i=t-window+1...t
```

### 参数、预热期与边界

- 默认 `window=10`，要求为不小于 2 的整数。
- 需要 `high`、`low` 和 `close`；高价低于低价的无效区间保留为缺失。
- 连续有效数据下，首次有效位置通常为第 `window - 1` 行。
- 零区间日不贡献方向，按 0 处理；缺失或无穷的价格不会被当作平盘日。
- 输出范围为 `[-1, 1]`；越接近 1 表示收盘更常靠近高位，越接近 -1 表示更常靠近低位。

### 使用建议与局限

适合用于识别趋势中的收盘确认和冲高回落/探底回升状态。它不区分区间内的成交量分布，也不能识别同一根日线内部的先后顺序；与影线、区间平衡和日内波动因子组合前应做去重。

## 4. `range_return_alignment`：区间收益协同

### 定义与经济直觉

该因子比较归一化真实区间与同期收盘收益的滚动相关性。它回答的不是“波动有多大”，而是“大区间更常出现在上涨日还是下跌日”：正值偏向上涨区间扩张，负值偏向下跌区间扩张。

### 数学公式

真实区间为：

```text
TR_t = max(
    high_t - low_t,
    abs(high_t - close_{t-1}),
    abs(low_t - close_{t-1})
)
```

归一化区间和收盘收益分别为：

```text
R_t = TR_t / (abs(close_t) + ε)
r_t = close_t / close_{t-1} - 1
```

因子为窗口相关性：

```text
RRA_t = corr(r_i, R_i), i=t-window+1...t
```

### 参数、预热期与边界

- 默认 `window=20`，要求为不小于 3 的整数。
- 需要 `high`、`low` 和 `close`；第一行收益因没有前收盘而为空。
- 连续有效数据下，首次有效位置通常为第 `window` 行，因此比只做价格区间滚动的因子多一个观测预热。
- 任一序列在窗口内方差接近 0 时返回 0；输出范围为 `[-1, 1]`。
- 相关性是同期结构描述，不包含未来收益，也不代表正值必然带来正向预测能力。

### 使用建议与局限

可与 `close_location_persistence` 区分“区间扩张的方向”和“收盘在区间中的位置”。它对极端收益、价格跳空和短窗口比较敏感，不同窗口的结果不应直接当作同一尺度。

## 5. `range_volume_alignment`：区间成交量协同

### 定义与经济直觉

该因子把真实区间与 `log(1+volume)` 的日变化做滚动相关性，观察区间扩张是否得到成交活跃度变化的同步确认。使用对数变化是为了降低极大成交量对相关性计算的支配，同时允许零成交量安全参与对数变换。

### 数学公式

```text
R_t = TR_t / (abs(close_t) + ε)
g_t = log(1 + volume_t) - log(1 + volume_{t-1})
RVA_t = corr(R_i, g_i), i=t-window+1...t
```

### 参数、预热期与边界

- 默认 `window=20`，要求为不小于 3 的整数。
- 需要 `high`、`low`、`close` 和非负 `volume`。
- 首个成交量变化因没有前一日成交量而为空；连续有效数据下首次有效位置通常为第 `window` 行。
- 成交量变化或区间在窗口内没有方差时返回 0；输出范围为 `[-1, 1]`。
- 负成交量、无穷成交量和缺失字段会使相关窗口失效并返回 `NaN`；零成交量可参与 `log1p`，不被当作缺失。

### 使用建议与局限

该因子适合做区间突破的成交确认或市场状态过滤，但它不区分主动买卖方向，也不替代成交额、盘口或逐笔数据。与 `volume_price_corr`、`volume_return_lead_lag` 等量价因子可能存在相关性。

## 6. 来源说明

本批次 4 个因子均为“**SVQuant 自研定义**”，不是对某一篇论文、平台指标或第三方同名公式的逐字复刻。设计依据是将 OHLCV 面板中的典型价格、收盘区间位置、真实区间、收益和成交量变化组合成可解释的价格发现结构信号；精确公式、参数边界和异常处理以本说明及源码为准。

工程计算使用的通用 API 可核验于 [pandas `DataFrame.rolling` 文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.rolling.html)、[pandas `DataFrame.pct_change` 文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.pct_change.html) 和 [NumPy `log1p` 文档](https://numpy.org/doc/stable/reference/generated/numpy.log1p.html)。这些链接用于说明计算接口，不代表本批次因子具有文献有效性或收益保证。

## 8. 组合使用提示

- `volume_weighted_price_deviation` 给出价格相对活跃成交基准的位置，`close_location_persistence` 给出收盘在日内区间中的持续方向，二者都可能在单边行情中偏高，组合前应检查相关性。
- `range_return_alignment` 关注区间扩张的收益方向，`range_volume_alignment` 关注区间扩张是否伴随成交活跃度变化，二者是方向与成交确认的互补描述，但都可能受事件日驱动。
- 与已有 `technical_lib` 的 `directional_range_balance`、`wick_reversal_pressure`、`volume_impact_score` 及 `trading_lib` 的量价因子组合时，应统一预热期、缺失处理、去极值、标准化和交易成本假设。
- 这些因子都是研究信号，不构成交易指令，不承诺收益、预测能力或风险结果；实际有效性需要在独立样本、成本与可交易性约束下验证。
