# 8.25 四个收益路径与市场状态因子说明

> 本批次新增 4 个自研定义的收盘价因子，从收益方向不确定性、波动聚集、回撤恢复和横截面分化描述市场状态。所有因子返回“日期 × 标的”的 `pandas.DataFrame`，只使用当前及历史数据，不读取未来行。
>
> 实现位置：`ResearchEngine/app/assets/factors/libraries/market_state_lib.py` / `MarketStateLib`

## 1. 批次目标与因子总览

昨天的价格发现批次关注日内区间和成交确认；本批次改用 `close` 的收益路径与截面结构，补充更适合做市场状态过滤、风险分组和组合条件控制的信号。

| 因子 | 类别 | 输入字段 | 默认参数 | 返回范围 | 方向解释 |
|---|---|---|---|---|---|
| `return_sign_entropy` | 收益路径 | `close` | `window=20` | `[0, 1]` | 越高表示上涨、下跌和平盘状态越分散，方向越不确定 |
| `volatility_clustering` | 波动状态 | `close` | `window=20, lag=1` | `[-1, 1]` | 正值表示大波动更容易跟随大波动，负值表示交替性更强 |
| `drawdown_recovery_fraction` | 回撤状态 | `close` | `window=60` | `[0, 1]` | 越高表示相对窗口内最深回撤已经恢复得越充分 |
| `cross_sectional_return_dispersion` | 市场状态 | `close` | `window=20` | `≥0` | 越高表示当期个股收益分化越强，结果在当日各标的间相同 |

共同实现约定：

- 结果保持输入的日期索引和标的列；窗口不足时保留为 `NaN`，不使用填充值制造早期信号。
- `close.pct_change(fill_method=None)` 只使用当前和前一交易日；无穷收益会转为 `NaN`。
- 价格缺失会使相关滚动窗口或回撤窗口失效；截面离散度在当日仍至少有 2 个有效标的时可以继续计算。
- 所有相关性使用 `1e-10` 数值保护；方差不可识别时返回 0，表示该窗口没有可区分的线性方向。

## 2. `return_sign_entropy`：收益符号熵

### 定义与经济直觉

该因子把每日收益离散为上涨、下跌和平盘三种状态，并计算窗口内状态分布的归一化 Shannon 熵。低熵表示方向状态集中，例如持续上涨或持续下跌；高熵表示三类状态更均衡，市场方向更不明确。

它描述的是收益路径的状态不确定性，不等同于收益波动率，也不把熵高低解释为看多或看空。

### 数学公式

令 `s_t` 为收益符号：

```text
r_t = close_t / close_{t-1} - 1
s_t ∈ {+1, 0, -1}
```

窗口内三种状态的频率为 `p_+`、`p_0`、`p_-`，因子为：

```text
H_t = -(p_+ log(p_+) + p_0 log(p_0) + p_- log(p_-)) / log(3)
```

概率为 0 的项按 0 处理，因此输出理论范围为 `[0, 1]`。

### 参数、预热期与边界

- 默认 `window=20`，要求为不小于 3 的整数。
- 首个收益因没有前收盘而为空；连续有效数据下，首次有效因子通常在第 `window` 个收益观测完成后出现。
- 窗口内存在缺失收益时，滚动频率不满足完整窗口，结果保留为 `NaN`。
- 全部收益同号或全为平盘时，熵为 0；三类状态接近均衡时，熵接近 1。

### 使用建议与局限

可作为趋势信号的置信度或市场状态过滤器，与动量方向因子联合使用；熵高只说明方向更混杂，不说明未来收益一定更低，也可能包含停牌、价格精度和微小收益阈值口径影响。

## 3. `volatility_clustering`：波动聚集

### 定义与经济直觉

该因子计算平方收益与其滞后收益平方的滚动相关性。正值表示高波动和低波动具有延续性，负值表示波动状态更容易交替；它刻画波动的时间依赖，而不是单纯衡量波动大小。

### 数学公式

```text
r_t = close_t / close_{t-1} - 1
q_t = r_t²
VC_t = corr(q_t, q_{t-lag})
```

相关性在最近 `window` 个有效配对上计算，输出裁剪到 `[-1, 1]`。

### 参数、预热期与边界

- 默认 `window=20`、`lag=1`；`window` 要求不小于 4，`lag` 要求为正整数且小于 `window`。
- 由于收益和滞后配对各需要预热，连续有效数据下首次有效位置通常约为第 `window + lag` 个索引位置。
- 平方收益没有可识别方差时返回 0；缺失值或无穷收益会使对应滚动窗口保留为 `NaN`。
- 输出无量纲；正值不是收益方向，不能直接作为多空方向解释。

### 使用建议与局限

适合和波动率水平、回撤或交易成本模型组合，用于区分“风险正在持续”与“风险正在切换”的环境。短窗口对单个极端收益敏感，跨资产比较时应统一收益和交易日口径。

## 4. `drawdown_recovery_fraction`：回撤恢复分数

### 定义与经济直觉

因子在每个滚动窗口内先维护只到当前日为止的运行峰值，再找到该路径中最深的峰谷回撤，最后衡量当前价格从该回撤低点向回撤前峰值恢复了多少。它区分“仍处于深度回撤”和“已经从深度回撤中修复”。

### 数学公式

对窗口价格路径 `P_1 ... P_n`：

```text
Peak_i = max(P_1, ..., P_i)
DD_i = P_i / Peak_i - 1
k = argmin(DD_i)
Recovery_t = clip((P_n - P_k) / (Peak_k - P_k), 0, 1)
```

如果窗口没有负回撤，定义恢复分数为 1。

### 参数、预热期与边界

- 默认 `window=60`，要求为不小于 4 的整数。
- 首次有效位置通常为第 `window - 1` 行；实现使用窗口内的历史路径，不访问窗口之后的数据。
- 窗口内价格缺失、无穷或非正时结果为 `NaN`；回撤区间接近 0 时定义为完全恢复 1，避免除零。
- 输出裁剪到 `[0, 1]`；超过回撤前峰值的价格按完全恢复处理。

### 使用建议与局限

可作为风险状态或持仓恢复过滤器，与最大回撤、趋势方向和流动性条件联合使用。窗口滚动会使历史最深回撤随样本移出而改变，因此不同窗口的分数不应直接混用。

## 5. `cross_sectional_return_dispersion`：截面收益离散度

### 定义与经济直觉

该因子先在每个交易日计算有效标的收益的横截面标准差，再取时间滚动均值，并把当天的市场状态值广播到所有标的。它衡量的是个股之间的收益分化程度，而不是某一只股票自身的波动。

### 数学公式

```text
r_{i,t} = close_{i,t} / close_{i,t-1} - 1
D_t = std_i(r_{i,t}),  ddof=0
CSD_t = mean(D_{t-window+1}, ..., D_t)
```

当日有效收益标的数少于 2 时，`D_t` 为缺失；最终的 `CSD_t` 按日期复制到输入的每一列。

### 参数、预热期与边界

- 默认 `window=20`，要求为不小于 3 的整数。
- 首个收益日没有有效收益；连续有效数据下首次有效位置通常为第 `window` 行。
- 截面缺少单个标的不必然使当天失效，只要仍有至少 2 个有效收益；若整个滚动窗口存在无效的日度离散度，结果保留为 `NaN`。
- 输出非负；它是市场状态因子，不适合作为单独的个股横截面排序信号。

### 使用建议与局限

适合做市场分化、行业轮动或组合集中度的条件变量。由于各标的当天共享同一数值，它不提供个股之间的相对排序；股票池变更、极端涨跌停和缺失处理会直接影响截面标准差。

## 6. 来源说明

本批次 4 个因子均为“**SVQuant 自研定义**”，不是对某一篇论文、平台指标或第三方同名公式的逐字复刻。设计依据是把标准 OHLCV 面板中的收盘收益路径与横截面统计组合成可解释的市场状态特征；精确公式、参数边界和异常处理以本说明及源码为准。

工程计算使用的通用 API 可核验于 [pandas `DataFrame.pct_change`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.pct_change.html)、[pandas `DataFrame.rolling`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.rolling.html)、[pandas `DataFrame.std`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.std.html) 和 [NumPy `maximum.accumulate`](https://numpy.org/doc/stable/reference/generated/numpy.maximum.accumulate.html)。这些链接用于说明计算接口，不代表本批次因子具有文献有效性或收益保证。

## 8. 组合使用提示

- `return_sign_entropy` 和 `volatility_clustering` 都描述收益路径，但前者关注方向状态的不确定性，后者关注波动幅度的时间依赖，组合前应检查窗口相关性。
- `drawdown_recovery_fraction` 提供价格路径的恢复阶段，`cross_sectional_return_dispersion` 提供市场横截面分化，适合作为个股信号的环境过滤器，而非替代个股排序。
- 与昨天的 `price_discovery_lib` 组合时，应检查收盘路径、区间量价和市场状态之间的相关性，统一预热期、去极值、标准化和交易成本假设。
- 这些因子都是研究信号，不构成交易指令，不承诺收益、预测能力或风险结果；实际有效性需要在独立样本、成本与可交易性约束下验证。
