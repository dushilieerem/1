# 四个经典技术因子说明

> 对应实现：`Factor/libraries/technical_lib.py` 与 `Factor/libraries/trading_lib.py`
>
> 本文档用于说明 CCI、Williams %R、OBV 和 Chaikin Money Flow（CMF）的当前实现口径。它们均返回“日期 × 标的”的 `pandas.DataFrame`，仅使用当期及历史行情，不使用未来数据。

## 1. CCI（商品通道指数）

### 用途

衡量典型价格相对其近期均值的偏离程度，可用于识别价格的强弱与超买超卖状态。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `cci` |
| 默认参数 | `window=20` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
TP = (High + Low + Close) / 3
CCI = (TP - MA(TP, n)) / (0.015 × MeanDeviation(TP, n))
```

其中 `MeanDeviation` 是窗口内典型价格相对于该窗口均值的平均绝对偏差。数值为正表示价格高于近期均值，数值为负表示价格低于近期均值。

## 2. Williams %R

### 用途

衡量收盘价处于近期最高价、最低价区间中的位置，是一个范围为约 `-100` 至 `0` 的动量振荡指标。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `williams_r` |
| 默认参数 | `window=14` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
Williams %R = -100 × (HH(n) - Close) / (HH(n) - LL(n))
```

其中 `HH(n)`、`LL(n)` 分别为最近 `n` 日的最高价和最低价。数值接近 `0` 表示收盘价接近近期高点，接近 `-100` 表示接近近期低点。

## 3. OBV（能量潮）

### 用途

按收盘价涨跌方向累计成交量，用于观察量能是否确认价格趋势。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `obv` |
| 默认参数 | 无 |
| 字段依赖 | `close`、`volume` |

### 公式

```text
收盘上涨：OBV(t) = OBV(t-1) + Volume(t)
收盘下跌：OBV(t) = OBV(t-1) - Volume(t)
收盘持平：OBV(t) = OBV(t-1)
```

当前实现以 `0` 作为起始值；因此应关注 OBV 的变化和趋势，而不是不同标的之间的绝对值横向比较。

## 4. Chaikin Money Flow（CMF，蔡金资金流）

### 用途

以收盘价在日内高低区间的位置为权重，对成交量进行滚动加权，反映累积与派发压力。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `chaikin_money_flow` |
| 默认参数 | `window=21` |
| 字段依赖 | `high`、`low`、`close`、`volume` |

### 公式

```text
MFM = ((Close - Low) - (High - Close)) / (High - Low)
CMF = Sum(MFM × Volume, n) / Sum(Volume, n)
```

CMF 为正表示窗口内收盘位置和成交量整体偏向累积，为负表示偏向派发；当 `High = Low` 时，当前实现以极小值保护分母，结果为 `0`。

## 使用边界

- 四个指标均为研究信号，不构成交易指令或收益承诺。
- 滚动窗口前置样本不足时会产生缺失值；回测前应统一处理缺失值、停牌、涨跌停与股票池。
- 需在独立样本中验证 IC、分层收益、交易成本和稳健性，避免只依据单一阈值触发交易。
- 指标依赖价格复权和成交量口径，跨数据源比较前应确认数据层口径一致。
