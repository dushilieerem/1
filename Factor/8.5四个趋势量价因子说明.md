# 四个趋势量价因子说明

> 对应实现：`Factor/libraries/technical_lib.py`
>
> 本文档说明正向方向指标（+DI）、负向方向指标（-DI）、平均趋向指标（ADX）和累积/派发线（A/D）的当前实现口径。所有因子均返回“日期 × 标的”的 `pandas.DataFrame`，仅使用当期及历史行情。

## 1. 正向方向指标（+DI）

### 用途

衡量窗口内上行方向运动相对于真实波幅的强度，用于识别上涨趋势的相对优势。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `positive_directional_index` |
| 默认参数 | `window=14` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
UpMove = High(t) - High(t-1)
DownMove = Low(t-1) - Low(t)

+DM = UpMove，若 UpMove > DownMove 且 UpMove > 0；否则为 0
TR = max(High - Low, |High - Previous Close|, |Low - Previous Close|)

+DI = 100 × WilderSmooth(+DM, n) / WilderSmooth(TR, n)
```

数值越高，表示近期向上方向运动相对真实波幅越强。

## 2. 负向方向指标（-DI）

### 用途

衡量窗口内下行方向运动相对于真实波幅的强度，用于识别下跌趋势的相对优势。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `negative_directional_index` |
| 默认参数 | `window=14` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
-DM = DownMove，若 DownMove > UpMove 且 DownMove > 0；否则为 0
-DI = 100 × WilderSmooth(-DM, n) / WilderSmooth(TR, n)
```

数值越高，表示近期向下方向运动相对真实波幅越强。+DI 与 -DI 通常配合使用，关注两者的相对大小和交叉关系。

## 3. 平均趋向指标（ADX）

### 用途

衡量趋势强度，但不表示趋势方向；可用于区分趋势行情和盘整行情。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `average_directional_index` |
| 默认参数 | `window=14` |
| 字段依赖 | `high`、`low`、`close` |

### 公式

```text
DX = 100 × |+DI - -DI| / (+DI + -DI)
ADX = WilderSmooth(DX, n)
```

ADX 上升表示趋势强度增强，但需结合 +DI 和 -DI 判断上涨还是下跌方向。

## 4. 累积/派发线（A/D）

### 用途

将收盘价在日内高低区间的位置与成交量结合，累计观察市场的买入累积或卖出派发压力。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `accumulation_distribution` |
| 默认参数 | 无 |
| 字段依赖 | `high`、`low`、`close`、`volume` |

### 公式

```text
Money Flow Multiplier = ((Close - Low) - (High - Close)) / (High - Low)
A/D(t) = A/D(t-1) + Money Flow Multiplier × Volume(t)
```

当前实现以 `0` 为起始值。当 `High = Low` 时，使用极小值保护分母，得到当期增量为 `0`。应关注 A/D 的变化和趋势，而不是不同标的之间的绝对值横向比较。

## 使用边界

- 因子是研究信号，不构成交易指令或收益承诺。
- DMI/ADX 使用 Wilder 平滑；窗口前置样本不足时会产生缺失值。
- 回测前应统一处理缺失值、停牌、涨跌停、交易成本和股票池。
- 价格复权和成交量口径由数据层决定，跨数据源比较前应确认口径一致。
