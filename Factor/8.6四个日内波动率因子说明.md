# 四个日内波动率因子说明

> 对应实现：`Factor/libraries/volatility_lib.py`
>
> 本文档说明 Parkinson、Garman-Klass、Rogers-Satchell 和 Chaikin Volatility 的当前实现口径。四项因子均返回“日期 × 标的”的 `pandas.DataFrame`，只使用当期及历史行情数据。

## 1. Parkinson 波动率

### 用途

利用日内最高价和最低价区间估计波动率，相较只使用收盘价收益率的估计可包含更多日内价格信息。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `parkinson_volatility` |
| 默认参数 | `window=20` |
| 字段依赖 | `high`、`low` |

### 公式

```text
Variance = Mean(log(High / Low)², n) / (4 × log(2))
Parkinson Volatility = sqrt(Variance)
```

该估计器只使用高低价区间，不反映隔夜跳空。

## 2. Garman-Klass 波动率

### 用途

同时利用开盘、最高、最低和收盘价估计日内波动率。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `garman_klass_volatility` |
| 默认参数 | `window=20` |
| 字段依赖 | `open`、`high`、`low`、`close` |

### 公式

```text
Variance = Mean(
    0.5 × log(High / Low)²
    - (2 × log(2) - 1) × log(Close / Open)²,
    n
)

Garman-Klass Volatility = sqrt(max(Variance, 0))
```

实现中将由于数值误差造成的轻微负方差截断为 `0`，保证输出可开方。

## 3. Rogers-Satchell 波动率

### 用途

使用 OHLC 数据估计波动率，并允许价格在窗口内存在趋势漂移。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `rogers_satchell_volatility` |
| 默认参数 | `window=20` |
| 字段依赖 | `open`、`high`、`low`、`close` |

### 公式

```text
Variance = Mean(
    log(High / Close) × log(High / Open)
    + log(Low / Close) × log(Low / Open),
    n
)

Rogers-Satchell Volatility = sqrt(max(Variance, 0))
```

实现中同样对轻微负方差截断为 `0`。

## 4. Chaikin Volatility

### 用途

衡量日内高低价振幅的扩张或收缩速度，而不是直接给出绝对波动率水平。

### 参数与字段

| 项目 | 内容 |
|---|---|
| 因子名 | `chaikin_volatility` |
| 默认参数 | `ema_window=10`、`change_window=10` |
| 字段依赖 | `high`、`low` |

### 公式

```text
High Low Average = EMA(High - Low, ema_window)
Chaikin Volatility = (
    High Low Average / High Low Average.shift(change_window) - 1
) × 100
```

正值表示日内振幅相对指定期数前扩大，负值表示振幅收缩。

## 使用边界

- 四项因子是波动率研究特征，不构成交易指令或收益承诺。
- 它们主要刻画日内价格范围，均不直接处理隔夜跳空；若需考虑跳空风险，应结合 ATR 或收盘收益率波动率。
- 窗口前置样本不足时会产生缺失值；回测前应统一处理缺失值、停牌和股票池。
- OHLC 价格必须采用一致的复权口径，跨数据源比较前应核对交易日历与复权规则。
