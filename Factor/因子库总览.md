## 1. 本文档的使用方式

这不是摘要目录。下文为每个可加载因子提供独立条目，包含用途/定义、默认参数、字段依赖与当前实现的完整计算代码。代码按仓库实现原样整理；因此当文字与代码出现差异时，以代码为准。

- 所有因子返回 `日期 × 标的` 的 `pandas.DataFrame`。
- `rolling`、`pct_change`、`shift` 和 EMA 的前置样本不足会产生空值；研究前应统一处理缺失值与有效股票池。
- 因子是研究信号而不是交易指令。应在独立样本中完成去极值、标准化、中性化、交易成本、停牌和涨跌停等检验。
- 价格复权、财务字段可见日和数据许可均由数据层决定；本库不会自行修正这些口径。

### `macdboll`

- **直接字段依赖**：`close`

```python
def macdboll(self):
    ema12 = self.close.ewm(span=12).mean()
    ema26 = self.close.ewm(span=26).mean()
    dif = ema12 - ema26
    dea = dif.ewm(span=9).mean()
    macd = dif - dea

    mid = self.close.rolling(20).mean()
    std = self.close.rolling(20).std()

    upper = mid + 2 * std
    lower = mid - 2 * std

    boll_pos = (self.close - lower) / (upper - lower)

    return macd * (1 - boll_pos)
```

### `momentum_decay`

- **定义**：指数衰减动量：对每日收益率加权平均，越近权重越高。
- **默认参数**：window: int = 20, decay: float = 0.9
- **直接字段依赖**：`close`
- **输出解释**：数值方向、量纲与缺失值处理均严格遵循下面实现；未做截面标准化或中性化。

```python
def momentum_decay(self, window: int = 20, decay: float = 0.9):
    """指数衰减动量：对每日收益率加权平均，越近权重越高。"""
    ret = self.close.pct_change()
    weights = [decay ** i for i in range(window)]
    weights = weights[::-1]  # 最近权重最大
    weights = [w / sum(weights) for w in weights]
    return ret.rolling(window).apply(lambda x: (x * weights).sum(), raw=True)
```

    """趋势位置：（当前价 - 最低价）/（最高价 - 最低价）。"""

def vr(self):
    """聚宽 VR：成交量比率。"""
    change = self.close.diff()
    up = self.volume.where(change > 0, 0.0)
    down = self.volume.where(change < 0, 0.0)
    flat = self.volume.where(change == 0, 0.0)
    return (up.rolling(26).sum() + flat.rolling(26).sum() / 2) / (

    )
