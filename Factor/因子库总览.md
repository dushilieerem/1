# SVQuant 内置因子库总览

> 更新日期：2026-07-24  
> 代码事实来源：`Factor/libraries/`、`Factor/libraries/index.yaml`  
> 适用版本：索引 `version: 1`，共 **10 个因子库、668 个可加载因子**。

## 1. 使用范围与阅读说明

本文件是当前内置因子库的统一目录。每个公开方法都是一个可计算因子，返回值均为“日期 × 标的”的 `pandas.DataFrame`；参数未显式传入时使用下表中的默认值。

| 因子库 | 前缀/命名 | 数量 | 定位 |
|---|---|---:|---|
| `alpha_library` | 原始名称 | 5 | 简单 Alpha 示例与组合指标 |
| `momentum_lib` | 原始名称 | 18 | 动量、反转与趋势 |
| `value_lib` | 原始名称 | 14 | 估值、股息与规模 |
| `technical_lib` | 原始名称 | 19 | 技术分析指标与 K 线形态 |
| `volatility_lib` | 原始名称 | 15 | 波动、回撤与尾部风险 |
| `trading_lib` | 原始名称 | 16 | 成交量、换手率与资金流 |
| `alpha_features` | `alpha158_*` / `alpha360_*` | 518 | Alpha158 / Alpha360 机器学习特征 |
| `technical_indicators` | 原始名称 | 15 | 技术指标首批 |
| `risk_indicators` | 原始名称 | 12 | 风险指标首批 |
| `emotion_indicators` | 原始名称 | 36 | 情绪指标首批 |

所有内置因子均由 SVQuant 原生复算；数据源、复权或缺失值口径不同会影响结果。财务、成长、质量等依赖点时财务数据的因子尚未实现。

## 2. 数据字段与通用注意事项

| 字段 | 含义 | 被哪些库使用 |
|---|---|---|
| `open`、`high`、`low`、`close` | 日线开高低收价格 | Alpha、动量、技术、波动、量价、风险与情绪 |
| `volume`、`amount`、`turnover` | 成交量、成交额、换手率 | 量价、Alpha、技术与情绪 |
| `total_mv` | 总市值 | `alpha_library`、价值 |
| `pe_ttm`、`pb`、`ps_ttm` | 滚动市盈率、市净率、市销率 | 价值 |
| 其他财务字段 | 如净利润、分红、EBITDA、增长率 | 价值库的部分因子，须由数据提供方提供 |
| `vwap` | 成交量加权均价 | Alpha 特征；缺失时按 `amount / volume` 推导 |

- 滚动窗口的前置样本不足通常产生空值；应在分析或回测前统一处理缺失值与有效股票池。
- 除特殊说明外，价格类因子使用输入面板的 `close`。数据是否前复权、后复权或不复权由数据层决定，库本身不转换复权口径。
- 因子仅给出截面信号，不等于交易指令。使用时应结合调仓频率、行业/风格暴露、中性化、去极值、停牌及涨跌停过滤进行研究验证。

## 3. 通用因子库

### 3.1 `alpha_library`（5 个）

| 因子 | 默认参数 | 说明 / 公式要点 | 字段 |
|---|---|---|---|
| `alpha101` | `window=5` | 动量，`close.pct_change(window)` | close |
| `alpha158` | `window=5` | 反转，`-close.pct_change(window)` | close |
| `marketcap` | — | 负总市值，偏向小市值 | total_mv |
| `macdboll` | — | MACD 柱值 × `(1 - 布林带位置)`；MACD 参数 12/26/9，布林参数 20/2 | close |
| `futureRes` | — | 下一日绝对价格变动 `close.shift(-1) - close` | close |

> **未来函数警告：**`futureRes` 使用未来一日价格，仅可作为标签、调试或监督学习目标；绝不可作为同一时点可交易因子参与回测。

### 3.2 `momentum_lib`（18 个）

| 因子 | 默认参数 | 说明 |
|---|---|---|
| `momentum_5d`、`momentum_10d`、`momentum_20d`、`momentum_60d`、`momentum_120d`、`momentum_250d` | 各为 `window=5/10/20/60/120/250` | 对应窗口的累计收益率 |
| `momentum_ratio` | `short=5, long=20` | 短期动量 / 长期动量 |
| `momentum_acceleration` | `fast=5, slow=20` | 短期收益率 − 长期收益率 |
| `momentum_decay` | `window=20, decay=0.9` | 近期权重更高的指数衰减收益 |
| `momentum_risk_adjusted` | `window=20` | 窗口收益率 / 窗口收益波动率 |
| `reversal_1d` | — | 1 日收益率的相反数 |
| `reversal_5d`、`reversal_20d`、`reversal_60d` | `window=5/20/60` | 对应窗口收益率的相反数 |
| `reversal_industry_neutral` | `window=20` | 个股反转信号减去同日行业均值；需要行业字段 |
| `trend_strength` | `window=20` | 当前收盘价 / 窗口均价 |
| `trend_position` | `window=60` | `(close - 窗口最低价) / (窗口最高价 - 窗口最低价)` |
| `trend_consistency` | `window=10` | 窗口内上涨日占比 |

除 `reversal_industry_neutral` 外均依赖 `close`；趋势位置额外依赖 `high`、`low`。

### 3.3 `value_lib`（14 个）

| 因子 | 说明 / 公式要点 |
|---|---|
| `ep_ttm`、`ep` | 滚动 / 静态市盈率倒数 |
| `bp` | 市净率倒数 |
| `sp_ttm`、`cp_ttm` | 滚动市销率 / 市现率倒数 |
| `composite_value` | EP、BP、SP 等权合成 |
| `value_vs_growth` | EP 与增长率的组合，`EP / (1 + growth)` |
| `earnings_yield` | EP 的截面 Z-score |
| `dividend_yield` | 股息率 |
| `dividend_cover` | 净利润 / 分红 |
| `peg` | 市盈率 / 增长率 |
| `ev_ebitda` | EV/EBITDA 的倒数 |
| `ln_cap` | 总市值的自然对数 |
| `small_size` | 负总市值，数值越大表示市值越小 |

`ep_ttm`、`bp`、`sp_ttm`、`ln_cap`、`small_size` 分别需要 `pe_ttm`、`pb`、`ps_ttm`、`total_mv`。其余财务型指标还依赖相应的基本面字段；必须使用公告日点时面板，避免把未披露财报带入历史。

| 因子 | 默认参数 | 说明 |

## 4. Alpha 特征库（518 个）

实现位置为 `Factor/libraries/alpha_features.py`，包含 Alpha158 与 Alpha360 特征结构。滚动窗口均为 `5, 10, 20, 30, 60`，分母中使用极小值防止零除。

### 4.1 Alpha360（360 个，完整命名规则）

每个组合均是一个已注册因子，故下式精确覆盖全部 360 项：

```text
alpha360_{field}{day}
field ∈ {close, open, high, low, vwap, volume}
day   ∈ {0, 1, 2, ..., 59}
```

| 字段组 | 因子范围 | 数量 | 公式 |
|---|---|---:|---|
| 价格 / VWAP | `alpha360_close0`…`close59`；`open0`…`open59`；`high0`…`high59`；`low0`…`low59`；`vwap0`…`vwap59` | 300 | `field.shift(day) / close` |
| 成交量 | `alpha360_volume0`…`volume59` | 60 | `volume.shift(day) / volume` |

其中 `vwap` 优先读取字段；缺失时使用 `amount / volume`。`day=0` 表示当日值，因此非成交量价格组的 `close0` 恒为 1。

### 4.2 Alpha158（158 个，完整命名规则）

| 特征组 | 精确因子名称 / 后缀 | 数量 | 公式要点 |
|---|---|---:|---|
| K 线形态 | `kmid`、`klen`、`kmid2`、`kup`、`kup2`、`klow`、`klow2`、`ksft`、`ksft2` | 9 | 实体、振幅、上下影线及其按开盘价/振幅归一化形式 |
| 当日相对价 | `open0`、`high0`、`low0`、`vwap0` | 4 | 对 `close` 的比值 |
| 滚动价格与量价特征 | 下表 29 个后缀 × 5 个窗口 | 145 | 名称为 `alpha158_{suffix}{window}` |

以下列表中的每一个 `suffix` 与每一个 `window ∈ {5,10,20,30,60}` 的笛卡尔积都对应一个因子，合计 145 个：

| 后缀 | 含义 / 公式要点 |
|---|---|
| `roc` | `close.shift(window) / close` |
| `ma`、`std` | 收盘价均值 / 标准差，再除以当前收盘价 |
| `beta`、`rsqr`、`resi` | 收盘价对时间序列线性回归的斜率、R²、末端残差（前两者按 close 归一化，R² 除外） |
| `max`、`min`、`qtlu`、`qtld` | 窗口最高、最低、80% 分位、20% 分位价格 / close |
| `rank` | 窗口内收盘价百分位排名 |
| `rsv` | `(close - 窗口最低) / (窗口最高 - 窗口最低)` |
| `imax`、`imin`、`imxd` | 最高/最低值位置及其差，再除以窗口长度 |
| `corr` | `close` 与 `log(volume + 1)` 的滚动相关性 |
| `cord` | 价格收益率与对数成交量变化的滚动相关性 |
| `cntp`、`cntn`、`cntd` | 正收益比例、负收益比例、二者之差 |
| `sump`、`sumn`、`sumd` | 正/负日价格变化占绝对变化总和的比例及其差 |
| `vma`、`vstd` | 成交量均值 / 标准差，相对当日成交量 |
| `wvma` | `abs(收益) × volume` 的标准差 / 均值 |
| `vsump`、`vsumn`、`vsumd` | 正/负成交量变化占绝对变化总和的比例及其差 |

完整 158 项 = 9 个 K 线特征 + 4 个当日相对价 + 29 × 5 个滚动特征。

## 5. 技术、风险与情绪指标（63 个）

### 5.1 技术类 `technical_indicators`（15 个）

| 因子 | 默认参数 | 说明 |
|---|---|---|
| `boll_down`、`boll_up` | `window=20, n_std=2.0` | 布林下轨 / 上轨后除以当日收盘价 |
| `ema5` | — | 5 日收盘价 EMA |
| `emac10`、`emac12`、`emac20`、`emac26`、`emac120` | — | 对应周期收盘价 EMA，再除以收盘价 |
| `mac5`、`mac10`、`mac20`、`mac60`、`mac120` | — | 对应周期收盘价 MA，再除以收盘价 |
| `macdc` | — | `(EMA12 - EMA26 - EMA9(DIF)) / close` |
| `mfi14` | — | 14 日资金流量指标，使用典型价格与成交量 |

### 5.2 风险类 `risk_indicators`（12 个）

所有因子以日收益率 `close.pct_change()` 为输入。`variance*` 年化乘以 252；`sharpe_ratio_*` 使用年化均值和标准差，固定无风险利率为 4%。

| 窗口 | 峰度 | 偏度 | 方差 | 夏普 |
|---:|---|---|---|---|
| 20 | `kurtosis20` | `skewness20` | `variance20` | `sharpe_ratio_20` |
| 60 | `kurtosis60` | `skewness60` | `variance60` | `sharpe_ratio_60` |
| 120 | `kurtosis120` | `skewness120` | `variance120` | `sharpe_ratio_120` |

### 5.3 情绪类 `emotion_indicators`（36 个）

| 子类 | 因子 | 说明 |
|---|---|---|
| 人气 / 意愿 | `ar`、`br`、`arbr` | 26 日 AR、BR 及二者之差 |
| 波动与资金 | `atr6`、`atr14`、`wvad`、`mawvad`、`money_flow_20` | 真实波幅、威廉变异离散量及典型价格资金流 |
| 换手率 | `davol5`、`davol10`、`davol20`、`turnover_volatility`、`vol5`、`vol10`、`vol20`、`vol60`、`vol120`、`vol240` | 短长换手比、20 日波动率和各窗口均值 |
| 成交额 | `tvma6`、`tvma20`、`tvstd6`、`tvstd20` | 成交额滚动均值 / 标准差 |
| 成交量 EMA / MACD | `vema5`、`vema10`、`vema12`、`vema26`、`vdiff`、`vdea`、`vmacd`、`vosc` | 成交量 EMA、DIF/DEA/MACD 与震荡率 |
| 成交量变化 | `vr`、`vroc6`、`vroc12`、`vstd10`、`vstd20` | 量比、成交量变动率和标准差 |
| 市场心理 | `psy` | 12 日上涨天数占比 × 100 |

情绪库依赖 `open`、`high`、`low`、`close`、`volume`、`amount` 与 `turnover`；其中涉及换手率的因子在缺少 `turnover` 字段时不可计算。

## 6. 加载与组合示例

```python
from researchengine import FactorLoader

loader = FactorLoader()
loader.load("momentum_lib")
factor = loader.factors["momentum_20d"]

# 使用内置库因子做组合时，可在用户库中声明所需 library_names，
# 然后通过 self.<因子名>() 调用。
```

内置因子回测 API 传 `library_name` 与 `factor_name`；用户自定义因子传单个函数体与 `factor_name`。API 的完整约束见 [FEAT-011](FEAT-011-builtin-factor-api/README.md)。

## 7. 维护约定

1. 新增、改名或删除因子时，必须同步更新实现、`Factor/libraries/index.yaml` 和本文件的数量及目录。
2. Alpha 特征生成规则或窗口集合变更时，必须重算 518 总数并补充回归测试。
3. 聚宽兼容因子只有在公式来源、字段许可、点时口径和验证状态清楚后才可标记为已实现。
4. 本文档描述的是当前实现，因子有效性不作承诺；任何生产或投资决策均应以独立样本、成本和风险约束下的验证结果为准。
