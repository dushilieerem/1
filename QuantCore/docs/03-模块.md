## QuantCore

```
QuantCore
├── DataEngine
├── FactorEngine
├── BacktestEngine
└── MetricEngine
```

## Data Engine

负责：

统一读取数据。

例如：

以后：

```
CSV

ClickHouse

AkShare

Wind

Parquet
```

Research：

永远不知道。

数据来自哪里。

只知道：

```
IDataProvider
```

## Factor Engine

负责：

真正计算：

```
factor.compute(...)
```

支持：

```
Python

C++

Numba

GPU
```

以后：

Research：

完全不用改。

整个：

例如：

```
撮合

手续费

滑点

成交

现金变化
```

Research：

不要知道。
