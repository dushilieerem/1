## QuantCore 类设计

依据 `03-模块.md` 中四大引擎的职责划分，完成以下类设计。

---

### DataEngine

统一数据读取，对 Research 暴露 `IDataProvider` 接口，数据来源对 Research 透明。

#### `IDataProvider`（抽象接口）

```
属性：
  name: str                  —— 数据源名称（如 "csv", "wind"）

方法：
  get_bars(symbol, start, end, fields) -> DataFrame
  get_universe(date) -> List[str]
  get_symbols() -> List[str]
```

#### `DataEngine`

```
属性：
  provider: IDataProvider    —— 统一通过接口调用，不关心具体来源

方法：
  set_provider(provider: IDataProvider)
  get_bars(symbol, start, end, fields) -> DataFrame
  get_universe(date) -> List[str]
```

#### 具体实现类（各自实现 `IDataProvider`）

- `CSVDataProvider`
- `ClickHouseProvider`
- `AkShareProvider`
- `WindProvider`
- `ParquetProvider`

---

### FactorEngine

因子计算引擎，Research 只写因子逻辑，不修改引擎代码。

#### `BaseFactor`（抽象基类）

```
属性：
  name: str                  —— 因子名称
  author: str                —— 因子作者
  params: dict               —— 因子参数

方法：
  compute(data: DataFrame) -> pd.Series   —— 因子核心计算逻辑（子类实现）
```

#### `FactorEngine`

```
属性：
  factors: Dict[str, BaseFactor]

方法：
  register(factor: BaseFactor)
  compute(factor_name, data_provider, universe, start, end) -> pd.DataFrame
  compute_all(...) -> Dict[str, pd.Series]
```

#### `ComputeBackend`（计算后端抽象）

```
属性：
  name: str                  —— "python" | "numba" | "cpp" | "gpu"

方法：
  execute(func, *args) -> Any
```

---

### BacktestEngine

交易模拟引擎，只做交易模拟，不计算任何指标。

#### `Order`

```
属性：
  symbol: str
  direction: int             —— 1=买入, -1=卖出
  quantity: float
  order_type: str            —— "market" / "limit"
  price: float | None        —— 限价单价格
  status: str                —— "pending" / "filled" / "partial" / "cancelled"
  create_time: datetime
```

#### `Fill`

```
属性：
  order_id: str
  symbol: str
  direction: int
  fill_price: float
  fill_quantity: float
  fill_time: datetime
  commission: float          —— 手续费
  slippage: float            —— 滑点
```

#### `Portfolio`

```
属性：
  cash: float
  positions: Dict[str, Position]
  total_value: float
  initial_capital: float

方法：
  update(fill: Fill)
  market_value() -> float
```

#### `MatchingEngine`

```
方法：
  match(order: Order, bars: DataFrame) -> List[Fill]
```

#### `TransactionCost`

```
属性：
  commission_rate: float
  min_commission: float
  slippage_rate: float

方法：
  calculate(order: Order, fill_price: float) -> (commission, slippage)
```

#### `BacktestEngine`

```
属性：
  data_engine: DataEngine
  matching_engine: MatchingEngine
  portfolio: Portfolio
  cost_model: TransactionCost
  start_date: datetime
  end_date: datetime

方法：
  run(strategy_func) -> BacktestResult
  set_portfolio(portfolio: Portfolio)
```

#### `BacktestResult`

```
属性：
  portfolio: Portfolio
  orders: List[Order]
  fills: List[Fill]
  equity_curve: pd.Series
  timestamps: List[datetime]
```

### MetricEngine（非常重要）

所有指标的统一入口，Research 只调用 `metric.calculate(...)`。Backtest 不计算 Sharpe，Factor 不计算 IC，全部集中在此。

#### `BaseMetric`（抽象基类）

```
属性：
  name: str                  —— 指标名称（如 "sharpe", "annual_return"）

方法：
  calculate(data: pd.Series | pd.DataFrame) -> float
```

#### `MetricEngine`

```
属性：
  metrics: Dict[str, BaseMetric]

方法：
  register(metric: BaseMetric)
  calculate(metric_names: List[str], data) -> Dict[str, float]
  calculate_all(data) -> Dict[str, float]
```

#### 具体指标类（各自实现 `BaseMetric`）

```
AnnualReturn              —— 年化收益率
  calculate(equity_curve: pd.Series) -> float

SharpeRatio               —— 夏普比率
  calculate(returns: pd.Series) -> float

SortinoRatio              —— 索提诺比率
  calculate(returns: pd.Series) -> float

CalmarRatio               —— 卡玛比率
  calculate(equity_curve: pd.Series) -> float

MaxDrawdown               —— 最大回撤
  calculate(equity_curve: pd.Series) -> float

Volatility                —— 波动率
  calculate(returns: pd.Series) -> float

InformationCoefficient    —— IC
  calculate(factor_values: pd.Series, forward_returns: pd.Series) -> float

RankIC                    —— 秩相关性 IC
  calculate(factor_values: pd.Series, forward_returns: pd.Series) -> float

WinRate                   —— 胜率
  calculate(returns: pd.Series) -> float

Turnover                  —— 换手率
  calculate(positions: pd.DataFrame) -> float
```

---

### 核心设计约束

| 约束 | 含义 |
|------|------|
| **DataEngine** | 对 Research 暴露 `IDataProvider` 接口，数据源对 Research 透明 |
| **FactorEngine** | Research 只写因子逻辑（`factor.compute`），不修改引擎代码 |
| **BacktestEngine** | 不计算 Sharpe 等指标，只做交易模拟 |
| **FactorEngine** | 不计算 IC 等指标，只做因子计算 |
| **MetricEngine** | 统一入口，Research 只调用 `metric.calculate(...)` |
