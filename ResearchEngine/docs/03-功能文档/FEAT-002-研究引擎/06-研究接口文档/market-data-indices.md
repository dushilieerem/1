# GET /api/market-data/indices

返回当前已发布市场数据中可查询的内置股指，供 WebApp 构建股指选择器。

```http
GET /api/market-data/indices
```

```json
{
  "indices": [
    {"code": "000016.SH", "name": "上证50"},
    {"code": "000300.SH", "name": "沪深300"}
  ]
}
```

当前内置范围为上证50、沪深300、中证500和中证1000；仅返回已发布且可读取日线文件的股指，按代码升序。若市场数据目录不可读、文件损坏或没有可用股指，返回 `503`。本端点不调用在线数据源，也不返回指数日线。
