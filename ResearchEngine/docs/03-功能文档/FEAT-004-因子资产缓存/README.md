## 1. 价值与范围

- 优先级：P0
- 提出日期：2026-07-17

### 1. 功能名称

因子资产目录与回测结果缓存。

### 2. 背景

当前因子库位于 `ResearchEngine/factor/`，与 ResearchEngine 的 Python 实现目录耦合；行情数据则已经作为根目录 `MarketData/` 的项目级资产管理。重复提交相同因子和参数时，ResearchEngine 每次都会重新计算因子和回测，造成不必要的等待和计算资源消耗。

### 3. 用户价值

- 研究员可在根目录集中管理因子源码、索引和相关文档，与 `MarketData/` 的资产管理方式一致。
- 相同因子、相同参数、相同数据版本再次回测时直接返回已缓存结果，缩短等待时间。
- 行情或算法变化后缓存自动失效，避免向用户返回过期结果。

### 4. 商业价值

- 提升频繁调参、重复查看结果时的响应速度，降低研究摩擦和留存风险。
- 减少重复计算带来的机器资源占用，为后续多用户与 AI 自动迭代研究控制成本。
- 将因子资产从服务实现中剥离，为后续团队共享、权限和版本管理奠定边界。

### 5. 竞品与替代方案

| 方案 | 优点 | 不采用原因 / 适用阶段 |
|------|------|----------------------|
| 每次重新回测 | 实现最简单 | 重复计算开销高，不满足高频研究体验。 |
| 复用现有 ResultStorage | 已具备 CSV/Parquet/SQLite 后端 | 当前缺少缓存键、命中查询、失效和并发控制，不能直接作为 API 缓存。 |
| 本地文件缓存（推荐 MVP） | 无新增基础设施，易于调试和自动清理 | 单实例缓存不共享；多实例阶段再升级共享缓存。 |
| Redis / 对象存储 | 支持多实例共享 | 当前运维成本过高，延后到 SaaS 阶段。 |

### 6. MVP 范围

#### 必须做

- 建立根目录 `Factor/`，其中 `libraries/` 存放因子库和 `index.yaml`。
- 将运行时回测缓存写入 `Factor/backtest_results/`，并加入 `.gitignore`。
- 基于因子代码、因子名、完整回测参数、算法版本与数据版本生成确定性缓存键。
- 缓存命中时返回完整的因子回测响应；未命中时执行回测并原子写入缓存。
- 提供容量或时间维度的自动清理策略，并通过响应头标识 `HIT` / `MISS`。
- 更新因子加载路径、内置因子枚举、示例、测试及相关文档。

#### 可以以后做

- Redis / 对象存储等多实例共享缓存。
- 用户可见的研究历史、收藏、命名与手动保留。
- 缓存管理 API、缓存命中率监控和后台预热。

#### 明确不做

- 不将缓存作为用户的长期研究记录或审计记录。
- 不将运行时缓存提交到 Git。
- 不在本 Feature 建立因子权限、协作或版本审批能力。

### 7. 初步验收标准

1. 因子库位于根目录 `Factor/libraries/`，且内置因子加载与 `/api/factor-libraries`、`/api/factors/{library_name}` 正常。
2. 相同请求在数据版本未变化时第二次调用不执行回测，并返回与首次一致的结果。
3. 因子代码、任一回测参数、算法版本或数据版本变化时，缓存不命中。
4. 并发相同请求不会产生损坏或部分写入的缓存文件。
5. 缓存文件可按设定的过期时间或容量上限自动清理。
6. `Factor/backtest_results/` 不进入版本控制。

### 8. 风险与待确认项

| 风险 / 待确认项 | 影响 | 初步缓解 |
|-----------------|------|----------|
| 数据版本缺少统一标识 | 可能误命中过期结果 | 引入显式 `data_version` 配置或数据清单。 |
| 多实例部署 | 本地缓存无法共享 | MVP 限定单实例；SaaS 阶段替换为共享后端。 |
| 缓存无上限增长 | 占满磁盘 | 配置 TTL 与最大容量，按最近访问时间清理。 |
| 源码路径迁移 | 内置因子加载与文档链接失效 | 完整搜索引用并以测试覆盖迁移路径。 |

### 交付说明

- `Factor/backtest_results/` 已加入 `.gitignore`，属于可自动清理的运行时缓存。
- 可通过 `SVQUANT_FACTOR_DIR`、`SVQUANT_BACKTEST_CACHE_DIR`、
  `SVQUANT_BACKTEST_CACHE_ENABLED`、`SVQUANT_BACKTEST_CACHE_TTL_DAYS` 和
  `SVQUANT_BACKTEST_CACHE_MAX_BYTES` 调整部署行为。
- 遗留的 `ResearchEngine/factor/__pycache__/` 为本地 Python 缓存，不纳入版本控制；因子源码已迁出。
