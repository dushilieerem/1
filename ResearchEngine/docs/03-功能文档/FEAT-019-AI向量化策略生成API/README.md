# FEAT-019：AI 自然语言向量化策略生成 API

- 状态：开发中（受控 MVP）
- 所属 Initiative：INIT-004 投研能力 Phase 2
- 所属能力：AI 研究助手 / 策略研究
- 优先级：P0

将研究员的自然语言假设生成一个可审阅的、只输出目标权重矩阵的向量化策略草稿；用户确认后才可提交既有策略回测 API。

## 1. 价值与范围

### 背景与价值

因子生成已能把自然语言转换为单个因子，但用户仍需自行拼装选股、权重和调仓逻辑，无法完成策略研究的 AI 入口。本功能复用既有 LLM 接入与 `POST /api/backtest/strategy`，让研究员得到可编辑、可复现的向量化策略草稿。

不做的影响是 AI 体验停在单因子层，用户需离开平台完成策略样板代码。MVP 仅支持日频自由目标权重策略；不生成事件驱动策略、不自动回测、不下单、不保存策略资产。

### 范围与优先级

- 必须做：受控生成端点、JSON/AST/编译校验、幂等、用户确认后复用既有策略回测。
- 以后做：结构化 `FactorPortfolioStrategy`、多轮修复、策略保存与异步执行。
- 不做：任意 Python、未来函数、文件/网络访问、自动执行、投资建议。

商业价值 5、用户价值 5、战略价值 5、技术成本 2，优先级评分 62.5，建议 P0。

## 2. 业务规则与场景

### 用户流程

```text
自然语言假设 → POST /api/ai/strategy-generations → 受控策略草稿
                                                    ↓ 用户审阅确认
                                      POST /api/backtest/strategy
```

### 业务规则与验收

1. 请求含 `prompt`、可选 `universe`/`frequency`/`preferred_strategy_name` 和 UUID `idempotency_key`；频率仅为 `1d`，未知字段返回 `422`。
2. 成功响应返回一个策略类源码、策略类名、说明、字段、假设、警告和校验状态；相同幂等键与内容不得重复调用供应商，不同内容返回 `409`。
3. 草稿必须是一个自由向量化策略类，含 `__init__(self, close)` 与 `generate_signals(self)`；后者返回“日期 × 标的”的 pandas `DataFrame` 目标权重。
4. 仅允许 `import pandas as pd`、`self.close`、白名单面板方法、局部计算及 `pd.DataFrame`；允许安全的算术取模和切片，以表达固定周期调仓；禁止其他 import、动态执行、双下划线属性、文件和网络访问。
5. 请求明确要求当前能力目录之外的数据字段、事件订单、多空或外部计算库时，服务在调用模型前返回 HTTP 200 与 `rejected`，并说明不支持的能力；不得以不等价的 close 策略冒充成功。
6. 静态校验或 JSON 解析失败返回 HTTP 200 与 `rejected`，不返回 `strategy`；错误须包含被拒绝的方法或结构；不会执行或自动回测代码。

验收：合法模型响应为 `ready` 且可编译；不安全源码为 `rejected`；幂等与冲突行为符合规则；生成代码可原样作为 `strategy_code` 提交至既有回测 API。

## 3. 方案设计

实现位于 `ResearchEngine/app/api/ai_strategy.py`，作为 SaaS AI 服务落地前的受控过渡层。它复用火山方舟 OpenAI 兼容调用方式，但不改变 `app.quantcore` 或回测编排。

```text
Web → 能力预检 → /api/ai/strategy-generations → LLM → JSON → AST/compile → 草稿
                                                              ↓ 用户确认
                                                   /api/backtest/strategy
```

Pydantic 定义独立的请求、响应与草稿模型；内存幂等记录按策略端点隔离。模型调用前先进行能力预检：明确请求成交量/基本面、事件订单、多空或 numpy/TA-Lib 等外部库时直接拒绝，避免模型悄悄改写语义后返回成功。AST 检查默认拒绝，只允许 pandas 别名导入、单个策略类、固定构造函数、固定生成方法和安全表达式。为支持“每 N 日调仓”，允许安全的算术取模、切片、`ffill`、布尔矩阵的 `astype` 和按行除法 `div`；提示词内置 TopN 调仓与均线信号等权的完整无循环模板。静态通过仅代表契约合规，生产回测仍须在无网络、资源受限的隔离环境运行。

回滚方式：移除路由即可停止新入口，不影响因子生成和既有策略回测。

### 验证结果

验证日期：2026-07-30

| 验收项 | 结果 | 证据 |
|---|---|---|
| 合法目标权重策略草稿可返回 | 通过 | API 契约测试返回 `ready` 与 `passed` |

| 既有策略回测接口无回归 | 通过 | `ResearchEngine/tests/test_api.py` 46 项通过 |
| 全量自动化测试 | 通过 | `pytest -q`：172 项通过（1 个既有依赖弃用警告） |

### 已知限制

- 仅支持 `self.close` 的日频自由向量化策略，不生成结构化因子组合或事件驱动策略。
- 草稿不自动执行；确认后的策略回测在生产环境仍须部署到受资源限制、无网络的执行隔离中。
- 幂等记录只在当前 Python 进程内保存，尚未接入鉴权、额度与持久化审计。

## 5. 计划与里程碑

| 任务 | 复杂度 | 风险 | 依赖 |
|---|---:|---|---|
| 请求/响应契约与路由 | 1 | 低 | 现有 API |
| LLM 提示词、JSON 解析、幂等 | 2 | 中 | AI 因子生成服务 |
| 向量化策略 AST 与编译校验 | 3 | 中 | 策略回测契约 |
| 单元与 API 契约测试、文档 | 2 | 低 | 前三项 |

里程碑：M1 受控草稿可生成；M2 安全与幂等测试通过；M3 文档化并可供前端接入。主要风险是模型生成无效权重矩阵，MVP 通过固定提示词、AST 校验和用户确认缓解；经济有效性留给回测验证。
