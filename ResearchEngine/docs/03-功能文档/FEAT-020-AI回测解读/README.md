# FEAT-020：AI 回测解读与优化建议

- 状态：开发中（MVP 第 1 轮）
- 所属 Initiative：INIT-004 投研能力 Phase 2
- 所属能力：AI 研究助手 / 策略研究 / 因子研究
- 优先级：P0（建议）
- 宏观影响：L1（补齐既有 AI 研究闭环，不改变产品模块边界）

## 目标

对已经成功完成的因子或向量化策略回测，先生成可复算、可引用的结构化证据，再由 AI 输出通俗解读和按优先级排列的优化实验建议。每条结论必须能回指证据；每条建议必须说明假设、权衡和验证方法。

## 核心决策

1. 采用“确定性证据与诊断 → AI 组织解读”的两阶段架构，不把原始回测结果直接交给模型自由判断。
2. MVP 只建议下一轮实验，不自动修改代码、自动回测或自动选择“最优”参数。
3. 数据不足、交易成本缺失、仅有样本内结果时，先提示研究有效性风险，再讨论提升收益。
4. MVP 通过内联结果快照接入现有回测 API；结果资产 ID 与历史解读复用在后续接入。

## Definition of Ready 状态

已获启动授权，MVP 范围已冻结：先交付确定性证据、诊断、人工实验建议与可降级 API；不进入自动调参、自动回测、结果资产库或 SaaS 身份/配额建设。其余接口、边界、验收、测试、回滚、任务和风险已有可评审草案。

## 1. 验收与证据

> 本记录随 MVP 迭代更新；当前为第 1 轮可验证实现，不代表 Feature 完成验收。

### 已验证能力

- 新增 `POST /api/ai/backtest-interpretations`，接受因子或向量化策略回测快照、原始运行上下文、关注点与 UUID 幂等键。
- 对净值序列执行日期递增、有限数值和 10,000 点上限校验；少于 60 点时返回 `insufficient`，不会调用供应商。
- 证据层生成稳定的结果指纹、净值点覆盖、总收益、最大回撤、基准收益、标准指标、成本/验证假设及因子 IC（如可用）。
- 诊断目录已覆盖短样本、缺少样本外验证、成本缺失/零成本、高换手、深回撤和弱因子信号，并生成最多 5 条 `manual_only` 实验建议。
- 未配置或不可用的 LLM Provider 时返回 `deterministic_fallback`，不影响已有回测端点；开关 `AI_BACKTEST_INTERPRETATION_ENABLED=false` 可关闭新入口。
