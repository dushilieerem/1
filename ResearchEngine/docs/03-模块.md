## ResearchEngine

```
ResearchEngine
├── ExperimentManager
├── FactorLoader
├── ConfigManager
└── ResultManager
```

## Experiment Manager（最重要）

整个ResearchEngine的核心。

负责：

一次实验。

例如：

```
experiment.run()
```

里面：

```
读取配置

↓

加载因子

↓

调用QuantCore

↓

得到结果

↓

保存结果
```

注意：

它**不计算收益。**

它只是：

组织流程。

## 把 "Experiment" 作为 ResearchEngine 的核心对象

我们目前的任务是：

> `main.py` → 加载因子 → 运行。

如果想让平台长期可维护，我建议把整个研究过程抽象成一个 **Experiment（实验）**。

例如：

```
experiment = Experiment(
    factor=Alpha101(),
    universe="CSI500",
    start="2020-01-01",
    end="2024-12-31",
)

result = experiment.run()
```

ResearchEngine 实际上管理的是 **Experiment**，而不是因子本身；QuantCore 执行的是 **Experiment** 中定义的计算任务。这样未来无论增加参数搜索、多因子组合、Walk Forward、滚动回测还是实验版本管理，都可以围绕 `Experiment` 扩展，而无需重构整个架构。这也是许多成熟量化平台采用的核心抽象。
