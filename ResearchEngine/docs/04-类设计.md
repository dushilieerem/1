## ResearchEngine 类设计

依据 `03-模块.md` 中四大模块 + 核心对象 Experiment 的职责划分，完成以下类设计。

---

### Experiment（核心对象）

```
属性：
  factor: BaseFactor              —— 要运行的因子（来自 FactorLoader）
  universe: str                   —— 股票池，如 "CSI500"
  start_date: str                 —— 开始日期 "2020-01-01"
  end_date: str                   —— 结束日期 "2024-12-31"
  config: ConfigManager           —— 实验配置
  result: ResultManager | None    —— 实验结果

方法：
  run() -> ResultManager          —— 执行完整实验流程
```

**说明：** ResearchEngine 实际上管理的是 Experiment，而不是因子本身。QuantCore 执行的是 Experiment 中定义的计算任务。未来无论增加参数搜索、多因子组合、Walk Forward、滚动回测还是实验版本管理，都可以围绕 Experiment 扩展。

---

### ExperimentManager（最重要）

整个 ResearchEngine 的核心，负责组织实验流程。

```
属性：
  experiments: Dict[str, Experiment]

方法：
  create(factor, universe, start, end, config) -> Experiment
  run(experiment: Experiment) -> ResultManager
  run_all() -> Dict[str, ResultManager]
```

**内部流程编排：**
```
读取配置
    ↓
加载因子
    ↓
调用 QuantCore
    ↓
得到结果
    ↓
保存结果
```

---

### FactorLoader

负责动态加载因子文件。

```
属性：
  factor_dir: str                 —— 因子文件目录（如 "factor/"）
  factors: Dict[str, BaseFactor]

方法：
  load(module_name: str) -> BaseFactor          —— 动态加载单个因子
  load_all() -> Dict[str, BaseFactor]           —— 加载目录下所有因子
  register(name: str, factor: BaseFactor)       —— 手动注册因子
```

**动态加载方式：**
```
importlib.import_module("factor.alpha101")
```

**示例因子文件结构：**
```
factor/
├── alpha101.py
│   └── class Alpha101(Factor):
│       def compute(...)
└── alpha158.py
    └── class Alpha158(Factor):
        def compute(...)
```

---

### ConfigManager

统一配置读取。

```
属性：
  config: dict                    —— 统一配置字典

方法：
  load(path: str)                               —— 从文件加载配置
  get(key: str, default=None) -> Any            —— 获取配置项
  set(key: str, value)                          —— 设置配置项
  to_dict() -> dict
```

**配置项示例：**
```
benchmark: CSI500
rebalance: weekly
commission: 0.0003
slippage: 0.001
```

---

### ResultManager

负责保存结果（不计算，只保存）。

```
属性：
  metrics: Dict[str, float]       —— 指标结果（如 sharpe, calmar, ic 等）
  factor_values: pd.Series        —— 因子值序列
  equity_curve: pd.Series         —— 净值曲线
  storage: ResultStorage          —— 存储后端

方法：
  save(path: str)                               —— 保存结果
  load(path: str)                               —— 加载结果
  get_metric(name: str) -> float                —— 获取指标值
  all_metrics() -> Dict[str, float]
  set_metric(name: str, value: float)           —— 记录指标值
```

#### `ResultStorage`（存储后端抽象）

```
属性：
  name: str                       —— "csv" | "sqlite" | "clickhouse"

方法：
  write(result: ResultManager)
  read(path: str) -> ResultManager
```

#### 具体实现类（各自实现 ResultStorage）
- `CSVStorage`
- `SQLiteStorage`
- `ClickHouseStorage`

---

### 核心设计约束

| 约束 | 含义 |
|------|------|
| **ExperimentManager** | 只组织流程，不计算收益 |
| **FactorLoader** | 只负责动态加载因子，不计算因子值 |
| **ConfigManager** | 统一读取配置，未来 GUI 接入无需修改代码 |
| **ResultManager** | 只保存结果，不计算任何指标 |
| **Experiment** | 是 ResearchEngine 的核心抽象，QuantCore 执行 Experiment 中定义的计算任务 |
