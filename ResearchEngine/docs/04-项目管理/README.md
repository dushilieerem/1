# ResearchEngine 项目管理与状态

本目录承载模块级交付追踪：当前实现状态快照和阶段汇报。

## 目录索引

| 目录/文件 | 用途 |
|-----------|------|
| [`模块状态/`](模块状态/) | 当前实现状态、已交付能力和缺口 |
| [`阶段汇报/`](阶段汇报/) | 阶段进展、质量结论和交付汇报 |

Feature 的验收证据和交付记录在对应功能包内维护（[`../03-功能文档/FEAT-*/`](../03-功能文档/)）；本目录只保存模块级管理事实。会议或实现产生的新结论必须在一个工作周期内回写到对应文档；模块状态与根目录 [`docs/04-项目管理/项目状态/`](../../../docs/04-项目管理/项目状态/) 保持一致。
