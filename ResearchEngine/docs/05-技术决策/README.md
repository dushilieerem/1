# ResearchEngine 技术决策

本目录保存只影响 ResearchEngine 模块边界、执行管线、数据访问或公开 API 的长期技术决策。跨模块或产品级决策仍记录在根目录 [`docs/05-技术决策/`](../../../docs/05-技术决策/)。

ADR 通过后，应同步更新 [`../02-架构文档/`](../02-架构文档/)、对应 Feature 功能包和 [`../04-项目管理/`](../04-项目管理/) 的交付证据。

## 当前决策状态

| 状态 | 决策 | 是否进入当前架构基线 |
|------|------|----------------------|
| 已接受 | ADR-018、019、020、022 | 是，分别约束区间语义、并发、批量存储和共享运行时。 |
| 当前接口/执行约束 | ADR-021、024、025 | 是；异步任务、`/api` 前缀和统一执行原则已落地，其中旧 Executor 内容仅作历史记录。 |
| 与项目级决策共同生效 | ADR-023、根目录 ADR-028、ADR-029 | 是；单一 `app.*` 命名空间、BacktestEngine 四引擎和 services/models/database 分层是当前基线。 |
| 提议/后续演进 | ADR-012、013、015、026 | 否；只能作为后续需求输入，不能覆盖当前架构文档的已实施描述。 |

同步顺序固定为：先更新已接受 ADR 的状态和结论，再更新 [`ResearchEngine 架构文档`](../02-架构文档/researchengine_architecture.md)；若影响系统边界、公共 API、MarketData 或部署方式，再同步根目录 [`架构文档`](../../../docs/02-架构文档/)。
