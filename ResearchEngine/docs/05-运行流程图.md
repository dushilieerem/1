### 5. 关键设计要点

| 要点 | 说明 |
|------|------|
| **Experiment 是核心** | 一切围绕 Experiment 展开，它是 Researcher 与 QuantCore 之间的桥梁 |
| **ExperimentManager 只编排** | 不计算收益、不计算因子、不计算指标，只负责调用顺序 |
| **FactorLoader 只加载** | 使用 `importlib.import_module` 动态加载因子文件，不参与计算 |
| **ConfigManager 统一配置** | 未来 GUI 接入只需替换配置来源，无需修改核心流程 |
| **ResultManager 只保存** | 不计算任何指标，结果来自 QuantCore 的 MetricEngine |
| **QuantCore 无感** | ResearchEngine 只调用 QuantCore，不关心其内部实现 |





下面按研究员视角讲清楚整套流程。

整体流程（研究员视角）

你写因子 (factor/xxx.py)
      │
      ▼
改 main.py 指定跑哪个因子
      │
      ▼
python ResearchEngine/examples/main.py
      │
   系统自动：
   读 price.CSV → 算因子值(面板) → 构组合 → 算 10 个指标 → 存 output/
      │
      ▼
看打印的指标 + output/xxx/ 下的结果文件

第一步：在哪写因子

在 ResearchEngine/factor/ 下新建一个 .py 文件，写一个 FactorLibrary 子类。每个公开方法就是一个因子，方法里用 self.close 直接拿数据：

# ResearchEngine/factor/my_lib.py
from quantcore import FactorLibrary

class MyLib(FactorLibrary):
    author = "你"                          # 作者设一次，本库所有因子共用

    def myalpha(self, window=5):           # 这就是一个因子，名字叫 myalpha
        return self.close - self.close.rolling(window).mean()
    
    def momentum(self, window=20):         # 再加一个因子
        return self.close.pct_change(window)

可用的数据字段（取决于你的 price.CSV 有哪些列，你的真实数据有）：
- self.close / self.open / self.high / self.low
- self["market_cap"]（总市值）

▎ 参考 ResearchEngine/factor/alpha_library.py，里面已有 alpha101（动量）和 alpha158（反转）两个现成示例。

第二步：跑实验

打开 ResearchEngine/examples/main.py，改这两行指向你的库和因子：

loader.load("my_lib")                    # 你的文件名（不含 .py）
factor = loader.factors["myalpha"]       # 挑一个方法名跑

然后在终端运行（用 ygquant 环境）：

"D:/Devtools/anaconda3/envs/ygquant/python.exe" ResearchEngine/examples/main.py

系统自动做什么

Experiment.run() 自动完成五步：

1. 读 config.yaml 配置（数据路径、调仓频率、分位数、存储方式等）
2. 读 data/price.CSV（Wind/Choice 宽表，自动按字段拆面板）
3. 调你的因子方法算因子值（整张宽表一次向量化算完）
4. 由因子值构多空分位组合 → 净值曲线
5. 算 10 个指标并打印：年化收益 / Sharpe / Sortino / Calmar / 最大回撤 / 波动率 / IC / RankIC / 胜率 / 换手

结果在哪看

- 终端直接打印指标摘要
- ResearchEngine/output/<因子名>/ 下有完整结果：metrics.csv（指标）、equity_curve.csv（净值）、factor_values.csv（因子值）、positions.csv（持仓）、meta.json

一句话总结

因子写在 ResearchEngine/factor/ 的 FactorLibrary 子类里（一个方法 = 一个因子，用 self.close），main.py 里 load 库 + factors["名字"] 选一个，跑 main.py 即出全部指标。
