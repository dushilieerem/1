# KnowledgeHub 使用说明

> **页面入口（推荐）：** 知识库平台 → 头像 → **使用说明**（`/settings/guide`）  
> **API 目录页：** `/settings/api` · Swagger：`http://192.168.3.32:8766/api/kh/docs`  
> **前端：** `http://192.168.3.32:9531/`

## 五步上手

1. **建知识库** — 首页 /「知识库」创建集合，选类型与分块策略。  
2. **上传文档** — md/txt/docx/pdf 或粘贴正文。Word/纪要优先「按编号标题」或「按段落合并」；版式乱的 PDF 用「固定窗口」。扫描版 PDF 暂不支持。  
3. **启用 / 停用** — 停用文档不删切片，但不参与检索与问答。  
4. **检索测试** — 库详情 →「检索测试」验证命中。  
5. **聊天问答** —「聊天」关联知识库；无命中不编造。

## 检索与问答

| 接口 | 作用 |
|------|------|
| `POST /api/kh/search` | 只返回命中切片 |
| `POST /api/kh/ask` | 基于片段回答；无命中不调 LLM |

仅 `status=ready` 且 `enabled=true` 的文档参与。

## 权限

仅 **admin**；模型在「模型供应商」配置。未配 Embedding 时检索为关键词。
