## 一、这篇论文到底在干什么？

用一句话：

> **把美股那套「海量异象挖掘」搬到 A 股，但加了两道紧箍咒：多重检验 + 中国本土风险因子；再证明单因子不行时，多信号/机器学习合成仍然有用。**

它解决的不是「给我一个必赚因子」，而是：

1. A 股到底有多少「看起来显著」的单因子？  
2. 其中多少是假阳性 / 风险补偿？  
3. 中国异象和美股哪里不一样？  
4. 实务上更该做单因子还是合成？

## 二、务必盯住的关键点（重点标记）

### 关键点 1｜「显著」要过两道门，不能只看 t>1.96

| 门槛 | 市值加权 raw 显著数 | 市值加权 CH4 α |
|------|---------------------|----------------|
| t=1.96（常规） | 104 / 454 | 22 |
| t=2.85（多重检验） | **38** | **0** |

**对 SVQuant 的含义**：因子检测页如果只报 IC/分层收益的普通 t 值，会**系统性高估**「有效因子」数量。中长期应引入 FDR / 多重检验门槛，或至少在报告里并列「未调整 / 调整后」两套结论。

### 关键点 2｜风险模型要用「中国版」，尤其流动性

论文用 **CH3 / CH4**（Liu–Stambaugh–Yuan），CH4 = 市场 + 规模 + 价值 + **流动性**。  
许多交易类「异象」在 CH4 后消失 → 很可能是**流动性风险**，不是免费午餐。

**对照 SVQuant**：ResearchEngine 已有自建 FF3（规模/价值），但对标论文还缺：

- 显式的 **中国流动性因子**（或至少在归因里控制换手/非流动性）  
- 与论文一致的「大市值 70% / 剔微盘」股票池规则（防壳污染）

### 关键点 3｜中国 vs 美国：交易强、会计弱

- 中国显著率更低（样本短、噪声大）。  
- **存活信号里交易/流动性占比更高**；会计信号相对更弱（披露/信息环境）。  

**对 SVQuant 的含义**：

- `trading_lib`（换手、成交额等）方向正确，值得加深（如非流动性、Amihud 类）。  
- `value_lib` 有 EP/BP 等估值，但论文里大量 **盈利/投资类会计信号**（ROE、资产增长等）需要扎实的 `05_fundamental` → 因子字段贯通。

### 关键点 4｜单因子弱 ≠ 不能做；合成/ML 才是主菜

四种合成：**综合得分、多元回归、Lasso、随机森林**。  
后三者明显强于「最好的单变量」，且常能过多重检验 + 风险调整。

**对照 SVQuant**：

| 论文方法 | 平台现状 |
|----------|----------|
| 十分位/十分位多空 | ✅ 分层回测 / `FactorQuantileStrategy` |
| 综合得分 | ✅ 检测页加权/积/自定义组合；`FactorPortfolioStrategy` |
| 多元回归 / Lasso / RF | ⚠️ 无原生训练管线；qlib Alpha158/360 可当特征输入，缺系统化样本外训练层 |

### 关键点 5｜宏观状态会「开关」异象

异象收益与市场发展、会计质量、**流动性**、监管事件共振；散户换手推高异象。  

**含义**：同一因子在牛市高换手期与熊市低换手期表现可能完全不同 → 研究/产品应支持**分时段、分市场状态**评估，而不是只看全样本一条曲线。

### 关键点 6｜样本与可投资性边界

- 样本：**2000.07–2020.12**（读结论时注意：不含近年全面注册制、量化监管等新阶段）。  
- 主结果：**剔最小 30% + 剔科创板**；等权会放大小票效应，**市值加权**更接近机构可投结论。

把论文当成一条可复现流水线：

```text
┌─────────────────────────────────────────────────────────────┐
```

**SVQuant 上可落成的「最小复现路径」**：

1. 股票池：CSI300 / CSI500 / CSI1000 或「全 A 剔微盘」规则（需与数据侧对齐）。  
2. 跑一批官方因子库 + 自写会计因子 → `analysis_level=full`（分层 + FF3 + IC）。  
3. 筛出「看起来好」的因子 → **人为提高门槛**或批量做多重检验。  
4. 用检测页 / `FactorPortfolioStrategy` 做综合得分；ML 合成作为下一阶段 roadmap。

## 四、本地数据能帮上什么？（只读结论）

路径：`E:\quant-lab\NBQuant\data\a_share`（与 `E:\quant-lab\data\a_share` 目录结构相同）。

| 目录 | 内容 | 对论文复现 |
|------|------|------------|
| `01_meta/` | 日历、股票列表、行业等 | ✅ 上市日期、ST、过滤基础 |
| `02_universe/index_constituents/` | 指数成分（含沪深300/中证500/1000 等；部分带**最新权重**） | ✅ 股票池 / 基准；历史截面部分有 `*_history_long` |
| `03_market/daily/` | 日行情（含后复权等） | ✅ 交易类信号、组合收益 |
| `04_index/daily/` | 指数点位 | ✅ 基准收益；≠ 成分权重 |
| `05_fundamental/` | `lrb` 利润表、`valuation`、`indicators`、`statements` | ✅ **会计类信号原材料**（盈利/成长等） |
| `06_factor/` | 因子 catalog + panels | ✅ 可直接对照/扩展信号列表 |

**已经比较对齐论文的部分**：

- 有行情 → 可做换手、动量、波动、流动性相关信号  
- 有基本面目录 → 具备 ROE/成长等会计异象的数据基础（需确认字段覆盖率与点-in-time）  
- 有指数成分 → 可做「指数内」或宽基可投宇宙；沪深300/中证1000 等有成分+权重快照  

**明显缺口 / 注意**：

| 论文需要 | 本地现状 |
|----------|----------|
| 完整历史**成分权重**时序 | 多为最新截面权重；历史多为代码列表 |
| 中证全指成分 `000985` | 先前成分侧缺失（指数日线也曾断档） |
| 分析师、股吧、搜索、新闻 | 论文有另类信号；本地 `a_share` 主包未必齐全 |
| CH4 流动性因子官方序列 | 需自建（用换手/非流动性构造） |
| 样本到 2020 之后 | 本地行情可更新到近年，**可做样本外延拓**，这是相对论文的优势 |

> 说明：SVQuant WebApp 生产环境主要打 **YGQuant ResearchEngine** 取数；本地 `a_share` 更适合 **离线复现论文 / 补字段 / 对照校验**，不必改平台即可先做研究脚本。
