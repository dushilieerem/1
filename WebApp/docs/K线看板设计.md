# SVQuant 数据栏 · K 线看板设计（TradingView 风）

> 状态：**入口已改**（下拉 · K 线面板默认 000001 · 搜代码预览）· 2026-07-28  
> 落地位置：导航「数据」下拉 → `K线面板` `/data/kline`  
> 数据源：同事 YGQuant ResearchEngine `192.168.3.64:9527`（经前端 `/yg-api` 代理）  
> 文档：`factor/06-research-api.md` · `factor/market-data-symbols.md` · `factor/market-data-daily.md`  
> 边界：SVQuant **本机不存行情**；列表/K 线只读 RE 已发布市场数据，**不落 PostgreSQL / SQLite**。

## 1. 接口实测（先通不通）

基址：`http://192.168.3.64:9527`

| 接口 | 结果 | 备注 |
|------|------|------|
| `GET /api/health` | ✅ 200 | `version 2.0.0` |
| `GET /api/market-data/symbols` | ✅ 200 | **5749** 只代码；字典序；**无** `.SH/.SZ` 后缀；**无**名称/行业 |
| `GET /api/market-data/daily/{symbol}` | ✅ 200 | 裸码可用，如 `000001`、`600519` |
| `GET .../daily/000001.SZ` | ❌ 404 | 文档示例带交易所后缀，**实机不认** |
| `start`/`end` 过滤 | ✅ | 含边界；未传返回全区间 |
| 倒置日期 | ✅ 422 | 符合文档 |
| 不存在代码 | ✅ 404 | 符合文档 |

**日线字段（仅此）：** `date / open / high / low / close`  
**明确没有：** 成交量、复权切换、实时盘口、名称、市值、PE/EPS、行业、涨跌停标记。

样例：`000001` 全区间约 **2263** 根（`2017-01-03`～`2026-04-30`）；`bars[]` 仅 OHLC。

> OpenAPI 已挂：`/api/market-data/symbols`、`/api/market-data/daily/{symbol}`。  
> 仓库里 FEAT 旧版 `06-research-api.md` 尚未写 symbols；以 `WebApp/backend/factor/` 下三份为准。

## 2. 和 TradingView 的能力差距（必须先对齐预期）

你截图里的 TV「全市场表」列了很多基本面列。对照同事**现在能调的**：

| TV 常见列 / 模块 | 能否直接从 RE 拿 | 本期怎么做 |
|------------------|------------------|------------|
| 代码 Symbol | ✅ symbols | 列表主列 |
| 名称 / 交易所 / 行业 | ❌ | 占位或本地轻量映射（二期）；概览先显示代码 |
| 最新价 / 涨跌 / 涨跌幅 | ⚠️ 需算 | 对「当前页可见行」拉近端日线末两根推算（懒加载） |
| 成交量 / 相对量 | ❌ | **不做**（接口无 volume） |
| 市值 / PE / EPS / 股息 | ❌ | **不做**；表格不假装有 |
| 分析师评级 / 新闻 | ❌ | **不做** |
| 概览面积图 / 区间表现 | ⚠️ 需算 | 用日线 OHLC 前端算 1D/1M/… 与折线 |
| K 线蜡烛图 | ✅ daily | lightweight-charts 日线蜡烛 |
| 成交量副图 | ❌ | K 线页先不做量能；UI 留位「待同事补 volume」 |

**结论：** 能做成「TV 骨架 + 我们有数据的列」；**不能**一比一抄满 TV 基本面表，除非同事加快照/基本面接口。

### 建议跟同事补的接口（可选，不阻塞设计预览）

1. `GET /api/market-data/quotes?symbols=000001,600519` → 最新价、昨收、涨跌幅、名称（列表一页一批）  
2. daily 增加 `volume`（K 线副图）  
3. 可选：`name` / `exchange` / `list_date` 元数据

## 3. 信息架构（放进「数据」栏）

```
/data                      → 重定向 /data/kline
/data/kline                K 线面板（默认展示 000001.SZ 概览 + 搜代码/名称）
/data/watchlist            自选股组合（待开发占位）
/data/symbol/:code         个股概览（TV Overview 风；code 含交易所后缀）
/data/symbol/:code/chart   K 线超级图（TV Superchart 风）
```

导航：「数据」为下拉；**K线面板**进看板，**自选股组合**暂占位。

symbols 新结构：`{ symbol: "000001.SZ", name: "平安银行" }`；daily 推荐后缀，六位裸码仍兼容，响应含 `name`。

```text
导航「数据」▼
    ├─ K线面板（/data/kline）
    │      ├─ 默认：000001 概览（面积图 / 区间表现 / 关键统计）
    │      │         └─「查看 K 线图」→ .../chart
    │      └─ 搜代码 → 预览卡片 → 点进个股概览（/data/symbol/:code）
    │                                 └─「查看 K 线图」→ 日线蜡烛图
    └─ 自选股组合（/data/watchlist）待开发
```

```mermaid
graph TD
  Nav[导航 数据下拉] --> Kline[/data/kline]
  Nav --> Watch[/data/watchlist 待开发]
  Kline -->|默认| Def[000001 概览]
  Kline -->|搜索预览| Prev[代码卡片]
  Prev --> Ov[/data/symbol/:code]
  Def --> Chart[/data/symbol/:code/chart]
  Ov --> Chart
```

**涨跌色（已定）**：同事确认 **红涨绿跌**（A 股习惯），不做 TV 绿涨。

**日线覆盖（实测，非文档臆测）**

| 项 | 结论 |
|----|------|
| 面板起点 | 多数老股约 **2017-01-03**（同事说的 2017-01-01 起库；首个交易日常是 1/3） |
| 新股 | **上市日后**才有，例如 `300750` 自 2018-06-11、`688981` 自 2020-07-16 |
| 最新日期 | 抽测多只末日均为 **2026-04-30**，**不是**停在 2026-01-01 |
| 是否「上市→退市全历史」 | **否**：2017 年前上市的股票，RE 侧从约 2017 起裁；退市股若已不在 `symbols` 则列表看不到 |

因此：每只股票可画「其在 RE 已发布区间内」的日 K，一般是 **max(上市, ≈2017-01) → 当前数据末日（抽测到 2026-04-30）**，不是无限回溯到更早 IPO。

## 4. 页面设计

### 4.1 全 A 列表 `/data`（仿 TV 市场表）

**布局**

```
┌─────────────────────────────────────────────────────────────┐
│ 数据 · A股                                                  │
│ [搜索代码]  共 5749                                         │
│ 概览（本期唯一 Tab；预留：表现）                             │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│ 代码      │ 最新价*   │ 涨跌幅*   │ 区间高*   │ 区间低* / 数据止 │
├──────────┼──────────┼──────────┼──────────┼─────────────────┤
│ 000001    │  …懒加载  │ 红涨绿跌  │ 近1年高   │ 近1年低 / 日期  │
│ 000002    │  …        │           │           │                 │
│ …分页 50～100 行/页                                         │
└─────────────────────────────────────────────────────────────┘
* 由 daily 近端推算；滚动/翻页时再请求，禁止一上来 5749 次全历史。
```

**交互**

- 搜索：前端过滤 `symbols`（已内存一份列表，可缓存 session）  
- 排序：先支持按代码；有报价缓存后再按涨跌幅  
- 点击行 → `/data/symbol/000001`  
- 涨跌色：**红涨绿跌**（同事已确认）  

**本机 API（建议薄封装，不落库）**

- 前端直打 `/yg-api/api/market-data/...`（已有代理），或本机 `8766` 加只读转发（便于计日志）；**不写 SQLite 行情**。

---

### 4.2 个股概览 `/data/symbol/:code`

目标：好看、信息够用，**只用 OHLC 能撑起来的模块**。

```
┌──────────────────────────────────────┬────────────────────┐
│ 000001                    [查看K线图] │ 自选（二期）        │
│ 最新价  涨跌  涨跌幅                  │ 或关键 OHLC 统计    │
│ 数据区间：2017-01-03 ~ 2026-04-30    │                    │
│ Tab: 概览                            │                    │
│ ┌──────────────────────────────────┐ │ 关键统计            │
│ │  面积/折线（近价） + 区间切换     │ │ 昨收 / 开高低收   │
│ │  1D 1W 1M 3M 1Y YTD ALL          │ │ 振幅 / 近52周高低 │
│ └──────────────────────────────────┘ │ （均从日线算）     │
│ 区间表现条：1D / 1M / 1Y / YTD %     │                    │
│ （可选）近 1Y 月收益小柱             │                    │
└──────────────────────────────────────┴────────────────────┘
```

**可展示（有数据）**

| 模块 | 算法 |
|------|------|
| 最新价 / 涨跌幅 | 末日 close vs 前一日 |
| 概览折线/面积图 | 选定区间 close |
| 区间表现 Tab | 各窗口首尾 close 比 |
| 关键统计 | 开高低收、振幅、52 周高低、均价 |
| 数据完整性 | `date_range` + bars 数 |

**不做或灰显（无接口）**

- 新闻、分析师仪表盘、财务瀑布图、雇员、ETF 持仓、成交量  

主 CTA：**查看 K 线图** → `/data/symbol/:code/chart`

### 4.3 K 线图 `/data/symbol/:code/chart`（尽量贴近 TV Superchart）

**视觉**

- 白底、浅灰网格、细蜡烛；**红涨绿跌**
- 右侧现价标签；十字光标 + OHLC 浮层
- 底部时间轴；顶栏：代码、周期（本期仅 **日线 D**）、图表类型（蜡烛）
- 库选型：**TradingView lightweight-charts**（体感接近、实现成本低）
- 左侧画线工具：**二期**；MVP 只浏览 + 缩放拖拽

**数据**

- 默认拉全区间或近 5 年日线；`start`/`end` 可随视口懒加载（二期）  
- 无 volume → 不画量能副图；图表下方留一行说明：「成交量待 RE 补字段」  

**顶栏**

- 返回概览  
- 区间快捷：1M / 3M / 1Y / 5Y / ALL（过滤已拉 bars 或改请求）

## 5. 技术要点（实现时）

| 项 | 选择 |
|----|------|
| 代理 | 已有 `/yg-api` → `192.168.3.64:9527` |
| 代码格式 | **一律裸码**（与 symbols 一致）；UI 可推断深/沪仅展示，请求不加 `.SZ` |
| 列表性能 | symbols 一次缓存；报价按页并发（如 20～50，限流） |
| 图表 | `lightweight-charts` |
| 缓存 | 仅浏览器内存/session；**禁止**写入本机行情库 |
| 空态 | 404 股票友好页；503 提示 RE 数据目录不可读 |
