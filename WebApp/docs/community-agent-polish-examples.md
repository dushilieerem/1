```html
<p>中证全指样本内（截至2026年初）20日平均换手率因子IC为负，表明低换手股票整体呈现一定超额收益倾向；但分层回测显示多头组合收益平淡，空头组合表现更差，且未进行涨停、ST等常见过滤处理。</p>

<ul>
<li>因子定义：<code>Turnover_20D = mean(amp_volume / tradable_shares)</code>（20日日均换手率）</li>
<li>测试池：中证全指成分股</li>
<li>关键限制：未做涨停、ST、次新股等过滤</li>
</ul>
<p>欢迎分享实测经验——尤其关于流通市值阈值选择、叠加后的IC稳定性及分层收益变化。</p>
```

## 例 5 · 策略分享（带糊弄数字）

**分区：** 策略分享  

**代码（可选）：**
```python
def signal(self):
    ma5 = self.close.rolling(5).mean()
    ma20 = self.close.rolling(20).mean()
    return (ma5 > ma20).astype(float)
```

### 润色前

**标题：**
```
双均线金叉策略回测了一下好像赚了？
```

**正文：**
```
5日线上穿20日线就买，反向就卖，最多持5只，初始100万那种。

基准沪深300，好像多赚了几十个点？夏普多少忘了，最大回撤好像挺吓人。手续费先没加。

代码很土求轻喷，有没有人用过带滑点的版本。
```

### 润色后（实测）

**标题：**
```
双均线金叉策略回测：5日线上穿20日线买卖，等权持5股，未计手续费与滑点
```

**正文：**
```html
<p>本策略采用经典双均线金叉逻辑：当个股5日均线向上穿越20日均线时买入（等权，最多5只）；下穿则卖出。初始资金100万元，未计入手续费与滑点。</p>
<p>基准沪深300，相对超额约数十个百分点（依周期/池而定）。夏普与最大回撤原文未给出明确数值。</p>
<ul>
<li>规则：5上穿20买入；5下穿20卖出</li>
<li>仓位：等权，最多5只</li>
<li>假设：无手续费、无滑点</li>
</ul>
<p>欢迎交流含滑点/手续费的增强版本。</p>
```

**观感：** 把「好像赚了」收成可对照的规则说明，并标明未计成本——适合发帖。
