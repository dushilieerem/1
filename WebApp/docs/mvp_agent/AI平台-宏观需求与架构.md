## 1. 一句话

**AI 平台** = SVQuant 上所有「大模型能力」的统一产品层与治理层：对话、生成、多智能体流水线、额度与合规；**算力试算与行情仍走 ResearchEngine（RE），本机不存 bars。**

---

## 2. 目标用户与要解决的事

| 用户 | 要什么 |
|------|--------|
| 投研 / 量化同学 | 用自然语言推进研究：问、搜、出 idea、起草因子/策略、读报告 |
| 社区作者 | 润色/审校帖子，不代发 |
| 管理员 | 模型清单、额度、审计、敏感数据不出网 |

**成功标准（宏观）：** 用户能分清「在跟谁说话、产出是什么、下一步点哪」；每条 AI 产出可追溯到模型/来源。

## 5. 架构草图（宏观分层）

| 层 | 职责 |
|----|------|
| **体验层** | `/ai/chat`、`/factor/ai`、`/strategy/ai`、搜集/idea UI、社区 AI 按钮 |

| **工具 / 数据** | 资讯检索、（后）外网只读、KH（非一版搜集）、RE HTTP |
| **治理** | 额度（`ai_usage`） |

## 6. 需求要点清单（周四正文可展开）

1. **统一身份**：所有 AI 入口须登录；额度按用户/角色。  
2. **统一模型配置**：助手已多模型；生成类是否共用同一网关 — 需求里定。  
3. **产出契约**：对话气泡 / 代码草稿 / 证据包 / idea 列表 — 类型分清，可引用。  
4. **人工闸**：生成不自动检测；搜集→idea 默认可关掉 idea；社区不代发。  
5. **来源白名单**：与「信息搜集」文档一致（资讯 + 外网；官方源后置）。  
6. **可观测**：generation_id / run_id / 模型名可查。  
7. **目录**：新 Agent 落 `backend/ai/crews/`，见 [`AI-Agent目录整理方案.md`](./AI-Agent目录整理方案.md)
