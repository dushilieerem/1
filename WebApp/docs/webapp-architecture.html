因子服务是 WebApp 最重的一块：元数据在 Postgres / 磁盘，计算一律走 ResearchEngine。 两类 502 已改为异步入队；多开回测后点「检测」长时间白屏，卡在前端占位页 + 本机短接口排队，不是 RE 只有 2 个 worker。

1. 官方目录 factor_store · re_factor_catalog

  • 磁盘：backend/factor/*.py + index.yaml
  • 展开：factor_catalog_expand.py（jq_compat / qlib_alpha 等）
  • RE 快照：re_factor_catalog.py → PG re_factor_catalog_*
  • API：GET /api/factor/index · /api/factor/re-catalog
通常不触发 502；慢时多为 PG 读或首次 sync RE 目录。

2. 用户库 / 自定义 user_factor_store · user_library_store

  • PG：user_factors · user_libraries
  • 代码落盘：backend/factor/custom_lib/（按 owner 隔离）
  • 试算：factor_trial.py → RE /api/backtest/factor（同步 ~180s）
  • API：/api/factor/custom · /api/factor/custom/trial
试算若仍同步打 RE，会占 API 线程；批量时可能拖死短接口。

3. 检测项目 detect_store 502-A

  • PG：detect_projects · detect_runs（按 user_id 隔离）
  • 前端：openDetectPlaceholderTab → openOrCreateForFactor()
  • API：GET/POST /api/detect/projects · /api/detect/runs
  • 纯 PG 读写 + JWT，不打 RE
回测改异步后，建项目不应再被 RE 回测堵住。若仍裸 502：8766 进程挂了，或自定义试算 factor_trial 仍同步占线程。
旧因：同步回测占满 ThreadingHTTPServer 处理，Vite /api 连不上 → 裸 502，文案「本机 API 暂不可达」。 本机 API 不是 FastAPI，没有「默认 40 worker」这回事。

4. 因子回测 BFF re_backtest_jobs 502-B

  • 入口：POST /api/factor/re-backtest → 立刻返回 job_id
  • 队列：默认 MAX_INFLIGHT=8（环境变量 SVQUANT_RE_BACKTEST_INFLIGHT）
  • 轮询：GET /api/factor/re-backtest/{job_id}（前端 ~1.5s）
  • 转发：re_backtest_bff → RE /api/backtest/factor
同事 RE：FastAPI 默认同步线程池约 40。以前 inflight=2 是 WebApp 自己节流，不是 RE 只能跑 2 路。 现默认 8，给面板/试算/同事留余量，不要一次打满 40。
检测页 502 且带 JSON：才是 RE/网关饱和或超时。Vite 断连仍是裸 502。

5. 因子面板 dashboard_store

  • SQLite：output/factor_dashboard/metrics.sqlite
  • 只批跑官方公开库（PANEL_OFFICIAL_LIBS）
  • API：/api/factor/dashboard · /refresh · /status
  • 后台脚本逐因子打 RE，写 IC/夏普缓存
批跑与检测回测共用 RE；高并发时 RE 侧仍可能 502。

白屏节点（多开回测后点「检测」）

  • 卡点在前端占位标签，不是 RE 40 线程用尽
  • 点击同步 window.open(about:blank)，再 await 建项目
  • 8766 忙（轮询 + json 大包 + 试算）时，空白标签会干等
  • 跳转后新标签再拉一整份 React + re-catalog?all=1
占位页已写入「正在打开检测页…」；检测页加载不再只显示浅灰「加载中」。

502 / 白屏排查

  • ① Network：失败 URL 是 /api/detect/* 还是 /api/factor/re-backtest*
  • ② 裸 502 无 JSON → 8766 是否在跑（重启后才吃到异步队列）
  • ③ JSON error 含 RE → 才查 9527；同事说 40 线程指的是这一端
  • ④ 轮询 JSON 里的 queued/running/max_inflight：排队多 = WebApp 节流
  • ⑤ 自定义试算仍同步 ~180s，会拖短接口
