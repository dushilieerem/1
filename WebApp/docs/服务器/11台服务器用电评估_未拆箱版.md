## 二、先弄清一个容易算错的问题：冗余电源不能直接相加

例如服务器装有 **2×2000W PSU，工作方式为 1+1 冗余**：

-   不能直接认为服务器一定消耗 4000W；
-   两块 PSU 的"2000W"表示每个电源模块的额定输出能力；
-   1+1 的目的主要是冗余，一路或一块 PSU 故障后另一块仍能维持设备；
-   服务器真正的耗电取决于 CPU、GPU、内存、硬盘、风扇等负载。

因此，本次不能用"所有 PSU
铭牌瓦数简单相加"的方式计算实际电费或实际运行功率。

但是在做机房配电规划时，又不能只按平均耗电算，必须留出峰值和安全余量。

## 三、当前条件下的功率估算

### 1. G2280

Excel 中目前能看到 **2000W** 电源信息。

在无法拆箱确认的情况下，先将每台按 **最高约 2.0kW 的规划值**估算：

**5 × 2.0kW = 10.0kW**

> 这是用于配电容量预估，不代表服务器正常运行时一定持续消耗 2kW。

### 2. G5580

Excel 中能看到 G5580 相关的 **2000W** 信息，同时表内还出现 **2700W**
数据。由于目前无法确认 5 台 G5580 实际安装的 PSU
型号、数量以及冗余模式，因此不建议把一个数字写死。

先做两个规划档位：

-   较低档：5 × 2.0kW = **10.0kW**
-   保守档：5 × 2.7kW = **13.5kW**

正式上电前，以机器 PSU 铭牌为准。

### 3. 元脑 NF5688G7

当前外箱标签能确认 CPU、内存、硬盘，但**没有显示 GPU 型号和 PSU 功率**。

这台机器是目前最大的不确定项。GPU 服务器是否安装 8 张高功率
GPU，会让整机功率产生数千瓦差异。

因此现阶段不要把 NF5688G7 的功率写死，建议用三档情景做公司供电判断：

-   低情景：约 **3kW**
-   中情景：约 **6kW**
-   高情景：约 **9kW**

其中 9kW
只作为"未确认配置前的高功率预留情景"，不是说这台机器已经确认会消耗 9kW。

**建议容量 = 服务器规划功率 × 1.25**

得到：

### 当前阶段的建议

在所有机器仍未拆箱、NF5688G7 GPU/PSU 尚未确认的情况下：

**建议先问公司：机房是否至少还能提供约 40kW 的"可用 IT 配电余量"。**

注意这里说的是**剩余可用容量**，不是配电柜铭牌写着 40kW 就算够。

例如公司总容量 60kW，但现有设备已经用了 30kW，那么剩余只有约
30kW，就不能按"公司有60kW"判断。

## 五、换算成电流，大概是什么概念

### 220V 单相

公式：

**电流 A ≈ 功率 W ÷ 220V**

举例：

-   2kW ≈ 9.1A
-   2.7kW ≈ 12.3A
-   3kW ≈ 13.6A
-   6kW ≈ 27.3A
-   9kW ≈ 40.9A

这也说明 NF5688G7 如果属于高功率 GPU 配置，通常不能把整机理解成一个普通
10A/16A 办公插座负载，需要看它实际有几路 PSU、每路如何接 PDU。

### 380V 三相总配电

粗略计算公式：

**I ≈ P ÷ (1.732 × 380 × 功率因数)**

若按功率因数 0.95：

-   29.5kW ≈ 47A
-   32.5kW ≈ 52A
-   40.6kW ≈ 65A

这只是总量换算。实际还必须看三相是否平衡、每个支路断路器、电缆、PDU
和插座容量。

## 六、现在服务器箱子不能拆，还能看什么？

11

如果外箱其他面还有标签，可以继续找下面这些字段：

-   Product / Model / 型号
-   Configuration / 配置
-   PSU / Power Supply / 电源
-   Input / 输入
-   200--240V AC
-   10A / 16A / 20A 等输入电流
-   1600W / 2000W / 2700W / 3000W 等 PSU 功率
-   PSU 数量，例如 ×2、×4、×6
-   1+1、2+2、3+1 等冗余方式
-   GPU / NPU / Accelerator 型号及数量
-   Gross Weight / 毛重
-   Net Weight / 净重
-   Rack Unit / 2U、4U、5U、6U 等
-   装箱单号、销售订单号、产品编码

**尤其值得拍的是：每个不同型号箱子的所有标签。相同型号的 5
台不需要每台都重复拍，除非标签配置不一样。**

## 七、比继续看服务器箱子更重要：去看机房

接下来真正决定"公司供不供得住"的数据，大部分已经不在服务器箱子上，而是在公司机房。

### 1. 看 UPS

拍 UPS 正面屏幕和铭牌，重点找：

-   UPS 总容量：多少 kVA
-   UPS 有功容量：多少 kW
-   当前 Load：多少 %
-   当前 Output Power：多少 kW
-   输入电压
-   输出电压
-   输入/输出电流
-   三相每相负载
-   UPS 是否还有其他服务器共用
-   UPS 是单机还是并机/N+1

**最有价值的数据：UPS 总 kW + 当前已经用了多少 kW。**

例如： - UPS 可输出 80kW - 当前已有设备占 35kW - 理论剩余约 45kW

这时才有条件进一步判断新来的 11 台是否可以全部接入。

### 2. 看机房总配电柜

找机房供电对应的配电柜，**只看外部铭牌、开关标识和仪表，不要自行打开带电柜体。**

需要记录：

-   总开关额定电流，例如 63A / 100A / 125A / 160A / 250A
-   三相还是单相
-   电压：380V / 220V
-   当前 A/B/C 三相电流
-   是否有功率表，当前显示多少 kW
-   是否有电能质量/功率因数显示
-   服务器机柜对应哪些支路
-   每个支路断路器多少 A
-   有没有空余支路

最好拍： 1. 配电柜整体； 2. 总开关； 3. 仪表屏； 4.
服务器机柜支路开关标识。

### 3. 看服务器机柜里的 PDU

这是非常关键的一项。

每个机柜后面通常有竖着的 PDU。找 PDU 铭牌并拍清：

-   输入电压
-   最大输入电流
-   最大功率
-   16A / 32A / 63A
-   单相还是三相
-   插口类型和数量
-   是否有电流/功率显示
-   当前已经用了多少 A / kW

如果有 A、B 两条 PDU，两条都拍。

### 4. 看机柜电源插座和接口

服务器高功率 PSU 不一定使用普通家用插头。

需要看：

-   PDU 有没有足够接口
-   接口类型是否和服务器电源线匹配
-   每路 PDU 能承受多少 A
-   A/B 两路是不是来自真正独立的供电路径
-   有没有足够的空闲插位

不要使用普通插线板给服务器临时扩容。

### 5. 看机房空调

电够不代表一定能运行，服务器用掉的电最后基本都会变成热。

需要记录：

-   精密空调有几台
-   每台型号
-   铭牌制冷量（kW）
-   当前是否全部运行
-   是否有 N+1 冗余
-   机房当前温度
-   机柜进风温度
-   是否已有热点
-   冷热通道是否分离

如果新服务器最终接近 30kW IT 负载，可以理解为机房大约又增加接近 30kW
的持续热负荷，因此空调余量同样必须核算。

### 6. 看机柜本身

除了电，还建议检查：

-   机柜高度：42U / 47U 等
-   还剩多少 U 空间
-   机柜深度是否够
-   服务器导轨是否匹配
-   机柜承重
-   服务器箱体毛重/设备重量
-   GPU 服务器准备装在哪个机柜
-   重设备是否安排在机柜下部
-   前后门通风率
-   后方维护空间是否足够

### 7. 看机房上级供电

如果 UPS 和机房配电看起来都够，还要问物业/行政/电工：

-   公司变压器容量多少 kVA
-   公司当前峰值负载多少 kW
-   机房分配了多少容量
-   新增约 30--40kW 是否已经计入公司用电容量
-   是否需要新增电缆/断路器
-   是否存在需量、电费或配电容量限制

这一步主要让持证电工或物业确认，不建议非电气人员自行操作。

## 十一、当前结论

1.  现有信息足够做**第一版容量预算**，但还不足以批准 11 台全部上电。
2.  5 台 G2280 暂按约 **10kW** 的规划上限考虑。
3.  5 台 G5580 暂按 **10--13.5kW** 区间考虑，等待实际 PSU 铭牌确认。
4.  NF5688G7 是最大不确定项，外箱目前无法确认 GPU 和 PSU，暂按 **3/6/9kW
    三档情景**评估。
5.  11 台服务器当前规划功率约 **23--32.5kW**。
6.  加 25% 容量余量后，建议先检查公司是否还有大约 **29--41kW
    的可用机房供电能力**。
7.  在配置无法继续确认的情况下，下一步最有价值的工作不是继续研究纸箱，而是检查
    **UPS → 配电柜 → PDU → 空调 → 机柜空间/承重**。
8.  如果公司能确认机房仍有约 **40kW 以上真实可用的 IT 配电余量**，再结合
    PDU 支路、A/B 路和制冷量继续判断，才有意义。
9.  正式上电前，应让机房运维/持证电工复核实际线路、断路器、电缆、PDU
    和保护配置。
