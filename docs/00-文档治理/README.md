# 文档治理

本目录定义文档如何产生、评审、更新和归档，不承载某个具体业务能力。

## 入口

- [需求到交付工作流](需求到交付工作流.md)：主链路、分级投入和决策关卡。
- [文档更新规则](文档更新规则.md)：不同变化应回写到哪个文档。
- [Definition of Ready](Definition-of-Ready.md)：进入实现前的分级准入清单。
- [Definition of Done](Definition-of-Done.md)：完成交付时的验收清单。
- [FEAT功能包模板](文档模板/FEAT功能包模板.md)：功能包 README 的默认模板与拆分文件约定。
- [Initiative 模板](文档模板/initiative-proposal.md)：新 Initiative 的立项模板。
- [五层主流程图](主流程-需求到实现.svg)：需求、业务、架构、功能、实现的思考顺序。

## 治理边界

- 本目录只定义方法、模板和门禁；结论本身分别写入 `01-需求文档`、`02-架构文档`、`03-功能文档`、`04-项目管理` 和 `05-技术决策`。
- 任何会议结论、技术决策或实现发现，只要改变主链路结论，就必须回写到对应文档。
- 历史版本移动到 `99-历史归档/`，不在当前文档中用旧版本作为唯一依据。
