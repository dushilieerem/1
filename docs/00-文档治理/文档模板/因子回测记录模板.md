# 因子回测记录模板

> 用途：记录一批因子的定义、依赖、回测配置、结果、异常和研究结论。
>
> 使用方式：每次回测复制一份本模板；先填写“批次信息”和“结果概览”，再为每个因子填写一份“因子明细”。没有实际结果的字段不要猜测，统一填写“待补充”或“不适用”。

### 2.1 状态定义

| 状态 | 使用条件 |
|---|---|
| `正常` | 因子代码可执行，因子值有足够有效样本，回测结果和图表均生成。 |
| `异常-依赖缺失` | 因子公式基本完整，但缺少内置函数、工具库、数据字段或变量。 |
| `异常-公式错误` | 因子公式、变量名、字段名或计算逻辑错误，无法编译或无法得到正确结果。 |
| `异常-数据异常` | 因子值大量/全部为 `NaN`、无穷值、有效样本不足或结果明显失真。 |
| `待复测` | 已完成修改，但尚未在同一批次配置下重新运行。 |

## 5. 回测前检查清单

- [ ] 因子名称、定义、经济含义和参数已填写。
- [ ] 因子只返回“交易日 × 股票”的宽表，日期和证券索引与输入一致。
- [ ] 直接字段均存在于数据面板；派生字段均已明确计算方式。
- [ ] 内置函数、工具库和变量均已注册或在运行环境中可用。
- [ ] 未使用未来数据，包括 `shift(-N)`、`bfill` 或其他向前填充造成的信息泄露。
- [ ] 滚动窗口、`min_periods`、除零保护和缺失值处理已说明。
- [ ] 已检查因子有效率、无穷值、极值和首个有效日期。
- [ ] 证券池、基准、复权口径、回测区间、调仓频率和分组数已记录。
- [ ] 佣金、印花税、滑点和过滤规则已记录；不能用“默认”代替实际数值。
- [ ] IC/IR、分层收益、净值、回撤和换手的计算口径已记录。
- [ ] 正常结果有图表和结构化产物；异常结果保留错误信息或日志。
- [ ] 结论区分“公式正确”“回测成功”和“因子有效”，不能把三者等同。

## 6. 研究结论使用边界

本模板用于记录因子计算和历史回测结果。单次回测通过不代表因子具备稳定预测能力，也不代表可直接用于实盘。正式纳入因子库前，至少应补充样本外验证、参数敏感性、交易成本敏感性、行业/规模暴露检查和多因子相关性检查。
