# 文档更新规则

| 变化 | 必须更新 |
|------|----------|
| 产品定位、目标用户、商业模式改变 | `docs/02-product/产品定位.md`、产品需求文档 |
| 新增、合并、拆分产品能力 | `docs/02-product/产品能力地图.md` |
| Initiative 优先级、阶段或资源改变 | `docs/02-product/产品路线图.md`、Portfolio Backlog |
| Feature 新增或状态改变 | Portfolio Backlog、Feature README |
| 公共接口、数据流或模块边界改变 | Feature 技术设计、`05-architecture/` |
| 重大且长期有效的技术选择 | `06-decisions/ADR-XXX-*.md` |
| Sprint 范围改变 | `docs/07-delivery/sprints/current.md` |
| Feature 完成或版本发布 | Verification、发布记录、状态快照 |

## 状态约束

统一状态为：`待分析 → 待决策 → 已批准 → 待开发 → 开发中 → 待验收 → 已完成`。

补充终止状态：`已暂缓`、`已拒绝`、`已取消`。

## 单一事实来源

- 能力边界：产品能力地图。
- 计划顺序：产品路线图。
- Initiative/Feature 状态：Portfolio Backlog。
- 功能详细定义：Feature 文档包。
- 已交付事实：Verification 和发布记录。
