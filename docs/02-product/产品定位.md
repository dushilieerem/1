# SVQuant 产品定位

> 本文档定义 SVQuant 的产品定位与核心价值主张，供老板与团队对齐方向。
> 关联：`产品需求文档.md`（完整 PRD）、`用户画像.md`、`竞品分析.md`

---

## 1. 一句话定位

**SVQuant 是一个以 AI 为核心驱动的一站式 A 股量化投研平台。**

让量化研究者——无论 coding 水平高低——都能借助 AI，把对市场、行业、政策的洞察转化为可验证的量化策略。

---

## 2. 我们解决什么核心问题？

### 2.1 市场现状

当前量化投研市场的主要平台存在三个共性问题：

| 问题 | 表现 | 严重程度 |
|------|------|---------|
| **AI 渗透浅** | 聚宽、米筐的 AI 仅停留在代码补全，BigQuant 停留在 AutoML，没有端到端 AI 研究助手 | ⚠️ 高 |
| **链路割裂** | 数据获取、因子计算、策略回测、绩效归因散落在不同工具或平台模块中 | ⚠️ 高 |
| **行业/政策分析缺失** | 现有平台只做数字分析，缺乏对行业景气度、政策走向的定性+定量融合分析 | ⚠️ 中 |

### 2.2 我们的切入点

```
AI 全链路研究助手 + 行业政策分析
         ↓
   双引擎回测（向量化+事件驱动）
         ↓
   数据基础设施（对标聚宽/米筐）
```

从「AI 全链路」和「行业政策分析」两个差异化点切入，基础设施不拖后腿。

---

## 3. 产品愿景

**"AI 赋能，量化投研。"**

让每一位量化研究者都能：
1. 用自然语言与平台对话，生成策略、解读结果
2. 在一个平台完成数据→因子→策略→回测→分析→报告的完整闭环
3. 看到其他平台看不到的东西——行业景气度、政策影响

---

## 4. 公司三大宗旨在本产品中的体现

| 宗旨 | 产品体现 |
|------|---------|
| **① 最大化 AI 能力** | AI 生成策略/因子代码、解读回测结果、归因分析、自动生成投研报告 |
| **② 全面分析行业和政策** | 内建行业分类、政策事件库、AI 自动追踪并解读政策影响 |
| **③ 基础量化设施不低于竞品** | A 股全市场数据、双引擎回测、IC/IR/分层/归因——对标聚宽/米筐同级别 |

---

## 5. 目标市场

- **市场**：A 股量化投研市场
- **用户**：量化开发者、投研团队、私募
- **形态**：CLI/SDK → Web SaaS（三阶段演进）
- **商业模式**：SaaS 订阅（免费版 → 个人专业版 → 团队版 → 机构版）

---

## 6. 不做什么（边界）

| 不做的 | 原因 |
|--------|------|
| 港美股/期货实盘交易 | 首期聚焦 A 股，实盘延后 |
| 高频/Tick 级策略 | 算力成本过高，非目标用户需求 |
| 投顾/荐股服务 | 合规边界，AI 不做投资建议 |
| 自研行情数据源 | 依赖第三方授权数据 |

---

## 7. 产品阶段演进

```
阶段一（当前）：投研核心
  CLI/SDK 形态，跑通研究闭环

阶段二：行业分析与实盘
  模拟盘、组合管理、风控、行业分析深化

阶段三：AI 平台
  Web SaaS、多租户、AI Agent 深化
```
