# SVQuant 产品路线图

> 路线图管理 Initiative 的阶段与先后顺序；具体 Feature 状态以 Portfolio Backlog 为准。

## Wave 1：投研核心

目标：跑通“数据模块 → 研究模块（因子/策略）→ 回测 → 分析 → 报告”的研究闭环。

- QuantCore 核心量化基础设施
- ResearchEngine 研究编排与 API
- 因子研究与策略回测基础能力
- AI 策略生成和 AI 回测解读

## Wave 2：新闻、行业分析与实盘/模拟盘

目标：从研究延伸到模拟和真实交易，并深化行业政策差异化能力。

- 新闻、公告、研报、行业与政策事件能力
- 模拟盘、组合管理和风险控制
- 事件驱动回测完善
- 券商接入与实盘执行

## Wave 3：用户、社区与 AI SaaS 平台

目标：形成可商业化的多租户 AI 投研平台。

- Web 工作台
- 用户、组织、权限、资产隔离和计费
- 团队协作与社区
- 多步 AI 研究 Agent

## 调整原则

路线图调整必须说明商业原因、被提前或延期的 Initiative、资源影响和新的成功指标。
