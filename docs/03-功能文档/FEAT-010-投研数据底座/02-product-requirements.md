# Product Requirements：投研因子数据底座

## 用户故事

1. 作为量化研究员，我希望财务因子只在财报公告后可见，以便回测不使用未来信息。
2. 作为数据负责人，我希望每个字段的来源、单位、报告期和修订版本可追溯，以便审计数据质量和授权。
3. 作为因子开发者，我希望用统一的日频面板访问字段，并在字段缺失时收到准确错误信息。
4. 作为回测系统维护者，我希望后复权价格与流动性形成固定数据集，避免运行时误选价格口径。
5. 作为 WebApp 用户，我希望 K 线看板使用真实未复权 OHLC，且展示数据采集不浪费额度下载无关字段。

## 数据范围

| 数据域 | MVP | 后续 |
|---|---|---|
| 日线量价、估值、市值 | 已有，持续质检 | 分钟线与更高频数据。 |
| 财务三表 | 原始披露记录、公告日、TTM/单季点时面板 | 预测与修订深度覆盖。 |
| 复权与交易状态 | 后复权回测行情、未复权展示行情、复权因子、上市/退市/停牌 | 前复权行情、停复牌原因、证券事件详情。 |
| 市场基准 | 全 A 流通市值加权日收益 | 风格风险模型基准版本。 |
| 行业 | — | 申万/聚宽/证监会历史分类。 |
| 预期与资本结构 | — | 分析师预测、分红、优先股、债务明细、无风险利率。 |

## 业务规则

- 财务原始记录必须含 `symbol`、`report_period`、`announcement_date`、`source_version` 与字段单位；缺任一关键元数据不得进入点时面板。
- 每个交易日的字段值仅可使用 `announcement_date <= trade_date` 的最新可见版本；同一报告期修订时采用最新已披露版本。
- TTM 仅由当时已公告的四个季度数据计算；数据不足时返回空值，不估算、不回填。
- 后复权、未复权行情与 `adj_factor` 必须明确记录口径和计算公式，调用方不得静默替换价格口径。
- 全 A 历史证券集合由每日 iFinD `p03291`“板块成份”在市板块（`blockname=001005010`）、已摘牌板块（`blockname=001005334011`）与退市整理板块（`blockname=001005334025`）三张快照合并得到；不按历史交易日重复下载全 A 成份。
- 全 A 证券主表只保留 iFinD `p03291` 实际返回的 `thscode` 和证券名称；在市、已摘牌快照必须非空，退市整理快照允许为空（iFinD 的 `-4001 / no data` 按空快照留存）。同一目标日三类快照之间必须不存在相同 `thscode`，发现任意交集即报错，不以状态优先级覆盖异常。通过校验后直接联合三张列表，不要求下载日期 × 证券矩阵。
- 行业分类与证券状态必须是按日期可查询的历史记录，最新静态映射不能用于历史中性化或行业因子。
- iFinD 指数权重只请求证券代码与权重字段；每个指数分别输出“日期 × 股票”宽表，缺席成分保留为空，不填零，权重保留供应商返回的百分比口径。
- iFinD 指数价格使用 `history_data`，每个请求只含一个指数代码与 `high,open,low,close`，不传复权参数，不请求成交量、成交额或换手率；输出列统一为 `date,open,high,low,close`。
- 指数权重与指数价格统一归属 `index/` 数据域，但分别写入 `index/index_weights/` 与 `index/index_price/`，不得合并成同一 CSV 或 Parquet。
- 指数最终产物必须分别命名为 `index_weights_<index>.csv/.parquet` 与 `index_price_<index>.csv/.parquet`；禁止只用 `<index>` 作为文件名。
- iFinD `market_data` 只请求后复权 OHLC（`CPS: "1"`）以及独立的不复权 `volume,amt,turn`，产物固定供回测使用，不再接受复权方式选择。
- iFinD `unadjusted_price` 只请求不带 `CPS` 的 `open,high,low,close`，产物固定供 WebApp K 线展示，不请求、不合并 `volume,amt,turn`。
- 当前不提供前复权下载入口；历史目录即使存在也不得由上述两条流程读取或写入。
- iFinD 每日总更新在刷新交易日历后，必须遍历脚本内可直接维护的指数代码列表，更新其中全部指数的权重与价格；每个指数资产以及回测行情、WebApp 未复权行情均按各自完整 CSV 的最大交易日独立计算缺口，补齐其下一交易日至 `as_of` 的全部实际交易日。多日缺口必须一次合并写回，不能只处理 `as_of` 或逐日重复重写完整宽表。全 A 证券主表只需按不晚于 `as_of` 的最新交易日更新一份快照。
- 每日总更新没有新增交易日且日历 Parquet 不早于 CSV 时，不得重复转换日历 Parquet。全 A 证券池的目标快照日期、CSV 和 Parquet 文件签名均与上次成功完成标记一致时，必须整步跳过 iFinD 下载、raw/CSV 重放和 Parquet 转换；完成标记缺失、损坏、日期不符或任一产物签名不符时必须重新生成，不能仅凭文件存在就跳过。
- Provider 缺少字段时抛出字段名列表；不得以零、当日值或未来值替代。
- 字段名、单位、口径和可见性以 `05-field-dictionary.md` 为准；数据资产、授权状态和发布验收以 `06-data-catalog.md` 为准。

## 验收标准

1. 给定同一财报的公告前后两个交易日，公告日前财务面板为空，公告日及之后可见；修订公告后值正确切换。
2. TTM、同比和单季因子夹具在指定披露序列上产生确定结果，且无未来数据。
3. 每个 MVP 字段能查到来源、单位、覆盖区间和版本；字段字典自动校验名称唯一性。
4. 后复权回测行情、未复权展示行情、复权因子、停牌、上市状态和全 A 市场收益可按各自产物契约读取。
5. 请求不存在字段时返回明确异常，既有量价因子与回测不回归。
6. 数据质量任务输出字段覆盖率、日期连续性、证券覆盖和异常值统计。
7. 每次可用数据发布均含清单、字段字典版本、文件哈希和质量报告；任一因子依赖的资产未处于 `ready` 状态时，加载失败信息包含字段名和数据资产 ID。
8. 当 `SVQUANT_DATA_DIR` 指向 `MarketData/` 根目录时，历史字段面板、指数成分和基准行情可从 `current/` 目录读取；旧版扁平 Parquet 目录仍可读取，且回测 API 返回有效净值与基准曲线。
9. 当退市整理板块无证券且 iFinD 返回 `-4001 / no data` 时，任务生成可重放的空快照并继续；在市或已摘牌为空仍失败，三类快照出现任意重复证券代码仍失败。
10. 回测行情命令的 iFinD 请求固定为后复权 OHLC 与流动性两组，输出包含七个标准字段；命令行不存在前复权或未复权选项。
11. WebApp 未复权价格命令的所有请求都只含 OHLC 且无 `CPS`，输出只有四个价格字段；测试应证明其不会访问 `market_data/raw/liquidity`。
12. `sources/ifind/` 根目录不直接生成 CSV、Parquet 或原始响应；每条采集管道只读写自己的业务子目录，迁移前遗留数据进入只读归档且不再参与重放。
13. 指数价格请求体与已确认超级命令一致：`codes` 为单个指数，`indicators` 固定为 `high,open,low,close`，且无 `functionpara`；CSV/Parquet 只包含标准化 OHLC。
14. 原 `sources/ifind/index_weights/` 完整迁入 `sources/ifind/index/index_weights/`，迁移前后文件数量与字节数一致，代码和文档不再引用旧路径。
15. 将权重和价格文件复制到同一目录时，文件名仍可直接区分数据产品且不会发生覆盖。
16. 当指数权重、指数价格、回测行情或 WebApp 未复权行情落后多个交易日时，直接运行每日总更新会从该资产现有最大交易日的下一交易日连续补至 `as_of`；各资产进度不一致时分别计算，且完整 CSV 每项最多批量写回一次。
17. 每日指数范围由 `everydayupdate.py` 内单一指数代码列表声明；增删列表项后无需修改下载、CSV 或 Parquet 编排，直接运行总更新即处理列表中的全部指数。命令行可临时覆盖该列表用于单指数排障。
18. 连续两次以同一最新交易日运行每日总更新时，第二次不读取或写入日历 Parquet，不请求或重放全 A 三类快照，也不读取或写入证券池 CSV/Parquet；删除、修改任一证券池产物或更换目标日期后会自动恢复完整生成流程。
