# FEAT-024：iFinD 宽表规范与渐进替换

- 状态：已批准
- 所属 Initiative：INIT-001 投研核心
- 所属能力：数据 / 研究基础设施
- 优先级：P0
- 关联 Feature：FEAT-010 投研因子数据底座
- 批准日期：2026-08-11

## 1. 价值与范围

### 背景

现有 AkShare 数据已经能够支持研究验证，不需要等待 iFinD 全量基本面完成后一次性切源。当前目标是继续使用可用数据，将已经下载并验证的 iFinD 行情、估值和状态字段逐步写入活动数据版本。

SVQuant 的回测数据是只读历史快照，并且价格、成交量、成交额和换手率通常一起加载。Parquet 本身支持列选择，因此没有必要为七个高度相关字段维护七个独立文件。现有 iFinD `market_data_hfq.parquet` 的业务分组方向正确，需要补齐文件边界、字段清单、版本和读取规范。

### MVP 范围

**必须做**：

- 固定“一个业务域一个多字段宽表”的文件规格。
- `market_data.parquet` 保存后复权 OHLC、成交量、成交额和换手率。
- `daily_basic.parquet` 保存市值、股本和估值。
- `security_status.parquet` 保存上市状态、行业、涨跌停状态、ST 和 `is_suspended`。
- `unadjusted_price.parquet` 独立保存未复权 OHLC。
- 支持 AkShare 与 iFinD 按字段渐进替换，并在 manifest 记录每个逻辑字段的来源。
- 发布版本和服务器内存快照只读；更新生成新版本，不原地修改旧数据。

**明确不做**：不统一供应商单位，不对 iFinD 数值做百分比、金额或股数换算；不在存储层填充缺失值；不等待全部财务和基本面数据完成；不将行情、基本面、状态、指数和元数据塞进一个无边界的超级宽表；不为了回测读取建设数据库。

### 用户价值

- 研究员可以马上使用现有数据，不被 iFinD 下载进度阻塞。
- 回测常用字段集中读取，文件数量和服务启动 I/O 更少。
- 每个文件有清晰业务含义，后续基本面扩展不会污染行情表。
- 历史版本不可变，单次回测始终绑定一致的数据快照。

### 决策

方案已于 2026-08-11 批准。优先完成三个研究宽表和一个展示宽表，再接入只读内存快照与共享回测进程池。

## 3. 计划与里程碑

| 任务 | 交付物 | 复杂度 | 预计人天 |
|---|---|---:|---:|
| 固化三个研究宽表 schema | `market_data/daily_basic/security_status` 字段契约 | 2 | 1 |
| 生成候选多字段宽表 | AkShare 基线 + iFinD 渐进覆盖的新 release | 3 | 2 |
| 增加 `is_suspended` | 停牌字段映射/生成和读取测试 | 2 | 1 |
| 扩展持久化 Provider | 多文件两级列扫描、字段投影和兼容读取 | 3 | 2 |
| 更新 manifest 与发布切换 | 字段级来源、哈希、不可变版本和回滚 | 3 | 2 |
| 真实因子和策略回测 | 行情、估值、行业、停牌场景验证 | 3 | 1.5 |
| 首日股票池固定与展示行情切源 | 点时权重解析、未复权行情 API、回归测试 | 2 | 1 |
| 进程级内存快照 | 服务启动预加载、请求复用、版本信息 | 3 | 2 |
| 共享回测进程池 | Linux 预加载后 fork、并发上限、内存验证 | 4 | 3 |

预计 14-15 人天；若只完成磁盘宽表和单机回测验证，预计 7-8 人天。

开发顺序：三个研究宽表 → Provider/manifest/发布切换 → 真实回测 → 只读内存快照和 Linux 共享 worker 池。当前已完成首日股票池固定解析与 `/api/market-data/` 未复权展示行情切源；指数动态注册、进程级内存快照和共享 worker 池仍是后续任务。

里程碑：

- M1：三个研究宽表和一个展示宽表 schema 固定。
- M2：候选 release 可被 Provider 按字段读取，`is_suspended` 可用于回测。
- M3：真实回测通过并支持 release 级回滚。
- M4：服务器正常请求只读取共享内存快照。
- M5：多用户压力测试期间不发生重复 Parquet 读取或基础数据副本膨胀。

## 4. 核心结论

1. `panels/market_data.parquet` 保存后复权价格和流动性七个字段。
2. `panels/daily_basic.parquet` 保存日频市值、股本和估值字段。
3. `panels/security_status.parquet` 保存上市状态、行业、涨跌停、ST 和是否停牌字段；`is_suspended` 由 `listed_status` 派生，`limit_status` 仅表示涨跌停原始状态。
4. `display/unadjusted_price.parquet` 单独保存 WebApp 未复权 OHLC。
5. `benchmark/index_weights_<index>.parquet` 同时保存指数权重和历史成分，不再单独保存 constituents 表。
6. `universe/a_share.parquet` 保存静态全 A 股票池列表。
7. 发布文件不可修改；数据更新生成新版本，验证后整体切换活动目录。
8. 服务器启动时将选定版本转换为按字段只读内存数组，正常回测不再读取 Parquet。
