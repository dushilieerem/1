# 回测系统功能需求

> 本文档定义 SVQuant 回测系统（Backtest Engine）的功能需求与设计约束。
> 关联：`../../01-需求文档/产品定位.md`、`../../02-架构文档/system_architecture.md` §3（双引擎设计）、`../FEAT-003-回测适配层/03-technical-design.md`（适配层设计）
> 当前状态：Native 自研向量化回测已落地；事件驱动日频内核已启动，本地可信开发范围内支持 A 股现金多头基础规则，API 与点时基本面待实现。

---

## 1. 背景与目标

### 1.1 为什么需要双引擎？

回测存在两类计算需求，单引擎无法同时满足：

| 需求 | 特点 | 适合引擎 |
|------|------|---------|
| 因子快速验证 | 批处理、矩阵运算、对速度要求高 | 向量化（VectorEngine） |
| 复杂策略模拟 | 逐根推进、条件单、T+1/涨跌停 | 事件驱动（EventEngine） |

### 1.2 业务目标

- 用户可根据需求在双引擎间切换，因子代码零改动
- 单次因子选股回测（3 年数据）≤ 10s
- 支持 A 股完整交易规则（T+1、涨跌停、交易时间、最小交易单位）

## 3. 回测流程

```
用户策略代码（因子逻辑）
       ↓
  IStrategy.generate_signals()
       ↓
  目标权重信号（日期 × 标的 矩阵）
       ↓
  IBacktestEngine.run(signals, config)
       ↓
  ┌──────────────────────────────────┐
  │ VectorEngine（向量化快速回测）    │
  │ 或 EventEngine（事件驱动精确回测）│
  └──────────────────────────────────┘
       ↓
  BacktestResult（净值 + 持仓 + 成交）
       ↓
  MetricEngine.compute() → 绩效指标
```

## 4. 适配层架构

```
ResearchEngine（实验编排）
       │  Experiment.run()
       ▼
IBacktestEngine ←── 适配器契约
       │
  ┌────┴────────────┐
  │                  │
  NativeEngine（自研实现）
```

**切换后端** = 改一行配置：

```yaml
backtest:
  engine: native
```

## 5. A 股市场规则（V2 事件驱动）

| 规则 | 说明 | 优先级 |
|------|------|--------|
| T+1 交易 | 当日买入股票，最早 T+1 日可卖出 | P1 |
| 涨跌停限制 | 主板 10%，科创/创业板 20% | P1 |
| 最小交易单位 | 100 股/手 | P1 |
| 交易时间 | 9:30-11:30, 13:00-15:00 | P1 |
| 佣金 | 默认万分之 2.5 | P1 |
| 印花税 | 卖出时千分之 1 | P1 |
| 滑点 | 可配置，默认 0.1% | P1 |
| 停牌处理 | 停牌期间不可交易 | P2 |

## 6. 性能目标

| 场景 | 目标 | 备注 |
|------|------|------|
| 单因子回测（5000 标的 × 3 年） | ≤ 10s | 向量化引擎 |
| 多因子组合回测（10 因子 × 5000 标的） | ≤ 30s | 向量化引擎 |
| 事件驱动回测（1 策略 × 3 年） | ≤ 60s | 事件驱动引擎 |
| 参数优化（100 组参数） | ≤ 5min | 并行优化 |

## 7. 依赖关系

```
ResearchEngine ──> BacktestEngine ──> DataEngine
                      │                     ↑
                      │                  IDataProvider
                      │
                      ▼
                 MetricEngine
                 
BacktestEngine 依赖:
  - IStrategy (策略信号)
  - IDataFeed (行情数据)
  - ICalendar (交易日历)
  - IMetrics (绩效指标)
```
