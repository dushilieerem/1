# FEAT-010：投研因子数据底座

- 状态：待批准
- 所属 Initiative：INIT-001 投研核心
- 所属能力：数据 / 因子研究
- 优先级：P0
- 宏观影响：L1（补齐既有数据与因子研究能力，不改变产品定位或模块边界）
- 提出日期：2026-07-22

> 当前仓库边界（2026-09-17）：`marketdata`、数据清单、质量报告和回测所需的数据读取由独立 ResearchEngine 在部署侧持有；SVQuant 只通过 ResearchEngine HTTP API 使用数据和研究结果。本 Feature 在 SVQuant 中保留字段契约、产品展示和跨仓库集成说明。

## 1. 价值与范围

### 背景

ResearchEngine 当前使用的日线行情覆盖 OHLC、成交量、成交额、换手率、市值、股本、PE/PB/PS、ST 与涨停等字段，已支撑技术、风险和情绪类聚宽兼容因子。基础、质量、成长、每股和大部分风格因子还依赖点时财务报表、历史行业分类、复权与交易状态、全 A 市场基准、分析师预期及资本结构数据。

如果只按财报期末日期填充财务数据，会把尚未公告的信息带入历史回测，产生未来函数。当前必须先建立“原始披露记录 → 公告日可见面板”的统一数据契约，才能安全扩展因子库。

### 用户价值

- 研究员能够可信计算财务、质量、成长、每股和风格因子，而非只研究量价因子。
- 用户可追溯一个因子使用了什么字段、什么版本的数据、何时对历史市场可见。
- 数据缺失或未授权时系统明确报错，不生成伪精确的因子和回测结果。

### 商业价值

- 使 SVQuant 的因子研究能力从量价研究升级为基本面与风格研究，补齐竞品基础能力。
- 用统一数据层支撑后续 AI 因子生成、行业政策分析和机构客户的数据治理要求。
- 避免未来函数造成回测虚高，保护产品可信度和专业用户留存。

### MVP 范围

**必须做**：

- 接入可合法使用的资产负债表、利润表、现金流量表原始记录，保留证券、报告期、公告/可见日、修订版本、来源与单位。
- 建立字段字典，覆盖因子首批所需的总/流动资产、总/流动负债、股东权益、现金、存货、应收/应付、收入、成本、利润、经营现金流等字段。
- 以公告日向后填充生成“日期 × 标的”日频点时面板；公告日前不可见，修订版本可审计。
- 固化后复权回测行情与未复权 SVQuant 展示行情，补充复权因子、上市/退市/停牌状态与全 A 市值加权市场收益。
- 建立数据质量校验、字段覆盖率与版本清单；因子引擎对缺字段明确失败。

**可以以后做**：申万/聚宽/证监会历史行业分类与行业因子；分析师一致预期、机构覆盖、目标价与预测修订；分红、优先股、长期债务等资本结构明细；日频无风险利率曲线；分钟级行情、北向资金、逐笔资金流及另类数据；前复权行情（需要时另行评审其研究价值和发布口径）。

**明确不做**：不自建或抓取未经授权的第三方数据源；不将数据供应商的受限原始数据或凭据提交到代码仓库；不在本 Feature 建立用户权限、计费或数据交易市场；不采集前复权行情。

**增量一：iFinD 日线价格职责拆分（2026-08-11 批准）**

- `market_data` 固定服务回测系统，只采集后复权 OHLC 与不复权的成交量、成交额、换手率。
- 新建 `unadjusted_price` 服务 SVQuant K 线看板，只采集未复权 OHLC，不重复采集或存储流动性字段。
- 两条采集流程使用独立命令和产物，避免调用方通过通用复权参数意外混用价格口径。

**增量二：iFinD 指数数据域整合（2026-08-11 批准）**

- 将原有 `index_weights` 迁入统一的 `index/index_weights`，权重非空列同时表达当日指数成分。
- 新建 `index/index_price`，通过 `history_data` 只采集指数 `high,open,low,close`，标准化输出为 OHLC，不采集成交量、成交额或换手率。
- 权重和价格保持独立产物，避免将“日期 × 成分股”的宽表与“日期 × OHLC”的指数序列混成同一 schema。
- 最终文件名显式携带数据产品前缀：`index_weights_<index>` 与 `index_price_<index>`，避免脱离目录后出现同名文件。

### 优先级评估

商业价值 5、用户价值 5、战略价值 5、开发成本 5，评分 25。虽成本高，但它是聚宽兼容基本面因子与可信回测的共同前置依赖，应优先按 MVP 建设。

### 排期与里程碑

- M1：数据授权、字段字典与样本确认。
- M2：点时财务面板和数据质量报告可用。
- M3：首批基本面因子可回测且通过未来函数验证。
- M4：行业、预期与资本结构扩展完成，发布数据覆盖报告。

### 风险管理

| 风险 | 影响 | 缓解 |
|---|---|---|
| 数据许可不覆盖产品使用方式 | 无法上线或再分发 | 开发前书面确认授权范围；未授权字段不落盘。 |
| 公告日或修订记录缺失 | 回测可能含未来函数 | 供应商验收、审计样本、缺记录即空值。 |
| 字段口径/单位不一致 | 因子数值错误 | 单一字典、单位换算测试、源版本记录。 |
| 存储增长 | 成本和加载性能下降 | 按字段 Parquet、压缩、版本保留策略和懒加载。 |

## 4. 当前结论

数据访问基础已经交付：ResearchEngine 的 DataEngine/IDataProvider、FieldParquetProvider 与真实因子回测 API 验证均已通过。活动发布物位于 ResearchEngine 配置的 `marketdata/` 目录（见 ADR-032 扁平只读消费目录，不再由 SVQuant 持有）；iFinD 采集、历史回填、日更和发布工具已按 FEAT-031 迁入独立 `IFind` 项目，SVQuant 只保留数据契约与 HTTP 展示适配。

本 Feature 仍保持“待批准”：DATA-001 的口径/许可盘点，以及公告日财务、复权、交易状态、市场基准和完整发布清单尚未完成；点时财务数据的授权和样本确认仍是进入后续开发的阻塞项。
