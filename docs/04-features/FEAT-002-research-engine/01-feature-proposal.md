# FEAT-002：ResearchEngine 研究服务

## 背景

QuantCore 提供计算能力，但用户仍需要一个面向投研场景的编排层，将因子或策略代码、数据配置、回测执行、指标分析和 API 调用组织为完整研究流程。

## 用户价值

量化研究员可以提交因子或策略并一次性得到回测与分析结果；前端和 AI Agent 可以通过稳定 API 复用同一研究能力。

## 商业与战略价值

ResearchEngine 将底层量化能力包装成可直接消费的研究服务，是 CLI/SDK 向 Web SaaS 和 AI 研究助手演进的关键接口层。

## MVP 范围

### 必须做

- 无状态研究运行器与配置对象。
- 因子和策略代码加载执行。
- QuantCore 回测适配层编排。
- 同步与异步 HTTP 回测 API。
- 标准结果和错误响应。

### 可以以后做

- AI 策略生成和结果解读。
- 用户级研究历史和团队协作。
- 分布式任务队列和持久化运行状态。

### 明确不做

- QuantCore 内部因子、回测和指标算法。
- 用户认证、计费和多租户管理。
- 券商接入与实盘订单执行。

## 宏观影响

- 所属 Initiative：INIT-001 投研核心。
- 所属产品能力：因子研究、策略研究、研究 API。
- 影响等级：L2，明确 ResearchEngine 与 QuantCore、前端和 AI Agent 的边界。

## 当前结论

基础版已经实现；AI、持久化和团队协作等能力必须作为独立 Feature 重新评估和交付。
