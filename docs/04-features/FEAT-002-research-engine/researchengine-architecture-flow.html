指标计算与收益口径

本节对应 factor_analysis.quantile_metrics 和顶层 metrics，先固定输入序列，再逐项给出唯一公式。

统计收益 → 指标 · 展示净值 → 曲线
口
一条总规则：指标不直接读取分组展示净值

分组和基准的绝对指标、相对指标都先取“统计日收益”计算。展示净值只服务前端画曲线；最大回撤虽然需要净值路径，也会从统计收益重建统计净值，不直接读取分组展示曲线。

1. 统计输入和展示输出

t0 是首个信号日，t1 是首个持仓/收益日；第一笔分组收益是 t0→t1。

对象统计输入：用于指标展示输出：用于画图
分组 Qrg,t = layered_returns[Q]；保留第一笔 t0→t1 收益。factor_analysis.cumulative_series；首个分组收益先置 0，曲线首点统一为 1.0。
基准rb,t = 归一化基准净值的 pct_change；首个有效日期的收益强制为 0。benchmark_curve；基准净值首点归一为 1.0。当前它与基准统计净值数值相同，但指标使用的是由它推导的日收益。
分组统计净值内部从 rg,t 前补初始净值 1.0 后复利，用于 max_drawdown。不单独返回；不要用分组展示净值代替它。
按指标归类：annual_return、volatility、sharpe 使用日收益；max_drawdown 使用由统计收益得到的统计净值；相对指标使用同一日期上的分组日收益和基准日收益；没有指标使用分组展示净值。

2. 分组和基准的绝对指标

公式只有一套：分组代入 rg,t，基准代入 rb,t。Tg、Tb 分别是两条统计收益序列的有效日期，n 是对应有效收益笔数。

指标唯一公式输入序列
annual_return(Πt∈T(1 + rt))252 / n − 1分组：rt=rg,t；基准：rt=rb,t。几何年化。
volatilitystdn−1(rt) × √252只用对应对象的统计日收益，样本标准差 ddof=1。
sharpemean(rt) / stdn−1(rt) × √252只用对应对象的统计日收益，无风险利率为 0。
max_drawdownmint(Et / maxu≤tEu − 1)分组：Et 从 rg,t 重建；基准：使用基准统计净值。返回负数。

3. 分组相对基准的指标

先按日期取共同集合 Tc = Tg ∩ Tb，所有比较都使用这两条统计日收益；不使用分组展示净值。

本表符号：Fg=Π(1+rg,t)、Fb=Π(1+rb,t)（t∈Tc）；Cb,t=Πu≤t(1+rb,u)−1 是基准累计收益。
指标唯一公式输入序列
annual_excess_return(1 + Fg − Fb)252 / |Tc| − 1共同日期上的分组和基准统计日收益；不是两个 CAGR 相减。
excess_volatilitystd|Tc|−1(rg,t − rb,t) × √252共同日期上的日超额收益，样本标准差。
information_ratioannual_excess_return / excess_volatility沿用本表前两项结果；分母为 0 时按安全规则返回 0。
benchmark_win_ratemean(𝟙(rg,t > Cb,t))当前约定是“分组当日收益 > 基准累计收益”；相等不算赢，也不是比较两条累计净值。

4. 顶层 API 的其他指标

这些字段位于顶层 metrics，输入是主组合的日收益、净值或因子远期收益，不属于分组基准对比表。

指标唯一公式输入
sortinomean(r) / √mean(min(r, 0)2) × √252主组合日收益。
calmarannual_returnnative / abs(max_drawdown)顶层底层指标的算术年化收益与最大回撤；可能不同于接口覆盖后的几何年化收益。
icmeant(corr(factort, forward_returnt))每天横截面的 Pearson 相关。
rank_icmeant(corr(rank(factort), rank(forward_returnt)))每天横截面的 Spearman 相关。
win_ratemean(𝟙(rt > 0))主组合日收益；与分组表的 benchmark_win_rate 不同。
turnovermeant(Σi|wt,i − wt−1,i| / 2)相邻日期持仓权重。
cumulative_icΣt ICt有效日期的 IC 简单累加，不是收益净值。
rolling_irmean(ICt−59:t) / stdsample(ICt−59:t)最近 60 个有效 IC，不乘 √252。

5. 返回字段和用途

字段内容是否参与分组指标
factor_analysis.quantile_metrics分组和基准的绝对、相对指标；输入是本页定义的统计收益。是。
factor_analysis.cumulative_series分组展示净值曲线，首点统一为 1.0。否，只画图。
benchmark_curve归一化基准净值曲线；基准日收益从它的变化推导，首个有效收益为 0。不直接作为日收益输入。
顶层 metrics主组合通用指标，例如年化收益、回撤、IC、胜率和换手。不属于分组表。
final_equity / annual_returns / drawdowns主组合最终净值、分年收益和回撤区间明细。不属于分组表。
结论：分组与基准不会在指标之间随机切换“统计用”和“展示用”收益。切换的是指标类型：绝对指标看各自统计收益，相对指标看共同日期的两条统计收益；只有画曲线才看展示净值，最大回撤使用由统计收益得到的统计净值路径。

策略回测运行流程

策略回测在因子研究链路之上增加交易规则、持仓变化和执行结果；系统支持向量化与事件驱动两条执行路径。

向量化 / 事件驱动
界
因子研究与策略执行的边界

因子提供排序或信号依据；策略进一步定义交易动作、目标权重、订单、成交和持仓变化，因此策略回测需要区分向量化计算与事件驱动执行。

PATH A · vectorized

向量化：一次把很多天算完

适合规则可以用表格和数组表达的策略，速度快，适合研究阶段反复试验。

  • 读取行情和策略需要的字段
  • 策略一次生成整段时间的信号
  • NativeEngine 计算净值、收益和持仓
generate_signals → NativeEngine
PATH B · event

事件驱动：一天一天模拟交易

更接近真实交易过程，可以看到订单、成交、持仓快照和事件时间线。

  • 按交易日触发策略回调
  • 产生订单并检查成交条件
  • 记录订单、成交和账户变化
initialize → EventBacktestEngine

什么时候用哪条路径？

想快速试验很多想法，先用向量化；想检查真实交易过程、订单和成交，再用事件驱动。两条路径共享指标和基准比较口径。
