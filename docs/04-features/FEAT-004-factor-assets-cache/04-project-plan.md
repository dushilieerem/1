# FEAT-004：因子资产目录与回测结果缓存 — Project Plan

- 状态：已规划

## 1. 任务拆解

| 任务 | 复杂度 | 风险 | 依赖 |
|------|--------|------|------|
| 建立 `Factor/` 资产目录并迁移因子库 | 2 | 中 | 路径引用盘点 |
| 新增资产路径解析与更新因子加载方 | 2 | 中 | 目录迁移 |
| 实现缓存键与数据指纹 | 3 | 中 | 路径解析 |
| 实现本地文件缓存、原子写入、锁和清理 | 4 | 中 | 缓存键 |
| 接入 API 响应头与异常降级 | 2 | 低 | 文件缓存 |
| 测试、文档和迁移验证 | 3 | 中 | 全部开发任务 |

## 2. 排期

### Week 1

- 完成因子资产目录迁移、路径解析和回归测试。
- 完成缓存键、数据指纹与本地读写验证。

### Week 2

- 接入 API、并发锁、TTL/容量清理和响应头。
- 完成异常、并发和全量回归测试；更新使用文档。

## 3. 里程碑

- M1：新目录下内置因子加载及 API 枚举通过。
- M2：相同因子回测第二次调用命中缓存。
- M3：数据变更失效、并发安全、清理机制和全量测试通过。

## 4. 发布与回滚

- 发布前备份现有因子库；迁移后运行完整测试和一次真实因子回测。
- 若缓存异常，关闭 `SVQUANT_BACKTEST_CACHE_ENABLED`；若资产路径异常，以 `SVQUANT_FACTOR_DIR` 指向备份目录。
