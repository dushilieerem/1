# FEAT-006：事件驱动策略回测引擎

- 状态：待评审
- 所属 Initiative：INIT-001 投研核心
- 所属能力：策略研究、策略回测、A 股市场规则
- 宏观影响：L1（补齐既有策略回测能力，不改变产品模块边界）

## 目标

在保留现有向量化因子/权重回测的前提下，新增面向状态机策略的事件驱动回测能力，使研究员可以表达定时任务、持仓状态、选股、订单、止盈止损和 A 股交易约束。

## 当前结论

聚宽策略不是“更复杂的目标权重公式”，而是事件驱动程序。本 Feature 不追求直接兼容聚宽的全局函数 API；采用 SVQuant 自有、可沙箱化的 `context` 对象 API，并提供迁移映射。
