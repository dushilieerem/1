# FEAT-007：因子回测 API 性能修复

- 状态：已验证
- 所属 Initiative：INIT-001 投研核心
- 影响等级：L0（既有能力的性能与正确性修复）

## 背景与范围

默认因子回测 API 将深度分析（分层、FF3、行业曲线）与核心回测绑定，并且字段 Parquet provider 未解析指数成分股，导致 `CSI500` 实际按全市场计算。

本次范围：

1. `CSI300`、`CSI500`、`CSI1000`、`SSE50` 使用最新一期成分股列筛选；
2. API 默认执行核心回测与各分组区间收益，`analysis_level="full"` 显式开启深度分析；
3. 响应返回分段耗时，支持线上定位。

不在范围：历史逐日指数调仓掩码、异步任务、算法口径变更。

## 验收标准

1. `CSI500` 请求的因子面板列数为 500，而非全市场列数；
2. 未传 `analysis_level` 时不执行和返回深度因子分析；
3. `analysis_level="full"` 保持原有分析字段；
4. 响应携带各阶段耗时；
5. QuantCore 与 ResearchEngine 相关测试通过。

## 验证记录

- 真实行情（2017-01 至 2026-04）`CSI500`、20 日动量、`analysis_level="core"`：端到端
  2.14 秒；其中因子计算 0.85 秒、信号与向量回测 0.38 秒、指标 0.64 秒。
- 自动化测试：`pytest -q`，102 passed，1 个第三方 TestClient 弃用警告。

## 已知限制

本次按最新一期指数成分筛选列，避免全市场误算。历史样本内逐日调入调出的精确成分与
持仓处理仍未实现，后续应以独立 Feature 增加日期×标的成分掩码，避免幸存者偏差。
