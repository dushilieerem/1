# Feature Proposal：聚宽兼容因子库

- 状态：已批准（限第一批技术因子）
- 所属 Initiative：INIT-001 投研核心
- 优先级：P0
- 提出日期：2026-07-22

## 1. 功能名称

聚宽兼容因子库（SVQuant 原生实现）。

## 2. 背景

聚宽通过 `get_all_factors` 枚举因子信息，并通过 `get_factor_values` 提供质量、基础、情绪、成长、风险、每股等数百个因子的取值；另有 Alpha101、Alpha191 与技术指标等相关集合。已收到一份 `get_all_factors()` 文本导出，完整包含 260 个唯一因子（9 类），可用于冻结本 Feature 的目录范围。SVQuant 已具备 `FactorLibrary` 的面板向量化写法及 Qlib Alpha158/Alpha360，但尚不能让从聚宽迁移的研究员按熟悉的因子名称和口径复现实验。

现有 `Factor/libraries/` 的 610 个因子主要基于 OHLCV、估值和市值字段。聚宽目录中的一部分因子依赖财务报表、公告可见日、行业分类、分析师预期或资金流等数据，不能在缺少数据与时点规则的情况下安全地“补写”。

## 3. 用户价值

- 聚宽研究员可以用熟悉的因子名称检索、迁移和复现实验。
- 研究员可看到每个因子的公式、字段依赖、数据口径、覆盖状态和验证结果，而不是黑箱取数。
- SVQuant 用户不依赖聚宽运行时或账号即可在自身已授权数据上计算已支持因子。

## 4. 商业价值

- 降低迁移成本，补齐竞品已有的基础量化设施，提升专业用户试用到留存的转化。
- 因子目录和数据契约可复用于 AI 因子生成、因子分析和后续团队资产管理。
- 以“兼容口径 + 可追溯验证”而非复制专有数据建立可信的差异化。

## 5. 竞品与差异化

| 方案 | 能力 | 局限 / 结论 |
|---|---|---|
| 聚宽在线因子库 | 提供目录、取值 API 与平台数据 | 依赖其账户、数据服务和运行环境。 |
| 直接搬运因子名或结果 | 上线快 | 无法保证公式、数据时点和授权合规；不采用。 |
| SVQuant 原生兼容实现（推荐） | 自有代码、数据源可替换、公式可审计 | 前期需建立清单和数据映射；作为本 Feature 的目标。 |
| 仅保留 Qlib 因子 | 已完成且可复现 | 不能覆盖 A 股基本面/风格因子迁移需求；不足。 |

## 6. MVP 范围

### 必须做

- 用合法授权的聚宽账号导出 `get_all_factors()` 的完整目录快照，保存**名称、分类、描述、抓取日期和来源版本**；不得提交任何受限的因子数值数据。
- 建立 `Factor/libraries/joinquant_compatible/manifest.yaml`，逐项记录原始名称、SVQuant 名称、分类、公式来源、依赖字段、点时可得规则、状态和验证级别。
- 先交付仅依赖已有或已明确补齐字段的第一批：行情/技术、估值/市值、财务基础、成长、盈利质量、风险与动量；每项均以 `FactorLibrary` 方法实现。
- 对所有已实现项做公式单元测试、无未来数据测试和与合法聚宽样本的逐值/容差对比测试。
- API 与 `index.yaml` 可发现已支持因子，并明确显示“不支持 / 数据缺失 / 待验证”的目录项。

### 可以以后做

- Alpha191 的独立兼容包与全量回归；WorldQuant Alpha 101 已由 `FEAT-023` 独立交付。
- 分析师预期、情绪、北向/资金流、行业风格等需要新增授权数据的类别。
- 前端兼容性筛选、自动迁移助手、因子别名搜索和批量回测。

### 明确不做

- 不抓取、转存、分发或依赖聚宽的受限因子值数据。
- 不承诺在缺少相同原始数据、复权规则、财报披露时点和行业分类版本时逐值一致。
- 不把聚宽 SDK 或在线 API 加入 SVQuant 的生产运行时依赖。
- 不修改既有因子名称和计算行为。

## 7. 优先级评估

商业价值 5、用户价值 5、战略价值 4、开发成本 5，评分为 20。因价值高且成本、数据依赖也高，按分批 MVP 推进；目录冻结与行情/估值/技术子集为 P0，其余类别根据数据授权逐批纳入。

## 8. 风险与待决策项

| 项目 | 风险 | 缓解 / 决策 |
|---|---|---|
| 目录持续变化 | “全部”没有固定边界 | 以日期和哈希冻结版本化清单；新增项走增量版本。 |
| 数据授权 | 财务、预期、资金流字段可能受许可限制 | 每个字段标注来源、许可和可再分发限制；未授权不实现。 |
| 点时可得性 | 财报按报告期而非公告日填充会产生未来函数 | 财务字段必须含公告/可见日期并以前向填充到后续交易日。 |
| 口径差异 | 同名因子可能存在复权、TTM、剔除规则差异 | 清单保存公式与版本；样本回归后才标记“已验证”。 |
