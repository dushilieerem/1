# Feature Proposal：投研因子数据底座

- 状态：待批准
- 所属 Initiative：INIT-001 投研核心
- 优先级：P0
- 提出日期：2026-07-22

## 1. 功能名称

投研因子数据底座。

## 2. 背景

SVQuant 当前日线行情覆盖 OHLC、成交量、成交额、换手率、市值、股本、PE/PB/PS、ST 与涨停等字段，已支撑技术、风险和情绪类聚宽兼容因子。基础、质量、成长、每股和大部分风格因子还依赖点时财务报表、历史行业分类、复权与交易状态、全 A 市场基准、分析师预期及资本结构数据。

如果只按财报期末日期填充财务数据，会把尚未公告的信息带入历史回测，产生未来函数。当前必须先建立“原始披露记录 → 公告日可见面板”的统一数据契约，才能安全扩展因子库。

## 3. 用户价值

- 研究员能够可信计算财务、质量、成长、每股和风格因子，而非只研究量价因子。
- 用户可追溯一个因子使用了什么字段、什么版本的数据、何时对历史市场可见。
- 数据缺失或未授权时系统明确报错，不生成伪精确的因子和回测结果。

## 4. 商业价值

- 使 SVQuant 的因子研究能力从量价研究升级为基本面与风格研究，补齐竞品基础能力。
- 用统一数据层支撑后续 AI 因子生成、行业政策分析和机构客户的数据治理要求。
- 避免未来函数造成回测虚高，保护产品可信度和专业用户留存。

## 5. 方案与范围

### 必须做（MVP）

- 接入可合法使用的资产负债表、利润表、现金流量表原始记录，保留证券、报告期、公告/可见日、修订版本、来源与单位。
- 建立字段字典，覆盖因子首批所需的总/流动资产、总/流动负债、股东权益、现金、存货、应收/应付、收入、成本、利润、经营现金流等字段。
- 以公告日向后填充生成“日期 × 标的”日频点时面板；公告日前不可见，修订版本可审计。
- 补充复权因子、未复权收盘价、上市/退市/停牌状态与全 A 市值加权市场收益。
- 建立数据质量校验、字段覆盖率与版本清单；因子引擎对缺字段明确失败。

### 可以以后做

- 申万/聚宽/证监会历史行业分类与行业因子。
- 分析师一致预期、机构覆盖、目标价与预测修订。
- 分红、优先股、长期债务等资本结构明细；日频无风险利率曲线。
- 分钟级行情、北向资金、逐笔资金流及另类数据。

### 明确不做

- 不自建或抓取未经授权的第三方数据源。
- 不将数据供应商的受限原始数据或凭据提交到代码仓库。
- 不在本 Feature 建立用户权限、计费或数据交易市场。

## 6. 优先级评估

商业价值 5、用户价值 5、战略价值 5、开发成本 5，评分 25。虽成本高，但它是聚宽兼容基本面因子与可信回测的共同前置依赖，应优先按 MVP 建设。
