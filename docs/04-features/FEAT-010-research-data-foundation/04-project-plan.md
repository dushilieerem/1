# Project Plan：投研因子数据底座

## 任务拆解

| 任务 | 复杂度 | 风险 | 依赖 | 完成条件 |
|---|---:|---|---|---|
| 确认授权数据源与许可 | 3 | 高 | 商务/数据负责人 | 数据用途、缓存、展示与再分发边界书面确认。 |
| 定义字段字典和数据清单 | 3 | 中 | 数据源样本 | 已完成 v1.0 文档基线；待以授权样本确认映射、覆盖与许可证。 |
| 建立统一数据访问与目录兼容 | 3 | 中 | 既有 MarketData | **已完成**：DataEngine/IDataProvider、FieldParquetProvider、`current/` 目录解析、旧版 Parquet 兼容与 API 回测验证。 |
| 建立 Wind 历史日频采集工具 | 3 | 中 | WindPy、字段映射 | **已完成基础版**：按字段批量下载并写 Parquet；全市场下载、财务采集和发布清单待后续任务。 |
| 建立 iFinD 全量回填与收盘后日增量任务 | 4 | 中 | iFinD 授权、证券池、交易日历与字段协议 | 全量任务可按指定区间断点续传；日增量任务只处理最近完成交易日并支持定时运行。 |
| 拆分回测行情与 WebApp 未复权价格 | 2 | 低 | 既有 iFinD 日线协议 | `market_data` 固定后复权加流动性；`unadjusted_price` 仅含未复权 OHLC；前复权入口关闭且测试通过。 |
| 整合指数数据域并补充指数价格 | 2 | 低 | iFinD `p03563` 与 `history_data` 协议 | `index/index_weights` 与 `index/index_price` 独立支持全量、增量、CSV 和 Parquet；最终文件带产品前缀；旧权重数据无损迁移。 |
| 建立原始财务记录导入 | 4 | 高 | 数据源 API/文件 | 报告期、公告日、修订与源版本可保留。 |
| 建立点时面板与 TTM 转换 | 5 | 高 | 原始财务记录、交易日历 | 公告日/修订/缺季度测试通过。 |
| 补齐复权、交易状态和全 A 基准 | 4 | 中 | 行情与证券主数据 | 标准字段可由 DataEngine 读取。 |
| 数据质量与版本回滚 | 3 | 中 | 以上任务 | 清单、哈希、覆盖率和回滚演练通过。 |
| 接入因子库与参考回归 | 4 | 高 | 点时面板、聚宽样本 | 首批财务因子可计算并通过无未来数据验证。 |

## 建议排期

```text
已完成：统一数据访问层、`MarketData/current` 目录重组、Wind 日频采集工具基础版和 API 兼容回归。
Week 1：确定授权来源、用 v1.0 字段字典和数据清单核对样本与数据质量基线。
Week 2：实现原始财务导入和完整发布清单；完成公告日点时转换原型。
Week 3：补齐 TTM/修订、复权、交易状态与全 A 基准；完成质量任务。
Week 4：接入基础/质量/成长/每股因子，做无未来数据与参考样本回归。
Week 5+：行业历史、预期、资本结构和无风险利率按授权分批交付。
```

## 里程碑

- M1：数据授权、字段字典与样本确认。
- M2：点时财务面板和数据质量报告可用。
- M3：首批基本面因子可回测且通过未来函数验证。
- M4：行业、预期与资本结构扩展完成，发布数据覆盖报告。

## 风险管理

| 风险 | 影响 | 缓解 |
|---|---|---|
| 数据许可不覆盖产品使用方式 | 无法上线或再分发 | 开发前书面确认授权范围；未授权字段不落盘。 |
| 公告日或修订记录缺失 | 回测可能含未来函数 | 供应商验收、审计样本、缺记录即空值。 |
| 字段口径/单位不一致 | 因子数值错误 | 单一字典、单位换算测试、源版本记录。 |
| 存储增长 | 成本和加载性能下降 | 按字段 Parquet、压缩、版本保留策略和懒加载。 |

## Definition of Ready

- [x] 所属 Initiative 和产品能力明确。
- [ ] Feature Proposal 待批准。
- [x] MVP、明确不做项、边界、验收、架构、测试和回滚已定义。
- [ ] 授权数据源、字段字典样本与数据负责人尚未确认，构成财务和扩展字段的开发阻塞。

结论：数据访问基础已交付；等待数据源授权和样本确认后，进入点时财务与扩展字段开发。

价格职责拆分增量已由需求方于 2026-08-11 明确批准；其范围、接口、数据影响、回滚方式和验收标准均已定义，且不依赖仍待确认的财务数据授权，可独立进入开发。回滚方式为保留既有 raw JSON，并恢复拆分前命令入口；本次不迁移或删除任何历史数据。
