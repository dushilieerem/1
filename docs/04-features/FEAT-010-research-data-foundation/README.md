# FEAT-010：投研因子数据底座

- 状态：待批准
- 所属 Initiative：INIT-001 投研核心
- 所属能力：数据 / 因子研究
- 优先级：P0
- 宏观影响：L1（补齐既有数据与因子研究能力，不改变产品定位或模块边界）

## 目标

补齐聚宽兼容因子和投研基础能力所缺的点时财务、历史分类、复权、交易状态、市场基准与预期数据，并以统一的字段字典、授权记录和 Parquet 数据契约对外提供。

## 当前结论

现有 `MarketData/` 已包含日线 OHLC、成交量、成交额、换手率、市值/股本、PE/PB/PS 和部分指数数据；本 Feature 不重复建设这些字段。第一阶段聚焦带公告日的财务三表与字段字典，这是基础、质量、成长和每股因子可信计算的前置条件。
