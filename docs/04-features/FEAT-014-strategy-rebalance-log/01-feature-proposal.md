# 策略调仓日志：Feature Proposal

## 功能名称

策略回测调仓日志按需返回。

## 背景

现有策略回测只返回净值、指标和可选持仓快照。Web 用户无法直接解释策略为何在某个调仓日换入或换出标的。

## 用户价值

研究者可在回测结果中查看每个调仓日的标的和权重变动，快速核验策略行为。

## 商业价值

提升回测结果的可解释性和可信度，是策略研究 Web 工作台的基础审计信息。

## 竞品分析

主流量化平台通常展示交易/调仓明细。MVP 优先提供与当前向量化目标权重模型一致的日志，不伪造尚不存在的订单成交信息。

## MVP 范围

- 必须做：记录目标权重变化；Web 请求时按调仓日返回标的、方向和前后权重。
- 可以以后做：成交价、金额、手续费、订单状态和导出文件。
- 明确不做：事件驱动订单撮合与实盘成交回报。
