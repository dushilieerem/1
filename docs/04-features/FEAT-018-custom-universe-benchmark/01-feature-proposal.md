# 自定义证券池与组合基准：Feature Proposal

## 1. 功能名称

自定义证券池与组合基准。

## 2. 背景

当前因子和策略回测可传入固定股票池名称，并只能选择少数内置指数作比较基准。研究员常见的研究对象却是自己维护的一组证券，例如“消费龙头 30 只”“排除 ST 的高股息候选池”或团队关注名单；他们也需要把自选篮子、固定权重组合或多指数配比作为比较对象。

现有 `universe` 与 `benchmark` 只是请求中的字符串。它无法保存成分和权重、无法记录版本，也无法让两类回测复用同一对象。另一方面，当前固定指数股票池按最新一期成分筛选，历史样本内仍存在幸存者偏差，不能成为动态池的正确实现基础。

## 3. 用户价值

- 研究员可一次定义、多次复用自己的证券范围，不必在每次回测中修改代码或粘贴代码列表。
- 研究员可用自己的投资机会集作为因子截面，并将策略收益与真正相关的被动组合比较。
- 回测结果明确记录股票池、基准、成分、权重及版本，使同一研究可复现、可审计。

## 4. 商业价值

自定义研究资产是从“演示型回测工具”走向个人专业用户和团队工作台的基础门槛。它提升用户留存：用户沉淀的研究范围和比较口径会随项目保存；同时它是后续团队共享、权限隔离、策略发布和模拟盘组合管理可直接复用的资产模型。

## 5. 竞品分析

主流量化研究平台通常同时提供指数股票池、用户列表/选股条件以及基准指数或自定义组合。其共同设计是把“选股范围”与“收益比较对象”独立配置：前者影响可选标的和因子截面，后者只影响报告与超额收益。SVQuant 由 WebApp 管理用户资产、在线编辑、版本与权限，ResearchEngine 只消费经鉴权后解析的快照，保证研究可复现且不承担用户数据职责。

## 6. 优先级评估

| 维度 | 评分 | 说明 |
|---|---:|---|
| 商业价值 | 4 | 专业研究的基础配置能力，提升留存与后续付费空间。 |
| 用户价值 | 5 | 直接解决自选组合无法复用和比较口径不匹配。 |
| 战略价值 | 4 | 可复用到策略、因子、模拟盘和未来用户资产。 |
| 技术成本 | 3 | MVP 可复用现有面板与向量化回测；历史成分另行分期。 |
| 优先级结论 | P1 | 应在当前 API/资产能力稳定后进入开发。 |

## 7. MVP 范围

**必须做**：WebApp 的用户级证券池与组合基准 CRUD、鉴权与版本解析；静态证券池（显式股票清单）；静态组合基准（显式股票权重）；WebApp 将不可变快照提交给因子与向量化策略回测；运行结果写入资产版本、内容哈希和实际成分/权重快照；保留已有固定指数参数兼容。

**可以以后做**：历史日期×证券成分和权重、定期调仓、指数历史成分、等权/市值权重自动生成、规则型股票池、CSV 导入导出、在线编辑、团队共享与权限。

**明确不做**：Wave 3 多租户资产服务；任意数据源的实时选股；实盘组合执行；用最新成分近似历史成分；为基准静默补齐缺失价格或忽略不可交易证券。
