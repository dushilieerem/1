# Project Plan：AI 自然语言向量化策略生成 API

| 任务 | 复杂度 | 风险 | 依赖 |
|---|---:|---|---|
| 请求/响应契约与路由 | 1 | 低 | 现有 API |
| LLM 提示词、JSON 解析、幂等 | 2 | 中 | AI 因子生成服务 |
| 向量化策略 AST 与编译校验 | 3 | 中 | 策略回测契约 |
| 单元与 API 契约测试、文档 | 2 | 低 | 前三项 |

里程碑：M1 受控草稿可生成；M2 安全与幂等测试通过；M3 文档化并可供前端接入。主要风险是模型生成无效权重矩阵，MVP 通过固定提示词、AST 校验和用户确认缓解；经济有效性留给回测验证。
