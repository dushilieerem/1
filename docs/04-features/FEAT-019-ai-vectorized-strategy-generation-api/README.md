# FEAT-019：AI 自然语言向量化策略生成 API

- 状态：开发中（受控 MVP）
- 所属 Initiative：INIT-004 投研能力 Phase 2
- 所属能力：AI 研究助手 / 策略研究
- 优先级：P0

## 目标

将研究员的自然语言假设生成一个可审阅的、只输出目标权重矩阵的向量化策略草稿；用户确认后才可提交既有策略回测 API。
