# 股指与成分股查询 API：Feature Proposal

## 背景与价值

Web 工作台需要让研究者选择市场基准并查看其成分股；现有 API 只能查询股票列表和个股日线，无法复用已发布的指数元数据。该能力降低前端维护静态指数清单和成分数据的成本，并为基准选择、证券池浏览提供可信的数据入口。

## MVP 范围

- **必须做**：列出当前已发布的内置股指；按股指代码返回最新一期成分股和名称。
- **可以以后做**：指定历史日期、指数日线、权重、行业筛选、分页。
- **明确不做**：在线数据源调用、指数自定义、实时数据、用户鉴权和投资建议。

优先级：P1（商业价值 3、用户价值 4、战略价值 3、技术成本 2）。
