# 股指与成分股查询 API：Product Requirements

## 用户故事

作为 Web 端开发者，我希望取得可用股指列表，并按股指代码取得其成分股，以构建基准选择器和成分股展示。

## 业务规则与验收

1. `GET /api/market-data/indices` 返回已发布且可读取的上证50、沪深300、中证500、中证1000，按代码升序。
2. `GET /api/market-data/indices/{code}/constituents` 返回该指数最新一期成分、证券名称和未映射数量；成分按代码升序。
3. 股指代码使用 `000016.SH`、`000300.SH`、`000905.SH`、`000852.SH`，并兼容对应内部标识。
4. 未知代码返回 `404`；成分文件、证券主数据或市场数据不可用时返回 `503`；不返回伪造数据。
5. 成分股是最新快照，不可表述为历史时点成分或当前实时成分。
