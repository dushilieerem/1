# Feature Proposal：经典策略迁移

## 功能名称

Wilder RSI、CANSLIM、KD 随机指标、一目均衡表、均线多头排列、配对交易，以及 OBV、蔡金、Dual Thrust 和净营运资产异象策略迁移。

## 背景与价值

用户提供的经典策略希望在 SVQuant 中研究与复现。迁移为版本化策略资产可让研究员直接回测、审阅公式及保存策略版本，也能验证事件引擎的状态、风控和调仓能力。

## MVP 范围

- 必须做：Wilder RSI(14)、MA200、最多三只持仓、RSI>70、-8% 止损和 +20% 止盈的日频事件策略；策略目录登记和自动化测试。
- 必须做：CANSLIM 数据依赖、算法映射与分阶段方案。
- 以后做：CANSLIM 的 C/A/I/N 完整筛选、历史证券状态和点时数据接入后端到端回测。
- 明确不做：聚宽 API 兼容层、实盘下单、把缺失基本面或股东数据补为零值。
- 必须做：KD 随机指标(14,3,3)趋势过滤与一目均衡表(9,26,52,26)云层趋势的日频事件策略、目录登记和自动化测试。
- 必须做：MA5/10/20/60 多头排列策略的日频事件版本，保留 MA20 回踩、排列/MA60/止盈止损退出、目录登记和自动化测试。
- 必须做：60 日价格比 Z-score 配对交易的向量化研究版本，保留 1.5/0.5/3.0 开平仓与风控阈值、等名义多空权重、目录登记和自动化测试。
- 必须做：12-1 动量、小盘价值、红利低波狗股和三重滤网的日频事件策略，保留各自调仓、评分或信号规则，目录登记和自动化测试。
- 必须做：抛物线 SAR 与 Fama-French/Carhart 多因子的日频事件策略，保留 SAR 标准递推、12-1 动量和月度调仓规则，目录登记和自动化测试。
- 必须做：凯特纳通道趋势突破与 Williams %R 趋势内超卖反转的日频事件策略，目录登记和自动化测试。
- 必须做：德邦特—塞勒长期反转与豪根—海因斯低波动异象的月度日频事件策略；使用点时行业、估值、流通市值、成交额与后复权价格面板，目录登记和自动化测试。
- 必须做：Piotroski F-Score 会计质量与股息增长的月度日频事件策略；使用公告日点时财务 TTM 面板与每股现金分红事件面板，目录登记和自动化测试。
- 明确不做：配对交易的融券、借券费、保证金、可卖空资格、分钟级成交及实盘执行；这些依赖后续多资产事件画像。
- 明确不做：策略文档要求的历史成分股、ST、停牌、上市日期、涨跌停与 T+1 可成交性过滤；这些由后续数据面板和事件引擎能力承载。
- 明确不做：在缺少历史行业、基本面、证券状态或涨跌停面板时，以当期值、零值或静态名单近似原策略的点时过滤。
- 明确不做：在当前事件引擎中模拟策略原聚宽版本的 ST、上市日期、停牌、涨跌停、T+1、整手和盘中分批成交约束；这些由上游数据面板和事件引擎后续能力承载。
- 明确不做：以报告期结束日、最新财务快照或静态分红历史回填过去；缺少公告日点时财务或分红事件字段时不执行策略。

## 本轮增量范围（2026-08-10）

- 必须做：OBV 能量潮和蔡金累积派发/振荡器的行业截面月度事件策略；保留量价指标、流动性、估值、市值和行业约束，目录登记和自动化测试。
- 必须做：Dual Thrust 双重推力的向量化研究版本；保留 `HH-LC`、`HC-LL` 波动区间、开盘锚定触发线、周度流动性候选池和等权持仓，目录登记和自动化测试。
- 必须做：净营运资产异象月度事件策略；保留 NOA/总资产公式、正 PE 与市值过滤、NOA 升序取前 10，目录登记和自动化测试。
- 明确不做：在当前日频引擎中声称复现 Dual Thrust 原脚本的 09:45 盘中价格触发；迁移版本以当日收盘触发线作为研究近似，由下一交易日收益承接。
- 明确不做：为四个策略补造 ST、停牌、上市日期、涨跌停、盘中价格或公告日财务值；缺少声明字段时拒绝运行或由上游数据面板负责。

| 维度 | 评分 |
|---|---:|
| 商业价值 | 3 |

| 战略价值 | 3 |

结论：经典策略资产继续以 P1 增量交付；完整 CANSLIM 依赖 FEAT-010 的数据发布后再启用。本轮四个策略已按当前引擎能力完成研究版迁移，其中 Dual Thrust 明确采用日线收盘近似。
