# Product Requirements：iFinD 宽表规范与渐进替换

## 1. 用户故事

1. 研究员可以继续使用 AkShare 已有字段，不因 iFinD 尚未下载完整而阻塞研究。
2. 数据维护者可以按业务域生成一个完整候选文件，并通过新版本切换发布。
3. 研究员看到文件名即可判断宽表的业务内容和可用字段。
4. 多用户回测共享同一只读内存快照，不重复读取或修改持久化数据。

## 2. 业务规则

- 一个 Parquet 宽表只包含同频率、同证券集合、同用途且通常一起读取的字段。
- 股票日频宽表每行代表一个交易日，列使用 `(证券代码, 字段名)` 两级结构。
- `market_data`、`daily_basic`、`security_status` 和 `unadjusted_price` 必须分开。
- `security_status.parquet` 必须包含 `is_suspended`，表示当日是否停牌。
- 不同逻辑字段可以处于不同切源阶段；manifest 按字段记录 AkShare/iFinD 来源。
- iFinD 原始值直接写入，不做单位换算；缺失值原样保留。
- 已发布 Parquet 不允许原地编辑。数据更新生成新的完整发布版本，验证后切换活动版本。
- 单次回测启动后固定一个 `release_id`，不得在运行中切换数据。
- 命名指数股票池在回测行情的首个实际交易日解析一次：使用该日可知的最近一期权重快照，权重非空且大于零的证券构成股票池；之后整个回测区间固定该列表，不随指数后续调仓变化。

## 3. 验收标准

- `market_data.parquet` 可按字段读取 `open/high/low/close/volume/amount/turnover` 并完成真实回测。
- `daily_basic.parquet` 可按字段读取市值、股本和估值数据。
- `security_status.parquet` 可读取行业、涨跌停、ST 和 `is_suspended`。
- 读取单个逻辑字段时无需加载同文件其他字段的数值数据。
- manifest 能指出每个逻辑字段的来源、iFinD 对应字段和文件哈希。
- 新版本校验失败时旧 `current` 保持可用；切回旧 release 后回测恢复旧数据结果。
- 回测起始日在非交易日时，以区间内首个实际行情日解析股票池；不得读取该日之后的权重快照。
- `/api/market-data/daily/{symbol}` 与 `/api/market-data/symbols` 使用 `display/unadjusted_price.parquet`，不读取研究用后复权行情。
- 服务器正常回测请求不访问 Parquet 或行情数据库。

## 4. 非目标

供应商单位解释、缺失值填充、异常值处理和研究期清洗由研究侧自行决定，不属于本存储规格。

## 5. 服务器运行要求

- 服务器启动时一次性加载当前发布版本的全部研究宽表；正常回测请求不得重新读取 Parquet。
- 磁盘上的多字段宽表加载后，转换为按字段二维只读数组；内存结构不强制保持磁盘文件分组。
- 所有回测任务读取同一份只读内存快照；单次任务只为自身计算中间结果分配内存。
- 多进程回测必须共享基础行情内存，不能每个 worker 各加载一套完整宽表。
- 数据更新通过新实例加载新快照并切换服务完成，不在运行中的旧快照上修改。
