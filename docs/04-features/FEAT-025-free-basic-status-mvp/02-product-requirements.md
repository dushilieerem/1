# Product Requirements：免费数据源补齐日频基本面与证券状态 MVP

## 1. 用户故事

1. 作为研究员，我希望 `daily_basic` 能覆盖行情已有的最新交易日，以便运行价值、规模和流动性相关因子。
2. 作为策略研究员，我希望查询历史 ST 和停牌状态，以便避免把不可交易证券纳入组合。
3. 作为数据维护者，我希望知道每个字段来自哪个免费源、覆盖哪些市场和日期，以便复现和排查问题。
4. 作为平台维护者，我希望数据更新失败时旧 `current` 继续可用，并能回滚到上一 release。
5. 作为审计人员，我希望免费源无法提供的字段明确保持缺失，而不是被口径不同的数据悄悄替代。

## 2. 业务流程

```text
读取 market_data 最大交易日
→ 采集 BaoStock / AKShare-CNINFO 原始数据
→ 标准化证券代码、日期、单位和字段
→ 按字段来源规则合并候选数据
→ 生成 daily_basic / security_status 候选文件
→ 运行 schema、覆盖率、重叠期和算术一致性检查
→ 写 manifest、质量报告和 SHA-256
→ 通过回归后切换 current
```

## 3. 业务规则

- 目标日期上限由 `market_data.parquet` 决定，不由机器当前日期决定。
- 2026-08-04 及以前的既有非空单元格不得被免费源覆盖。
- 同一标准字段在一个 release 中只能有一个明确主来源；不允许按单元格静默混源。
- `total_shares`、`float_shares` 存储单位为股；CNINFO 返回的万股必须显式乘以 10,000。
- `total_mv`、`float_mv` 使用未复权收盘价与同日有效股本计算，单位沿用现有字段契约。
- `pe` 与 `pe_ttm` 是不同字段；免费源动态 PE 不得写入 `pe`。
- `is_st` 和 `is_suspended` 对外分别为布尔语义；缺失不能转换为 `False`。
- 行业必须是点时数据。没有变更生效日的当前行业快照不得回填历史。
- `limit_status` 是原始文本字段；无法可靠取得时保持缺失，不用 `is_suspended` 反推完整涨跌停状态。
- 发布文件不可原地修改；所有变更必须生成新 release。

## 4. 边界与异常行为

| 情况 | 处理 |
|---|---|
| BaoStock 当日请求失败 | 记录失败证券和日期，字段保留缺失，候选 release 不得标记为完整 |
| CNINFO 股本变动缺少生效日 | 不向前展开，只保留原始事件并列入异常清单 |
| 证券代码无法映射 | 不写入面板，记录映射失败原因 |
| 免费源与已有 iFinD 值冲突 | 仅用于质量报告，不覆盖旧 release 值 |
| 北京市场缺少 BaoStock 字段 | 保留缺失，并在 manifest 标记市场覆盖范围 |
| 行情价格为零或股本非正 | 不计算市值，记录算术异常 |
| 候选 release 检查失败 | 不切换 `current`，旧 release 保持可读 |
| 数据源返回限流或登录提示 | 断点续传并退避；超过重试上限后失败退出，不写半成品面板 |

## 5. 非功能要求

- 可复现：相同原始快照、代码版本和配置应产生相同结果。
- 可审计：manifest 记录源、字段、市场、日期范围、转换规则、采集时间和哈希。
- 幂等：重复运行不产生重复日期或重复证券列。
- 安全：采集任务不得把在线响应直接暴露给回测；必须先落原始快照再发布。
- 性能：沪深全市场日增量应支持断点续传；全量回补允许数小时级网络运行时间。
- 兼容：不修改 `FieldParquetProvider` 对外字段名和两级列物理格式。

## 6. 验收标准

| 编号 | 验收标准 |
|---|---|
| AC-1 | 两张目标表最大日期等于 `market_data.parquet` 最大日期，当前缺失的 6 个交易日均有明确处理结果 |
| AC-2 | schema、两级列、日期唯一性和升序符合 FEAT-024/ADR-017 |
| AC-3 | 切换日前已有非空单元格零覆盖；差异报告能列出新增和变化单元格 |
| AC-4 | 沪深已上市股票的 `is_st`、`is_suspended` 有效覆盖率不低于 99.5% |
| AC-5 | 与已有 iFinD 停牌区间比较，`is_suspended` 精确率和召回率均不低于 99.5% |
| AC-6 | 新增日期股本字段目标覆盖率不低于 98%，未覆盖证券有清单 |
| AC-7 | 市值与未复权收盘价×股本的误差在配置阈值内；异常值有报告 |
| AC-8 | `pe` 保持明确的 partial/blocked 状态，不能声称已由免费源补齐 |
| AC-9 | 候选 release 失败时 `current` 不改变；成功切换后可通过 release_id 回滚 |
| AC-10 | 重复执行幂等，Provider 读取测试和一组代表性因子回测通过 |
