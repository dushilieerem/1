# Project Plan：免费数据源补齐日频基本面与证券状态 MVP

## 1. 任务拆解

| 任务 | 交付物 | 复杂度 | 技术风险 | 依赖 | 预计人天 |
|---|---|---:|---|---|---:|
| 源连通性与字段样本验证 | 沪深/北京各 100 只股票的样本报告 | 2 | 中 | 无 | 1 |
| BaoStock 采集器 | 断点续传、限流、原始快照和重试 | 3 | 中 | 样本验证 | 1.5 |
| CNINFO 股本采集器 | 股本事件原始表和生效日检查 | 3 | 高 | 样本验证 | 1.5 |
| 字段标准化 | 代码、日期、单位和布尔字段转换 | 2 | 中 | 两个采集器 | 1 |
| `daily_basic` 构建器 | 市值计算、估值合并、旧值保护 | 3 | 高 | 标准化、未复权行情 | 1.5 |
| `security_status` 构建器 | ST、停牌、行业/涨跌停边界处理 | 3 | 高 | BaoStock、旧 release | 1 |
| 质量检查和 manifest | 覆盖率、重叠期、哈希和异常报告 | 3 | 中 | 两个构建器 | 1.5 |
| Provider 与回测回归 | 字段投影、因子和状态策略回归 | 2 | 中 | 候选 release | 1 |
| 切换演练与文档 | release 切换、回滚、运行手册 | 2 | 低 | 全部前置任务 | 0.5 |

预计 7～9 个工作日；公共接口全量回补的网络运行时间另计，不占用开发人天承诺。

## 2. 开发顺序

1. M1：验证 BaoStock、AKShare/CNINFO 的字段、市场覆盖和授权边界。
2. M2：完成原始数据断点采集和标准化长表。
3. M3：生成两张候选宽表并通过质量检查。
4. M4：执行 Provider、代表性因子和停牌/ST 回测回归。
5. M5：完成 release 切换演练，内部环境启用免费源版本。

## 3. 排期

### Week 1：技术验证与采集骨架

- 完成样本接口验证、代码映射和字段契约。
- 完成 BaoStock、CNINFO 原始快照和断点文件格式。
- 确认 `svquant` 环境中的依赖版本。

### Week 2：候选 release 与质量验证

- 完成沪深增量和历史回补。
- 生成 `daily_basic`、`security_status` 候选文件。
- 运行覆盖率、停牌准确性、市值一致性和旧值保护检查。

### Week 3：回归、切换与文档收口

- 完成 Provider 单字段读取和代表性因子回测。
- 演练失败不切换、成功切换和回滚。
- 固化 manifest、质量报告和日增量运行手册。

## 4. 里程碑

- M1：100 只股票样本通过，字段口径和市场范围获评审确认。
- M2：原始数据可断点采集，重复运行不会产生重复记录。
- M3：候选 release 追平行情最大日期，质量报告完整。
- M4：沪深 ST/停牌回归通过，因子和策略读取不改接口。
- M5：内部环境完成一次 release 切换和回滚。

## 5. 负责人和协作

| 角色 | 责任 |
|---|---|
| 数据工程 | 采集器、标准化、发布和质量检查 |
| 量化研究 | 估值口径、停牌/ST 样本和回测结果验收 |
| 平台维护 | release 切换、Provider 回归和运行配置 |
| 产品/负责人 | 确认 MVP 是否仅限内部研究，批准后续商业化范围 |

## 6. 风险登记

| 风险类型 | 具体风险 | 触发条件 | 应对 |
|---|---|---|---|
| 技术 | 公共接口限流、字段变更 | 连续请求失败或 schema 改变 | 退避、缓存原始响应、固定版本并停止发布 |
| 数据 | 估值口径与现有 iFinD 不一致 | 重叠区间差异显著 | 标记来源切换，禁止静默覆盖，重新评估因子 |
| 数据 | 股本事件没有可验证生效日 | 仅有公告日期 | 不进入日频标准面板，保留异常清单 |
| 产品 | 用户误解为全字段免费替代 | 请求 `pe`、行业或完整涨跌停 | 在 manifest/API 能力声明中标记 partial/blocked |
| 合规 | 免费源缓存和再分发授权不清 | 准备对外展示或 SaaS 化 | 先完成授权审查，MVP 限内部研究 |

## 7. Definition of Done

- 文档包和 backlog 已更新。
- 采集原始数据、标准化表和候选 release 可定位。
- 两张目标表满足 schema 和日期契约。
- 质量报告明确覆盖率、异常、来源和未完成字段。
- 旧 release 可回读，新 release 可切换和回滚。
- 测试和代表性回测通过，未引入隐式填充或未来函数。
