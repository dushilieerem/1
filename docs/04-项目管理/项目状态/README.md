# 项目状态

本目录保存项目级当前状态和已交付事实。具体 Feature 的状态以 [`../../01-需求文档/项目组合/portfolio-backlog.md`](../../01-需求文档/项目组合/portfolio-backlog.md) 和 Feature README 为准；ResearchEngine 的模块状态见 [`ResearchEngine/docs/04-项目管理/模块状态/`](../../../ResearchEngine/docs/04-项目管理/模块状态/)。

状态快照应回答：当前完成了什么、正在做什么、阻塞是什么、下一步是什么，以及事实由哪份验证或发布记录支撑。
