# ADR-008：财务因子数据采用公告日点时面板

## 问题

基础、质量、成长和每股因子依赖财务报表。若以报告期结束日将财务值填入日频面板，历史回测会使用当时尚未公开的报表，产生未来函数。

## 选择

保存包含报告期、公告日、来源版本和修订信息的原始财务记录；仅在公告日及之后，将当时可见的最新版本转换为日频 `日期 × 标的` 点时面板。TTM 仅使用当时已公告的四个季度，数据不完整时返回空值。字段字典统一定义单位、频率和口径。

## 备选方案

1. 按报告期结束日填充：实现简单，但会引入未来函数。
2. 只存供应商已经加工的日频指标：接入快，但无法审计公告日、修订和供应商口径。
3. 运行时直接访问供应商 API：数据最新，但回测不可复现，且受网络、配额和权限影响。

## 后果

研究结果更可信、可复现且可审计；代价是需要维护原始记录、转换任务、数据版本和更严格的数据质量测试。因财报披露滞后，因子覆盖率在公告窗口前会自然降低，这属于真实信息边界而非缺陷。
