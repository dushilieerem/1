# SVQuant 使用说明

## 1. 系统简介

SVQuant 是量化投研产品，提供用户界面、用户与权限、研究资产管理、社区、知识库和研究结果展示。行情读取、因子/策略执行与回测由独立 ResearchEngine（RE）提供；SVQuant 通过后端 API 调用，不在浏览器中直连 RE。

## 2. 登录与访问

- 部署环境的访问地址和账号由系统管理员提供。
- 本地开发环境默认前端地址为 <http://127.0.0.1:9530>；启动方式见[部署文档](../07-部署文档/部署文档.md)。
- 登录失败时先确认用户名、密码和账号状态；管理员可通过用户管理流程处理账号，不要把密码或 Token 发到文档、群聊或 Git 仓库。
- 不同页面和管理操作受用户角色限制；无权限时联系系统管理员。

## 4. 使用限制

- 研究计算需要 RE 服务可访问；RE 不可用时，SVQuant 会报告服务错误，不承诺回退到本地计算。
- 内置因子/策略目录和执行能力由 RE 管理；SVQuant 页面展示、鉴权和用户产品数据由 SVQuant 管理。
- 策略和因子 API 的实际字段以运行中的接口文档及 API 契约为准；指南中的示例用于说明写法，不替代接口 schema。
