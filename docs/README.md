## 推荐阅读顺序

1. 阅读 [需求文档/PRD.md](需求文档/PRD.md)，理解项目背景、目标、范围和风险。
2. 阅读 [架构文档/系统架构.md](架构文档/系统架构.md)，理解 SVQuant 与 ResearchEngine 的职责边界。
3. 阅读 [模块详细设计/SVQuant产品层/模块设计.md](模块详细设计/SVQuant产品层/模块设计.md)，进入模块拆分和核心逻辑。
4. 涉及实现、数据、接口、验证、启动和用户操作时，分别查看类设计、流程设计、数据库设计、API 设计、测试设计、部署文档和使用说明。
