## 维护规则

1. 当前版只写语义目录，不再新增 `*新/`、`最终版`、`v2` 之类目录或文件名。
2. 旧版移动到 `归档/YYYY-MM-主题/`，保留原路径结构，不直接删除。
3. 模块设计放 `模块设计/<模块>/`；功能包放 `功能包/FEAT-*/`，两者不混放。
4. 移动或重命名文档时，必须同步修复相对链接，并跑一次全库链接检查。
5. 文档结论变化时，回写上游（PRD/架构）与下游（FEAT/测试），不要只改一处。
6. 文档 ID（`ADR-033`、`FEAT-010`、`01-测试策略`）保留；目录名不再加数字前缀。
