## 1. 因子编写手册（目录草案）

**目标读者**：要在 SVQuant 里写自定义因子、跑检测的人  
**一句话**：从「打开因子库/检测」到「写出可跑因子并看懂报告」

1. 概述：什么是因子、和策略的区别、本手册范围  
2. 平台入口  
   - 因子库 / 用户库  
   - 因子检测列表与新建检测  
   - AI 因子生成（可选入口）  
3. 因子代码约定  
   - 函数签名与 `self.close` 等字段  
   - 返回值形状（日期 × 标的）  
   - 常见坑：未来函数、空值、预热  
4. 最小可跑示例（1～2 个，如动量）  
5. 跑检测：参数含义（股票池、分组、换仓、基准）  
6. 报告怎么读：分组收益、IC、多空（点到为止，链到因子文档）  
7. 入库与社区克隆到因子  
8. 附录：字段速查表；相关链接（API / RE）

**建议落点**：`docs/help/因子编写手册.md` → `/help` 内链或同页折叠

## 2. 策略编写手册（目录草案）

**目标读者**：要写/回测策略、看研究报告的人  
**一句话**：从「打开策略库/研究」到「写出可回测策略并看懂报告」

1. 概述：策略与因子检测的关系、本手册范围  
2. 平台入口  
   - 策略库 / 研究列表  
   - 回测页（配置 / 代码）  
   - AI 策略生成（可选）  
3. 策略代码约定（与平台模板对齐，待补真实模板字段）  
4. 最小可跑示例  
5. 回测参数：区间、股票池、基准、费用  
6. 报告怎么读：净值、回撤、夏普等（点到为止）  
7. 入库与社区克隆到策略  
8. 附录：与因子手册交叉链接

**建议落点**：`docs/help/策略编写手册.md`

## 3. 因子文档（目录草案）

**目标读者**：查某个内置/用户因子「是什么、怎么算」的人  
**一句话**：因子说明与查阅，不是「怎么写」教程（怎么写见手册 1）

1. 使用说明：如何检索、如何打开因子详情  
2. 内置库总览（按库分类导航；可链现有 `因子库总览.md`）  
3. 单因子条目模板  
   - 名称 / 所属库  
   - 定义与用途  
   - 默认参数  
   - 字段依赖  
   - （可选）实现摘要或链到总览全文  
4. 用户自定义因子：本账号库内说明约定  
5. 附录：与检测报告字段对照

**本周最小交付**：目录 + 入口页 + **链到** `docs/因子库总览.md`（或摘 1～2 个样例条目），不要求本周重写 600+ 因子全文。

**建议落点**：`docs/help/因子文档.md`（索引页）
