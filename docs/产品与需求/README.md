## 进入下一层的最低条件

- 明确要解决的业务问题和目标用户。
- 有可衡量的成功指标或可验证的判断标准。
- 写清必须做、可以以后做和明确不做的范围。
- 标注优先级、风险、依赖和时间约束。
- 能说明“不做这个需求”会造成什么影响。
- 业务流程、角色规则和状态闭环已定义，不得用页面或接口设计替代业务定义。
