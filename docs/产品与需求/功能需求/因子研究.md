## 1. 背景与目标

### 1.1 为什么需要因子引擎？

因子是量化研究的核心——因子引擎的质量直接影响研究效率。

| 用户需求 | 因子引擎的响应 |
|---------|--------------|
| "我想验证动量因子是否有效" | 支持快速定义因子 → 计算因子值 → 分析有效性 |
| "WorldQuant alpha101 的因子我都要" | 内置 alpha101 因子库，开箱即用 |
| "这个因子在哪些行业表现好？" | 因子分析支持分行业 IC/IR |
| "我的因子组合收益率拆解" | 因子归因分析（Brinson/Barra） |

### 1.2 业务目标

- 用户能在 5 分钟内完成从定义因子到查看 IC/IR 的全流程
- 支持 5000+ 标的 × 2000+ 交易日的因子矩阵计算
- 因子分析覆盖 IC/IR/分层回测/相关性/换手/归因

## 3. 核心流程

```
输入数据（行情/基本面）
       ↓
因子表达式 → FactorEngine.compute()
       ↓
因子值矩阵（标的 × 日期）
       ↓
         ├── IC/IR 分析
         ├── 分层回测
         ├── 相关性矩阵
         ├── 换手率分析
         └── (V2) 分行业 / 归因分析
```

---

## 4. 技术约束

| 约束 | 说明 |
|------|------|
| 数据规模 | 5000+ 标的 × 2000+ 交易日，因子值内存占用可控 |
| 计算性能 | 单因子全市场计算 ≤ 5s |
| 存储格式 | Parquet 按字段存储（FieldParquetProvider），因子值以 numpy 数组形式管理 |
| 后端支持 | NumPy/Pandas 向量化计算（VectorEngine） |

---

## 5. 与其他模块的关系

```
DataEngine ──> FactorEngine ──> MetricEngine ──> BacktestEngine
    ↑               ↑                ↑                ↑
  行情数据        因子值          IC/IR/分层       策略回测
```

- **DataEngine**: 提供因子计算所需的行情/基本面输入
- **MetricEngine**: 消费因子值，计算 IC/IR/分层等指标
- **BacktestEngine**: 消费因子值或因子信号，构建策略组合并回测
