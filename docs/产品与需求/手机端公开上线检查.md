# 公开运行检查清单（Invest H5）

> 当前代码是 **MVP**：29 只标的已接腾讯/东方财富公开 EOD，主题为成分股等权代理，公告/研报/要闻为公开标题；账号/合规/生产运维未完成。公开运行前逐项确认；任何“未完成”都不应直接上线。

## A. 数据与版权（最高风险）

- [ ] 逐源确认：是否允许**公网展示**、商业使用、缓存、再分发、衍生指标。
- [ ] 当前 MVP 使用腾讯 K 线 + 东方财富财务/估值公开接口；公开展示前必须书面确认条款，必要时换持牌源。
- [ ] 新闻只保留标题、来源、时间、原文链接；不复制全文。
- [ ] 行情/财务/估值页面标注来源、数据日期、延迟口径。
- [ ] 机构评级/目标价不展示（当前未接）。
- [ ] 与法务/合规确认：免费源（含 AKShare 上游）公开使用的边界。
- [ ] 准备 provider 抽象与下线开关；被限流/封禁时可切回缓存或停用模块。

**结论：未完成前不要公开抓取数据；可先邀请制/内测，或缩减到指数/板块 + 组合体检。**

## B. 账号与权限

- [ ] 公开注册策略：注册代理已实现（默认关闭），是否开放、是否只允许主站注册后登录，需拍板。
- [ ] 若开放注册：验证码/频率限制/邮箱验证；避免刷号。
- [ ] H5 用户是否会越权访问桌面端社区/AI/模拟盘？需要 `invest` 角色/开关或邀请码。
- [ ] 找回密码：接 SVQuant 主站流程，或在 H5 提供邮箱重置。
- [ ] 账号注销：SVQuant 主站处理；H5 至少能删除 Invest 数据（已实现）。
- [ ] 登录限流、撞库防护、异常登录提示。

## C. 合规文本

- [ ] 隐私政策：收集范围、目的、保存期限、共享、删除/导出、联系方式（`/privacy` 草案已写，需法务审）。
- [ ] 用户协议（`/terms` 草案已写，需法务审）。
- [ ] 风险提示：非投资建议、不承诺收益、数据可能延迟/有误。
- [ ] 未成年人、适当性、投顾资质边界确认。
- [ ] ICP 备案（中国大陆公网）、公安备案（如适用）、域名/HTTPS。
- [ ] 客服/投诉入口（当前只有 toast 占位）。

## D. 安全

- [ ] `INVEST_JWT_SECRET` 强随机，禁用默认值。
- [ ] `INVEST_CORS_ORIGINS` 白名单，不放 `*`。
- [ ] Nginx/网关限流、WAF、防爬、登录/注册限流。
- [ ] CSP、XSS 清洗、HTTPS/HSTS、依赖扫描。
- [ ] SQLite/备份文件不在 Web 根目录；`data/` 不可公网访问。
- [ ] 管理/调试接口不暴露；`/docs` 公开前关闭或加鉴权。
- [ ] 持仓等敏感数据加密/脱敏、访问审计、保留期限。

## E. 运行与观测

- [ ] 单机 SQLite 迁移到 Postgres（并发/备份/恢复）。
- [ ] 每日 18:30 数据任务：失败告警、重试、质量检查、数据日期。
- [ ] 备份与恢复演练。
- [ ] 错误监控/可用性监控/核心漏斗埋点。
- [ ] 版本发布/回滚流程。

## F. 内容与产品边界

- [ ] 全站 0 “AI”文案；0 买卖建议/目标价/收益承诺。
- [ ] 0 自动交易/自动调仓/券商连接。
- [ ] “收盘数据/非实时”标识 100% 覆盖。
- [ ] 组合偏离只展示，不输出调仓建议。
- [ ] 热点 base rate 标注样本/区间/“不是预测”。
