# 用户画像与角色

> 本文档定义 SVQuant 的目标用户画像与角色权限体系。
> 关联：`产品定位.md`、`PRD.md` §3

---

## 1. 用户画像

### 画像一：量化开发者

| 属性 | 说明 |
|------|------|
| **占比预期** | 中高 |
| **特征** | 会 Python，有策略想法，熟悉量化概念 |
| **核心诉求** | 因子研究、回测、AI 辅助开发/debug、绩效归因 |
| **典型场景** | 编写因子 → 跑 IC/IR 分析 → 构建多因子策略 → 回测 → AI 解读结果 → 优化 |
| **技术门槛** | 中 |

### 画像二：投研团队/私募

| 属性 | 说明 |
|------|------|
| **占比预期** | 中（增长中） |
| **特征** | 专业投研背景，需要策略生产化 |
| **核心诉求** | 组合管理、风控、归因分析、策略生产化、合规报告 |
| **典型场景** | 策略部署到模拟盘 → 监控组合风险 → 归因分析 → 调优 |
| **技术门槛** | 中低 |

### 画像三：投研教学/学习

| 属性 | 说明 |
|------|------|
| **占比预期** | 低 |
| **特征** | 高校学生/培训机构 |
| **核心诉求** | 教学演示、AI 辅助学习量化概念 |
| **典型场景** | 跟随 AI 指导学习因子/策略概念 → 运行示例策略 → 理解回测结果 |
| **技术门槛** | 低 |

## 2. 用户角色与权限

| 角色 | 目标用户 | 关键权限 |
|------|---------|---------|
| **免费用户** | 入门体验者 | A 股日线数据、限额 AI 调用、限额回测次数 |
| **个人专业版** | 量化开发者 | 分钟数据、高额度 AI/回测、因子研究全功能 |
| **团队版** | 投研团队 | 共享策略/因子、团队协作空间 |
| **机构版** | 私募/自营 | 组合管理、风控、合规审计、专属算力 |
| **平台运营** | 内部人员 | 用户管理、内容审核、数据监控 |

## 3. 用户旅程

### 旅程 A：量化开发者 — 深度研究

```
Step 1  编写/导入因子代码
           ↓
Step 2  AI 辅助因子分析（IC/IR/分层）
           ↓
Step 3  构建多因子策略 → 向量化/事件驱动回测
           ↓
Step 4  AI 解读回测结果 → 优化建议
           ↓
Step 5  绩效归因（行业/风格/因子贡献）
```

### 旅程 B：投研团队/私募 — 策略生产化

```
Step 1  策略从研究环境部署到模拟盘
           ↓
Step 2  实时监控组合风险敞口
           ↓
Step 3  自动生成合规与绩效报告
           ↓
Step 4  归因分析驱动策略调优
```

### 旅程 C：AI 新手 — 引导式学习

```
Step 1  AI 对话："帮我写一个低估值高股息策略"
           ↓
Step 2  AI 生成代码 + 解释策略逻辑
           ↓
Step 3  一键回测 → AI 解读结果
           ↓
Step 4  提问式学习："什么是 IC/IR？"
```

## 4. 用户决策路径

用户在选型时关注什么？

| 决策因素 | 权重 | 说明 |
|---------|------|------|
| 数据覆盖 | ⭐⭐⭐⭐⭐ | 基础要求，不全直接出局 |
| 回测精度 | ⭐⭐⭐⭐ | 是否支持 T+1、涨跌停等 A 股规则 |
| AI 能力 | ⭐⭐⭐⭐ | 能否真正提升效率 |
| 因子分析 | ⭐⭐⭐ | IC/IR/分层/归因是否完整 |
| 价格 | ⭐⭐⭐ | 对比聚宽/米筐定价 |
| 行业分析 | ⭐⭐ | 独特价值，决策加分项 |
