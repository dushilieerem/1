## 1. 背景与目标

机构版服务的是「研究驱动」的资产管理团队：研究员按条线找因子，策略从因子里长出来，经过研究质量与风控两道审批，最后由基金经理决定上不上、上多少，托管进产品。

目标：让 **因子 → 策略 → 审批 → 托管 → 产品** 这条链在一个工作台里跑通，每一步都有 Agent 参与、有据可查、有人负责。

**非目标**：本版不做券商柜台直连、不做估值核算、不做面向个人投资者的销售流程。

---

## 2. 角色与职责

| 角色 | 职责 | 关键动作 |
| --- | --- | --- |
| 技术指标研究员 | 量价、动量、波动、形态类因子 | 研究工作台验证想法、挖因子、构建策略、提交审批 |
| 基本面研究员 | 财务、估值、质量、行业景气因子 | 同上（基本面条线） |
| 宏观情绪研究员 | 宏观、资金流、舆情、另类数据因子 | 同上（宏观条线） |
| 研究总监 | 研究质量把关、因子入库与共享 | 研究审批、因子共享、查看全部策略 |
| 风控总监 | 容量、集中度、流动性、限额 | 风控复核、限额调整、熔断与处置 |
| 基金经理 | 最终决策：上不上、上多少 | 托管决策、额度分配、一页纸、产品分析 |

三条研究线各自独立沉淀因子与策略；跨条线可引用因子，但策略归属创建者。

## 3. 核心流程

```
研究员（三条线）
  ├ 研究工作台：想法 → 候选 brief（进度+三选一）→ 对话调整 → 代码 → 回测 → 诊断 → 改进 → 归档
  ├ 因子库：挖掘 → 检测（IC/IR、共线性、中性、极值、未来函数）→ 入库 / 共享
  └ 策略库：从因子库选因子 → 构建 → 回测 → 五角度分析 → 优化 → 提交
        │
        ▼
研究总监：研究审批（逻辑、过拟合、样本外、文档）      ← 研究预审 Agent
        │ 通过
        ▼
风控总监：风控复核（容量、流动性、集中度、相关性）    ← 风控审查 Agent
        │ 通过
        ▼
基金经理：决策（上 / 不上 / 上多少）                  ← 一页纸 Agent
        │ 托管
        ▼
产品：策略进入产品，按额度运行；产品分析 Agent 定期出多角度分析与一页纸
```

状态机：`草稿 → 待研究审批 → 待风控复核 → 待基金决策 → 托管中`（任一步可 `已拒绝`）。

**硬约束**：提交人不能参与自己策略的审批；Agent 只能给建议，状态变更必须人工确认。

## 4. 功能需求

### F1 机构空间与角色（P0）

- 多机构切换；机构内按角色分权（见第 5 节）。
- 角色可随时切换查看（演示态），真实环境由管理员分配。
- 验收：越权操作被隐藏或拒绝，并记录审计。

### F2 研究工作台（P0）

研究员的「实验台」，把模糊想法推进到可复现结论，而不是直接跳去写策略。

- 八步流程：想法 → 候选 brief（生成进度 + 三选一）→ 对话调整 → 代码 → 回测 → 诊断 → 改进复测 → 结论归档。
- 想法：一句话 + 股票池 / 调仓频率 / 成本 / 基准标签；点「生成研究 brief」后显示生成进度条。
- 候选 brief：进度完成后给出 3 个候选（稳健 / 进攻 / 低换手），展示股票池、调仓、约束与预期。
- 对话调整：研究员与 Agent 多轮对话，按「换手 / 规模 / 区间 / 行业」修改所选 brief，并回显变更。
- 代码：选定 brief 后生成代码，带 brief 参数；体检未来函数、成本、停牌/涨跌停、字段口径、留出集五项。
- 回测：年化、超额、回撤、Sharpe、换手；净值曲线与分年度表现。
- 诊断：成本/换手、IC 衰减、风格暴露、过拟合四项，每项带证据与阈值。
- 改进：A/B/C 候选，固定区间/成本/基准/留出集做同条件复测，只选一个。
- 结论：有条件通过 / 不通过，附保留意见、失效条件、复现信息；归档后进入策略库草稿。
- 研究纪律：实验预算、留出集只用一次、多重检验（PBO / Deflated Sharpe）。
- 验收：同一研究从想法到归档全程可追溯；归档后策略库可见且带着复现信息。

### F3 因子库（P0）

- 因子字段：名称、条线、来源（研报/公告/财报/数据/舆情/自研）、IC、IR、覆盖率、被使用次数、状态、说明。
- 状态：草稿 / 检测中 / 已入库 / 已共享。
- 因子工厂：常驻运行的生产线，非手动单轮。每轮调度 Agent 拆任务，技术 / 基本面 / 宏观 Agent 并行提假设，检测 Agent 跑五项检查，汇总成候选池；研究员逐条审核入库或驳回（记录原因）。待审核积压到阈值自动暂停，审核后自动恢复；Agent 不直接改因子库。
- 检测项：IC/IR、分组单调性、共线性、行业中性、极值、未来函数。
- 研究总监可将因子共享到机构库；共享后其他条线可引用。
- 验收：未入库因子不能被策略引用；检测报告可追溯到样本区间。

### F4 策略库（P0）

- 策略字段：名称、条线、负责人、因子组合、年化、回撤、夏普、容量、版本、状态。
- 从因子库选因子构建；构建 Agent 给出权重、调仓频率与相关性检查。
- 策略分析 Agent 从收益归因、风格暴露、容量、换手、相关性五个角度给结论。
- 策略优化 Agent 针对回撤/换手/容量给可执行方案，生成 vNext 草稿。
- 验收：策略任一版本可回看因子组合与回测口径。

### F5 审批中心（P0）

- 三条泳道：研究审批、风控复核、基金决策。
- 每个策略卡片展示 Agent 预审摘要；通过/拒绝/退回均需填写意见。
- 研究总监通过 → 进入风控复核；风控通过 → 进入基金决策；任一步拒绝 → 已拒绝并通知研究员。
- 验收：审批链完整可查（谁、何时、什么意见），不可跳级。

### F6 基金经理决策与托管（P0）

- 基金经理看到待决策策略的一页纸：逻辑、业绩、风险、相关性、额度建议。
- 决策：托管（填写额度，建议 ≤ 容量 60%）或不上（填原因）。
- 托管后策略进入产品，按额度运行；额度变更需重新审批。
- 验收：托管记录包含决策人、额度、产品、时间。

### F7 产品管理（P0）

- 产品列表：规模、年化、回撤、夏普、托管策略、基金经理。
- 产品详情：净值、托管策略及额度、策略贡献。
- 多个 Agent 从业绩、回撤、集中度、策略贡献角度分析，生成一页纸。
- 验收：一页纸数据与产品页一致，导出带水印。

### F8 风控中心（P0）

- 限额：单票集中度、行业暴露、回撤、换手、杠杆、流动性；机构 → 产品 → 组合取最严。
- 事件：触发、指派、处置、关闭；熔断可暂停策略，恢复需风控总监确认。
- 验收：触发到通知 ≤ 60 秒；熔断与恢复均留痕。

### F9 Agent 协作层（P0）

见第 6 节。

### F10 研讨厅（P0）

- 议题：支持个股、因子、策略三类标的。
- 9 步议程：立题 → 事实冻结 → 价值研究 → 正方立论 → 反方立论 → 交叉质询 → 证伪确认 → 裁决 → 归档。
- 事实官冻结带 fid 的 FactPack 并做哈希；正反方每条论点必须绑定 fid + confidence + falsifier；引用不存在的 fid 会被拦截，不计入裁决。
- 反方首轮与正方互不可见；主持按裁决矩阵出结论，不得用票数裁决；记录员生成结论先行的一页纸，少数意见挂跟踪编号。
- 人机协作：FactPack 数据准确性由真人负责；管理层诚信等定性判断由真人补位；裁决公正性与留痕完整由真人确认。
- 验收：一次完整研讨 ≤ 10 分钟；每条有效论点可回溯到 fid；一页纸含结论、关键事实、多空要点、裁决条件与少数意见。

### F11 审计与报告（P1）

- 审计：登录、审批、托管、额度变更、Agent 动作。
- 报告：策略一页纸、产品一页纸、月度合规报告。
- 验收：任一策略生命周期 3 次点击内可追溯。

## 7. 非功能需求

- **安全**：SSO + 双因素；会话 30 分钟失效；敏感操作二次确认；导出水印。
- **审计**：写操作记录操作者、时间、IP、对象、前后值；不可篡改；保留 ≥ 5 年。
- **性能**：列表 P95 < 800ms；策略详情 < 2s；一页纸生成 < 30s。
- **可用性**：核心页面 99.9%；日终结算失败重试 3 次并告警。
- **部署**：公有云与私有化；私有化提供离线升级包。

## 10. 验收标准（首版）

1. 研究员能在 10 分钟内完成「挖因子 → 检测 → 入库 → 构建策略 → 提交」。
2. 一条策略从提交到托管，审批链完整、不可跳级、每步有意见与时间。
3. 基金经理能在一页纸中看到额度建议并直接决策。
4. 任一产品的业绩可拆到策略与因子贡献。
5. Agent 建议均可展开证据；未经确认不改变任何业务状态。

## 12. 开放问题

- 三条研究线是否需要各自的因子入库标准（技术看衰减、基本面看行业中性、宏观看样本长度）？
- 策略容量由谁测算：风控统一，还是研究员自报 + 风控复核？
- 基金经理的额度决策是否需要投委会二次确认？
- 一页纸对外发送的合规审核流程由谁负责？
- Agent 默认模型与私有化推理的边界。
