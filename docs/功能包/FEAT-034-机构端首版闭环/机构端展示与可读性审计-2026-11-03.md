## 2. 共用改动

- `StatusBadge` 补齐 `submitted / watch / research / dropped / demo / changed / revoked / expired / open / reviewing / resolved / approve / conditional / return` 等枚举中文。
- 新增 `industryLabel`：行业代码（`801120.SI`）与 null 统一显示「行业待补充」。
- 新增 `HelpTip` 与 `Badge.title`：动量、PE TTM、PB MRQ、权重、严重度等可悬停解释。
- 新增 `fmtDateTime`：审批、授权、预警、异常时间统一本地格式。
- 研究/审批/执行/投后/组合的两栏布局从 `lg` 改为 `xl`，1024 窄屏自动堆叠，避免右侧栏挤压。
