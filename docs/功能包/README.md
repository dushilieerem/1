## 目录约定

```text
FEAT-XXX-名称/
├── README.md                  # 状态、范围、上下游、验收摘要
├── 02-product-requirements.md # 需求与业务规则（如有）
├── 03-technical-design.md     # 技术方案（如有）
└── 05-verification.md         # 验收与证据（如有）
```

## 规则

- 目录名使用 `FEAT-XXX-名称`，XXX 为稳定编号，不复用。
- 功能包内部只放本次交付相关材料；跨模块结论回写 `模块设计/`，长期决策写 `技术决策/`。
- 功能包完成后保持只读；后续变更新建功能包，不直接改历史验收记录。
- 历史 FEAT 仍保留原编号与目录结构，迁移只改变父目录，不改包内文件。
