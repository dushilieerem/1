## 1. 产品概述

### 1.1 一句话定位

SVQuant 是一个**以 AI 为核心驱动的一站式 A 股量化投研平台**，让量化研究者高效完成策略研发、回测、行业分析与绩效归因，并能向模拟盘与实盘交易平滑延伸。

### 1.2 背景与问题

当前量化投研市场的主要平台存在以下问题：

1. **AI 渗透浅**：聚宽、米筐、BigQuant 的 AI 多停留在代码补全或可视化建模层面，缺少以自然语言驱动的端到端研究助手，未能真正降低量化研究门槛。
2. **链路割裂**：数据获取、因子计算、策略回测、绩效归因散落在不同工具或平台模块中，研究效率低。
3. **行业/政策分析缺失**：现有量化平台只做数字分析（因子、回测、IC/IR），缺乏对行业景气度、政策走向的定性+定量融合分析能力。

### 1.3 产品愿景

让每一位量化研究者——无论 coding 水平高低——都能借助 AI 的力量，把对市场、行业、政策的洞察转化为可验证的量化策略。**"AI 赋能，量化投研。"**

### 1.4 公司三大宗旨在本产品中的体现

| 宗旨 | 产品体现 |
|------|---------|
| **① 最大化 AI 能力** | AI 生成策略/因子代码、解读回测结果、归因分析、自动生成投研报告；AI 辅助行业与政策分析 |
| **② 全面分析行业和政策** | 平台内建行业分类、政策事件库、行业景气度指标；AI 自动追踪并解读政策影响；量化因子 + 基本面 + 政策的融合分析 |
| **③ 基础量化设施不低于竞品** | 数据覆盖（A股日线/分钟/基本面/另类）、回测引擎（向量化+事件驱动双引擎）、因子分析（IC/IR/分层/归因）、绩效报告——对标聚宽/米筐/BigQuant 同级别 |

## 2. 市场与竞品分析

### 2.1 目标市场

A 股量化投研市场，面向量化开发者、投研团队与私募等专业投资者。

### 2.2 竞品对标

| 维度 | 聚宽 JoinQuant | 米筐 RiceQuant | BigQuant | SVQuant |
|------|---------------|---------------|----------|---------|
| **AI 能力** | 弱（代码补全级） | 弱 | 中（AutoML） | **强（AI 对话+分析+报告+行业分析）** |
| **行业/政策分析** | 无 | 无 | 无 | **有（AI 行业分析+政策解读）** |
| **数据覆盖** | A股/期货/基金 | A股/期货/期权 | A股/期货/ETF | A股全市场（对标） |
| **回测引擎** | 事件驱动 | 事件驱动 | 图形+Python | 向量化+事件驱动双引擎 |
| **因子分析** | IC/IR/分层 | IC/IR/分层 | 因子挖掘 | IC/IR/分层/归因 |
| **目标用户** | 个人量化 | 个人+机构 | 个人量化 | **量化开发者 + 投研团队** |
| **产品形态** | SaaS | SaaS | SaaS | **平台化（从研究到实盘）** |

### 2.3 核心差异化

| 差异化点 | 说明 |
|---------|------|
| **AI 驱动全链路** | 不同于竞品的"AI 点缀"，从策略生成、回测调度、结果解读、归因分析到报告生成，AI 贯穿始终 |
| **行业+政策分析** | 竞品不做、用户需要的独特能力。AI 自动追踪行业景气度、政策变化，融合到量化分析中 |
| **基础设施不落下风** | 数据、回测、因子分析对标聚宽/米筐，不打折扣 |

## 3. 目标用户与角色

### 3.1 用户画像

| 画像 | 占比预期 | 特征 | 核心诉求 |
|------|---------|------|---------|
| 量化开发者 | 中高 | 会 Python、有策略想法 | 因子研究、回测、AI 辅助开发/ debug、绩效归因 |
| 投研团队/私募 | 中（增长中） | 专业投研、需要策略生产化 | 组合管理、风控、归因分析、策略生产化 |
| 投研教学/学习 | 低 | 高校/培训 | 教学演示、AI 辅助学习量化 |

### 3.2 用户角色与权限

| 角色 | 说明 | 关键权限 |
|------|------|---------|
| 免费用户 | 注册即得 | 日线数据、限额 AI、限额回测 |
| 个人专业版 | 订阅个人档 | 分钟数据、高额度 AI/回测、因子研究 |
| 团队版 | 多人协作 | 共享策略/因子、团队空间 |
| 机构版 | 私募/自营 | 组合管理、风控、合规审计、专属算力 |
| 平台运营 | 内部 | 用户管理、内容审核 |

### 3.3 典型用户旅程

**旅程 A（量化开发者）：深度研究**
1. 在平台上编写/导入因子代码
2. AI 辅助因子分析（IC/IR/分层）
3. 构建多因子策略 → 向量化/事件驱动回测
4. AI 解读回测结果 → 优化建议
5. 绩效归因（行业/风格/因子贡献）

**旅程 B（投研团队/私募）：策略生产化**
1. 研究产出的策略部署到模拟盘
2. 实时监控组合风险
3. 自动生成合规报告
4. 策略归因与调优
