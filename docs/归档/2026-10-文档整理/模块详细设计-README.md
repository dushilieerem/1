## 规则

- 新模块设计放在 `<模块>/`，包含模块、类、流程三份；不再使用编号目录。
- 新功能包使用 `FEAT-XXX-名称/README.md`，内部文件按 `02-product-requirements.md`、`03-technical-design.md`、`05-verification.md` 组织。
- 跨模块决策写入 [`../09-技术决策/`](../../技术决策/)；不要在多个模块里复制同一结论。
- 历史模块设计（`03-模块详细设计/`）已归档到 `../99-历史归档/2026-10-文档整理/03-模块详细设计/`。
