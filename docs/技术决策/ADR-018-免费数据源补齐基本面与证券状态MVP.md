# ADR-018：免费数据源补齐基本面与证券状态 MVP

- 日期：2026-08-14
- 状态：提案中
- 关联：FEAT-010、FEAT-024、FEAT-025、ADR-010、ADR-017

## 问题

`daily_basic.parquet` 和 `security_status.parquet` 落后于行情数据，且现有证券状态中的 `is_st` 为空。短期内若等待商业数据源全量完成，基本面因子和停牌/ST 相关回测会继续阻塞；但直接把不同口径的免费数据混入现有 release，又会破坏历史可复现性。

## 选择

1. 采用 BaoStock 作为沪深历史估值和交易状态的 MVP 来源。
2. 采用 AKShare/CNINFO 股本变动作为股本事件来源；用本地未复权收盘价和股本计算市值。
3. 免费源仅通过采集、标准化和候选 release 进入系统，不允许在线响应直接进入回测。
4. 按字段指定唯一主来源，不做逐单元格静默多源回退。
5. 保留 `pe` 的 iFinD 语义；不使用免费源动态 PE 替代。
6. 没有有效日期的申万行业、完整涨跌停文本不回填历史。
7. MVP 默认仅限内部研究，数据再分发和商业化必须另行审查授权。

## 备选方案

### 只使用 AKShare

接口覆盖广，但历史字段口径分散、稳定性和上游授权需要逐接口确认，无法单独承担沪深历史估值和交易状态的稳定契约。

### 只使用 BaoStock

适合沪深日频字段，但股本事件、北京市场和部分快照校验能力不足，无法覆盖完整 MVP。

### 直接把免费源覆盖当前文件

不采用。会破坏既有 release 的可复现性，且无法审计数据口径切换。必须先生成候选 release 并验证后切换。

### 用当前行业快照回填历史

不采用。它会把未来分类泄漏到过去，污染行业因子和历史回测。

## 后果

### 正面

- 开发环境可较快恢复沪深估值和交易状态数据。
- 保持 FEAT-024 的文件、字段和 Provider 契约不变。
- 免费源覆盖不足和口径差异均可通过 manifest 和质量报告暴露。
- 后续切回 iFinD 或接入其他源时只需新增字段级 release 规则。

### 负面与约束

- 免费源并不保证全市场、全历史和商业可再分发。
- BaoStock 与 iFinD 的估值口径可能不同，因子结果需要重叠期复核。
- 北京市场、行业历史和完整涨跌停状态仍有缺口。
- 采集任务需要处理限流、断点续传、SDK 版本和原始快照保存。
