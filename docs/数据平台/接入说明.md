# 数据平台接入说明

> 数据平台仓库：`/home/dev01/project/svquant-data`（独立 git 仓库）
> 当前视图：`research-rv-20261031`

## 边界

- 数据平台负责：采集、规范化、质量/对账、release、目录/血缘。
- SVQuant 只负责业务：API/UI/社区/AI；只读数据视图，**不再新增采集脚本**。
- ResearchEngine 只负责计算：只读视图，运行结果记录 `view_id`。

## 读取

```python
from svquant_data.reader import DataView

view = DataView("research-rv-20261031")
daily = view.read("daily_bars")
valuation = view.read("valuation", start="2026-09-30", end="2026-09-30")
financial = view.read("financial_income", symbols=["600519.SH"])
```

配置：

```text
SVQUANT_DATA_ROOT=/home/dev01/project/svquant-data
SVQUANT_DATA_VIEW=research-rv-20261031
```

## 现有 SVQuant 采集脚本

`scripts/etl_marketdata.py`、`fetch_financials.py`、`load_marketdata_missing.py`、
`sync_h5_news.py`、`populate_invest_topics*.py` 属于**过渡期脚本**：

- 新数据应先进 `svquant-data` 的 raw/release；
- 生产业务只读 release；
- 迁移完成后删除 SVQuant 侧采集入口，避免两套口径。

## 约束

- 不写 `free/`、`vendor/`；
- 不直接读 `free/staging`；
- 回测/研究记录 `view_id`；
- 财务按公告日 PIT，禁止最新值回填历史。
