## 边界

- 数据平台负责：采集、规范化、质量/对账、release、目录/血缘。
- SVQuant 只负责业务：API/UI/社区/AI；只读数据视图，**不再新增采集脚本**。
- ResearchEngine 只负责计算：只读视图，运行结果记录 `view_id`。

```python
from svquant_data.reader import DataView

view = DataView("research-rv-20261031")
daily = view.read("daily_bars")
valuation = view.read("valuation", start="2026-09-30", end="2026-09-30")
financial = view.read("financial_income", symbols=["600519.SH"])
```

```text

# 自动同步目标；显式研究/回测仍可传具体 view id
SVQUANT_DATA_VIEW=current
```

## 数据需求流程

数据采集/落盘/发布统一由 `svquant-data` 负责。SVQuant/RE 只做业务，不写采集脚本。

需要数据时，按下面格式提出，由用户转给数据项目：

```text
数据集：
用途/业务页面：
字段：
粒度：日 / 分钟 / 事件 / 快照
时间范围：
主键与去重：
PIT 规则：公告日 / 生效日 / 无
更新频率：
质量要求：覆盖率、对账源、缺失处理
期望 release / view：
验收样例：
```

拿到发布物后，业务侧只读 view；缺数据先提需求，不在 SVQuant 里临时补采集。
