  1. `valuation_daily.float_mv/ps_ttm` 是否允许“iFinD 为主 + 免费源补两列”的显式跨源；

- **已确认 blocked**：A/H/ADR、FX、美/港财务与公告、交易规则、ETF 成分、主题历史成分、P1-1 指数。

## 4. 硬要求（更新频率 / 延迟 / 历史 / 单位）

- **频率与延迟**：日频 EOD，18:30 CST 前发布，19:00 前 `views/current` 切换完成；不做实时。
  失败时保留上一 view 并告警，不发布半成品。
- **历史起点**：日线 2005+；估值/财务 2016+（PIT）；分钟 2025+ 即可。
- **单位**：
  - 成交量=股、成交额=元；
  - 换手率、指数权重、**iFinD 股息率（`valuation_daily.dividend_yield_ttm`）与 `pershare_index.gross_margin`=百分数**；
  - **免费 `valuation.dividend_rate`=小数**（0.05172=5.17%），与 iFinD 定义、单位都不同，**不可互换、不可统一乘除 100**；
  - PE/PB/PS=倍数；缺失保持 null，不填 0。
- **复权**：`hfq` 与 `none` 显式区分；执行与估值用未复权，图表/回测用后复权。
- **PIT**：财务 `m_anntime <= as_of`；指数成分按生效日；universe 按 as_of 当日。
- **代码**：`600519.SH` / `AAPL.O`；北交所保留 `.BJ`；退市证券保留历史。
- **变更**：契约版本 + changelog；新增字段向后兼容，删除/改单位必须升版本。

## 5. 与 RE 共享的口径

1. 同一 `view_id`、同一 `free/compat` 树；研究/回测记录 `view_id`。
2. **股息率按字段处理**：
   - `valuation_daily.dividend_yield_ttm`：百分数（3.406 = 3.406%）；
   - `valuation.dividend_rate`：小数（0.05172 = 5.17%），且是免费源不同定义；
   - SVQuant 侧只在 `md_valuation_daily.dividend_yield_ttm` 存百分数（H5 渲染时加 `%`）。
3. **毛利率在 SVQuant PG 里有两套历史约定，loader 必须显式转换**：
   - `fin_indicator.gross_margin`（机构端）= 小数 0.8976；
   - `financials.gross_margin`（H5）= 百分数 89.76；
   - 数据平台 `pershare_index.gross_margin` = 百分数 89.56；
   - loader：机构表 `/100`，H5 表原样写入。
4. **行业口径**：业务与 RE 都用 SW L1/L2；THS code 仅辅助。映射完成前，`sw_*` 为 null 时按 THS 展示并标注“行业待映射”。
5. **复权口径**：`daily_bars` 为 hfq、`daily_bars_unadjusted` 为 none；两侧不得各取一套。
6. **as_of 语义一致**：`date <= as_of`，财务按公告日；`latest=True` 只用于快照，不用于回测。
7. **列名**：免费域 `time`、iFinD 域 `date`、派生域 `date`；契约提供 `trade_date` 统一别名。
