## 0. 结论（修订后）

- 现有 29 个 dataset 覆盖 SVQuant 的 **A 股业务基线约 85%**：行情、估值、财务 PIT、状态、行业、
  指数/成分、日历、ETF 日线都能直接用。
- **可立即补的 P0（现有数据即可）**：
  1. `security_status_daily` 增加 `is_st` / `is_suspended` 布尔并固定枚举；
  2. `daily_bars_unadjusted` 补 `volume/amount/turnover`（`pre_close` 归入 P1-3）；
  3. 财务毛利改用 `pershare_index.gross_margin`（百分数），不要求营业成本字段；
  4. 契约增加 `trade_date` 别名与 `column_source`。
- **需要用户决策**：
  1. `valuation_daily.float_mv/ps_ttm` 是否允许“iFinD 为主 + 免费源补两列”的显式跨源；
  2. SW 行业映射（P1-4）是否采购/授权映射表。
- **已确认 blocked**：A/H/ADR、FX、美/港财务与公告、交易规则、ETF 成分、主题历史成分、P1-1 指数。
- `ifind/us_stock` 可入契约，但需拆成 `us_stock_quotes_hfq/bfq`、`us_stock_calendar`、`us_stock_universe`。
- serving 派生表由 **SVQuant 自行派生**，不需要数据平台额外提供。

## 4. 硬要求（更新频率 / 延迟 / 历史 / 单位）

- **频率与延迟**：日频 EOD，18:30 CST 前发布，19:00 前 `views/current` 切换完成；不做实时。
  失败时保留上一 view 并告警，不发布半成品。
- **历史起点**：日线 2005+；估值/财务 2016+（PIT）；分钟 2025+ 即可。
- **单位**：
  - 成交量=股、成交额=元；
  - 换手率、指数权重、**iFinD 股息率（`valuation_daily.dividend_yield_ttm`）与 `pershare_index.gross_margin`=百分数**；
  - **免费 `valuation.dividend_rate`=小数**（0.05172=5.17%），与 iFinD 定义、单位都不同，**不可互换、不可统一乘除 100**；
  - PE/PB/PS=倍数；缺失保持 null，不填 0。
- **复权**：`hfq` 与 `none` 显式区分；执行与估值用未复权，图表/回测用后复权。
- **PIT**：财务 `m_anntime <= as_of`；指数成分按生效日；universe 按 as_of 当日。
- **代码**：`600519.SH` / `AAPL.O`；北交所保留 `.BJ`；退市证券保留历史。
- **变更**：契约版本 + changelog；新增字段向后兼容，删除/改单位必须升版本。

## 5. 与 RE 共享的口径

1. 同一 `view_id`、同一 `free/compat` 树；研究/回测记录 `view_id`。
2. **股息率按字段处理**：
   - `valuation_daily.dividend_yield_ttm`：百分数（3.406 = 3.406%）；
   - `valuation.dividend_rate`：小数（0.05172 = 5.17%），且是免费源不同定义；
   - SVQuant 侧只在 `md_valuation_daily.dividend_yield_ttm` 存百分数（H5 渲染时加 `%`）。
3. **毛利率在 SVQuant PG 里有两套历史约定，loader 必须显式转换**：
   - `fin_indicator.gross_margin`（机构端）= 小数 0.8976；
   - `financials.gross_margin`（H5）= 百分数 89.76；
   - 数据平台 `pershare_index.gross_margin` = 百分数 89.56；
   - loader：机构表 `/100`，H5 表原样写入。
4. **行业口径**：业务与 RE 都用 SW L1/L2；THS code 仅辅助。映射完成前，`sw_*` 为 null 时按 THS 展示并标注“行业待映射”。
5. **复权口径**：`daily_bars` 为 hfq、`daily_bars_unadjusted` 为 none；两侧不得各取一套。
6. **as_of 语义一致**：`date <= as_of`，财务按公告日；`latest=True` 只用于快照，不用于回测。
7. **列名**：免费域 `time`、iFinD 域 `date`、派生域 `date`；契约提供 `trade_date` 统一别名。

## 8. 对 `research-rv-20261101-08` 的验收（2026-11-01）

**通过项**

- `contract-check --view research-rv-20261101-08`：`ok=true`，35 个 dataset，无 errors。
- 抽样与数据平台给的验收值一致：
  - `valuation_daily` 600519.SH @2024-06-28：total_mv/float_mv/pe_ttm/pb_mrq/ps_ttm/dividend_yield_ttm 全对，float_mv 非空；
  - `daily_bars_unadjusted` 同日：close=1467.39、volume=3,858,202、amount=5,699,649,047、turnover=0.3071（%）；
  - `security_status_daily` 同日：is_st=147、is_suspended=29；
  - `financial_income` 已含 gross_margin（百分数）与 gross_profit（元）；
  - `us_stock_quotes_bfq` AAPL.O 最新 close=344.63。

**发现的消费问题（数据侧）**

1. `DataView.read(start=..., end=...)` 只按分区裁剪文件，**不对长表做行级日期过滤**；
   读 `2024-06-28` 会返回整个 2024 年。建议加行级过滤，或在文档里明确 start/end 只是分区提示。
2. 契约 `path` 与物化目录不一致：契约写 `free/datasets/valuation`、`derived/datasets/...`，
   实际物化为 `free/valuation`、`derived/...`。按契约路径直接读目录会失败；走 DataView/manifest 正常。
3. 视图暴露了聚合数据集 `us_stock`（不在契约），DataView 列出 36 个 dataset，契约 35 个。
   建议列入契约并标 deprecated，或从视图清单移除。
4. `financial_income` 长表列名用 `Symbol`，其他派生长表用 `symbol`；`m_timetag/m_anntime`
   是 `YYYYMMDD` 字符串。建议统一列名并在契约写清日期格式。
5. `security_status_daily` 单日 5650 行，契约写 symbols=5956；需说明是“当日在市”口径。

**SVQuant 侧待改（loader 批次）**

- PG `md_daily_bar.turnover` 现存小数（0.00479），H5 按百分数渲染会显示 0.00%；
  loader 统一转百分数并回填。
- 毛利两套约定：机构表 `fin_indicator.gross_margin` 小数、H5 `financials.gross_margin` 百分数；
  从 `pershare_index.gross_margin`（百分数）按目标表转换。
- 未复权量/额/换手可补 PG 的空值。
- `is_st`/`is_suspended` 直接映射。
- breaking 名称不影响当前 iFinD 直读路径；只影响未来 loader 的 dataset 名。
