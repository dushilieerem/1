# 数据需求回复（SVQuant → svquant-data）

> 对应视图：`research-rv-20261101-06`；回复日期：2026-11-01。
> 口径：SVQuant/RE 只读消费，不采集、不写 `free/`、`vendor/`。

## 0. 结论

- 现有 29 个 dataset 覆盖 SVQuant 的 **A 股业务基线约 80%**：行情、估值、财务 PIT、状态、行业、
  指数/成分、日历、ETF 日线都能直接用。
- **P0 缺口 5 个**：`float_mv/ps_ttm` 为空、SW 行业字段为空、状态缺显式 ST/停牌字段、
  未复权行情缺量额/昨收、财务缺营业成本/毛利。
- **P1 缺口**：发行人主数据（A/H/ADR）、汇率、美/港财务与估值、公告/研报证据、交易规则、
  ETF 成分、主题历史成分。
- iFinD 物化树里已有 `ifind/us_stock`（美股票行情），但不在契约内，建议正式纳入契约。

## 1. 消费方式

| 场景 | 方式 |
|---|---|
| Web API / H5 / 机构端 | PG 服务表（`md_*`/`fin_*`）由 SVQuant 侧的 loader 从 `views/current` 物化目录只读加载 |
| 研究 / ETL / 批处理 | `svquant_data.reader.DataView(view_id, as_of=...)`，按列投影、按日期分段 |
| RE 计算 | `views/current/free/compat` 兼容树，研究记录 `view_id` |

建议保持 `views/current` 原子切换 + `RELEASE.lock`；schema 变更走 contract 版本号并在 `manifest` 里注明。

**希望额外提供 serving 派生表**（可选，能显著降低 SVQuant 启动/查询扫描）：

1. `serving_latest`：每 symbol 最新一条（close/pre_close、成交量额、PE/PB/PS/股息率、
   total_mv/float_mv、状态、SW L1/L2）。
2. `financial_latest_pit`：每 symbol 最新可见报告期（三表 + 比率），按 `m_anntime`。
3. `execution_reference`：最新收盘、涨跌停价、ST/停牌、每手/最小变动（交易所规则）。
4. `theme_index_daily`：主题/概念成分 + 等权代理指数日线（H5 热点用）。

不提供也可以，SVQuant 从基础数据集自行派生，但契约要稳定。

## 4. 硬要求（更新频率 / 延迟 / 历史 / 单位）

- **频率与延迟**：日频 EOD，**18:30 CST 前发布**，19:00 前 `views/current` 切换完成；不做实时。
  失败时保留上一 view 并告警，不发布半成品。
- **历史起点**：日线 2005+；估值/财务 2016+（PIT）；分钟 2025+ 即可（H5 无分时需求）。
- **单位**：成交量=股、成交额=元、换手率=百分数、股息率=百分数、指数权重=百分数；
  比率（PE/PB/PS）为倍数；**不要用 0 填充缺失**，保持 null。
- **复权**：`hfq` 与 `none` 显式区分，禁止隐式混源；执行与估值用未复权，图表/回测用后复权。
- **PIT**：财务 `m_anntime <= as_of`；指数成分按生效日；universe 按 as_of 当日。
- **代码**：`600519.SH` / `AAPL.O`；北交所保留 `.BJ`；退市证券保留历史。
- **变更**：契约版本 + changelog；新增字段保持向后兼容，删除/改单位必须升版本。

## 5. 与 RE 共享的口径

1. 同一 `view_id`、同一 `free/compat` 树；研究/回测记录 `view_id`。
2. **股息率统一百分数**：免费 `valuation.dividend_rate` 与 `valuation_daily.dividend_yield_ttm`
   都是百分数，请在契约字段说明里写死，避免一边 3.7 一边 0.037。
3. **行业口径**：业务与 RE 都用 SW L1/L2；THS code 仅作辅助。P1-4 映射完成前，
   请明确 `sw_*` 为 null 时业务应按 THS 展示并标注“行业待映射”。
4. **复权口径**：`daily_bars` 为 hfq、`daily_bars_unadjusted` 为 none；RE 与 SVQuant 不得各取一套。
5. **as_of 语义一致**：`date <= as_of`，财务按公告日；`latest=True` 只用于快照，不用于回测。
6. **列名**：免费域 `time`、iFinD 域 `date`、派生域 `date`；建议在契约里提供统一别名
   （如 `trade_date`），或明确 SVQuant 侧做映射。

## 6. 验收样例（发布后我们抽样核对）

- `600519.SH` @2026-10-30：close/PE/PB/股息率与 iFinD 终端一致；`float_mv` 非空。
- 财务：`600519.SH` 2025 年报 `m_anntime` 与公告日一致；`gross_margin` 与 `(revenue-operating_cost)/revenue` 一致。
- 状态：构造 ST/停牌样本（如历史 ST 股），`is_st`/`is_suspended` 可判定。
- 指数：000300/000905 成分权重和为 100%（±0.01）；`index_price` 与行情对账。
- 美股：`AAPL.O` 最新收盘与公开源一致；确认是否提供财务/估值。
