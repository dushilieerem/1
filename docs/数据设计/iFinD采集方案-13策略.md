# iFinD 采集方案：支撑 13 个聚宽策略的近 10 年回测

> 配套文档：[iFinD数据缺口-13策略.md](iFinD数据缺口-13策略.md)（缺口依据与逐策略依赖）
> 基线数据：release `ifind-sync-20261030-094129`
> 回测窗口：**2016-10-30 → 2026-10-30**
> 采集器仓库：`/home/dev01/project/ifind`
> 编写日期：2026-10-30

---

## 1. 目标与边界

**目标**：让 13 个聚宽策略在 SVQuant 上具备 **2016-10-30 起、10 年** 的回测数据。

**原则**：

1. **能派生就不采集。** 总市值、EPS、PS、换手率、ST 布尔、停牌状态、个股行业归属、上市日，全部由现有字段计算，见缺口文档 §5。
2. **额度按桶分配。** 「基础数据」桶周额度 500 万点（`ifind/README.md:322`），是这个方案最硬的约束；「行情」桶按次计（1.4 亿点/次），两者不能混算。
3. **先核实再入采集器。** 所有新增 iFinD 指标 ID 与 `indiparams` 必须先用「超级命令」验证，验证结果回写到本方案。
4. **每批有独立验收。** 对账不过不进入下一批。

**不在本方案内**：改策略代码、改聚宽平台参数、回测框架本身。

## 2. 额度模型

| 额度桶 | 当前已知 | 依据 | 涉及本方案 |
|---|---|---|---|
| 基础数据（`date_sequence`） | **500 万点/周**，单次 450 万点 | `ifind/README.md:322`、`config.yaml` `date_sequence_max_estimated_points` | 总股本、涨跌停价、分析师 |
| 行情（`history_data` / `high_frequency`） | 1.4 亿点/次/域，周额度未知 | `config.yaml` `max_estimated_points` | 分钟线、指数、行业指数、涨跌停价（备选） |
| 财务数据 | **未知** | 尚无采集器 | 财务三表 |
| 事件数据 | **未知** | 尚无采集器 | 分红、回购、北向 |

**点数公式**：`点数 = 证券数 × 交易日数 × 字段数`

基准值：A 股 5,956 只；10 年 2,440 个交易日；`date_sequence` 现有 2,617 天（新增字段回填按 2,617 天算，保留与主表一致）。

## 4. 批次计划

### 第 0 批：前置核实（不采数据，1–2 天）

在「超级命令」里逐条确认，结果回填到本表：

| 待核实 | 影响 |
|---|---|
| 总股本指标 ID、单位（股/万股）、是否与 `current_mv` 同一流通口径 | 总市值/EPS/PS 全部依赖 |
| 涨跌停价指标 ID，以及能否从 `history_data` 取 | 6.2 周 vs 1 次跑批 |
| 财务数据接口路径、可返回字段、是否含 `pub_date` 与报表类型 | 第 2 批能否启动 |
| 财务/事件/北向各自的额度桶与周额度 | 排期 |
| 分钟线历史授权起点（能否取到 2016） | 第 7 批能否做 10 年 |
| 申万行业指数指标 ID | 第 5 批 |
| 港股行情接口（现有 `us_stock` 只含美股） | 第 6 批 |
| 分析师一致预期是否单独授权 | 暂缓项 |

**核实方式**：每个指标先用 1 只票 × 5 个交易日取数，检查字段名、单位、空值、与本地已有字段的重合度，再扩到 100 只 × 1 个月。

### 第 1 批：股票池与估值分母（P0，约 4 周）

**解锁**：全部 13 个策略的股票池与市值排序。

| 步骤 | 内容 | 数据量 | 额度 |
|---|---|---|---|
| 1.1 | `config.yaml` 的 `index_codes` 增加 `399101.SZ`、`399303.SZ`、`399317.SZ`，回填 2016-01-01 起的成分、权重、日线 | 约 4,200 万点 | 行情，1 次 |
| 1.2 | `date_sequence` 的 `INDIPARA` 增加「总股本」指标，回填 2016-01-19 → 2026-10-30（2,617 天） | 1,559 万点 | 基础数据，3.1 周 |
| 1.3 | 主表派生 `list_date`/`delist_date`：取未复权行情首/末有效记录，并用 `listed_status` 的 `终止上市`/`退市整理` 修正退市日 | 0 | 无 |
| 1.4 | 派生层落库：总市值、流通市值、换手率、EPS、PS、静态 PE、ST 布尔、停牌、涨跌停状态 | 0 | 无 |

**改造点**：
- `config.yaml`：`index_codes`、`index_earliest_start_dates`
- `ifind/src/data_ingestion/ifind/date_sequence/download.py:37` 的 `INDIPARA` 增一项
- 新增 `ifind/src/data_ingestion/ifind/derived/`（或同等位置）存放派生表

**验收**：
- 601398.SH 2026-10-30：`current_mv` = 2.367 万亿元；派生总市值 ≈ 3.13 万亿元（总股本 3,564.06 亿股 × 8.78 元）。该股 A 股流通股本远小于总股本，两者**必须不等**；若相等说明总股本指标取错。
- 399303 每月末成分数应接近 2,000；399317 应覆盖绝大多数 A 股（数千只）。具体数值以 iFinD 返回为准，不预设容差。
- `list_date` 抽 20 只 2016 年后上市的票，与 iFinD 主表误差 ≤ 1 个交易日。
- ST 布尔抽 2020–2026 每年 10 只，与 `listed_status` 原文一致。

**降级**：总股本若无法按日取，可退化为按季（财务报告股本），但市值排序在送转除权日附近会失真，需在回测报告标注。

### 第 2 批：财务三表（P0，约 3 周，含对账）

**解锁**：破净、红利、自由现金流、三正、国证2000、增速差额、成长多因子、沪深300增强（8 个）。

| 项 | 要求 |
|---|---|
| 区间 | **2013-01-01 → 2026-10-30**（10 年窗口 + 2 年 TTM 回看 + T-5 期） |
| 期数 | 每只约 55 期；必须保留 `end_date`、`pub_date`、`report_type` |
| 表 | 利润表、资产负债表、现金流量表 |
| 字段 | 见缺口文档 §4.1；先只采必需字段，不采全表 |
| 体量 | 约 98 万行 |

**硬性验收**：

1. **`pub_date` 必填率 100%**，且不存在 `pub_date < end_date`。
2. **TTM 对账**：选 10 只票（含 1 只银行、1 只周期、1 只亏损股），用「本期累计 − 上年同期累计 + 上年全年」还原 `net_operate_cash_flow_ttm`、`np_parent_company_owners_ttm`，与聚宽 `get_factor_values` 同日值相对误差 ≤ 0.5%。
3. **时点回测**：取 2020-04-30 当天，用 `pub_date <= 2020-04-30` 过滤后的最新报告期，抽样 100 只票，与聚宽 `get_fundamentals(date=2020-04-30)` 的 `total_assets` 一致率 ≥ 99%。
4. **报表类型**：同一 `code + end_date` 只保留 `report_type == 0` 的一行（或显式保留多行并加类型键），不得静默去重。

**降级**：若 iFinD 财务接口不提供 `pub_date`，本批**不能启动**——没有公告日的财务数据会直接引入未来函数，比没有数据更糟。

---

### 第 3 批：涨跌停价（P0，1 次跑批或 6.2 周）

**解锁**：11 个策略的「涨停不买」风控。

优先级：

1. **首选 `history_data`**：若返回字段支持涨停价/跌停价，与行情同批回填 2016-01-01 起，约 3,116 万点，一次跑批完成。
2. **次选 `date_sequence`**：增加 2 个指标，回填 2,617 天，约 6.2 周。
3. **兜底自算**：`pre_close × (1 ± 幅度)`，按板块/ST/新股分别判断。**只用于对账与补缺，不作生产主值。**

**验收**：
- 抽样 100 只 × 20 个交易日，`close == high_limit` 与 `up_and_down_status == '涨停'` 的一致率 ≥ 99.5%。
- ST 股（`listed_status` 为 `ST`/`*ST`）涨停幅度应为 5%，抽 20 只验证。
- 2020 年后创业板 20% 幅度、北交所 30% 幅度各抽 10 只。
- 新股上市首日无涨跌幅限制，确认字段为空而非 0。

### 第 7 批：分钟线（P0 但可降级，约 4 周）

**范围**：只回填 **000300 成分**，2016-01-01 → 2025-01-14（2025-01-15 起已有全市场分钟线，可直接切片复用）。

| 项 | 数值 |
|---|---|
| 证券数 | 约 300（按每月成分并集，实际略多，建议按 400 预留） |
| 交易日 | 约 2,190 |
| 字段 | `open` `high` `low` `close` `volume` `amount` |
| 点数 | 约 9.5 亿 |
| 存储 | 约 4.9 GB |
| 跑批 | 约 7 次（1.4 亿点/次） |

**用途**：
- MA、高斯：`get_intraday_high` 取「09:30（或买入时刻）至当前分钟」的 `high` 累计最大值。**不能用日线 high 替代**，否则引入未来函数。
- 自由现金流：当日 1m `volume` 累计 vs 120 日最高日成交量。**建议降级**为日线总量近似（14:50 时约等于全日量的 95%），并在回测报告标注。

**验收**：
- 任取 100 只 × 20 天，`max(1m high)` 与日线 `high` 的相对误差 ≤ 1e-6。
- 任取 100 只 × 20 天，`sum(1m volume)` 与日线 `volume` 的相对误差 ≤ 1e-6。
- 分钟时间戳覆盖 09:30–15:00 共 242 根，无缺分钟。

**降级**：
- 若授权不支持 2016 起，退到可用起点，并在策略回测报告标注实际区间。
- 若额度不足，可只存策略检查时点（10:05 / 11:20 / 13:30 / 14:20 / 14:50）的累计最高价，约 330 万行，但牺牲通用性。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 基础数据周额度不足 | 总股本/分析师回填排不下 | 优先总股本；分析师暂缓 |
| 财务接口无 `pub_date` | 第 2 批无法启动 | 改用聚宽财务因子导出做交叉验证，或换供应商接口 |
| 分钟线授权不足 10 年 | MA/高斯只能短区间回测 | 明确标注回测区间，不写「10 年」 |
| 涨停价字段不存在 | 需自算，ST/新股边界易错 | 自算 + 用 `up_and_down_status` 交叉校验 |
| 行业代码三套并存 | 行业轮动选错行业 | 建映射表并纳入测试用例 |
| 集合竞价不可得 | 国证2000 竞价因子失效 | 用开盘价近似，回测报告标注 |
| 港股行情无接口 | 量价背离的北向调仓日不准 | 用港交所日历手工维护，或按 A 股日历近似 |
