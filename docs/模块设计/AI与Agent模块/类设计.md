# AI 与 Agent 模块 类/函数设计

> 函数式组织（仅错误类）。以下单元来自真实代码（`backend/ai/**`、`app/routers/ai.py`、`app/routers/agent.py`）。

## 1. 单元关系图

```text
routers/ai.py ──▶ gateway/ark_chat（chat/流式） / gateway/speech_transcribe
routers/agent.py ──▶ runtime/runtime.start_run ──▶ runtime/orchestrator ──▶ runtime/skills
                 └─▶ crews/gather_idea/pipeline（五段流水线）
runtime/skills ──▶ gateway/llm_client / crews/_shared/metrics_trust
runtime/orchestrator ──▶ runtime/store（配额与记账）
```

## 2. routers/ai.py（4 端点）

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `GET /api/ai/chat/models` | — | `list_ark_models()` 模型列表 |
| `GET /api/ai/speech/status` | — | `speech_ready()` |
| `POST /api/ai/chat` | — | `_sse_chat_frames(messages, model, temperature)` → `StreamingResponse` SSE；错误 `code = 503 if "未配置" in msg else 502` |
| `POST /api/ai/speech/transcribe` | — | multipart → `transcribe_bytes`；参数错误 400，未配置 503 |

## 3. routers/agent.py（8 端点）

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `_perm_http(exc)` | — | PermissionError：文案含"配额"→ 403，否则 401 |
| `GET /api/agent/usage/me?days=7` | require_user | `usage_summary_for_user` |
| `GET /api/agent/usage?days=7` | require_user + role==admin（否则 403） | `usage_admin_summary` |

| `POST /api/agent/runs` | require_user | `start_run`（技能编排） |

| `POST /api/agent/factor` | require_user | `run_factor_pipeline` |
| `POST /api/agent/factor-backtest` | require_user | `run_backtest_pipeline` |
| `POST /api/agent/factor-eval` | require_user | `run_eval_pipeline` |

## 5. ai/runtime

#### store.py（配额与记账）

| 函数 | 说明 |
|---|---|
| `ensure_ai_usage_schema()` | 建 `ai_usage` 表 |
| `new_run_id()` | run 标识生成 |
| `usage_today_count(user_id)` | 当日已用次数 |
| `get_user_quota(user_id)` | 配额：`ai_quota_daily`（默认 200）+ 用户覆盖 |
| `assert_quota_available(user_id, need=1)` | 超额抛 PermissionError（文案含"配额"） |
| `record_usage(...)` | 按次记账（user_id, run_id, skill, created_at） |
| `usage_summary_for_user(user_id, days=7)` | 个人用量汇总 |
| `usage_admin_summary(days=7, limit=200)` | 管理员全局汇总 |
| `set_user_ai_quota(...)` | 设置用户配额 |

#### runtime.py

| 函数 | 说明 |
|---|---|
| `resolve_skills(skills, goal)` | 显式 skills 过滤 `SINGLE_SKILLS`；否则关键词路由：读帖/tldr/tl;dr/摘要（非润色）→ `summarize_post`；仅标题 → `polish_title`；仅正文 → `polish_body`；默认两者 |
| `start_run_single(...)` | 单技能执行（board 步骤包装） |
| `start_run(...)` | 多技能串联入口（/api/agent/runs） |

#### orchestrator.py

| 函数 | 说明 |
|---|---|
| `new_board(goal, context)` / `new_read_board(goal, context)` | 创作/读帖看板初始化 |
| `_step(...)` | 单步执行与 board.steps 追加 |
| `_run_and_bill(...)` | 执行 + `record_usage` 计费 |
| `_latest_critic_decision(board)` | 最近审计决策 |
| `run_community_crew(...)` | 创作 crew：标题 → 正文 → 板块 → 审计 → 剥离 |
| `run_community_read_crew(...)` | 读帖 crew：截断 → 摘要 → 面板指标 → 风险提示 |

#### skills.py

| 单元 | 说明 |
|---|---|
| `SECTION_IDS = ("strategy","factor","qa","hotspot","official")` | 板块常量（社区模块复用） |
| `SINGLE_SKILLS = ("polish_title","polish_body","summarize_post")` | 可单选技能 |
| `strip_html` / `extract_json_object` | 文本/JSON 提取工具 |
| `skill_polish_title` / `_mock_polish_title` | 标题润色（LLM + mock 降级） |
| `skill_polish_body` / `_mock_polish_body` | 正文润色 |
| `skill_suggest_section` | 板块建议 |
| `skill_audit_claims` | 声明审计（数字/承诺/platform_ref 对账） |
| `skill_strip_unverifiable` | 剥离不可验证内容 |
| `skill_lookup_panel_metrics` | 查询因子面板真实数字 |
| `skill_summarize_post` / `_mock_summary_md` | 帖子摘要（读帖） |
| `skill_flag_read_risks` | 阅读风险提示 |
| `_read_limits` / `_maybe_truncate` / `_source_from` / `_draft_from` / `_board_trust` | 内部工具（截断限制、来源、草稿与信任标记组装） |
| `get_skill(skill_id)` / `run_skill(...)` / `apply_board_patch(board, patch)` | 注册表与执行入口 |

## 6. ai/crews

#### _shared/metrics_trust.py（护栏）

| 单元 | 说明 |
|---|---|
| `PROMISE_RE` | 承诺话术（稳赚/必涨/保证收益/闭眼买/全仓梭哈…） |
| `QUANT_CLAIM_RE` | 量化数字声明 |
| `infer_platform_ref_from_share_body(body)` / `body_claims_platform_share(body)` / `normalize_platform_ref(raw)` | 平台引用识别与归一 |
| `_allowed_number_set(ref)` / `_number_near_allowed(n, allowed, tol=0.02)` | 数字对账（2% 容差） |
| `looks_like_quant_claim(text)` / `looks_casual_share(text)` | 类型判断 |
| `evaluate_metrics_trust(...)` | 综合信任评估 |
| `trust_prompt_block(trust)` | 注入 LLM 的提示块 |
| `summary_number_flags(...)` | 数字标记汇总 |
| `strip_html(text)` | 工具 |

#### gather_idea/（五段流水线）

| 文件 | 关键函数 | 说明 |
|---|---|---|
| gather_agent.py | `normalize_request(body, user_id)`、`run_gather(body, user_id) -> EvidencePack` | 请求归一、来源平衡取样（`_take_balanced`）、规则/LLM 摘要（`_rule_digest`/`_llm_digest`）、缺口（`_build_gaps`） |
| idea_agent.py | `run_idea(body, user_id) -> IdeaBundle` | 因子构思（`_normalize_factor_spec`/`_normalize_validity`） |
| factor_agent.py | `run_factor(body, user_id)` | 因子代码生成（`_validate_factor_code`、`_fallback_code`） |
| backtest_agent.py | `run_backtest_report(body, user_id)` | 回测报告组装（执行经 RE） |
| eval_agent.py | `run_eval(body, user_id)` | 评估结论 |
| pipeline.py | `run_gather_pipeline` / `run_idea_pipeline` / `run_factor_pipeline` / `run_backtest_pipeline` / `run_eval_pipeline` | 各段组合入口（agent 路由直接调用） |
| schemas.py | dataclass（GatherRequest、EvidencePack、IdeaBundle 等） | 段间数据结构 |
| web_sources.py | 资料源适配 | gather 段外部资料 |
| `_smoke_*.py` | 冒烟脚本 | 开发自测，不参与运行时 |

> `crews/community/` 目录仅含 `__init__.py`；社区 crew 实现位于 `runtime/orchestrator.py`。
