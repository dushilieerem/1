# KnowledgeHub 模块 类/函数设计

> 函数式组织（`knowledge_hub` 包无业务类，只有错误类与注册表）。以下单元来自真实代码。

## 1. 单元关系图

```text
backend/app/routers/kh.py（catch-all）
  └─▶ knowledge_hub/http_handlers.handle_kh_get/post/put/delete ──▶ knowledge_hub/store
store ──▶ extractors / chunking.registry / embedding / attachments / llm
```

## 2. routers/kh.py（SVQuant 侧挂载，100 行）

| 单元 | 说明 |
|---|---|
| `@router.api_route("/api/kh/{path:path}", methods=["GET","POST","PUT","DELETE"])` | catch-all 入口 `kh_catch_all`，`optional_user` 注入 |
| `_collect_json(fn, *args)` | 提供 `send_json(payload, status)` 回调给 handler；未处理（返回 False）→ 404 |
| `kh_docs` / `kh_openapi` | `/api/kh/docs` Swagger 页、`/api/kh/openapi.json` |
| `kh_model_providers_test` | `POST /api/kh/model-providers/test` 直连测试（不经 store） |
| 异常映射 | `HTTPException(400) invalid JSON`；`except PermissionError → HTTPException(401)` |

## 3. http_handlers（knowledge_hub/http_handlers.py）

| 函数 | 说明 |
|---|---|
| `_require_admin(user)` | 权限门：登录用户须 `role=="admin"`（否则 403「仅管理员可进入知识库平台」）；匿名且 `KH_REQUIRE_AUTH` 未开启 → `_ANON_ADMIN` 放行；开启 → 401 |
| `_ANON_ADMIN` | `{"id": None, "username": "kh-anon", "role": "admin", "display_name": "知识库调试"}` |
| `_actor_id(user)` | `created_by` 取值；匿名/无效 id → NULL（避免 FK 撞 users.id=0） |
| `handle_kh_get(path, *, user, send_json) -> bool` | GET 分发：meta、collections、collections/{id}/documents、documents/{id}（/chunks、/progress、/attachment）、chats、conversations、messages、files、model-providers、default-models、docs/outline |
| `handle_kh_post(path, body, *, user, send_json) -> bool` | POST 分发：collections、documents、documents/structured、documents/{id}/ingest、search、ask、chats、conversations、messages、files、model-providers（+ /test）、default-models |
| `handle_kh_put(...)` | PUT：collections/{id}、documents/{id}、chats/{id}、conversations/{id}、default-models |
| `handle_kh_delete(...)` | DELETE：collections/{id}、documents/{id}、conversations/{id}、chats/{id}、files/{id}、model-providers/{key} |

## 4. store（knowledge_hub/store.py，约 2500 行）

#### Schema 与进度

| 函数 | 说明 |
|---|---|
| `ensure_kh_schema()` / `_ensure_kh_schema_unlocked(conn)` | 10 张 `kh_*` 表幂等建表（带锁） |
| `_migrate_chat_conversations(conn)` | 会话结构迁移（幂等） |
| `_set_ingest_progress(doc_id, ...)` / `get_ingest_progress(doc_id)` / `_clear_ingest_progress(doc_id, delay_sec=2.0)` | 摄取进度内存态（延迟线程清理） |
| `list_pipelines()` | 摄取管线清单（meta 页展示） |

#### 知识库与文档

| 函数 | 说明 |
|---|---|
| `list_collections()` / `create_collection(...)` / `update_collection` / `delete_collection` | 知识库 CRUD（带 doc_count） |
| `list_documents(collection_id)` / `get_document(doc_id)` / `delete_document` | 文档读取/删除 |
| `create_document(...)` | 文本/附件文档创建 |
| `create_structured_document(...)` | 结构化文档（字段域 DOMAIN_OPTIONS，论文=paper 等） |
| `update_document(doc_id, body)` | 文档更新 |
| `ingest_document(doc_id)` | 摄取主流程：抽取 → 切块 → 向量化 → 入库（见流程设计） |

#### 检索与问答

| 函数 | 说明 |
|---|---|
| `list_chunks(document_id)` | 块列表 |
| `search_chunks(...)` | 混合检索主入口 |
| `_tokenize_query(q)` | 中英分词 |
| `_hinted_structured_fields(q)` / `_ensure_structured_field_coverage(...)` | 结构化字段提示与覆盖补充 |
| `_enrich_hits_with_attachment(hits)` / `referenced_documents_from_hits(hits)` / `get_document_attachment(doc_id)` | 命中增强与引用汇总 |
| `_format_knowledge(hits)` | 知识上下文拼装 |
| `ask(...)` | 问答主入口（检索 + LLM + 会话落库） |

#### 对话三层

| 函数 | 说明 |
|---|---|
| `list_chats` / `get_chat` / `create_chat(name, created_by)` / `update_chat` / `delete_chat` | chat 层 |
| `list_conversations(chat_id)` / `get_conversation` / `create_conversation` / `ensure_default_conversation(chat_id)` / `update_conversation` / `delete_conversation` | conversation 层（含默认会话） |
| `list_conversation_messages` / `append_conversation_message` / `clear_conversation_messages` / `list_chat_messages` / `append_chat_message` / `clear_chat_messages` | message 层 |

#### 文件与模型配置

| 函数 | 说明 |
|---|---|
| `list_files` / `create_file(...)` / `delete_file(file_id)` | kh_files 资料文件 |
| `list_model_providers` / `upsert_model_provider(body)` / `delete_model_provider(provider_key)` | 供应商凭据管理 |
| `get_default_models()` / `set_default_models(body)` | role（llm/embedding）默认模型指向 |
| `api_catalog()` | 接口目录（docs/outline 数据源） |

## 5. 支撑单元

#### chunking/registry.py

| 单元 | 说明 |
|---|---|
| `register(strategy_id, ...)` | 策略装饰器注册表 |
| `list_strategies()` / `get_strategy(strategy_id)` | 策略清单/获取（`_ensure_builtins` 懒加载内置） |
| `chunk_text(...)` | 按策略切块入口 |

#### chunking/strategies.py（内置策略）

| 函数 | 参数 | 说明 |
|---|---|---|
| `markdown_heading(text, window=1200)` | — | 按标题切块 |
| `plain_window(text, ...)` | — | 滑窗切块 |
| `qa_pair(text)` | — | 问答对切块 |
| `table_row(text, window=800, overlap=80)` | — | 表格行切块 |
| `paragraph_merge(text, window=1000)` | — | 段落合并 |
| `numbered_heading(text, window=1400)` | — | 数字编号标题切块 |
| `structured_fields(text)` | — | 结构化字段切块 |

#### embedding.py

| 函数 | 说明 |
|---|---|
| `get_role_credentials(role_key="embedding")` | 从 `kh_default_models` + `kh_model_providers` 解析凭据 |
| `get_provider_credentials(...)` | 指定 provider 凭据 |
| `embed_texts(...)` | 批量向量化（OpenAI 兼容 `/embeddings`） |
| `cosine(a, b)` | 余弦相似度 |
| `_post_json(...)` | 内部 HTTP |

#### extractors.py

| 函数 | 说明 |
|---|---|
| `is_binary_doc(file_name)` | 二进制文档判断 |
| `extract_text(file_name, data)` | 分派 `_from_docx` / `_from_pdf` / 纯文本；`_normalize_ws` 清洗 |

#### attachments.py

| 函数 | 说明 |
|---|---|
| `attachment_root()` | `KH_ATTACHMENT_DIR`（环境变量，未设时默认目录以实现为准） |
| `save_attachment_bytes(data, file_name)` | 保存附件（`_safe_name` 防路径穿越）→ 返回元数据 |
| `read_attachment(attachment_id)` / `delete_attachment(attachment_id)` | 读取/删除 |
| `attachment_info(attachment_id)` | 元数据组装 |

#### llm.py

| 单元 | 说明 |
|---|---|
| `KhLlmError(RuntimeError)` | LLM 错误 |
| `llm_configured()` | role=llm 凭据是否存在 |
| `chat_completions(messages, temperature=0.2, max_tokens=2048, top_p, model_override, creds)` | OpenAI 兼容调用；返回 `{content, model, tokensIn, tokensOut, providerKey}` |

#### schemas/knowledge_unit.py

- `DOMAIN_OPTIONS` / `DOC_TYPE_OPTIONS` / `FIELD_LABELS_ZH`：结构化文档的领域、类型与中文标签常量（meta 接口与 `create_structured_document` 使用）。

## 6. 数据表（10 张 kh_*）

| 表 | 关键列（摘要） |
|---|---|
| kh_collections | name, description, doc_count, created_by |
| kh_documents | collection_id, title, body/source, doc_type, structured fields, status |
| kh_attachments | document_id, file_name, mime, 大小, 附件目录相对路径 |
| kh_chunks | document_id, ordinal, text, vector, 元数据（字段/页码） |
| kh_files | file_name, 大小, created_by |
| kh_chats / kh_conversations / kh_chat_messages | 对话三层（chat → conversation → message；created_by 匿名 NULL） |
| kh_model_providers | provider_key, baseUrl, key, model |
| kh_default_models | role（llm/embedding）→ provider + model |
