## 规则

- 每个模块固定三份：`模块设计.md`、`类设计.md`、`流程设计.md`。
- 模块设计只写长期稳定的职责、边界与协作；一次性的方案取舍放 `功能包/FEAT-*/03-technical-design.md`。
- 跨模块、长期有效的决策写入 [`../技术决策/`](../技术决策/)。
- 历史模块设计 README 已归档到 `../归档/2026-10-文档整理/模块详细设计-README.md`。
