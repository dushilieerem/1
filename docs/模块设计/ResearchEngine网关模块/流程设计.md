# ResearchEngine 网关模块 流程设计

## 1. 流程说明

覆盖三条流程：策略回测转发（同步/异步双形态）、行情展示（缓存）、自选股管理；并给出网关错误映射规则。

## 2. 参与模块

| 参与者 | 职责 |
|---|---|
| frontend | 回测页、行情/自选股页面 |
| `routers/re_gateway.py` | 白名单端点入口 |
| `re_http_gateway` / `lan_http` / `re_config` | 转发与直连 |
| `market_data_bff` | 日线缓存适配 |
| `watchlist_store` | 自选股持久化 |
| ResearchEngine | 计算与数据 |

## 3. 正常流程

### 流程 A：策略回测（异步形态）

```text
前端 POST /api/backtest/strategy
  → require_user
  → forward_re("POST", "/api/backtest/strategy", payload, timeout=1800)
  → RE 202 {run_id}
  → rewrite_run_poll_url：poll_url → /api/backtest/strategy/{run_id}
  → 响应加 Location 头 → 前端
前端循环 GET /api/backtest/strategy/{run_id}（timeout=60）
  → RE 状态透传，直到 completed/failed
取消：DELETE 同路径（timeout=60）
```

同步形态：RE 直接在 POST 上返回结果（网关长等 1800s），前端无需轮询。

### 流程 B：日线行情展示

```text
前端 GET /api/market-data/daily/{code}?start&end&fresh
  → market_data_bff.fetch_market_daily
      → fresh=1 ? 绕过缓存 : 查 _cache_key(symbol,start,end)
      → 未命中：forward_re 拉取 → 适配展示字段 → 写缓存
  → 前端图表
```

### 流程 C：自选股

```text
创建分组 POST /api/watchlists {name}
添加成员 POST /api/watchlists/{id}/symbols（_normalize_symbol 归一化）
批量添加 POST .../symbols/batch
查询/重命名/删除：均经 _require_watchlist(user_id, wl_id) 归属校验
```

## 4. 时序流程（网关转发与错误映射）

```text
调用方 -> re_gateway 路由：请求（require_user 已过）
路由 -> forward_re(method, path, payload, timeout)
forward_re -> lan_http.request_json(url, ...)
request_json -> RE：直连（NO_PROXY 白名单，无代理 opener）
alt 连接失败（URLError）
  request_json --> 调用方：(502, {}, {"error": "..."})
else HTTP 4xx/5xx
  request_json --> 调用方：(code, headers, body)   # 不抛异常
else 成功
  request_json --> 调用方：(200, headers, json)
end
路由 --> 前端：状态码 + 透传头（Retry-After）+ JSON（策略回测另做 poll_url 改写）
```

## 5. 异常流程

| 异常 | 触发 | 处理 |
|---|---|---|
| RE 不可达 | 网络失败/服务未启动 | 502 + 明确错误文案；前端保留输入 |
| RE 慢 | 计算耗时长 | 提交端 1800s 长等或 202 轮询；轮询端 60s |
| RE 4xx | 参数/资产校验拒绝 | 状态码透传（业务语义保留） |
| RE 5xx | RE 内部错误 | 透传 + 前端展示失败态 |
| 本机代理劫持 | Clash 等拦截局域网 | `ensure_lan_no_proxy` 导入时注入 NO_PROXY + 无代理 opener 兜底 |
| 自选股越权 | 非本人分组 | 403/404 |

## 6. 状态流转

```text
回测 run（RE 侧）：submitted/running → completed / failed / canceled
网关本身无状态，不持有任务状态；状态事实在 RE，产品记录在各业务模块。
```

## 7. 并发处理

- 网关函数无共享状态（线程安全）。
- 并发占用：每个同步长等请求占用一个后端工作线程；无网关级排队（因子回测排队在业务模块层）。
- 自选股并发写依赖数据库约束（分组归属校验 + 唯一键，以表结构为准）。

## 8. 幂等设计

- GET 轮询幂等；DELETE 取消重复调用安全（RE 侧语义）。
- POST 提交非幂等（新 run_id）；去重待 RE 契约确认。
- 自选股批量添加对重复成员幂等（唯一约束/存在性检查，以实现为准）。

## 9. 超时和重试

| 调用 | 超时 | 重试 |
|---|---|---|
| 回测提交 | 1800s | 无自动重试 |
| 轮询/取消 | 60s | 前端轮询 |
| market-data 目录类（symbols/indices） | 请求级默认（以实现为准） | 无 |
| 日线拉取 | 请求级默认 | 缓存失效后用户重试 |
| 资讯源（对照） | 20s | 下一采集周期 |
