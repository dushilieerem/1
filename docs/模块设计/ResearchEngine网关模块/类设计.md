# ResearchEngine 网关模块 类/函数设计

> 函数式组织。以下单元来自真实代码（`services/core/`、`app/routers/re_gateway.py`、`services/data/`、`app/routers/watchlists.py`）。

## 1. 单元关系图

```text
app/routers/re_gateway.py ──▶ services/core/re_http_gateway.forward_re
                                   └─▶ services/core/lan_http.request_json ──▶ ResearchEngine
services/core/re_config（RE_BASE，导入期校验）
routers/news.py ──▶ services/data/market_data_bff.fetch_market_daily ──▶ RE
routers/watchlists.py ──▶ services/data/watchlist_store ──▶ PostgreSQL
```

## 2. re_config（services/core/re_config.py）

| 单元 | 说明 |
|---|---|
| `RE_BASE` | 模块导入时从 `backend/.env` 读取 `YG_RE_BASE`：去除尾斜杠；缺失或非 http(s) 完整 URL 直接 `RuntimeError`（快速失败） |
| `re_host()` | 提取主机名，供 `NO_PROXY` 白名单 |

## 3. lan_http（services/core/lan_http.py）

| 函数 | 说明 |
|---|---|
| `ensure_lan_no_proxy(*hosts)` | 合并写入 `NO_PROXY`/`no_proxy`：RE 主机 + `192.168.0.0/16`、`127.0.0.1`、`localhost`；模块导入时执行 |
| `urlopen_direct(req, timeout)` | 无代理 opener（`ProxyHandler({})`）打开请求 |
| `request_json(url, *, method, payload, timeout=120)` | 通用 JSON 请求：4xx/5xx 返回 `(status, headers_lower, body)` 不抛异常；`URLError` → `(502, {}, {"error": ...})` |
| `get_json(url, *, timeout=60)` | GET JSON（HTTPError 转 RuntimeError + detail 摘要） |
| `post_json_with_status` / `post_json` | POST JSON（默认 600s）；前者返回 `(status, body)` |

## 4. re_http_gateway（services/core/re_http_gateway.py）

| 函数 | 签名要点 | 说明 |
|---|---|---|
| `forward_re` | `(method, path, *, payload=None, query=None, timeout=120) -> (status, headers, data)` | path 以 `/` 开头；query 过滤 None；透传 `Retry-After` 头 |
| `rewrite_run_poll_url` | `(data, base_path) -> data` | dict 且含 `run_id` 时把 `poll_url` 改写为 `{base_path}/{run_id}` |

## 5. re_gateway 路由（app/routers/re_gateway.py）

| 端点 | 鉴权 | 转发目标 | 超时 | 特殊处理 |
|---|---|---|---|---|
| `POST /api/backtest/strategy` | require_user | RE 同路径 | 1800s | poll_url 改写 + Location 头 |
| `GET /api/backtest/strategy/{run_id}` | require_user | RE 同路径 | 60s | 透传 |
| `DELETE /api/backtest/strategy/{run_id}` | require_user | RE 同路径 | 60s | 透传 |
| `GET /api/re/health` | 公开 | RE 健康端点 | 默认 | 与本机 `/api/health` 区分 |
| `POST /api/ai/factor-generations` | require_user | RE AI 因子生成 | 默认 | 代理（生成计算在 RE） |
| `POST /api/ai/strategy-generations` | require_user | RE AI 策略生成 | 默认 | 代理 |
| `POST /api/ai/backtest-interpretations` | require_user | RE 回测解读 | 默认 | 代理 |
| `GET /api/market-data/symbols` | require_user | RE 证券列表 | 默认 | 透传 |
| `GET /api/market-data/indices` / `indices/{key}/constituents` | require_user | RE 指数/成分 | 默认 | 透传 |

辅助：`_resp(status, headers, data)` 统一 JSONResponse 组装。

## 6. market_data_bff（services/data/market_data_bff.py）

| 函数 | 说明 |
|---|---|
| `_cache_key(symbol, start, end)` | 日线缓存键 |
| `fetch_market_daily(code, *, start, end, bypass_cache)` | 展示日线获取：缓存优先，`fresh=1`（bypass）强制 RE 拉取；展示字段适配 |

## 7. watchlist_store（services/data/watchlist_store.py）

| 函数 | 说明 |
|---|---|
| `ensure_watchlist_schema()` | 建 `user_watchlists` / `user_watchlist_symbols` |
| `list_watchlists(user_id)` / `create_watchlist(user_id, name)` / `rename_watchlist` / `delete_watchlist` | 分组 CRUD（含 `_wl_row` 组装与 symbol_count 聚合） |
| `list_watchlist_symbols(user_id, wl_id)` | 成员列表 |
| `add_watchlist_symbol` / `add_watchlist_symbols_batch` / `delete_watchlist_symbol` | 成员管理（`_normalize_symbol` 归一化） |
| `_require_watchlist(conn, user_id, watchlist_id)` | 归属校验（越权拒绝） |

## 8. 数据表

| 表 | 关键列（摘要） |
|---|---|
| user_watchlists | user_id, name, 排序/时间戳 |
| user_watchlist_symbols | watchlist_id, symbol（归一化代码），加入时间 |
