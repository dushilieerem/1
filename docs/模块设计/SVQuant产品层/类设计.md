# SVQuant 产品层 类设计（总览）

> 本文描述产品层统一的代码组织模式与分层约定。各模块的具体类/函数设计见各模块目录的 `类设计.md`。

## 1. 分层模式

当前代码不依赖复杂继承树，采用 **Router → Service/BFF → Store/Gateway/Provider** 的函数式分层：

```text
APIRouter（backend/app/routers/*.py）
    ↓ 依赖注入鉴权（app/deps.py）
Router Handler（模块级函数）
    ↓
Service / BFF 函数（backend/services/<域>/*.py、backend/ai/**）
    ↓
Store（PostgreSQL 读写）  Gateway/Provider（HTTP 外呼）
    ↓                         ↓
PostgreSQL        ResearchEngine / LLM / 资讯源 / 附件目录
```

## 2. 分层职责

| 层 | 位置 | 职责 | 线程安全 |
|---|---|---|---|
| Router | `backend/app/routers/*.py` | 接收 HTTP 请求、依赖注入鉴权、参数校验、调用服务层、返回响应 | 请求级无状态 |
| Service/BFF | `backend/services/<域>/`、`backend/ai/` | 业务编排、请求快照组装、外部调用适配、错误翻译 | 无共享可变状态；后台任务用 daemon 线程 + 锁 |
| Store | `backend/services/<域>/*_store.py` | 封装 SQL/事务/领域规则；`ensure_*_schema()` 建表 | 依赖数据库事务与唯一约束 |
| Gateway | `services/core/re_http_gateway.py`、`lan_http.py` | RE 转发、超时、错误映射、代理绕行 | 无状态 |
| Provider | `backend/ai/gateway/*.py` | 模型/转写供应商协议适配 | 无状态 |

## 3. 公共基础设施

| 组件 | 位置 | 说明 |
|---|---|---|
| `get_conn()` | `services/core/db.py` | psycopg 连接上下文管理器（dict_row，自动 commit/rollback） |
| `env()` / `load_env()` | `services/core/env_config.py` | 从 `backend/.env` 加载环境变量（不覆盖已有 os.environ） |
| `RE_BASE` | `services/core/re_config.py` | RE 地址唯一来源；缺失/非法直接抛 RuntimeError |
| `forward_re()` / `rewrite_run_poll_url()` | `services/core/re_http_gateway.py` | RE 薄转发与 poll_url 改写 |
| `request_json()` / `ensure_lan_no_proxy()` | `services/core/lan_http.py` | 无代理直连 HTTP；NO_PROXY 白名单 |
| `write_audit()` / `infer_action()` | `services/core/audit_log_store.py` | 审计写入与动作推断 |
| `user_from_authorization()` | `services/auth/auth_store.py` | JWT 解析为用户字典 |
| `require_user/require_admin/optional_user/require_db_user_id/soft_db_user_id` | `app/deps.py` | 鉴权依赖分级 |

## 5. 设计原则

1. **单一职责**：路由不做计算，Store 不发 HTTP，Gateway 不读数据库。
2. **函数式优先**：领域能力通过模块函数与组合实现；仅策略样例继承 RE 的 `FactorPortfolioStrategy`（示例代码，非 SVQuant 运行时依赖）。
3. **面向公开契约**：RE 交互只依赖 HTTP 契约，不依赖内部实现。
4. **可再生缓存**：展示缓存可重建，审计事实只在 `app_audit_logs` 等产品表。
5. **凭据隔离**：密钥只经 `env_config` 读取，不落代码与日志。
