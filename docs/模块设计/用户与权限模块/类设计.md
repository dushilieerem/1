# 用户与权限模块 类/函数设计

> 本模块为函数式组织（无业务类）。以下单元均来自真实代码。

## 1. 单元总览

```text
app/deps.py                     鉴权依赖（FastAPI Depends）
app/routers/auth.py             账号/资料/关注 HTTP 入口
app/routers/admin_logs.py       审计日志 HTTP 入口（管理员）
services/auth/auth_store.py     用户、密码、JWT
services/auth/profile_store.py  资料、关注、用户主页
services/core/audit_log_store.py 审计写入/查询/清理
```

## 2. auth_store（services/auth/auth_store.py）

#### 职责

users 表访问、密码哈希、JWT 签发/解码、请求身份解析。

#### 关键函数

| 函数 | 签名要点 | 说明 |
|---|---|---|
| `ensure_schema()` | — | 建 users 表（role CHECK user/admin，status CHECK active/disabled）+ 索引 + 列补齐（avatar_url 等） |
| `seed_admin()` | — | 按 `ADMIN_USERNAME/ADMIN_PASSWORD` 种子管理员（存在即跳过） |
| `hash_password(password)` / `verify_password(password, hash)` | str → str/bool | 密码哈希与校验 |
| `register_user(*, username, password, email=None, display_name=None)` | → dict | 唯一性校验 + 哈希落库 + `_public_user` |
| `login_user(*, username, password)` | → dict | 校验并返回用户 |
| `issue_token(user)` | → str | JWT（`JWT_SECRET` 签名，`JWT_EXPIRE_DAYS` 天） |
| `decode_token(token)` | → dict | 载荷解码 |
| `user_from_authorization(header)` | str? → dict? | Bearer 解析 + 查库校验 status；`DEV_SKIP_AUTH=1` 返回假用户 |
| `me_response(header)` | → dict | `/api/auth/me` 响应 |
| `dev_skip_auth()` | → bool | 开发跳过鉴权开关 |
| `get_user_by_username / get_user_by_id` | → dict? | 查询 |

#### 依赖

`services/core/db.get_conn`、`env_config.env`；无外呼。

## 3. profile_store（services/auth/profile_store.py）

#### 职责

user_follows 表、公开资料聚合、资料更新、关注关系。

#### 关键函数

| 函数 | 说明 |
|---|---|
| `ensure_schema()` | 建 user_follows（联合主键 + 自关注 CHECK + 双向索引） |
| `_normalize_image(data_url, *, max_chars, label)` | 头像/背景 data URL 长度与格式归一化，超限抛 ValueError |
| `get_public_profile(username)` | 公开主页数据（资料 + 计数聚合） |
| `update_my_profile(user_id, body)` | 更新 display_name/avatar_url/cover_url/headline/bio |
| `follow_user(follower_id, username)` / `unfollow_user(follower_id, username)` | 关注/取关，目标不存在 404 语义 |
| `list_user_posts(username, ...)` | 用户帖子列表（复用 community_store 查询逻辑） |
| `list_user_follows(username, kind)` | following/followers 列表（`_follow_user_brief` 组装） |

## 4. audit_log_store（services/core/audit_log_store.py）

#### 职责

审计表 schema、写入、动作推断、查询、清理、5xx 去重抑制。

#### 关键函数

| 函数 | 说明 |
|---|---|
| `ensure_audit_schema()` | 建 app_audit_logs |
| `infer_module(path)` / `infer_action(method, path)` | 由路径推断 module 与 action 字符串 |
| `write_audit(*, action, user_id, username, role, method, path, resource, status_code, duration_ms, ip, user_agent, detail, request_id, module=...)` | 写入一条审计；无 user 时落"游客" |
| `list_audit_logs(...)` | 管理端分页筛选查询（module/username/action/status/method/writeOnly/path/since/until） |
| `purge_audit_logs(*, days=...)` | 按保留天数清理，返回删除条数 |
| `_should_skip_dup_5xx(...)` | 同请求重复 5xx 抑制 |
| `_clip(s, n)` | 字段截断（detail 200 字等） |

## 5. deps（app/deps.py）

| 依赖 | 返回 | 失败 |
|---|---|---|
| `optional_user` | 用户 dict 或 None | — |
| `require_user` | 用户 dict | 401"未登录" |
| `require_db_user_id` | int（DB 用户 ID） | 401 |
| `require_admin` | 用户 dict | 401 / 403"需要管理员权限" |
| `soft_db_user_id` | int 或 None | 静默 None |
| `request_auth_header(request)` | 原始 Authorization | — |

> 实现细节：`require_db_user_id` / `soft_db_user_id` 复用 `services/factor/user_factor_store.resolve_db_user_id`。这是历史形成的跨模块依赖（JWT 用户 ↔ 数据库用户映射最初在因子包内实现），文档如实记录；收敛归属为待确认重构项。

## 6. 路由（routers/auth.py、routers/admin_logs.py）

| 端点 | 依赖 | 调用 |
|---|---|---|
| `POST /api/auth/register` | — | `register_user` + 显式 `write_audit`（成功/失败） |
| `POST /api/auth/login` | — | `login_user` + `issue_token`（中间件记录失败审计） |
| `GET /api/auth/me` | Authorization | `me_response` |
| `POST /api/profile/me` | 登录 | `update_my_profile` |
| `GET /api/users/{username}`、`/posts`、`/following`、`/followers` | 公开 | `get_public_profile` / `list_user_posts` / `list_user_follows` |
| `POST/DELETE /api/users/{username}/follow` | 登录 | `follow_user` / `unfollow_user` |
| `GET /api/admin/logs` | `require_admin` | `list_audit_logs` |
| `POST /api/admin/logs/purge` | `require_admin` | `purge_audit_logs` |

## 7. 数据表

| 表 | 关键列 | 约束 |
|---|---|---|
| users | id, username, email, password_hash, role, status, display_name, ai_quota_daily, created_at, updated_at, avatar_url, cover_url, headline, bio | username UNIQUE；role CHECK(user/admin)；status CHECK(active/disabled)；email UNIQUE |
| user_follows | follower_id, following_id, created_at | PK(follower_id, following_id)；CHECK 非自关注；ON DELETE CASCADE |
| app_audit_logs | id, action, module, method, path, resource, user_id, username, role, status_code, duration_ms, ip, user_agent, detail, request_id, created_at | 索引按查询条件（以实现为准） |
