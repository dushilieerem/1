# 策略研究模块 类/函数设计

> 本模块为函数式组织；`strategy_store.py` 内含两个策略示例类（仅作为用户样例代码模板的来源，运行时由 RE 执行，SVQuant 不实例化执行）。以下均来自真实代码。

## 1. 单元关系图

```text
routers/strategy.py
  ├── strategy_store（项目/运行/摘要/blob）
  ├── builtin_strategies_store ──▶ RE GET /api/strategies（同步） + builtin_strategies 表
  ├── strategy_library_store（兼容门面）──▶ builtin_strategies_store
  ├── user_strategy_library_store（用户策略库）
  └── strategy_plaza_store（广场）
回测执行 ──▶ routers/re_gateway.py（见 ResearchEngine网关模块）
```

## 2. strategy_store（services/strategy/strategy_store.py）

#### 常量

| 名称 | 说明 |
|---|---|
| `SAMPLE_ID = "sample_momentum_20d"`、`SAMPLE_NAME = "多因子合成 样例"` | 样例项目 |
| `DEFAULT_STRATEGY_CODE` | 新建策略默认代码模板（`SVQUANT_PARAMS` 参数区与前端表单同步） |
| `_BLOB_ROOT = backend/data/strategy_run_blobs` | 完整结果 blob 根目录 |

#### 示例类（模板来源，不参与 SVQuant 运行时）

| 类 | 说明 |
|---|---|
| `MyStrategy(FactorPortfolioStrategy)` | 单因子样例（继承 RE 提供的策略基类，仅存在于模板代码字符串/历史代码） |
| `MultiFactorSampleStrategy(FactorPortfolioStrategy)` | 多因子合成样例 |

#### 关键函数

| 函数 | 说明 |
|---|---|
| `_blob_path(user_id, run_id)` | `{_BLOB_ROOT}/{user_id}/{run_id}.json.gz` |
| `write_run_blob` / `read_run_blob` / `delete_run_blob` | 完整结果 gzip JSON 读写删 |
| `slim_strategy_result_for_db(result)` / `slim_strategy_request(request)` | 结果/请求瘦身（库内只存摘要，防 JSONB OOM） |
| `_attach_builtin_source_snapshot(request)` | 回测请求附着内置策略源码兼容快照 |
| `ensure_sample_project(user_id)` | 新用户样例策略项目 |
| `list_projects` / `get_project` / `upsert_project` / `create_project` / `delete_project` | strategy_projects CRUD |
| `list_runs` / `list_all_runs` / `get_run` / `save_run` / `delete_run` | strategy_runs 管理（save 落摘要 + blob） |
| `update_run_remark` / `update_run_flagged` | 备注/标记 |

## 3. builtin_strategies_store

| 函数 | 说明 |
|---|---|
| `ensure_builtin_strategies_schema()` | 建 `builtin_strategies` 镜像表 |
| `list_builtin_strategies_from_db()` | 读镜像（total + items） |
| `get_builtin_strategy(strategy_id)` | 单条详情 |
| `sync_builtin_strategies_from_re()` | RE `GET /api/strategies` → upsert 镜像 |
| `_parse_tags(raw)` | 标签字段归一化 |

## 4. strategy_library_store（兼容门面）

| 函数 | 说明 |
|---|---|
| `libraries_root()` | 恒返回 None：内置策略已无 SVQuant 本地目录 |
| `load_index()` / `list_builtin_strategies()` | 转发 `list_builtin_strategies_from_db()` |
| `get_strategy_source(...)` | 转发镜像查询（兼容旧脚本导入路径） |

## 5. user_strategy_library_store

| 函数 | 说明 |
|---|---|
| `list_user_strategy_libraries` / `create_user_strategy_library` / `delete_user_strategy_library` | user_strategy_libraries CRUD |
| `list_library_strategies` / `add_library_strategy` | user_library_strategies 条目管理（代码/引用/元数据） |
| `get_library_strategy_archive(user_id, strategy_id)` | 策略代码归档查看（前端"归档"页数据源） |

> `mark-detected` 与 archive 的写路径由 router 直接调用对应 store 函数（标记字段更新），具体列名以表结构为准（待确认列清单）。

## 6. strategy_plaza_store

#### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `_MAX_CURVE_POINTS` | 360 | 净值曲线降采样上限 |
| `_MAX_TITLE` | 120 | 标题上限 |
| `_MAX_BODY` | 8000 | 正文上限 |
| `_MAX_CODE` | 200,000 | 代码快照上限 |

#### 关键函数

| 函数 | 说明 |
|---|---|
| `build_snapshot(payload)` | 组装快照：`_slim_metrics`（关键指标瘦身）+ 曲线降采样 |
| `_downsample_curve(points, limit)` | 曲线降采样（日期有效行清洗） |
| `create_plaza_item(...)` | 发布（author_id、source_run_id、snapshot JSONB、status=published） |
| `list_plaza_items(...)` / `get_plaza_item(item_id, *, bump_view)` | 列表/详情（浏览计数） |
| `hide_plaza_item(item_id, author_id, *, as_admin)` | 作者或管理员隐藏 |
| `_row_to_item(row, *, include_code)` | 行组装（是否含代码） |

## 7. 路由要点（routers/strategy.py）

| 端点 | 鉴权 | 语义 |
|---|---|---|
| `GET/POST /api/strategy/projects`、`GET/PUT/DELETE /api/strategy/projects/{id}`、`GET .../runs` | 登录 | 项目 CRUD + 项目运行列表 |
| `POST/GET /api/strategy/runs`、`GET/PATCH/DELETE /api/strategy/runs/{run_id}` | 登录 | 运行记录管理 |
| `GET /api/strategy/library`、`POST /api/strategy/library/sync`、`GET /api/strategy/library/{strategy_id}` | 登录（sync 权限待确认） | 内置目录镜像 |
| `GET/POST/DELETE /api/strategy/libraries*` | 登录 | 用户策略库 |
| `POST /api/strategy/library-strategies/{id}/mark-detected`、`GET .../archive` | 登录 | 标记/归档 |
| `GET/POST/DELETE /api/strategy/plaza*` | 浏览公开；发布/删除登录 | 策略广场 |

## 8. 数据表

| 表 | 关键列（摘要） |
|---|---|
| strategy_projects | user_id, project_id, name, config(JSONB, 含策略代码与参数), 时间戳 |
| strategy_runs | user_id, run_id, project_id, request 摘要(JSONB), result 摘要(JSONB), 状态, 备注, flagged |
| builtin_strategies | strategy_id, 名称, 类型, 执行模式, 版本, 标签（RE 同步快照） |
| user_strategy_libraries / user_library_strategies | 库与条目（代码/引用/标记） |
| strategy_plaza_items | author_id, title, body, source_run_id, snapshot(JSONB), view_count, status(published/hidden) |
