## 0. 开发校正与首期实现（2026-11-04，V3.1）

本章是正式开发的当前范围，优先于下文目标产品的场景示例。原型仍用于评审完整目标；运行工作区直接调用真实后端，二者入口分开。

公司正式产品采用流程方案版，业务分支为 **SVQuant/dev-zxd**。用户另行维护的自主研究版不再决定此分支的产品方向；保留旧历史，不覆盖未提交工作。回测扩展独立提交到 ResearchEngine 特性分支。

### 0.1 本期范围

| 业务模块 | 已实现的人工流程与工具 | AI 能力 | 本期边界 |
| --- | --- | --- | --- |
| 数据资源 | 发布版本选择、真实 OHLCV 样本查询、质量与覆盖记录、版本摘要 | 为下游助手提供固定版本和字段上下文 | 暂缓采集、清洗、调度和数据治理开发；使用已发布真实样本 |
| 因子工厂 | 研究定义 → 表达式构造 → 计算检验 → 诊断比较 → 候选复核 → 研究资产 | 按步骤建议字段、校验表达式、实际计算、读取证据、候选送审 | 当前为量价表达式；不宣称训练模型、严格独立验证或显著性证明 |
| 策略研究 | 研究目标 → 选择因子 → 交易规则 → 策略回测 → 候选复核 → 研究资产 | 建议当步参数、配置资产、调用回测、解读报告 | 使用已有 PortfolioEngine / MetricEngine；未接撮合、参数搜索或实盘 |
| 投资组合 | 组合目标 → 策略配置 → 组合计算 → 风险检查 → 方案复核 → 方案留档 | 参数建议、历史组合分析、证据复核 | 固定权重混合已扣费策略收益；剩余权重为零收益现金；无资金授权 |
| 运行监控 | 队列、失败记录、助手工具调用、操作事件 | 各任务的工具动作、参数、返回证据、错误和用量可追溯 | 监控研究服务；并未监控真实账户和成交 |

六步骤用于定位当前任务和操作入口，不强制所有任务从头串行重做。用户可以直接复用已有研究资产；共享数据版本、因子报告和策略报告通过固定 ID 和摘要连接。

### 0.2 修正原因与约束

1. **参数以真实工具能力为准。** horizon 为 1–20 个交易日，groups 为 2–5 且每层至少 2 只证券，rebalance 为 1–60 个交易日，top_n 不超过数据版本证券数，单边综合 cost_bps 为 0–200。界面由能力接口和所选数据版本限制；服务端再次校验。目标原型的范围不是引擎承诺。
2. **研究复用不等于人工登记。** 计算完成、硬检查通过的资产自动成为探索资产，可直接用于下游研究。未达候选条件的实验仍留档。只有达到候选条件的当前任务版本才能送审；人工通过后增加已审核标记。均为 research_only。
3. **独立验证不能用研发对照冒充。** 70% / 30% 时间切分可反复查看，属于研发诊断；真正的独立留出、试验记账、多重试验控制、封存访问权限仍属后续需求。
4. **任务版本与证据绑定。** 修改输入生成新版本；历史输入、实验和报告保留。旧报告不能送审新版本。正在计算或当前版本送审时禁止覆盖输入。并发写入采用 revision 检查，冲突返回 HTTP 409。
5. **避免重复计算。** 同一任务版本在排队、运行或成功后重试，返回同一个 run_id；失败或取消后可重新运行。任务快照、数据发布摘要、数据内容摘要与计算源码摘要保存在报告中。
6. **人工与 AI 同工具。** AI 填表只返回建议，人工采纳才保存；AI 执行模式可保存当前步骤字段或调用该步骤开放的工具。工具参数与人工入口使用同一校验。模型无权审批、修改预算或下单。
7. **异步状态真实可查。** 页面显示模型选用工具、工具输入、返回证据、耗时、错误、取消、用量。不是模型私有思维链，也不是预制的进度动画。
8. **审批边界真实。** 目前采用回环监听 + SSH 隧道的内部研发工作区，操作人记为研究责任人。尚未接入公司统一身份，不提供前端身份切换伪装权限。正式多用户发布前必须接入机构身份与独立审批。
9. **主观投资保持独立。** 本期不合并同事主观投资产品。前端沿用机构紫白样式，不复制同事业务。

### 0.3 首期候选筛选规则

规则版本 research-screen-v1。规则固定并随送审快照留存；不能由助手在一次实验后自行放宽。它仅减少人工审阅数量，不能代表机构已认可策略质量。

| 类型 | 条件 |
| --- | --- |
| 全部 | 实验成功，硬检查无失败，任务与报告版本相符 |
| 因子 | 有效 IC 至少 60 天，绝对平均 Rank IC 至少 0.02，覆盖率至少 80%，返回的研发分段 Rank IC 与全区间方向一致 |
| 策略 / 组合 | 至少 60 个收益观察日，扣费后夏普大于 0，最大回撤绝对值不超过 35% |

固定 16 股样本具有选择偏差，阈值通过也不能代表统计显著、全市场有效或可实盘。该规则应在后续接入更完整的数据、基准与独立验证后重新评估。

### 0.4 已接入接口

| 接口 | 用途 |
| --- | --- |
| GET /api/catalog | 真实发布版本与 ResearchEngine 能力、参数限制 |
| POST /api/preview | 只读行情预览 |
| GET /api/v3/state | 任务、资产、实验、筛选结果、助手运行、事件 |
| POST /api/v3/tasks | 新建因子、策略或组合任务 |
| POST /api/v3/tasks/update | 携带 id、revision、patch 保存新版本 |
| POST /api/v3/tasks/run | 固定当前版本运行真实计算；同版本幂等 |
| POST /api/v3/tasks/submit | 将符合条件的当前任务及报告送人工审核 |
| GET /api/runs/{id}、GET /api/runs/{id}/export | 完整报告与 JSON 导出 |
| POST /api/assistant | 携带 task_id、revision、stage、intent 和任务描述启动步骤助手 |
| POST /api/v3/assistant/apply | 采纳已完成的字段建议，拒绝覆盖过期版本 |
| POST /api/assistant/cancel、POST /api/cancel | 停止后续模型调用或停止接收计算结果 |
| POST /api/review | 人工通过、退回或拒绝研究登记 |
| POST /api/connection、POST /api/method | 模型连接、累计额度、共享研究方法版本 |

Agent 角色是业务职责，不等于独立常驻进程。当前共用有边界的工具执行器和模型连接，按当前任务步骤开放不同工具，最多 4 次工具调用和 1 次实验。独立角色的技能发布、检索库、评测与微调仍按后续需求实现，不在 UI 中伪造完成状态。
