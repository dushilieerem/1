日期：2026-11-04。产品分支：dev-zxd。以下为服务器开发环境成果，不是生产上线通知。

## 一、产品定位与整体流程
面向机构量化团队，人工与 AI 使用同一套研究工具。与同事负责的机构主观投资产品并列，登录时选择“机构端 → 量化投研”。
整体目标：数据资源 → 因子工厂 → 策略研究 → 投资组合与执行 → 运行监控与风险。研究可直接复用已有因子与策略，不强制逐批串行交接。

## 三、建议汇报顺序
1. 打开产品原型，先讲五个业务模块和各模块步骤；原型中的模拟指标、审批和 Agent 过程只是设计说明。
2. 打开真实系统，选择机构量化登录，展示因子工厂、策略研究、资产库及历史真实报告。
3. 在因子工厂填写研究假设，让 AI 给出代码建议；人工采纳后配置回测并运行。AI 草稿、静态校验、真实计算、投资审批是不同状态。
4. 展示报告中的数据来源与平台签名，再说明下一阶段的组合、机构共享、独立审批与持续 Agent 执行。
