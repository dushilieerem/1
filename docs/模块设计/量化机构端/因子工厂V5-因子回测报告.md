# 因子工厂 V5：因子回测报告（UX106）

状态：2026-11-10 用户要求后的实施规格；实现、加载、PM 验收分别记录。

## 1. 产品目标

因子库中的因子不只是一条名称或一段代码，应能查看支持它的实际回测材料。既有平台已保存的报告直接复用；没有完整报告时展示真实历史摘要和明确的缺失状态。查看报告不运行回测、不重导入因子、不改变审批结论。

## 2. 已核实的数据现状

- RE 私有副本的 SQLite 含 331 个因子定义及源码，没有报告表。
- 当前开发数据库的公共因子面板有 3972 条历史指标，覆盖 331 个因子，每个因子 12 种组合：沪深300/中证500 × 近3月/近1年/近3年 × 过滤涨停开/关；均过滤停牌。采样时更新于 2026-11-09，error 列无错误。
- 面板保存标量指标、范围选项和计算时间，没有净值/基准/IC序列、报告 ID、源码/数据版本指纹。不能用标量拼造曲线，不能从“近3年＋计算时间”伪造实际起止日，也不能断言与当前源码版本一致。
- 当前授权的三个 QA 主体里，2527 有 11 份已保存且能按库和稳定因子 ID 对上的完整结构报告，涉及 SV08_0060、SV13_0049、SV06_0010。抽查前三份含净值、基准、IC序列、实际区间和版本元数据。不是 331 份完整报告全部已有；只按登录用户原有权限提供。
- RE 有文件缓存，但没有可作为 331 公共报告目录的稳定公开索引；普通缓存读取还会触发更新时间/失效清理。不能因找到缓存就将其他用户私有结果发布到因子库。
- 新审批研究资产已经冻结研发、查重和封存结果指纹，完整证据仍保存在候选和封存记录里。现详情仅摘要，需补完整报告读取入口；不重算、不改变原批准快照。

## 3. 因子详情

沿用 UX105 抽屉、来源与代码，三个页签为「概览」「实现代码」「回测报告」。

### 3.1 平台历史回测

- 标明「历史回测摘要」，默认展示有记录的沪深300/近3年/过滤涨停组合；没有该组合时选择实际存在的一项，不合成默认结果。
- 股票池、回看区间、过滤选项由真实记录生成。切换只读取已保存结果，不后台重算；显示计算时间。
- 展示预测能力（Rank IC、Pearson IC、ICIR）、收益风险（年化收益、最大回撤、夏普、波动率、胜率）、分组收益/换手等实际保存的指标。为空显示「—」，0 是有效值；缺少序列明确说明，不画空壳或估计曲线。
- 单位按原平台映射：百分数保存字段转为合适展示单位；IC 值显示相关系数，IR/夏普无量纲。原平台未记录的显著性、实际起止或来源版本不得推算。详细计算设定可折叠查看。
- 简短说明当前摘要没有保存曲线和当次定义版本；报告仅代表其当时的范围与设定，不授予当前机构准入资格。普通主界面不展示 yg_v1、内部端口、接口或字段名。

### 3.2 已保存的完整报告

- 列出当前用户有权读取、库和稳定因子 ID 精确对应、没有自定义代码覆盖的历史检测记录。不得仅按中文名称关联。
- 每条显示实际区间、股票池、完成时间及记录状态；进入现有机构版报告页面，查看原有净值与基准、IC、分组、回撤、统计与追溯信息。缺失项目按原结果提示，报告存在不等于通过门槛。
- 没有时显示「尚无可查看的完整回测报告」，保留原「基于此因子建立研究」入口；不自动创建任务或发起回测。
- 如果曾在本机构正式登记复现验证，保留该固定资产及报告入口；私有试验与机构批准资产的权限不可混用。

## 4. 机构研究资产

- 已批准的新因子和复现验证记录均提供「研发报告」「独立验证报告」入口，读取审批时固定的完整结果。
- 新只读端点按同机构已批准资产校验注册快照、候选快照、研发结果/查重结果/封存结果指纹及报告身份。缺证据或不一致要报错，不使用最新试验替代。
- 报告页复用现有专业图表，显示批准资产名称、版本和报告阶段；只读返回因子库，不出现修改、重跑或拥有者私有工作台入口。
- 不为展示额外改变旧 registration_hash、不新建表、不扩大另一机构访问权限。当前 Agent 研究上下文与工具白名单不变，封存细节不反馈给调参/选题过程。

## 5. 接口约束

- GET /api/inst/quant/factor-workflow/imports/{id}/reports：先鉴权和 org 校验；返回 identity、历史摘要列表、当前用户报告索引，白名单字段。没有覆盖代码的精确定义关联；无权/不存在统一 404。
- GET /api/inst/quant/factor-workflow/assets/{id}/reports/{phase}：phase 仅 development/sealed；同机构已批准资产，沿用冻结完整性检查，从证据生成只读报告 DTO，不能借作者 uid 直接开放其任意报告。
- 不接收任意路径、数据库、上游 URL 或运行参数。GET 不计算、不迁移、不写业务数据；查询有界。摘要 API 失败与没有数据分别呈现，换因子/关闭抽屉后的迟到响应不能覆盖当前因子。
- 记录阶段、数据范围、来源定义版本能读到什么就显示什么；旧记录未保存的字段按缺失处理。

## 6. 验收

1. 331 条因子的指标组合与真实平台记录一致；检查三类因子、不同参数、0/null 和异常值口径。
2. 已保存报告的详情入口、曲线/基准、返回导航真实可用；不读其他用户或机构的私有正文。
3. 已批准资产双报告的完整性/阶段/跨机构/未批准拒绝，用隔离固定证据测试；当前没有真实合格入库资产时不得伪称真实入库验收完成。
4. API 401/404、摘要缺失/服务错误、乱序响应与重复切换；原源码/复制/分类搜索不回归。
5. 1366/1024/760 实页检查、页签键盘与滚动；不出现整页横溢出。
6. 先适当专项测试和串行构建，再核零在途后只加载自有 BFF；不启动研究或新回测，不动共享服务，不应用 CR102 迁移。

## 7. 本次非目标

不批量重算 331 个因子，不声称每个因子已有完整报告，不将失败历史删除或改为通过。后续补报告应作为明确范围的真实研究任务执行和留存，保持定义版本与验证证据关联。
