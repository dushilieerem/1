# 因子工厂：自动迭代与专业报告

2026-11-04；在已确认 V3 六步原型内扩展，不另起导航，不覆盖其它模块。

## V3.8 增量（2026-11-05）

新因子挖掘须同时通过研发数值、完整冻结库的因子值去重和样本外门槛，才自动送研究复核。F1 读取实际因子库，F2 明确研究目的及对照条件；重复定义与高相关失败继续在预算内改进，服务异常或不完整停止。复现旧因子不申报新发现。详情与真实失败演示见《因子新颖性与因子库对照.md》。

## 用户操作

F1 建任务 → F2 登记经济假设、初始表达式、允许的改进范围、研发/样本外区间与硬门槛 → F3 人工或 Agent 完成实现 → F4 保存股票池、基准、费用与成交参数。

F4 可选择单次手动检验，也可设置「本次最多迭代轮数（含初始检验）」后开始自动迭代。前者用于定向操作；后者由后台持续调工具，刷新、离开页面不重复启动。每轮结果可点入报告与对应 F6 候选。

| 状态 | 实际动作 | 后续 |
|---|---|---|
| 冻结起点 | 固定计划、日期、门槛、交易参数和初始源码 | 真实研发计算 |
| 研发不达标 | 保存报告与未通过项；Agent 依据研发反馈改进实现，平台静态校验，再冻结新候选 | 未到上限则下一轮 |
| 研发通过 | 对当前冻结代码进行一次样本外复验，核对数据和源码版本 | 通过则整理证据送独立研究复核 |
| 样本外失败 | 保存失败证据；停止本次搜索 | 人工复盘，不能针对已看过的验证区间继续自动调参 |
| 达到上限 / 无新实现 | 保留全部候选和失败报告 | 不自动送审 |
| 人工暂停 / 人工修改 | 停止后续调用；原子比较后才写代码，不能覆盖人工修改 | 可查看已完成结果；已提交的固定版本计算继续完成留档；Agent 停止后续回填，不自动重跑 |
| 服务、预算、计算异常 | 停止并说明原因 | 原输入和证据保留，不伪装质量结论 |

本次最多 1—20 轮，同时服从 F2 研究总尝试预算与现有模型额度；不扩容配额。允许改进范围留空时只能修复原定义实现，不能偷偷改窗口、公式语义或方向。新实现与旧实现相同则停止，避免重复计算。运行期固定门槛，不自动修改日期、费用、股票池、因子方向或审批状态。不同轮数据版本变化时停止比较。同一项目已查看过的重叠样本外区间不能开启新的自动搜索。当前全服务最多一个自动迭代任务；基础单次计算/Agent 队列沿用现有限额。

送审 = 提交独立研究意见请求。研发与样本外门槛通过仍不等于正式封存验证、共享准入或投资审批。模型不代签，不下单。

## 页面内的执行实况

自动迭代面板展示状态、上限、当前工具事件、每轮未通过项、函数名、改进依据、固定候选 ID、研发/复验报告及停止原因。F3 显示当前实际写入实现；每轮旧代码保存在不可变候选快照。未来可增加代码差异与更详细的假设修订提案；本期不会编造模型推理过程。

## 专业报告

参考现有 SVQuant 报告的信息范围和 ECharts 能力，机构页面独立实现，沿用紫色/白色机构风格。

- 收益与风险：组合/真实基准累计收益对比，动态回撤，相对基准收益，收益风险指标，成本、月度/年度收益及回撤区间。
- 分组表现：Q1—QN 与基准曲线、年化收益/波动/夏普/回撤/超额/IR/胜率/换手表、分层摘要。Q1 为最高因子值；分组未扣费与主组合扣费明确区别。
- IC 诊断：Pearson IC、Rank IC、非年化 IC IR、正 IC 比例、有效观测数、日度 IC、累计 IC、滚动 IR。无 Rank IC 日序列时不能把 Pearson 序列改名代替。
- 行业分析：仅展示实际返回的行业及行业内分组曲线；缺失明确说明。FF3 风格回归独立标记，不能冒充行业归因。
- 输入与来源：实际/请求日期、代码、费用、成交过滤、计算/数据/源码指纹、完整请求/返回、结果签名与 JSON 导出。

图表支持悬停/点击数值、图例切换与区间缩放（最近20期、60期、全部快捷范围）；缺失值保留断点，序列按日期对齐。累计收益 = NAV−1；相对基准 = NAV策略/NAV基准−1，不能混同引擎的年化超额定义。月度收益由连续报告净值计算，首尾月份可能不完整。成本比例不显示成现金金额。报告不补假数据。

## 技术与验收

业务表 `quant_factor_iterations`（迁移 0009，仅开发库）：成员/机构/项目外键、状态和轮数约束、每项目唯一 active、基线快照、追加事件、轮次证据、子任务引用。

复用 `quant_factor.agent_jobs` → 平台因子代码生成/校验；`quant_factor.service` → ResearchEngine 研发与复验；`review.request_review` → 独立研究复核。机构令牌、成员边界和后端权限保持不变。

验收需覆盖：真实两轮计算；失败/上限；一次样本外失败停止；成功仅送研究复核（不审批）；暂停与刷新恢复；人工改动不覆盖；已看过验证集阻断；按日期对齐及缺失报告；其它模块完整原型不回退。
