# SVQuant 产品层 模块设计（总览）

> 本文是产品层模块总览与跨模块约定。各核心模块的详细设计见文末目录索引；
> 系统级边界见 [架构文档/系统架构.md](../../架构文档/系统架构.md)。

## 1. 模块信息

- 模块名称：SVQuant 产品层
- 负责人：SVQuant 技术组
- 所属系统：SVQuant
- 文档版本：v2.0（2026-09-23，按当前代码事实重写）

---

## 2. 模块职责

本模块负责：

1. 承载 Web 产品体验、用户业务、权限、社区、知识库和 AI 编排。
2. 管理用户因子、策略、研究资产和产品展示缓存。
3. 通过 HTTP API 集成 ResearchEngine 的研究计算能力。

本模块不负责：

1. ResearchEngine 内部行情读取、因子计算、策略执行和结果存储。
2. 生产级容器编排、高可用和自动回滚方案。

## 7. 核心逻辑（跨模块约定）

### 产品请求处理

1. 前端向 `/api` 发送请求；路由按依赖分级鉴权（`optional_user` / `require_user` / `require_db_user_id` / `require_admin`）。
2. 路由层只做参数校验与编排，不做研究计算。
3. 服务层读写 PostgreSQL（`*_store`）或经网关调用外部服务。
4. 统一错误形状 `{"error": ...}`；HTTP 中间件把写操作与错误写入审计日志。

### 研究计算集成

1. 服务层将用户资产和参数解析为研究请求快照。
2. 网关（`forward_re`）调用 ResearchEngine，超时与错误映射为产品错误（502）。
3. 异步接口提交后轮询终态；"已提交"不等于"已完成"。
4. SVQuant 保存可再生展示缓存并返回前端；RE 不可用时明确失败，不伪造结果。

## 8. 外部依赖

| 依赖 | 用途 |
|---|---|
| PostgreSQL | 产品事实、用户、权限、社区、知识库、因子/策略配置、审计、AI 用量 |
| ResearchEngine | 行情、因子、策略和回测计算 |
| LLM 供应商 | AI 对话、生成、解读和 Agent |
| 资讯供应商 | 新闻和市场信息 |

矩阵详见 [架构文档 §11](../../架构文档/系统架构.md)。

## 9. 数据依赖

读取：

- PostgreSQL 产品数据与缓存；ResearchEngine 公开 HTTP API。

写入：

- PostgreSQL 产品事实、审计、配置和缓存。
- `backend/output/` 本机临时状态；`backend/data/strategy_run_blobs/` 回测结果 blob。

## 10. 异常处理

| 异常 | 处理方式 |
|---|---|
| 未登录或无权限 | 401 / 403 |
| PostgreSQL 不可用 | 产品写操作失败并记录日志 |
| ResearchEngine 不可用 | 网关映射为 502 + 明确文案，不回退本地计算 |
| 外部模型不可用 | 503（未配置）或 502（失败）；润色类降级 mock |
| 参数不合法 | 400 + 可修复提示 |

容错矩阵详见 [架构文档 §13](../../架构文档/系统架构.md)。

## 11. 性能要求

- 数据量：产品数据由 PostgreSQL 承载，行情和回测数据不进入 SVQuant。
- 并发：因子回测在途限流默认 8；其余待生产部署方案确认。
- 响应时间：AI 首响应 ≤ 3s、回测目标按 PRD；实际依赖 RE 和供应商。

## 12. 风险

- RE API 不兼容导致研究功能不可用（锁步发布缓解）。
- 生产部署和监控方案尚未完整定义。
- job.json / 后台线程任务重启不自愈（待 RE 任务 API 接管）。
- LLM 输出质量和成本存在不确定性（额度 + 护栏缓解）。
