# 因子研究模块 类/函数设计

> 本模块为函数式组织。以下单元与签名均来自真实代码（`backend/services/factor/`、`backend/app/routers/factor.py`、`backend/app/routers/detect.py`）。

## 1. 单元关系图

```text
routers/factor.py
  ├── user_factor_store ──────────▶ backend/factor/ 同步产物（index.yaml、custom_lib）
  ├── user_library_store ──▶ user_factor_store（方法名/规范化共用逻辑）
  ├── factor_trial ──▶ re_backtest_bff.forward_factor_backtest ──▶ RE
  ├── re_factor_catalog ──▶ 快照表（re_factor_catalog_snapshot）
  ├── re_backtest_jobs ──▶ re_backtest_bff ──▶ RE
  ├── re_factor_async_proxy ──▶ RE（/api/backtest/factor 兼容代理）
  └── dashboard_store ──▶ RE（批量） + factor_dashboard_metrics_store + factor_verification_store
routers/detect.py ──▶ detect_store
```

## 2. 用户因子资产

### user_factor_store

| 函数 | 说明 |
|---|---|
| `resolve_db_user_id(user)` | JWT 用户 → 数据库用户 ID（被 app/deps 复用） |
| `method_name_for(user_id, name)` | 用户因子的安全方法名映射（防重名冲突） |
| `_extract_def_name(body)` / `_normalize_body` / `_body_as_method` | 代码格式校验与规范化（def 名称一致性、描述注入） |
| `add_user_factor` / `update_user_factor` / `delete_user_factor` | user_custom_factors CRUD + `rebuild_custom_lib` 重建同步产物 |
| `list_user_factors` / `get_user_factor` | 按 user_id 过滤查询 |
| `filtered_index_yaml(owner_id)` | 生成按用户过滤的 YAML 因子索引（`/api/factor/index`） |
| `custom_lib_source_for_user(owner_id)` | 生成用户 custom lib 源码 |
| `migrate_legacy_custom_to_admin()` | 旧本地 custom 因子迁移到管理员名下（启动执行） |
| `rebuild_custom_lib()` | 重建 `backend/factor/custom_lib.py` 与 index.yaml |

### user_library_store

| 函数 | 说明 |
|---|---|
| `list_user_libraries` / `create_user_library` / `delete_user_library` | 因子库 CRUD（user_factor_libraries） |
| `list_library_factors` / `list_all_user_library_factors` | 库内因子查询（user_library_factors） |
| `add_library_factor` / `update_library_factor` / `delete_library_factor` | 库内因子 CRUD（代码校验同 user_factor_store） |

### factor_store（兼容层）

`add_custom_factor` / `update_custom_factor` / `delete_custom_factor` / `rebuild_custom_lib` / `migrate_legacy` —— 转发 user_factor_store，保留旧导入路径。

## 3. RE 目录与回测适配

### re_factor_catalog

| 常量/函数 | 说明 |
|---|---|
| `PRIMARY_LIBS` | 主库集合（目录同步范围基线） |
| `_pull_from_re(include_all)` | 拉取 RE 目录并归一化（45s 超时） |
| `content_hash(libraries, factors)` | 目录内容哈希（判重） |
| `sync_from_re(include_all)` | 同步：hash 变化才落快照 + sync_log |
| `fetch_re_catalog(force, include_all)` | 读路径：优先快照，force 强制拉取 |
| `clear_re_catalog_cache()` / `warm_re_catalog_async()` | 缓存清理 / 启动后台预热线程 |

### re_backtest_jobs（异步排队）

| 函数/常量 | 说明 |
|---|---|
| `MAX_INFLIGHT = _max_inflight()` | 环境变量 `SVQUANT_RE_BACKTEST_INFLIGHT`，默认 8 |
| `JOB_TTL_SEC = 3600` | job 保留时长，超时 `_purge_locked` 清理 |
| `submit_factor_backtest(payload, *, user_id)` | 生成 job_id → queued → 线程池调度 → 立即返回 |
| `get_factor_backtest_job(job_id, *, user_id)` | 查询状态（校验归属） |
| `cancel_factor_backtest_job(job_id, *, user_id)` | 取消/清理 |
| `_run_job(job_id, payload)` | 工作函数：调 `forward_factor_backtest`，写 job.json 终态 |
| `queue_snapshot()` | 队列在途/排队快照（运维观测） |

### re_backtest_bff

| 函数/常量 | 说明 |
|---|---|
| `RE_URL = f"{RE_BASE}/api/backtest/factor"` | RE 因子回测端点 |
| `DEFAULT_TIMEOUT_SEC = 1800` | 轮询总超时 |
| `_SV_ONLY_KEYS` | 转发前剥离的 SV 专有键集合 |
| `forward_factor_backtest(payload)` | 提交 + `_poll_factor_run` 轮询终态，返回结果/错误 |
| `_looks_like_result(data)` | 结果形态判定 |

### re_factor_async_proxy（`/api/backtest/factor` 兼容代理）

| 函数 | 说明 |
|---|---|
| `proxy_submit_factor_backtest(...)` | 提交（剥离 SV 键），202/同步兼容 |
| `proxy_get_factor_run(run_id)` / `proxy_cancel_factor_run(run_id)` | 状态/取消；`_rewrite_poll` 把 RE poll_url 改写为本站路径 |

### factor_trial

| 函数 | 说明 |
|---|---|
| `trial_via_re(*, body, factor_name="trial_factor", universe="CSI300", period="3m")` | 校验 def/函数名 → 组 payload → 经 `forward_factor_backtest` 试算；成功 = 无 error 且有 metrics |

## 4. 因子面板

### dashboard_store

| 函数/常量 | 说明 |
|---|---|
| `JOB_PATH`、`RULES_VERSION`、`PANEL_LOCAL_LIBS` | job.json 路径、指标规则版本、面板排除的本地/用户库 |
| `load_factor_index(include_qlib)` | 面板目录：读 RE 目录快照（`re_factor_catalog`，PG 优先），排除本地/用户库；不再维护官方库名白名单（RE 重组为单库「主因子库」后白名单会让面板变空）。`include_qlib` 仅兼容旧签名 |
| `map_yg_response(data)` | RE 回测响应 → 面板指标行（IC/IR 等格式化 `_fmt_*`） |
| `call_yg_backtest(payload, timeout=600)` | 单因子 RE 调用 |
| `read_job()` / `write_job(data)` | job.json 读写（本机临时状态） |
| `refresh_lock()` / `refresh_lock_available()` | 跨进程 `flock`（`panel_refresh.lock`）：整批回测互斥，覆盖 API 刷新与命令行日更；随进程退出自动释放 |
| `start_refresh(*, universe, period, filter_limit_up, filter_suspended, limit, skip_ok, analysis_level)` | 抢锁启动 `_run_batch` daemon 线程；重复触发拒绝；跨进程锁被占用时同步拒绝 |
| `_run_batch(**kwargs)` | 外层：抢跨进程刷新锁，抢不到写 failed + 原因并告警，不并发 |
| `_run_batch_locked(...)` | 内层：实际批跑（写 job.json 进度、逐因子 upsert） |
| `query_metrics(...)` / `lookup_panel_metric(...)` / `prune_orphan_metrics(...)` | 指标查询/单点查/孤儿清理 |
| `set_verify_status(...)` / `upsert_row(conn, row)` | 校验状态写入 / 指标行 upsert |

### factor_dashboard_metrics_store

| 函数 | 说明 |
|---|---|
| `ensure_schema`（`CREATE TABLE factor_dashboard_metrics` + `factor_dashboard_legacy_imports`） | 可再生指标缓存表 |
| `migrate_legacy_factor_dashboard_metrics()` | 旧 metrics.sqlite 只读导入（迁移键 `factor_dashboard_metrics_from_sqlite_v1`，一次性） |

### factor_verification_store

| 函数/常量 | 说明 |
|---|---|
| `VERIFY_STATUSES = {pending, passed, failed}` | 校验状态集 |
| `set_factor_verification_status(...)` | 写 `factor_dashboard_verifications`（长期记录） |
| `list_factor_verification_map()` | 全量校验状态映射 |
| `migrate_legacy_factor_verifications()` | 旧 SQLite 只读导入 |

## 5. 检测项目（detect_store）

| 函数/常量 | 说明 |

## 6. 因子目录扩展（factor_catalog_expand）

`factors_from_py(file_name)`（从本地 .py 提取因子）、`factors_alpha_features()`、`factors_qlib_alpha()`、`expand_lib_factors(lib_key, lib)`、`expand_index(index)`、`merge_source_name(...)` —— 面板/索引展示用的本地因子清单展开，不参与计算。

## 7. 路由要点（routers/factor.py、routers/detect.py）

| 端点组 | 鉴权 | 语义 |
|---|---|---|
| `GET /api/factor/index` | optional_user | 按登录用户过滤的 YAML 因子索引 |
| `GET/POST /api/factor/re-catalog*` | 登录 | 目录读取/同步 |
| `POST/GET/DELETE /api/factor/re-backtest*` | 登录 | 异步回测任务 |
| `POST/GET/DELETE /api/backtest/factor*` | 登录 | 兼容异步代理（re_factor_async_proxy） |
| `/api/factor/libraries*`、`/api/factor/libraries/{lib}/factors*` | 登录 | 因子库/因子 CRUD |
| `POST/PUT/DELETE /api/factor/custom*`、`POST /api/factor/custom/trial` | 登录 | 自定义因子与试算 |
| `/api/factor/dashboard*` | 登录 | 面板查询/刷新/校验 |
| `GET /api/factor/file/{name}` | 登录 | 同步产物文件 |
| `/api/detect/projects*`、`/api/detect/runs*` | 登录 | 检测项目与运行 CRUD |

## 8. 数据表

| 表 | 关键列（摘要） |
|---|---|
| user_custom_factors | user_id, name, body, description, 时间戳 |
| user_factor_libraries / user_library_factors | 库与因子条目（含代码规范化文本） |
| re_factor_catalog_snapshot / re_factor_catalog_sync_log | payload(JSONB)、content_hash、同步状态 |
| detect_projects / detect_runs | 项目配置(JSONB)、运行结果、备注、flagged |
| factor_dashboard_metrics | 因子 × 参数 × 指标列（`METRIC_COLUMNS`），可重建 |
| factor_dashboard_verifications | 因子、状态(pending/passed/failed)、备注，长期记录 |
| factor_dashboard_legacy_imports | 迁移标记（两 store 各自使用） |
