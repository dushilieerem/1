# 社区与新闻模块 类/函数设计

> 函数式组织。以下单元来自真实代码（`services/community/community_store.py`、`services/news/*`、`app/routers/community.py`、`app/routers/news.py`）。

## 1. 单元关系图

```text
routers/community.py ──▶ community_store ──▶ PostgreSQL
routers/news.py ──▶ news_store（读）/ news_ingest（手动采集、单条增强）
后台线程 ──▶ news_ingest.ingest_news ──▶ FETCHERS ──▶ news_tag_dict
```

## 2. community_store（services/community/community_store.py，约 2000 行）

#### 帖子

| 函数 | 说明 |
|---|---|
| `list_posts(...)` | 分页列表（板块/关键词过滤；viewer_role 传入决定可见范围） |
| `list_hot_posts(...)` | 热门榜（互动指标聚合） |
| `get_post(post_id, *, viewer)` | 详情 + 浏览计数 |
| `create_post(author_id, *, title, body, section, author_role, ...)` | 发布（板块校验；@提及 → 通知） |
| `update_post(post_id, author_id, ...)` | 作者编辑 |
| `delete_post(post_id, author_id, *, as_admin)` | 删除（作者或管理员） |
| `moderate_post(post_id, *, author_role, pinned, status)` | 管理员置顶/上下架（`author_role != "admin"` 抛 PermissionError；status 仅 published/hidden） |
| `purge_post(post_id, *, author_role)` | 管理员彻底清除 |
| `list_my_posts(author_id, ...)` | 我的帖子 |

#### 评论与投票

| 函数 | 说明 |
|---|---|
| `list_comments(post_id, ...)` / `create_comment(...)` | 评论列表/发布（@提及同样触发通知） |
| `set_post_vote(post_id, user_id, value)` / `set_comment_vote(comment_id, user_id, value)` | 赞/踩 toggle |
| `add_favorite(user_id, post_id)` / `remove_favorite(...)` / `list_favorites(user_id)` | 收藏 |

#### 通知

| 函数 | 说明 |
|---|---|
| `list_notifications(user_id, ...)` / `unread_notification_count(user_id)` / `mark_notifications_read(user_id, ...)` | 站内通知 |
| `_insert_notification(...)` / `_find_mentioned_user_ids(body)` | 内部：落通知、解析 @提及 |

#### 管理与举报

| 函数 | 说明 |
|---|---|
| `ops_summary()` | 运营摘要（总量/新增/待处理） |
| `list_moderation_posts(...)` | 待审核/已隐藏队列（admin） |
| `create_report(reporter_id, ...)` | 用户举报 |
| `list_reports(...)` / `resolve_report(report_id, *, author_role, ...)` | 举报处理（admin） |
| `refresh_demo_feed()` | 演示数据刷新（开发/演示用） |
| `_parse_platform_ref(...)` | 平台引用解析（供 metrics_trust 校验的 platform_ref 字段） |

#### 帖子板块

- `strategy` / `factor` / `qa` / `hotspot` / `official`（与 `backend/ai/crews/skills.py` 的 `SECTION_IDS` 一致）。

## 3. routers/community.py（25 端点）

| 组 | 端点 | 鉴权 |
|---|---|---|
| 浏览 | `GET /api/community/posts`、`/hot`、`/posts/{id}`、`/posts/{id}/comments` | optional_user（viewer） |
| 我的 | `GET /api/community/favorites`、`/my-posts`、`/notifications`、`/notifications/unread-count` | require_user |
| 写入 | `POST/PUT/DELETE /api/community/posts*`、`POST .../comments`、`.../vote`、`.../favorite` | require_user |
| 消息 | `POST /api/community/notifications/read` | require_user |
| 管理 | `GET /api/community/moderation`、`/reports`、`/ops/summary`、`POST .../moderate`、`.../purge`、`.../reports/{id}/resolve` | require_user + store 内 role=admin 校验 |

错误映射：`PermissionError → 403`、`KeyError → 404`、`ValueError → 400`。

## 5. news_ingest（services/news/news_ingest.py）

| 单元 | 说明 |
|---|---|
| `FETCHERS` | 源注册表：cls / eastmoney / eastmoney_research / eastmoney_policy / cninfo / wallstreetcn / 10jqka |
| `UNSUPPORTED_SOURCES` | 显式标记暂不支持的源 |
| `fetch_cls(...)` | 财联社（带签名参数） |
| `fetch_eastmoney` / `fetch_eastmoney_research` / `fetch_eastmoney_policy` | 东财市场/研报/政策 |
| `fetch_cninfo` / `fetch_wallstreetcn` / `fetch_10jqka` | 巨潮 / 华尔街见闻 / 同花顺 |
| `upsert_news_items(items)` | hash 去重 upsert 入库 |
| `_hash_key(source, url, title, published_at)` | 去重键 |
| `_extract_symbols(...)` | 从标题/正文抽取关联证券代码 |
| `backfill_news_tags(...)` / `enrich_news_body(...)` | 标签回填、正文增强 |
| `ingest_news()` | 执行一轮完整采集 |
| `start_news_ingest_scheduler()` | 后台 daemon 线程；`NEWS_INGEST_INTERVAL_SEC`（默认 900，≤0 关闭）、`NEWS_INGEST_LIMIT`（默认 12） |

## 6. news_tag_dict（services/news/news_tag_dict.py）

| `enrich_news_tags(item)` | 为单条资讯补标签 |

## 7. routers/news.py（6 端点，均无鉴权依赖）

| 端点 | 语义 |
|---|---|
| `GET /api/news` | 列表（多条件过滤） |
| `GET /api/news/dict` | 标签词典 |
| `GET /api/news/{news_id}` | 详情 |
| `POST /api/news/ingest` | 手动触发一轮采集 |
| `POST /api/news/{news_id}/enrich` | 单条正文增强 |
| `GET /api/market-data/daily/{code}` | 展示日线（挂载于本路由，见 ResearchEngine网关模块） |

## 8. 数据表

| 表 | 关键列（摘要） |
|---|---|
| posts | author_id, author_role, section, title, body, status(published/hidden), is_pinned, 互动计数 |
| post_comments / comment_votes / post_votes | 评论与投票（user_id + 目标 id 唯一） |
| post_favorites / notifications / community_reports | 收藏、通知（user_id, read）、举报（status） |
| news_items | source, url, title, body, category, published_at, tags, symbols, hash 去重键 |
