# 策略研究模块 模块设计

## 1. 模块信息

- 模块名称：策略研究模块
- 位置：`backend/services/strategy/`、`backend/app/routers/strategy.py`
- 负责人：SVQuant 技术组
- 文档版本：v1.0（2026-09-23）
- 需求依据：[PRD §6.3 策略研究与回测](../../需求文档/PRD.md)
- 历史基线：[01-需求文档/功能需求/策略回测.md](../../01-需求文档/功能需求/策略回测.md)；RE 集成见 [02-架构文档/engine-design.md](../../02-架构文档/engine-design.md)

---

## 2. 模块职责

1. 策略项目 CRUD 与样例项目（含默认策略代码模板，参数区 `SVQUANT_PARAMS` 与前端表单同步）。
2. 策略运行记录：保存回测摘要（PostgreSQL）+ 完整结果 gzip blob（`backend/data/strategy_run_blobs/`）、备注/标记、删除。
3. 内置策略目录镜像：经 RE `GET /api/strategies` 同步到 `builtin_strategies` 表，供页面展示与回测解析。
4. 用户策略库：库与库内策略条目 CRUD、代码归档查看、mark-detected 标记。
5. 策略广场：发布回测快照（标题/正文/指标/净值曲线降采样）、浏览计数、隐藏/删除。
6. 内置策略源码快照附着（`_attach_builtin_source_snapshot`）：回测请求附带兼容快照。

## 3. 不负责的范围

- 不执行策略回测、不实现撮合语义——全部由 ResearchEngine 完成（经 [RE 网关](../ResearchEngine网关模块/模块设计.md)）。
- 不保存内置策略源码的权威版本（RE 是事实源，SVQuant 只存同步快照与归档查看）。
- 不管理因子检测（属因子研究模块）。
- 模拟盘/实盘不在当前版本（FEAT-032 规划中）。

## 4. 输入

| 输入 | 来源 | 说明 |
|---|---|---|
| 项目 CRUD | `/api/strategy/projects*` | 名称、描述、配置（策略代码、universe、基准、周期、费用参数等） |
| 运行记录 | `/api/strategy/runs*` | 回测提交后保存的 run（run_id、request 摘要、result 摘要、状态） |
| 目录同步 | `POST /api/strategy/library/sync` | 管理员/用户触发（权限以待确认为准） |
| 用户策略库 | `/api/strategy/libraries*` | 库名、策略条目（代码/引用） |
| mark-detected / archive | `/api/strategy/library-strategies/{id}/*` | 标记已检测、查看代码归档 |
| 广场发布 | `POST /api/strategy/plaza` | 标题 ≤120、正文 ≤8000、source_run_id、指标与净值曲线、代码 ≤200,000 字符 |

## 6. 子模块

| 单元 | 位置 | 职责 |
|---|---|---|
| strategy_store | `services/strategy/strategy_store.py` | 项目/运行 CRUD、样例项目、blob 读写、内置源码快照附着 |
| builtin_strategies_store | 同目录 | RE 目录同步到 `builtin_strategies` 镜像 |
| strategy_library_store | 同目录 | 兼容门面：转发 builtin_strategies_store，不读本地目录 |
| user_strategy_library_store | 同目录 | 用户策略库与条目、归档 |
| strategy_plaza_store | 同目录 | 广场快照构建/发布/浏览/隐藏 |
| routers/strategy.py | `app/routers/` | HTTP 入口（回测本身走 RE 网关 `/api/backtest/strategy`） |

## 7. 内部结构

```text
routers/strategy.py ─┬─ strategy_store（项目/运行/blob）
                     ├─ builtin_strategies_store（同步/查询镜像）
                     ├─ user_strategy_library_store（库/归档）
                     └─ strategy_plaza_store（广场）
前端回测请求 → POST /api/backtest/strategy（RE 网关，见 ResearchEngine网关模块）
运行完成后 → POST /api/strategy/runs（保存摘要 + blob）
```

## 8. 核心逻辑

### 运行记录保存（大结果拆分）

1. `save_run` 把完整回测结果 `write_run_blob`（gzip JSON 到 `backend/data/strategy_run_blobs/{user_id}/{run_id}.json.gz`）。
2. 数据库只存摘要（`slim_strategy_result_for_db` / `slim_strategy_request`），避免大 JSONB OOM。
3. 详情页读取时 `read_run_blob` 还原；`delete_run` 同时删库行与 blob。

### 内置策略镜像

1. `sync_builtin_strategies_from_re()` 拉取 RE `GET /api/strategies`，upsert `builtin_strategies`（id/名称/类型/执行模式/版本/标签）。
2. 页面读镜像（`list_builtin_strategies_from_db`）；回测只提交 `strategy_id`。
3. `strategy_library_store.load_index()` 等旧 API 保留为兼容门面，不访问本地策略目录。

### 策略广场快照

1. `build_snapshot(payload)`：`_slim_metrics` 提取关键指标、`_downsample_curve` 净值曲线降采样 ≤360 点。
2. `create_plaza_item` 落 `strategy_plaza_items`（status=published）；`get_plaza_item(bump_view=True)` 浏览计数。
3. 隐藏：作者本人或管理员（`hide_plaza_item(as_admin)`）；管理员可见隐藏条目。

## 9. 外部依赖

| 依赖 | 用途 | 失败行为 |
|---|---|---|
| ResearchEngine | 目录同步、回测执行（经网关） | 同步失败保留旧镜像；回测 502 |
| PostgreSQL | 项目/运行/库/广场表 | 写失败并记录日志 |
| 本地文件系统 | `backend/data/strategy_run_blobs/` | blob 缺失时详情降级为摘要（以待确认实现为准） |

## 10. 数据依赖

| 存储 | 说明 |
|---|---|
| `strategy_projects` / `strategy_runs` | 项目与运行摘要（run_id 唯一，user_id 隔离） |
| `builtin_strategies` | RE 目录同步快照（可重建） |
| `user_strategy_libraries` / `user_library_strategies` | 用户策略库与条目 |
| `strategy_plaza_items` | 广场快照（published/hidden） |
| `backend/data/strategy_run_blobs/{user_id}/{run_id}.json.gz` | 完整回测结果（不入 Git） |

## 11. 异常处理

| 异常 | 行为 |
|---|---|
| 项目/运行/库/广场无权限 | 403/404（按 user_id/author_id 过滤） |
| RE 回测失败/不可达 | 网关 502；运行记录不落库或落失败态（以实现为准，待确认） |
| 目录同步失败 | 保留旧镜像 + 日志；同步接口返回错误 |
| 广场字段超限 | 400（标题/正文/代码上限） |
| blob 读取失败 | 详情降级摘要 + 明确提示（待确认） |

## 12. 性能要求

- 摘要入库 + blob 外置，控制 JSONB 体积与内存。
- 广场曲线降采样 ≤360 点；指标瘦身为有限键。
- 目录镜像避免每次外呼；同步为手动/低频操作。

## 13. 风险

- blob 为本机文件：备份策略未定义（待确认）；换机迁移需连带 `backend/data/`。
- 回测失败时运行记录的落库语义待确认（是否保存 failed run）。
- 广场公开内容（含代码快照 ≤200k 字符）可能包含用户敏感信息，审核依赖人工举报（待确认是否加自动检查）。
