# FT-003 社区深层回复展示修复

日期：2026-10-12。工作分支：`feat-zxd`。

## 问题与范围

帖子 #16 的公开评论接口返回 17 条记录：8 条一级评论、9 条回复。历史数据存在 `8 → 7 → 5` 的父级关系。原界面只按一级评论 ID 查找直属回复，遗漏 #8，全部展开后只能显示 16 条。

本次修复评论分组与展示，不修改服务器或数据库，不通过减少统计数掩盖缺失内容。

## 修改

- 新增纯函数 `groupCommentThreads`，沿父级关系查找所属楼层，将深层回复放入原有两层界面。
- 保留原始评论 ID、父级 ID、正文及互动状态；缺少显式回复对象的历史记录，根据直接父评论补充展示对象。
- 保持点赞数降序、同赞按时间升序的既有排序和每楼默认展示两条回复的折叠行为。
- 对父评论缺失或父级循环进行容错，避免已有可见记录被漏掉或无限循环。
