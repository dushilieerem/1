# H5 11.6 优化实现与验证（2026-11-06）

依据：`/home/dev01/download/11.6梦妍优化.pdf`
范围：多标的对比、多空辩论、AI 图表/参数位、量化快速实验；只使用服务端已算好的数据。

## 已实现

### 1. 多标的对比

- 新增 `/api/invest/compare?codes=A,B[,C]`，支持 2–3 只；超过 3 只只取前 3 只。
- 名称解析改为：代码 → 全名 → 子串 → 简称别名；先剥离「对比/比较/哪个好/vs/估值/财务」等意图词，再按「和/与/、/跟/同」切分。
- 解析失败返回 200 + `suggestions`，AI 管家提示「暂时没有『X』的数据，您想找的是不是 Y？」。
- 维度：
  - 行情：最新价、当日涨跌、5 日涨跌、成交额、换手率。
  - 财务：营收、营收同比、单季营收同比（用累计口径差计算）、归母净利、净利同比、毛利率、ROE、经营现金流净额。
  - 估值：PE(TTM)、PB、PE 分位、股息率。
  - 亮点与风险：按标的各列 ✓/⚠，只取财报、行情、估值分位、资金流与规则风险。
  - 总结：每行一个事实结论；跨行业自动加「只描述各自水平，不并排比大小」。
- 缺失值显示「—」，表下注明哪只标的缺哪项；不补估算值。
- 含 ETF 时提示先穿透底层持仓；ETF 没有完整财务报表。
- 前端 `/compare/:a/:b/:c` 最多 3 只，新增第三只搜索、移除标的；对比卡片在 AI 管家中复用同一组件。

### 2. 多空辩论

- AI 管家输入「多空分析/看多/看空 + 标的」进入独立 `debate` 意图。
- 服务端按财报、行情、估值分位、资金流、规则风险拆成「利多 / 利空」各最多 4 条，每条带来源。
- 不站队、不判断谁对；固定收尾「双方都有证据，不构成任何方向的建议」。
- 公告/研报未接入时明确标注，不用占位文案补齐。

### 3. 图表自动展示

- AI 个股回答按问题类型返回 `charts`：
  - 毛利率：近 4 期柱图；
  - 贵不贵/估值/PE：PE 值与近 3 年分位条；
  - 资金/流入：近 20 日主力净流入柱图；
  - 走势：保留原 K 线 sparkline。
- 图表数据全部来自服务端已算好的数组，模型不参与计算；前端按 `type` 渲染。

### 4. 截图识图（多模态 LLM）

- 「全部」面板新增「截图识图」，支持 PNG/JPEG/WebP；前端先压缩到最长边 1800px 再上传。
- 新增 `/api/invest/ai/vision` 与 `invest.vision` TaskSpec；调用当前 `LLM_MODEL` 的图片输入能力，不接第三方 OCR。
- 识别出的股票名/代码/条件回填输入框，不自动发送；错误名称沿用语音实体校正。
- 单图上限 8MB；只输出一行可编辑文字，识别失败或内容不合规时明确报错。

### 5. 预设问法参数高亮

- 预设填入后，输入框上方显示「参数位」，`[标的]`/`[条件]` 以浅红底红字标签展示。
- 点击标签自动聚焦并选中对应占位文字，输入后标签消失，发送时不再从整句猜股票名。

### 6. 量化研究

- 因子页：
  - 因子名下方加大白话解释（`plain/plain_en`）；
  - 因子榜底部新增「带着因子去建策略」，带着当前第一只因子跳到快速实验。
- 快速实验第 1 页：
  - 因子卡显示大白话、分位、近 20 日方向；
  - 选中后卡片右上角显示「方向 高/低」，点击切换；
  - 保留「已选 N/4」；
  - 相关性 ≥0.5 提示重复暴露，<0.5 提示分散度不错。
- 第 2 页配置：
  - 股票池（沪深 300/中证 500/全市场）、选股（10/20/30）、调仓（月度/双周/季度）、过滤开关（ST/上市 60 天/成交额 5000 万）、权重（等权/自定义）。
  - 自定义权重为逐因子百分比输入，合计不等于 100% 时提示并阻止回测；不自动归一化用户输入。
  - 配置块实时刷新；底部「开始回测 / 返回修改 / 保存草稿」。
  - 非默认配置走本地同口径引擎；RE 仅在默认配置时使用，避免 UI 与结果不一致。
- 第 3 页新增「AI 回测点评」；AI 不可用时整块隐藏，不留空卡。

## 数据与合规

- 对比/辩论未用公告、研报、一致预期；页面明确写「公告与研报数据尚未接入」。
- 没有目标价、买卖点、仓位建议、收益预测、评分排序。
- 缺失 PE 不补 PS（数据源未提供 PS），只显示「—」。
- 截图识图依赖 `LLM_MODEL` 的图片输入能力；模型不支持时会返回“AI 识图未配置/识图失败”，不会降级到假数据。
