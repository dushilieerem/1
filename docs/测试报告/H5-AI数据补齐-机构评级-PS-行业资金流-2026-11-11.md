# H5 AI 数据补齐：机构评级、PS、行业资金流与风格（2026-11-11）

## 一、已补齐的“有数据但没取到”

### 机构覆盖与评级

- 数据源：`doc_item` 的 `doc_type='research'`，近 180 天。
- 新增 `_institutional_view(conn, code)`：
  - 覆盖机构数；
  - 研报数量；
  - 评级分布（买入 / 增持 / 中性 / 持有 / 未评级）；
  - 最近研报日期。
- 目标价、盈利预测仍没有结构化字段，继续明确写“未提供”，不把评级当目标价。

### 估值指标

- 行业平均 PE 过滤负值和异常值（`0 < pe < 300`），修复此前茅台 `industryPe = -5.19`。
- 新增 `PS(TTM)`：
  - 由 `fin_income_statement` 计算 TTM 营收；
  - 用 `md_valuation_daily.total_mv ÷ TTM 营收` 计算；
  - 不再直接写“未提供”。
- 新增 `dividendPerShare`：来自 `fin_dividend.cash_per_share`。
- 总股本 / 流通股本缺失时，从 `fin_share_capital` 补齐。

### 今日复盘

- 新增行业主力资金流：
  - 用 `md_fund_flow_daily` 按 `stocks.industry` 聚合；
  - 输出净流入 / 净流出前三行业。
- 新增市场风格：
  - 全市场个股按总市值分半，计算大盘 / 小盘等权平均涨跌；
  - 按正 PE 分半，计算价值 / 成长等权平均涨跌；
  - 明确口径是“全市场个股等权平均”，不是官方风格指数。

## 四、首页“今日行业热度”

原首页“今日热点”的 `heat` 是初始化种子值，且 `topics` 只有 3 条固定数据，所以长期不变。

已改为方案 A：

- 首页展示 `industryHeat`，不再依赖主题-成分股映射。
- 热度分由四项综合：
  - 行业成交额 40%
  - 行业平均涨跌幅 20%
  - 行业主力净流入 25%
  - 近 7 日行业资讯数 15%
- 每项先做行业间分位排名，再加权为 0–100 热度。
- 首页标题改为「今日行业热度」，明确口径为“全市场个股等权平均”。
- 原 `/topics` 主题页保留，首页入口改为「主题」。

当前测试库示例：电力设备、电子、机械设备、计算机等按综合热度排序，不再固定为 AI 算力 / 高股息 / 新能源。
