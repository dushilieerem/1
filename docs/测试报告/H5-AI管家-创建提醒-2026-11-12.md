# H5 · AI 管家「创建提醒」实现与测试报告

日期：2026-11-12
文档依据：`AI管家-创建提醒功能说明.md`

## 一、实现范围

### 1. AI 管家

- 新增功能键「创建提醒」（输入框上方，与「条件选股」并列）。
- 点开可选 6 类示例：价格、财报、事件、估值、资金、热度 / 舆情。
- 一句话解析为结构化提醒，返回回显卡：
  - `帮你盯着 宁德时代（300750）`
  - `跌破 220 元时提醒 · 长期有效`
  - `[确认创建] [改一下]`
- 缺阈值不猜：追问问句 + 可点选项（如「跌破 220 元」「跌 5%」）。
- 缺标的：优先使用会话记忆的当前标的，没有才追问。
- 多标的拆分：一次说两只，按标的段落分别解析条件。
- 重复检测：同标的、同类型、同条件、同阈值不重复创建。
- 「帮我买」等诉求：明确提示只做提醒、不代下单，并转成价格提醒回显。
- 创建成功卡：`✅ 已创建`、同步说明、`查看提醒` 直达自选页并高亮。
- 标的未加自选时，询问是否加入，不静默加入。
- 支持会话内输入「我的提醒」，读取自选页同一份提醒数据。

### 2. 自选与提醒页

- 术语统一：区块标题改为「提醒」，顶部计数「N 只 · M 条提醒」。
- 条目两行展示：
  - 第一行：`标的 · 类型提醒` + 「AI 创建」/「未加自选」标签 + 状态。
  - 第二行：条件 + 当前值 + 距触发（数据缺失时只写条件）。
- 状态：生效中 / 已暂停 / 已触发，右侧开关可暂停与恢复。
- 点条目打开修改面板：可改阈值、截止日期、描述，可删除（二次确认）。
- 新建提醒 Sheet 改为 6 类「xx提醒」，并说明收盘后检查、不提供盘中推送。
- 触发日志保留「AI 创建」来源标签。
- `?highlight=<id>` 进入时滚动并高亮刚创建的提醒。

### 3. 后端

- `services/invest/reminders.py`：解析、回显、创建、列表、修改、暂停/恢复、删除、收盘后触发。
- `invest_event` 新增字段：`condition_op / threshold / unit / note / end_date / source / updated_at`。
- `invest_event_log` 新增 `source`，用于触发日志保留「AI 创建」。
- 新接口：
  - `POST /api/invest/reminders/parse`
  - `GET/POST /api/invest/reminders`
  - `PATCH/DELETE /api/invest/reminders/{id}`
  - `POST /api/invest/reminders/{id}/toggle`
  - `POST /api/invest/reminders/scan`
- `POST /api/invest/events/scan` 同时执行用户提醒检查，命中后写入触发日志。
- 触发文案只描述「发生了什么 + 为什么 + 可以看什么」，不出现买卖建议。

## 二、数据口径

| 类型 | 当前值来源 |
|---|---|
| 价格 / 涨跌幅 | `invest_stocks.price / prev_close` |
| 财报 | `invest_stocks.next_report_date` |
| 事件 | `fin_dividend.ex_date`（当前仅分红除权） |
| 估值 | `md_valuation_daily.pe_ttm` 近 750 交易日分位 |
| 资金 | `md_fund_flow_daily.main_net_inflow`，单位万元 |
| 热度 | `md_daily_bar.amount` 近 250 交易日分位 |

缺失处理：当前值取不到时只写条件，不写「距触发」，不填 0；数据源整类缺失时该类型置灰并提示「数据待接入」。

## 三、验证结果

| 项 | 结果 |
|---|---|
| 后端 Invest 测试 | `104 passed`（新增提醒 9 条：解析、追问、记忆、多标的、去重、买入转提醒、模糊事件组合、列表第二行、触发入日志） |
| H5 E2E | 49 条中 48 条通过；新增 4 条全部通过：创建提醒全流程、缺阈值追问、自选页管理与高亮、AI 查询我的提醒（唯一失败为下方备注的组合页慢 LLM 用例） |
| 前端构建 | `npm run build` 通过 |
| 横向溢出 | 390 / 360 宽度下提醒卡与自选页无横向溢出 |

备注：本地 E2E 环境中的组合页 AI 用例因后端 LLM 生成耗时超过 15 秒等待而失败（单次实测 43 秒，返回 6 个板块正常）；与本次提醒改动无关。

## 四、边界与未实现项

- 无推送通道：只在收盘后检查并写入「触发日志」，不发送系统推送。
- 免打扰时段、单日同类 3 条上限、重复提醒选项未实现（无推送通道，当前无实际影响）。
- 会话内「改阈值 / 取消提醒」的对话式操作未实现；可在自选页修改、暂停、删除，AI 会话查询会读取同一份数据。
- 事件类提醒当前只支持分红除权；公告、解禁、停复牌由数据平台事件流接入后再开放。
