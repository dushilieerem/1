# H5 · AI 管家术语解释匹配规则 实现与测试报告

日期：2026-11-12
文档依据：`AI管家-术语解释匹配规则.md`

## 一、匹配流程

```
原始提问
  → 抽取：剥掉「什么是 / 是什么意思 / 怎么算」等模板词与括号
  → 归一化：NFKC 全角→半角、小写、去空格与中英文标点
  → 分层匹配：1 精确 → 2 别名 → 3 包含 → 4 编辑距离 → 5 模型归一
  → 命中即止；未命中返回最多 3 个真实候选
```

实现位于 `backend/services/invest/glossary.py`：

| 层 | 规则 |
|---|---|
| 1 精确 | 归一化后等于词条名或词条 ID |
| 2 别名 | 等于任一 alias；别名与词条名冲突时单测报错 |
| 3 包含 | 互为子串且查询 ≥2 字；停用字（率/比/值/数/额/线等）不参与；长词优先；短英文缩写仅接受前缀，不做任意包含 |
| 4 编辑距离 | Levenshtein ≤1；2 字简称通过别名容错（夏谱 → 夏普） |
| 5 模型归一 | `invest.glossary` 只返回 `term_id`；ID 不存在则视为未命中 |

## 二、别名与词条

- 规范名改为中文主名，英文/缩写进别名：
  - 市盈率（PE / P/E / 本益比 / 市盈 / PE(TTM)）
  - 市净率（PB / P/B / 市净）
  - 净资产收益率（ROE / 权益回报率 / 净资产回报率）
  - 贝塔（Beta / β / 贝塔系数）
  - 阿尔法（Alpha / α / 超额收益）
  - 夏普比率（夏普 / 夏普率 / 夏普指数 / Sharpe / Sharpe ratio）
- 补充夏普对照词条：索提诺比率、信息比率、卡玛比率。
- 补充常用别名：最大回撤率 / MDD；波动 / 标准差；周转率。

## 三、兜底

- AI 管家未命中时返回：
  - `没找到「X」的独立词条，你要找的是不是：`
  - 最多 3 个候选按钮，点击直达 `/learn?term=<id>`。
  - 「反馈补充」写入 `invest_glossary_feedback`，只记录词，不生成内容。
- 学习中心搜索无结果时同样调用 `/api/invest/glossary/lookup` 给出候选。

## 四、词条内容

- 首屏保留 4 块：定义 / 怎么看 / 参考区间 / 例子。
- 新增「展开更多」：
  - 怎么算：公式 + 变量解释 + 数字算例；
  - 常见误读：2–3 条「误解 + 为什么错」；
  - 相近概念：指标 / 分母口径 / 使用场景对比表；
  - 在哪看：产品内位置。
- 已为市盈率、市净率、ROE、毛利率、净利率、股息率、夏普、索提诺、信息比率、卡玛、最大回撤、波动率、贝塔、阿尔法、换手率、量比等写入公式与算例；其余词条至少保留一条常见误读。
- 定义与内容全部来自词库，模型不生成定义；页脚固定「术语库口径 · 非投资建议」。

## 五、接口

| 接口 | 说明 |
|---|---|
| `GET /api/invest/glossary/lookup?q=` | 分层匹配；返回 `matched / layer / candidates / message` |
| `POST /api/invest/glossary/feedback` | 记录未命中词 |
| `POST /api/invest/ai/chat` | `glossary` 意图返回 4 块词条卡 + `glossary.id/term`；未命中原样返回候选 |
| `invest.glossary` AI 任务 | 仅输出 `{"term_id": "..."}`，ID 必须存在 |

## 六、验证结果

| 项 | 结果 |
|---|---|
| 后端 Invest 测试 | `110 passed`（术语库 11 条，含 16 条验收入口的匹配用例） |
| 匹配验收 | 夏普比率 / 夏普 / 夏普比 / 夏谱 / Sharpe / sharpe ratio / 什么是夏普 / 夏普比率是什么意思 / ROE / roe 怎么算 / 市盈率 / PE / 夏 / 率 / 阿巴阿巴 全部符合预期 |

| 前端构建 | `npm run build` 通过 |

备注：本地 E2E 环境中的组合页 AI 用例因后端 LLM 生成耗时 43 秒、超过 15 秒断言等待而失败，与本次术语改动无关。

## 七、边界

- 第 5 层模型归一依赖 LLM 配置；未配置时直接走候选兜底，不报错。
- 学习中心静态列表搜索仍为包含匹配；无结果时再由 `/glossary/lookup` 给候选。
- 反馈只落库，不在本次实现后台审核界面。
