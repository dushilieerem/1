# H5 AI 管家个股诊断七板块改造（2026-11-11）

依据：`/home/dev01/download/AI管家-个股诊断输出规范.md`

## 一、输出结构

AI 管家个股回答从短卡片改为 7 个问句式板块：

1. 公司是什么来头
2. 最近一期业绩怎么样
3. 当前估值贵不贵
4. 资金面什么信号
5. 机构怎么看
6. 核心亮点与风险
7. 综合结论

每个板块使用「章节 → 块」：

- 段落：2–4 句，讲判断、原因和含义；
- 要点：并列清单，每条 ≤28 字；
- 表格：业绩指标、估值指标、近 5 日资金、机构预测；
- 图表：近 5 期营收/净利、近 5 日主力净流入；
- 行情走势图复用个股透视页的 `KLineChart`：K 线 + MA5/10/20，支持 MA/BOLL 切换，放在结论下方。

## 二、数据与口径

- 业绩、估值、资金、财务趋势均来自服务端 `build_stock`。
- 业务收入构成、PS、北向、机构评级/目标价/盈利预测当前未接入：统一写「未提供 / 无法核验」，不填 0。
- 机构数据在文案中标注「第三方数据，非本产品观点」。
- 目标价、评级和盈利预测不由 AI 生成。
- 回测/个股结论统一标注「AI 生成 · 非投资建议」。

## 三、AI 与降级

- `invest.stock` 改为「AI 管家个股诊断」，默认提示词改为 7 板块 `sections → blocks`。
- 模型只写段落和要点；服务端按数据附加表格与图表。
- 若模型只返回部分文本，默认板块的要点/表格仍会保留，不会出现空板块。
- 无 LLM Key 或 AI 失败时，返回服务端规则版诊断，7 个板块仍可用。
- Agent 管理中的「AI 管家个股诊断」可单独编辑/恢复默认。
