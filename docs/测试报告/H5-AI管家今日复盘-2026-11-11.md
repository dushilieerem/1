# H5 AI 管家今日复盘改造（2026-11-11）

依据：`/home/dev01/download/AI管家-今日复盘输出规范.md`

## 一、输出结构

回答顺序固定为「市场 → 结构 → 我的组合 → 异动 → 为什么 → 盯什么」：

- 必答：
  1. 大盘概览
  2. 市场结构
  3. 我的组合
- 按需：
  4. 关注标的异动
  5. 今天为什么
  6. 后续盯什么

有内容才输出按需板块，没有异动不写「今日无异常」凑数。

## 二、数据与块

- 市场：三大指数、成交额与环比、涨跌家数/涨跌停、北向（未提供）。
- 结构：领涨/领跌板块、热点主题、风格与主力行业流向（未提供）。
- 组合：今日收益 vs 沪深300；逐只归因按「权重 × 涨跌」算术结果，只列主要贡献/拖累。
- 异动：自选/持仓事件、公告/财报预约披露。
- 原因：首页复盘摘要与资讯，找不到明确催化写「无明显单一催化」。
- 跟踪：成交额、涨跌家数、自选公告、领涨板块等观察变量。
- 图表：今日指数涨跌、组合今日归因。

## 三、AI 与降级

- 代理管理中的「今日复盘」可单独编辑/恢复默认。
