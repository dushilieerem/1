# H5 AI 管家组合风险改造（2026-11-11）

依据：`/home/dev01/download/AI管家-组合风险输出规范.md`

## 一、输出结构

组合风险改为 6 个板块：

1. 结论与风险分
2. 结构风险（越线项）
3. 今日影响
4. 压力测试
5. 目标偏离
6. 观察与局限

每节使用「章节 → 块」：

- 段落：结论与判断；
- 要点：关键指标、贡献/拖累、观察与自查；
- 表格：越线项、压力情景、目标 vs 当前；
- 图表：压力测试影响、今日归因。

## 二、数据与口径

- 风险分、等级、主要越线项来自组合体检。
- 只输出越线项；未越线项最多一句话说明。
- 越线表包含：风险项 / 实测值 / 阈值 / 超出幅度 / 影响，按严重度排序。
- 穿透后集中度同时标注覆盖率；未覆盖部分不计入。
- 今日归因只写「权重 × 涨跌」的算术贡献。
- 压力测试保留情景假设、beta 与冲击幅度。
- 目标偏离只描述目标 vs 当前，不写调仓建议。
- 风险分是结构描述，不预测涨跌。

## 三、AI 与降级

- `invest.portfolio` 改为「组合风险」，提示词输出 6 个板块。
- 模型只写段落和要点；服务端附加表格与图表。
- 无 LLM Key 或 AI 不可用时返回规则版，6 个板块仍可用。
- 组合页「AI 关键结论」和 AI 管家组合问题统一使用 `blocksMode + showCharts`。
