# H5 AI 自动生成、50 字限制与 Agent 管理

- 日期：2026-11-04
- 范围：`frontend/invest/**`、`backend/app/routers/invest_ai.py`、`backend/services/invest/agent_prompts.py`、`backend/services/invest/ai_cache.py`、`backend/migrations/0008_invest_ai_agent.sql`

## 1. 自动生成

- 个股 AI、组合 AI、多标的对比、回测/模拟盘 AI 点评进入页面后自动请求，不再显示首次「生成」按钮。
- 生成结果仍保留「重新生成」按钮；重新生成使用 `refresh=1` 绕过缓存并覆盖同一缓存键。
- 生成失败时只显示失败/重试态，不阻塞指标、图表与持仓数据。

## 2. 50 字限制

- 后端卡片统一压缩：`summary` 最多 50 个字符，超出截断并加省略号；`sections` 强制为空。
- 组合深度解读、回测点评、模拟盘点评、量化点评均改为 50 字结论；不再展示长篇分点。
- AI 提示词同步改为要求「不超过 50 个汉字、sections 为空」。
- AI 管家卡片同样走该压缩逻辑；合规拦截话术保留固定全文。

## 3. 落盘缓存

- 新增 `services/invest/ai_cache.py`，按 `user_id + 命名空间 + 输入哈希` 存 JSON：
  `backend/data/invest_ai_cache/<user_id>/<namespace>/<sha256>.json`。
- 缓存键包含 task_id、结构化输入和最终提示词；数据变化或提示词变化会自然生成新键。
- 重新生成覆盖同一个键；不设 TTL，重新进入页面优先读缓存。
- 目录位于 `backend/data/`，已在 `.gitignore` 中。

## 4. Agent 管理

- 「我的」新增「Agent 管理」入口，路由 `/agents`。
- 展示 H5 可用 Agent：个股、组合、公告、对比、日报、条件选股、配置定投、回测、量化、模拟盘、意图识别。
- 支持查看默认提示词、编辑、保存、恢复默认；意图识别为结构化解析，提示词锁定。
- 覆盖落 `invest_ai_agent_prompt`（user_id + task_id），按用户隔离；所有 H5 AI 调用通过 `resolve_prompt` 应用覆盖。
- 修改提示词后缓存键变化，下一次生成使用新提示词。

- 快速实验结果若含 `quality/growth`：页面明确提示「含 RE 暂无的基本面因子，可保存草稿但不能开模拟盘」，开按钮禁用。

## 8. 边界

- 缓存按用户与本机 `backend/data` 落盘；多实例部署需共享存储或改为对象存储。
- 50 字限制是展示层强约束；结构化字段和合规固定话术不受影响。
- Agent 提示词只对 H5 `/api/invest/ai/*` 与量化点评生效，不修改全局 TaskSpec 或其他端 Agent。
