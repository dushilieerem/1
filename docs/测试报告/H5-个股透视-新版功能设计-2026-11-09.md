# H5 个股透视新版功能设计实现（2026-11-09）

依据：`/home/dev01/download/个股透视-功能设计.pdf`
分支：`feat/h5-11.6-optimization`
范围：个股透视首屏、行情快照、财务指标趋势、财报弹层与估值展示。

## 一、行情快照

按设计 1:1 改为「左侧大价格 + 右侧 3×3」：

- 去掉卡片外框、圆角、背景、阴影、内外边距和九宫格分割线。
- 高度固定 58px（390/360 宽实测均为 58px），九项在同一横条内，不换行、不滚动。
- 左块约 28–30%：现价 28px 粗体，涨红跌绿；第二行涨跌额 + 涨跌幅 12px 同色。
- 右块 3×3：
  - 高 / 低 / 开
  - 市值 / 流通 / 市盈
  - 量比 / 换手 / 额
- 每格「标签在左、值在右」同一行；标签 9px 浅灰，值 10.5–11px。
- 高/低/开按昨收着色；市值、流通、市盈、量比、换手、额用常规色。
- 数字区不再显示日期 / 收盘状态；日期移到走势图右上角。
- 顶栏副标题改为「代码 · 行业 · 板块」，名称居中，右侧搜个股 / 分享；加自选仍在底部。

## 二、走势图

- 移除「分时」周期和分时图，只保留日 K / 周 K / 月 K。
- K 线上方左侧新增「均线 / BOLL」切换：
  - 均线：MA5 橙、MA10 紫、MA20 蓝；
  - BOLL：20 日、2 倍标准差，MID 橙、UP 红、LOW 蓝。
- 价格图图例放在价格图上方，按当前指标显示 MA5/10/20 或 MID/UP/LOW；K 线图例同时保留。
- 成交量改为独立图表，与价格图分开渲染，不再共用同一个 lightweight-charts 实例。
- 成交量图上方左侧显示最新成交量「x.x 万」，并保留成交量图例。
- 成交量图增加成交量 MA5（橙）/ MA10（紫）两条均线，图例放在成交量图上方；不足 5/10 根时对应线不画。
- 分时接口和前端分时状态已删除；分时 E2E 改为「分时入口不存在 + BOLL/成交量可见」。

## 三、财务指标趋势

按设计重做：

- 标题「财务指标趋势」。
- 8 个指标，4 列 × 2 行等宽网格，不横向滚动：
  - 营业收入 / 归母净利 / 扣非净利 / 每股收益
  - 毛利率 / 净利率 / ROE / 经营现金流
- 默认选中「营业收入」；选中态浅绿底 + 绿色字。
- 图例行在图表上方：左侧蓝块「指标值」+ 橙块「同比增速」；右侧报告期下拉。
- 报告期下拉：年报 / 中报 / 一季报 / 三季报；当前项浅红底红字；点空白收起。
- 图表：
  - 蓝色竖柱，柱宽约间距 45%，柱顶标数值；
  - 橙色同比折线，点落柱上方，标百分比；
  - 左侧 4 个 Y 轴刻度，单位标在轴顶；
  - X 轴只放 4 个同类型报告期；
  - 无同比数据的指标隐藏橙块和折线；
  - 图高约 196px。
- 摘要句随指标、报告期同步更新；三季报营收额外给出单季 Q3。
- X 轴取该报告类型最近 4 个可用年份，不混 2025Q3 → 2025Q4 → 2026Q1。
- 每个点均为该报告期累计值，不是单季值。

示例（贵州茅台，测试库）：
- 2025Q3 营业收入 1,284.5 亿元，同比 +6.3%；单季 Q3 390.6 亿元。
- 切换年报名后 X 轴变为 2022–2025 年报，柱、线、轴、摘要同步刷新。

## 四、财报与估值

- 财务 Tab 下提供利润表 / 资产负债表 / 现金流量表三个入口，统一进财报弹层。
- 弹层：
  - 利润表：营收、归母净利、毛利率、净利率；
  - 资产负债表：总资产、总负债、净资产、资产负债率；
  - 现金流量表：经营 / 投资 / 筹资净额。
- 估值保留 PE / PB / 股息率三数并排；PE 增加行业 PE 对照，PB 增加历史分位；分位条和「低分位不等于安全边际」提示保留。
- PS、历史中位数数据源未提供，不用估算值补。

## 五、数据口径与缺口

- 财务序列来自 `fin_income_statement` + `fin_indicator` + `fin_cash_flow`，按报告期累计。
- 当前测试库最新报告期为 2026H1；三季报取最近 4 个可用 Q3，因此是 2022Q3–2025Q3，而不是设计稿示例的 2023Q3–2026Q3。
- 扣非净利 serving 字段尚未提供（`deducted_net_profit` 在视图里存在，但 `fin_income_statement` 未落库），该 tab 暂显示「该指标暂无数据」。
- 公告 / 研报 / 公司简介 / 分红 / 股本入口仍等数据业务 serving 表同步；不做占位数据。
- AI 五维分析仍依赖现有 AI 链路，本轮未改 AI contract。
