## 一、走势图副图

主图保留日 K / 周 K / 月 K，以及均线 / BOLL 切换。

副图从单一成交量升级为 5 个指标切换：

| 指标 | 内容 |
|---|---|
| 成交量 | 红绿柱 + MA5 / MA10 |
| 成交额 | 红绿柱 + MA5 / MA10 |
| MACD | DIF / DEA 线 + 红绿柱（12,26,9） |
| KDJ | K / D / J 三线（9,3,3） |
| RSI | RSI6 / RSI12 / RSI24 三线 |

- 切换按钮在副图左上角。
- 图例随指标联动，显示当前值。
- 成交量/成交额单位分别为「万」/「亿」。
- MACD 柱按正负显示红/绿；DIF/DEA 分色。
- KDJ 使用 RSV → K/D 平滑 → J=3K−2D。
- RSI 使用涨跌均值计算。

## 二、主图与副图联动

- 主图和副图使用同一份 K 线横坐标。
- 两张图的可见逻辑区间通过 lightweight-charts `visibleLogicalRange` 同步：
  - 主图缩放/拖动 → 副图同步；
  - 副图缩放/拖动 → 主图同步。
- 横坐标标签格式为 `YYYY-MM-DD`。
- 两张图使用固定右轴宽度，减少横坐标偏移。

## 三、财务指标趋势

- 后端 `financialTrend` 读取完整财报历史，不再只从 2022 年开始。
- 前端默认展示同类型报告期最近 **4 年**。
- 图例行右侧新增 `− / +` 时间范围控制：
  - 默认 4 年；
  - 点击 `+` 逐步展示更早年份（可查看 2016–2021）；
