# 个股透视 P0 实现与验证（2026-11-06）

依据：`/home/dev01/download/11.6梦妍个股透视.pdf`
范围：只上有数据、可闭环的部分；无数据模块不展示入口。

## 已实现

- 顶栏：返回 + 居中名称 + 代码/板块 + 搜个股 + 分享；加自选已移到底部。
- 行情快照 3×3：高/低/开、总市值/流通市值/PE、量比/换手/成交额。
  - 新增后端字段：`floatMarketCap`、`volumeRatio`、`board`、`exchange`、`listDate`、`totalShares`、`floatShares`。
- 走势：分时 / 日K / 周K / 月K，保留成交量与 MA5/10/20。
- AI 个股分析：复用现有 AI 个股结论；生成失败整块不渲染。
- Tab：
  - 资讯：仅有要闻时展示，取最近 4 条；无个股资讯时不显示 Tab。
  - 财务：营业收入/归母净利/毛利率/ROE 四切换、三张报表入口、估值位置。
  - 资金：今日/5 日主力净流入、四类资金分布、资金与股价背离；不足 20 日时不画 20 日图。
  - 简况：基本信息、同业比较、主要风险；无数据的公司简介/股东/分红不展示。
- 底部固定操作：问 AI / 加自选（状态切换）。

## 后端补充

- `build_stock` 新增：流通市值、量比、板/交易所/上市日、总股本/流通股本、三大报表、资金流、同业列表。
- 资金流：
  - 使用 `md_fund_flow_daily` / `md_fund_flow_candidate`；
  - 展示金额与连续天数，不使用资金流表 `close/change_pct` 算价格/收益；
  - 20 日值仅在数据达到 20 个交易日时返回。
- 财务三表来自 `fin_income_statement` / `fin_balance_sheet` / `fin_cash_flow`。
