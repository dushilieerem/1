# H5 图表与分点样式修复（2026-11-11）

依据：`/home/dev01/download/图表与分点样式-修复说明.md`

## 一、柱宽与居中

- 所有 AI 柱状图改为 SVG 实现。
- 单柱最大宽度 `40px`，柱宽 = `min(40, 槽位 × 55%)`。
- 每根柱子在各自槽位内居中，整组柱子水平居中。
- 数据点少时不撑满整行；数据点多时按槽位自动变窄。

## 二、负值与 0 轴

- Y 轴值域强制包含 0：
  - 正值从 0 轴向上，红色 `#e54d42`；
  - 负值从 0 轴向下，绿色 `#16a34a`。
- 图中绘制独立 0 轴，刻度包含 0 与负值。
- 主力净流入、月度/年度策略收益等正负混合数据可同时看到上下两侧。
- 资金流图颜色同步为同一套红/绿。

## 三、分点样式

- `.ai-points li` 去掉边框、背景、圆角、阴影。
- 行首统一使用红色圆点，行与行靠间距区分。
- `.ai-section`、`.ai-analysis-section` 去掉卡片外框，正文连续阅读。
- 独立提示卡（合规拦截、免责声明）和表格仍保留边框。
