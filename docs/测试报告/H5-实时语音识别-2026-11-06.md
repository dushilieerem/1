# H5 实时语音识别（ASR）实现与验证（2026-11-06）

## 已实现

- AI 管家麦克风优先使用浏览器 **Web Speech API**（`SpeechRecognition` / `webkitSpeechRecognition`）：
  - `continuous=true`、`interimResults=true`，边说边把 partial/final 文本写入输入框；
  - 语音只填入输入框，不自动发送；
  - 已有文字时追加，不覆盖；
  - 支持权限拒绝、无声音、识别失败、浏览器不支持等错误提示；
  - 页面卸载时中止识别、释放录音。
- 不支持 Web Speech API 的浏览器继续走原有 `MediaRecorder → /api/invest/ai/voice → SenseVoice` 批量识别兜底。
- `/api/invest/ai/voice` 补上 `require_user`，避免未登录调用。

## 浏览器范围

- Chrome / Edge / 部分 Android Chromium：支持实时识别。
- iOS Safari、Firefox：通常没有可用的 `SpeechRecognition`，会走“录完再识别”的兜底，不是实时。
- 浏览器 Web Speech 的音频由浏览器厂商处理，不是我们自建 ASR；如要求完全自建/可控，需要下一阶段接 FunASR/sherpa-onnx + WebSocket/WebRTC。
