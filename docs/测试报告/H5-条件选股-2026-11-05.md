## 1. 已实现流程

- AI 管家输入框上方新增「选股」入口；点击才打开选股面板（Sheet），不点击不出现。
- 面板展示 6 个预设方向 + 「自己写」；点击预设把整句填进多行输入框，数字和条件可改。
- 输入框改为自动增高的 `textarea`，支持多行；Enter 发送，Shift+Enter 换行。
- 支持直接输入条件句触发，不强制从面板进入。
- 解析后：
  - 全部识别 → 直接执行筛选；
  - 部分识别 → 无法识别片段标红，每条给 2 个可执行替代说法；
  - 条件冲突 → 指出冲突，不执行；
  - 用户自己输入到未知条件 → 标「暂不支持」，不执行；可点红色标签删除后重筛其余条件。
- 筛选边界：
  - 0 条 → 指出最可能卡住的条件 + 3 个放宽动作；
  - >200 条 → 提示「条件偏松」+ 3 个加条件建议；
  - 1–200 条 → 结果卡。
- 结果卡：
  - 顶部「按你设定的 N 个条件，共筛出 M 只」；
  - 条件标签可单独删除并重筛；
  - 列表最多 5 只，左侧「+」加自选，整行点进个股透视；
  - 「查看全部 M 只 →」展开；
  - 2–3 条小总结（中位数/区间/行业集中度）+ 1 条风险提示；
  - 「存成自选分组」；
  - 3 条「继续问」建议：行业分布、按 ROE 排序、放宽条件；
  - 行业分布按行业横向条形 + 只数/占比。
- 中英文界面文案均有；条件本身为 A 股中文口径。

## 2. 后端接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/invest/condition/parse` | 只解析条件，不执行 |
| POST | `/api/invest/condition/screen` | 传 `query` 或删标签后的 `conditions` 执行筛选 |
| POST | `/api/invest/condition/watchlist` | 批量存为自选分组（最多 200 只） |

核心文件：
- `backend/services/invest/condition.py`：中文条件解析、冲突/未识别判断、逐层收窄筛选、结果摘要、行业分布、放宽动作。
- `backend/app/routers/invest.py`：上述 3 个接口。
- `frontend/invest/src/components/ConditionScreener.tsx`：选股面板、解析卡、空/过宽/结果卡、行业条形图。
- `frontend/invest/src/pages/AiChat.tsx`：选股入口、多行输入、条件状态与自选动作。

## 3. 指标与数据口径

| 条件 | 实现数据源 |
|---|---|
| 总市值 | `invest_stocks.market_cap`（亿元） |
| N 日涨幅（预设 20 日） | `md_daily_bar(adjust='hfq')` 收盘价 |
| PE 分位 | `md_valuation_daily.pe_ttm` 近 5 年日频分位 |
| 股息率 | `invest_stocks.dividend_yield` |
| ROE | `fin_indicator.roe` 最新报告期，转换为百分比 |
| 近 3 年净利润连续增长 | `fin_income_statement` 最近 3 个完整年度，归母净利逐年递增且为正 |
| 1 年最大回撤 | `md_daily_bar` 近 250 个交易日收盘净值 |
| 60 日新高 / 站上 MA60 / 60 日高点回撤 | `md_daily_bar` 近 60 个交易日 |
| 成交量放大 | 当日量 ÷ 近 5 个交易日均量 |
| 连续 N 日收阳 | 最近 N 个交易日收盘 > 开盘 |
| 行业分布 | `invest_stocks.industry`（申万一级） |
| 主力净流入 / 连续 N 日为正 | `md_fund_flow_candidate`：`main_net_inflow_5d`（元→万元）、`consecutive_inflow_days`；资金流表 `close/change_pct` 不用于收益计算 |

## 5. 已知限制

1. 资金流已由数据平台发布并接入 `md_fund_flow_candidate`；两条预设已恢复。资金流 `close/change_pct` 是观察日回溯复权口径，H5 价格仍来自 `md_daily_bar`，不使用资金流表价格算收益。

3. `svquant_test` 行情历史只有约 5 个交易日，完整筛选在 `svquant_dev` 只读验证；生产环境部署后需再用真实数据复核 60 日/250 日窗口与耗时。
