# H5 柱高、分点间距与行业热度深读（2026-11-11）

依据：`/home/dev01/download/柱状图柱高与分点间距-修复说明.md`

## 一、柱状图

- 基线固定为 0：
  - 有负值时 0 轴在中间；
  - 无负值时 0 轴在底部。
- 顶部保留 8% 白：`yMax = max(0, rawMax) × 1.08`。
- 柱高 = `abs(y(value) - y(0))`，不再使用固定高度。
- 正值从 0 轴向上，红色；负值从 0 轴向下，绿色。
- Y 轴刻度统一 1 位小数，单位在标题处只标一次。
- 柱宽仍保持上一轮上限 40px。

## 二、分点间距

- 列表项上下 padding 4px；
- 行高 1.65；
- 圆点与文字 gap 6px；
- 容器左 padding 0；
- 仍保持无边框、无背景。

## 三、行业热度可点击

- 首页行业热度行从静态块改为可点击；
- 点击进入 `/topic/industry:<行业名>`；
- 后端新增 `build_industry_topic`：
  - 行业成分股、涨跌、成交额、资金流、资讯、等权走势；
  - 估值分位、拥挤度、行业 base rate 未提供时显示「未提供」，不填 0；
- `Topic` 页兼容行业详情：
  - 无估值分位时标题为「行业热度深读」；
  - 无 base rate 时显示「—」；
  - 仍保留关键事实、相关标的、相关资讯。
