# H5 · 行业热度深读「你现在正在追高吗？」数据补齐

日期：2026-11-12

## 问题

首页「今日行业热度」点进「热点深读」后，风险护栏「你现在正在追高吗？」里：

- 估值分位、拥挤度分位都显示「未提供」；
- 未来 20 日收益中位数、最大回撤、上涨概率、样本全部为「—」。

原因不是没有原始数据，而是 `build_industry_topic()` 里把这三项写死为空：

```python
"valuationPercentile": None,
"turnoverPercentile": None,
"baseRate": {"sample": 0, ...}
```

此前行业页只计算了热度、等权涨跌、成交额、资金流和资讯数量。

## 修复

新增 `_industry_history()`：一次查询行业成分股近 3 年日线 + 估值，按交易日对齐，生成：

- 行业等权指数：成分股收盘价按各自首日归一后逐日平均；
- 估值序列：成分股正 PE 的日中位数；
- 换手序列：优先取日行情 `turnover`，缺失时用 `成交额 ÷ 流通市值` 折算；
- 迷你走势仍复用同一份等权指数。

再计算：

- 估值分位：当前行业 PE 中位数在近 3 年序列中的分位；
- 拥挤度分位：当前换手中位数在近 3 年序列中的分位；
- 历史分布：复用 `compute_base_rate()`，以「估值 + 换手同时处于高分位」为入场条件，统计未来 20 日收益中位数、最大回撤、上涨概率与样本数。

## 数据不足时的处理

- 不填 0、不伪造：
  - 历史少于 60 个交易日；
  - 估值或换手覆盖率低于 60%；
  - 有效样本少于 8 次。
- 任一条件不满足，仍显示「—」和「样本不足」，页面文案不变。

## 其它

- 原「跑赢概率」标签实际统计的是未来 20 日收益为正的比例，改为「上涨概率 / Positive-return probability」，避免误导。
- 关键事实新增一条「估值与拥挤度」，写明 PE 中位数分位与换手分位。
