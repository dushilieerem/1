# H5 量化研究：27 因子与因子榜/因子库改造（2026-11-09）

依据：`/home/dev01/download/量化研究-改动说明.md`

## 一、因子体系

从 6 个风格因子扩展为 **7 大类、27 个细分因子**：

| 大类 | 细分因子 |
|---|---|
| 动量 | 20 日涨幅、60 日涨幅、12 月动量（剔除最近 1 月）、52 周新高、5 日反转 |
| 价值 | EP（1/PE）、BP（1/PB）、SP、股息率、PEG、EBIT/EV |
| 质量 | ROE(TTM)、ROA、毛利率、低应计利润、ROIC |
| 成长 | 营收同比、净利同比、扣非净利同比 |
| 波动 | 20 日波动率、60 日波动率、Beta |
| 流动性 | 日均成交额、换手率、Amihud 非流动性 |
| 规模 | 总市值、流通市值 |

保留原 6 个 factor key（`value`/`momentum`/`volatility`/`quality`/`growth`/`liquidity`），避免旧草稿、回测、预设失效；新增 21 个 key。

## 二、因子榜

- 默认展示 7 张分类卡片；卡面标题为「大类因子 · 细分因子」，大白话作为副标题。
- 卡片显示当前选中细分的近 1 月/近 1 年收益、分位。
- 点卡片展开该大类细分，选择后卡面标题、分位、收益同步更新。
- 保留「近 1 月 / 近 1 年」切换和「带着因子去建策略」入口。

## 三、因子库

- 新增「因子榜 / 因子库」二选一，默认因子榜。
- 因子库按 7 大类分组，共 27 行；每行显示细分名、口径、分位、多空收益。
- 点任一行打开详情弹层，并同步为该大类当前选中因子。

## 四、调仓频率

回测支持 5 档：

- 日频
- 周频
- 双周
- 月度（默认）
- 季度

后端 `_rebalance_groups`、回测配置校验、配置预览均同步。

## 五、计算口径

新增因子按日频/财报 PIT 计算，统一转为横截面分位后按方向选股。

| 因子 | 实现口径 | 说明 |
|---|---|---|
| 60 日涨幅 | 现价 / 60 日前收盘 − 1 | 日频 |
| 12 月动量 | 21 日前收盘 / 252 日前收盘 − 1 | 剔除最近 1 月 |
| 52 周新高 | 现价 / 近 252 个交易日最高收盘 | 窗口不足 100 个交易日不计算 |
| 5 日反转 | 现价 / 5 日前收盘 − 1，方向低 | 与动量方向相反 |
| BP | 1 / PB | 估值日频 |
| SP | 营业收入 / 总市值 | 营收优先取最新年报，缺失时取最新报告期 |
| 股息率 | `dividend_yield_ttm / 100` | 估值日频 |
| PEG | PE(TTM) / 近 3 年净利 CAGR（%） | 年报净利 CAGR ≤ 0 或亏损不计算 |
| EBIT/EV | 营业利润 /（总市值 + 总负债 − 货币资金） | 营业利润近似 EBIT，页面口径注明近似 |
| ROA | 净利润 / 总资产 | 财报 |
| 毛利率 | `fin_indicator.gross_margin` | 财报 |
| 低应计利润 | （经营现金流 − 净利润）/ 总资产 | 越高表示现金含量越高 |
| ROIC | 营业利润 /（归母权益 + 总负债 − 货币资金） | 近似口径，页面注明 |
| 净利同比 | `profit_yoy` | 财报 |
| 扣非净利同比 | 扣非净利同比 | serving 当前缺 `deducted_net_profit`，暂不计算 |
| 60 日波动率 | 近 60 日收益标准差 | 至少 40 个有效收益 |
| Beta | 近 60 日相对沪深 300 的回归 Beta | 至少 40 对有效收益 |
| 换手率 | 近 20 日平均换手率 | 日频 |
| Amihud | 近 20 日 `|收益| / 成交额` 均值 | 值越小流动性越好，方向高为冲击大 |
| 总市值 / 流通市值 | `total_mv` / `float_mv` | 规模方向低（小市值优先） |

已知数据限制：

- `deducted_profit_yoy` 所需扣非净利 serving 字段尚未落库，因子保留在库中但当前无收益值。
- EBIT/EV、ROIC 为现有 serving 字段的近似口径，不是完整有息负债/所得税口径；详情页和因子库保留「近似」说明。
- SP 使用最新年报/报告期营收，不是严格 TTM。
- `_BOARD_CACHE_VERSION` 已升到 3，旧 6 因子缓存会失效并重算。
