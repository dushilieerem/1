### 今日卡（首页唯一实体卡）
- 上行「我的」：
  - 有持仓：组合今日涨跌幅 + 上次体检日期；点整行进组合页。
  - 无持仓：整行换成「建立组合」引导，不显示 0.00%。
- 下行「市场」：
  - 四格：上证指数 / 深证成指 / 创业板指 / 两市成交；
  - 指数取 `md_index_bar` 对应代码，涨跌按前收计算；
  - 两市成交取沪深全部个股 `md_daily_bar.amount` 汇总（亿元，展示为万亿），并计算较上一交易日变化；
  - 当前数据视图缺少三个旗舰指数时，格内显示「— / 数据待补」，**不用沪深300或其他指数冒充**；
  - 10:00 前当日成交额不展示，避免早盘数值误导；周末右上角显示「休市」，否则「收盘」。

### 今日概览
- 三条按来源独立选择，最多 3 条，每条带数字：
  1. 个股条：自选 ∪ 持仓中，7 日内有预约披露的最近事件；没有事件时回退到池内当日异动最大标的。
  2. 组合条：组合体检越线项，按超出阈值幅度取第一条；没有越线时回退到配置偏离。
  3. 市场条：两市成交额及环比；成交额不可用时用涨跌家数。
- 点击行进入个股/组合/主题；「查看完整日报」打开 Sheet，含三条 + 复盘正文 + 数据事实。
- 首页加载后异步调用现有 `/api/invest/ai/daily`，成功则用 50 字 AI 结论替换一行复盘并标「AI 生成 · 规则校验」；AI 不可用时保留规则复盘并标「规则生成」。
- 三条都为空时整块不渲染。
- 每条左侧圆点：红=个股，琥珀=组合，灰=市场。

### 今日热点
- 只显示前 3 条，行内为：标题 + 热度 + 一句说明 + 风险标签。
- 风险标签由现有数据实时推导：
  - 估值分位 ≥85% → 估值偏高；≥70% → 估值不低；
  - 成交额分位 ≥80% → 拥挤度高；
  - 都没有 → 数据待验证（保证每行至少一个风险标签）。
- 「全部」进入新增 `/topics` 热点列表页，不再指向搜索页。

### 学习 + 合规
- 学习一行：标题 + 箭头，进入学习中心。
- 页尾保留一次数据口径/非实时/不构成投资建议提示。

## 4. 数据缺口与限制

1. **三个旗舰指数缺失**：当前数据视图 `md_index_bar` 只有 000015/000300/000905/399101/399303/399317，没有 000001.SH、399001.SZ、399006.SZ。首页按要求显示「— / 数据待补」，不拿其他指数冒充；需数据平台补这三个指数。
2. **两市成交是行情汇总口径**：用沪深个股 `amount` 求和，不是交易所直接发布的官方成交额；应与数据平台确认口径后再对外称“交易所成交额”。
3. **上次体检日期是近似值**：组合体检每次按当前持仓实时计算，没有单独保存“体检完成时间”；当前优先取 `portfolio_meta.updated_at`，没有则回退最近调仓日期。
4. **热点证据数/研报覆盖/搜索词频未接入**：风险标签只基于现有估值分位与成交分位；`数据待验证` 是兜底，不代表真实风险判断。
5. **学习一行是固定入口**：课程库与近 7 天浏览标签匹配未接入，当前进入学习中心。
6. **5 分钟行情延迟提示**：当前数据为 EOD 快照，没有实时行情时间戳，沿用现有 stale banner；未伪造「行情延迟 5 分钟」。
7. **AI 日报**：三条事件由规则确定性选出，AI 只尝试生成一句复盘；AI 不可用时保留规则复盘，未把整块隐藏（避免首页出现空洞）。如果产品坚持“AI 失败整块不出现”，需要再调整。
8. 本次未提交、未推送、未合并。

## 5. 数据业务确认（2026-11-05）

- 三大旗舰指数：数据业务实测东方财富指数日线，`000001.SH` / `399001.SZ` / `399006.SZ` 均有 2016-01-04→2026-11-04 的 OHLC、volume、amount；当前 `index_price` 只有 000015/000300/000905/399101/399303/399317。计划新增 `flagship_index_price`（或扩展 `index_price`）并在下个 view 发布，建议字段 `date,index_code,open,high,low,close,prev_close,volume,amount,source`，ETA 约 1 个工作日。发布后 SVQuant 需同步到 `md_index_bar`。
- 两市成交额：数据业务可提供指数口径 = `000001.SH.amount + 399001.SZ.amount`，2016 起可用；`399001` 的 amount 与深证综指一致，为深市全市场口径。**不是交易所官方发布表**，对外只能标“沪深两市成交额（指数口径）”；若必须叫“交易所官方成交额”，需 SSE/SZSE 官方日汇总，当前没有。
- 资金流：当前无表；数据业务首批可做“近 5 日主力净流入 + 连续净流入天数”候选表，ETA 1–2 个工作日，完成前两条预设继续标“数据待补”。
- 热点证据/研报/搜索热度：当前没有可用数据，暂标“数据待验证”，无 ETA。
- 实时性：数据平台 EOD，不提供 5 秒推送或 5 分钟延迟时间戳；H5 按“收盘/EOD”展示，不做 5 分钟延迟判断。
