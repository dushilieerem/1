## 规则

- 报告只记录实际执行结果；未执行的用例写 `NOT RUN`，不得写 `PASS`。
- 新报告按 `R<轮次>-<主题>-<日期>.md` 命名；一次性记录按 `<主题>-<日期>.md`。
- 结论变化要回写测试设计与追踪矩阵，不要只留在报告里。
