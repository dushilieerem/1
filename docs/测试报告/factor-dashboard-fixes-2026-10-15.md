# 因子面板问题处理（2026-10-15）

## FT-003：空结果提示

有缓存但搜索/分类/校验等条件未匹配时，显示“没有符合条件的因子，请调整搜索或筛选条件”。仅当原始缓存行数为零时显示“该口径暂无缓存数据”。加载中与加载失败分别显示对应状态。“不过滤”旁的无缓存提示也按原始数据判断，避免被搜索条件误触发。

## FT-006：Q1/Q5 换手补算

现有映射已读取 ResearchEngine 的 `factor_analysis.quantile_metrics[].turnover`。旧口径迁移会把组合换手搬到 `turnover`，清空 Q1/Q5 分位换手，等待重算。

本次修复补算工具的两个遗漏：

- 原来只选择 `q1_return` 为空的组合，会漏掉收益已有、分位换手仍为空的缓存；现在检查 Q1/Q5 收益与换手四列，任一为空即纳入。有效值 0 不视为缺失。
- 原来虽然注明 full，调用 `run_one` 时仍使用默认 core；现在显式请求 full。

此改动修复补算入口，不代表已确认线上缺值全部由旧缓存造成。没有连接服务器数据库或检查 ResearchEngine 实际响应，不能保证补算后上游一定返回换手。继续保持缺失值为 null，不用组合换手或 0 冒充。
