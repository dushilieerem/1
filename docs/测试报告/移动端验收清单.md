# 移动端验收清单（P2-05）

> 目标：关键流程在手机/平板可用；触控、键盘、横屏行为明确。
> 本清单记录已实现项与每次发版需人工复验项。

## 已实现

- 图表页：全屏模式、安卓 CSS 伪横屏、iOS 真横屏、Safari 动态视口适配（`visualViewport`）。
- 全局触控：按钮/链接 `touch-action: manipulation`，避免双击缩放延迟。
- 移动分区切换：因子检测、策略研究页提供「配置 / 代码与日志」切换。
- 图片懒加载：社区评论缩略图 `loading="lazy"`。
- 复杂表单采用 `grid` 单列 → `lg` 多列断点。
