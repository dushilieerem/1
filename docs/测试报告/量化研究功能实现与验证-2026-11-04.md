### 2. 因子

- 市场风格：6 因子近 20 日多空收益排序，前二同正→进攻、同负→防御、其余→均衡；附 3 个标签与口径说明。
- 因子榜：6 行（大白话名称 + 公式 + 收益值 + 分位），可切近 1 月 / 近 1 年；切换只重排与更新口径，不重复请求详情。
- 因子详情 sheet：一句话解释、当前分位、近 20 日多空收益、历史有效性 / 拥挤度 / 何时失效三行结论、取值最高/最低各 5 只。
- 底部「带着这个因子去建策略」预选因子与方向进入快速实验。
- 因子数据缺失时显示「—」，不填 0；页脚固定「分位只描述取值大小」与历史数据声明。

### 3. 策略

- 快速实验：2–4 个因子、方向可切、股票池三选一、相关性 > 0.5 提示重复暴露 r²；配置页展示固定参数；结果页 6 指标 + 双线图 + 回测假设 + 保存草稿 / 开模拟盘 / 改因子重跑。
- 一句话建策略：自然语言 → 因子组合；不足 2 个方向不进入实验并提示补一句；AI 不可用时走规则解析兜底。
- 我的策略：状态仅「跟踪正常 / 跟进关注」；卡展示今日、当前回撤、下次调仓；详情展示规则、因子、股票池、风险对照、最近回测、模拟盘入口。
- 草稿：保存 / 回测 / 开模拟盘 / 删除；空态一行说明，不重复放按钮。
- 策略广场：复用现有 `strategy_plaza_store`；收益榜 / 回撤榜 / 关注榜；卡片 3 指标 + 迷你曲线；详情含区间、基准、超额、最大回撤、夏普、因子；快照带 `quant_factors` 时支持复制到草稿，否则明确提示无法复制。

### 4. 回测

- 记录列表：名称 + 区间与调仓频率 + 累计收益 + 基准；按创建时间排列，不按收益排序。
- 回测报告：累计 / 年化 / 最大回撤 / 夏普 / 胜率 / 交易次数 / 波动率 / β / α 九项指标 + 策略与基准双线图 + 基准与超额两行 + 固定回测假设。
- AI 点评按需生成，按收益来源、风险特征、稳定性、与基准比、失效条件 5 个方面输出结构化数组；生成失败时整块隐藏，不显示降级文案。

### 5. 模拟盘

- 列表、详情、新建；与真实账户在视觉上区分，固定「模拟」标签。
- 详情展示累计、运行天数、起始资金、相对回测偏离、6 个指标、持仓、最近交易。
- 交易记录逐条「模拟成交」，区块标注「历史记录，非建议」。
- 新建从「我的策略 + 草稿」发起，默认 100 万，下一交易日开始；只记账，不接券商、不下单。
- AI 点评按偏离原因、集中度、一致性、要留意的变量 4 个方面输出；失败隐藏。

## 二、数据与计算口径

- 因子原始值：EP = 1/PE(TTM)、近 20 日涨幅（剔除最近 1 日）、近 20 日收益标准差、ROE(TTM)、营收同比、近 20 日日均成交额。
- 去极值（MAD，k=3）→ 横截面 z-score；低波动方向取负；综合分等权。
- 因子榜样本：全市场总市值前 500，页面明确披露；避免首屏扫描全市场。
- 回测：月度调仓、前 20 只等权、单边 0.1%、剔除 ST / 上市不足 60 天 / 近 20 日日均成交额低于 5000 万；前复权价格含分红。
- 基准：优先沪深300 / 中证500 指数日线，缺失时回退股票池等权，并在假设中注明。
- 年化、回撤、波动、夏普、β、α、胜率、超额全部由净值序列派生；无风险利率统一 2%。
- 模拟盘偏离 = 模拟盘累计收益 − 同策略同区间回测累计收益。
- 所有页面保留「历史数据，不代表未来」与非投资建议声明。

## 五、已知边界

- 因子榜使用「全市场总市值前 500」代表样本，并在页面口径披露；全市场回测仍使用全市场股票池。
- 回测为月度调仓、固定前 20 只等权，不提供参数级自定义（按设计文档固定参数）。
- RE 策略 DSL 目前支持 EP、动量、波动、流动性；ROE / 营收同比不在 RE 字段表内，含这两个因子的组合会标注「本地降级」。
- 模拟盘复用 `paper_store` + RE 结算；含 ROE / 营收同比的组合暂不支持创建模拟盘，页面给出明确提示，不另建本地模拟盘状态机。
- 模拟盘从下一交易日开始；若数据日期尚未更新到该交易日，详情显示「还没有持仓，等下一次调仓」。
- AI 点评依赖后端 AI 配置；不可用时按设计隐藏，不影响指标与图表。
- 策略广场复用现有 `strategy_plaza_store`；关注数暂用浏览量展示，收藏为本机状态，不新增关注表。
