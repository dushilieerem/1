## 4. 测试数据与账号

### 标准账号（通过 API 注册创建；禁用用户经 DB 将 status 置 disabled——无用户管理界面，属已知运维路径）

| 代号 | 角色 | 用途 |
|---|---|---|
| TEST_ADMIN | role=admin | 管理接口、审核、日志、额度管理；由 `ADMIN_USERNAME/ADMIN_PASSWORD` 种子 |
| TEST_USER_A | role=user | 资源创建方（隔离测试的被攻击方） |
| TEST_USER_B | role=user | 隔离测试的"他人访问"方 |
| TEST_DISABLED_USER | status=disabled | 登录拒绝、token 失效测试 |

### 数据规范

- 所有测试数据带 `RUN_ID` 前缀（如 `SVQ-20260923-01-`），可清理、可重复创建、不污染示例数据（`sample_momentum_5d` 等种子项目只读不改）。
- 边界数据集：空串/null、0、超长（标题>120、正文>8000、代码>200000）、特殊字符（HTML/SQL/Markdown）、最大 limit、非法枚举。
- AI Prompt 集合：正常需求、超长、注入（要求泄露系统提示/密钥）、承诺话术（触发 metrics_trust）。
- 文件集（KH）：正常 md/pdf/docx、空文件、损坏文件、超大文件、中文文件名、双扩展名。
- 行情数据依赖 RE：使用内网 RE 测试实例的稳定标的；RE 不可用时相关用例标 BLOCKED 而非 FAIL。

## 5. 证据与报告规范

```text
docs/测试设计/evidence/<RUN_ID>/
  env-summary.md        # 版本、配置摘要（无密钥）
  commands.txt          # 命令与退出码
  api-responses/        # 请求/响应/状态码/耗时（脱敏）
  screenshots/          # E2E/前端证据
  logs/                 # backend/frontend 日志片段（脱敏）
```

红线：任何证据不得包含密码、token、API key、JWT_SECRET 明文；.env 内容只允许出现"键名存在性"。

## 9. 环境变更类用例隔离规则（TEST-DESIGN-ISSUE-002 修正）

以下用例会修改共享环境（.env / 进程环境变量 / 服务重启），执行时必须：

1. **先快照** `backend/.env`（复制为 `.env.bak-<RUN_ID>`，不入库）；
2. 在**独立执行窗口**内进行，窗口内不并行其他用例；
3. **执行后立即恢复**并重启服务验证恢复成功；
