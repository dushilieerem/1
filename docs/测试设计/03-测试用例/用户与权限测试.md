# 用户与权限测试用例（M1）

> 模块：用户与权限（认证/JWT/资料/主页/关注）。代码：`backend/app/routers/auth.py`、`services/auth/*`、`app/deps.py`。
> 关键代码事实：注册用户名 3–32 位字母数字下划线、密码 ≥6、email 可选唯一；登录失败 401 并写审计 `auth.login_failed`；JWT HS256（`JWT_SECRET`，默认 7 天），无服务端吊销但每请求回查 users.status；角色仅 `user/admin`；重复用户名返回 **400**（非 409）。
> 状态：全部 NOT RUN。Req 基线：PRD §6.1。
