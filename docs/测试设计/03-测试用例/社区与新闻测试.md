# 社区与新闻测试用例（M7/M8）

> 模块：社区（帖子/评论/投票/收藏/通知/举报/审核/运营）与新闻（列表/详情/摄取/富化）。代码：`backend/app/routers/community.py`、`news.py`、`services/community/community_store.py`、`services/news/*`。
> 关键代码事实（community，24 端点）：列表/热帖/详情/评论列表**匿名**（optional_user），其余 require_user；`bump` 默认 "1"（0/false/no 之外都加浏览数）；管理类（moderation/reports/ops/summary/moderate/purge）在 **store 层按 author_role 校验**，非 admin → PermissionError→403；错误映射 ValueError→400、KeyError→404；`DELETE /posts/{id}/favorite` 无显式错误映射（行为记录）；举报 open 态部分唯一索引 `idx_reports_open_uniq`（同目标仅一条 open）；notifications/read 支持 ids/type/all 组合。
> 关键代码事实（news，6 端点）：**全部匿名**（含 POST ingest/enrich——安全留档项）；`POST /api/news/ingest` sources 白名单 = FETCHERS ∪ UNSUPPORTED_SOURCES，非法 → 400 且返回 `supported/unsupported` 清单；`limit` 默认 12；详情/enrich 非数字 id → 400、不存在 → 404；`GET /api/market-data/daily/{code}` 同文件（异常 → 502 `{"error": str(exc)}`，可能泄漏内部异常文案，见 TC-NEWS-014）。
> 状态：全部 NOT RUN。Req 基线：PRD §6.5、§6.6。**环境依赖说明（TDI-006）：TC-NEWS-005/009/010/011 依赖真实外部新闻源，结果可能随外网波动——失败时先区分 EXPECTED ENVIRONMENT FAILURE（网络/源站不可达）与真缺陷，再定 PASS/FAIL。**
