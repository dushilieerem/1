# 行情与自选股测试用例（M2/M6）

> 模块：行情展示（RE 代理）与自选股。代码：`backend/app/routers/re_gateway.py`（market-data 三端点）、`news.py`（market-data/daily）、`watchlists.py`。
> 关键代码事实：`GET /api/market-data/symbols|indices|indices/{key}/constituents` **匿名**（RE 转发，60s 超时）；`GET /api/market-data/daily/{code}` 匿名 + 产品侧缓存（`fresh=1` 绕过，ValueError→400、其他→502）；自选股 8 端点：GET 匿名返回空集（soft_db_user_id），其余登录+归属；SVQuant 不落任何行情数据本体（PRD §7.7）。
> 状态：全部 NOT RUN。Req 基线：PRD §6.4。
