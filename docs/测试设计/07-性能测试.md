# 07 性能测试（L8 层）

> 基线：PRD §8.1 性能目标。**责任边界原则：RE 计算类目标（回测/试算/组合/参数优化）属 ResearchEngine 责任，SVQuant 测试只验证"链路可达 + 记录开销"，不替 RE 判定达标；SVQuant 自身责任 = 网关开销、认证/列表类接口、SSE 首帧转发。SVQuant 侧 P95 阈值 PRD 未定义（待确认），测得数据先建立基线，达标结论由产品确认后再下。**
> **本轮没有任何"达标/通过"结论——全部用例状态 NOT RUN。**
> 工具约定：不引入新压测框架；用 Python（httpx/asyncio）轻量脚本 + 现有契约脚本改造，脚本与结果入 `docs/测试设计/evidence/<RUN_ID>/perf/`。绝对禁止对生产环境施压。
