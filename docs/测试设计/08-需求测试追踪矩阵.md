# 08 需求测试追踪矩阵（RTM）

> REQ 编号承接 01-测试策略 §需求对照表（PRD §6.1–6.10 + §7/§8 NFR）。映射关系自各用例文件的 `Req` 字段汇总生成；一用例可对应多条需求（复合标注），故各模块"用例数（去重）"≤各行计数之和。
> 覆盖状态口径：**已覆盖** = 用例已设计（状态 NOT RUN，执行后由 09-缺陷管理规范 的结果语义接管）；**GAP** = 已识别但无对应用例（本轮仅两类记录型 GAP，见 §3）；**NOT APPLICABLE** = 规划中/未实现能力，不构成覆盖缺口。
> L2（数据库）/L7（安全）/L8（性能）用例不逐条挂 REQ，以层覆盖呈现在 §4。
