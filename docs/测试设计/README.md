## 状态纪律（重要）

1. 本体系当前只有**设计**，没有执行结果。任何用例不得写 PASS。
2. 执行状态枚举：`NOT RUN`（已设计未执行）、`PLANNED`（规划中，载体/环境未就绪）、`NOT APPLICABLE`（对应功能规划中，如套餐/组织/模拟盘）。
3. 执行后允许：`PASS / FAIL / BLOCKED / NOT_RUN`（定义见 [09-缺陷管理规范](09-缺陷管理规范.md) §5）。
4. 性能指标在实测前不得写"达标"；安全扫描在执行前不得写"通过"。
