## 验收清单

### 1. 生产版标识清理

- [x] 页面可见文本不含 `v3 / 版本号 / 演示 / 预览 / 当前环境 / 原型 / 角色切换`（浏览器全文扫描 `forbidden=[]`）。
- [x] 侧栏移除演示环境说明与静态统计；顶栏移除版本标识。
- [x] 当前角色只作为身份显示，不提供切换控件。

### 2. 数字与空态

- [x] 移除静态业务计数（6 个环节、5 个工作台、10% 现金下限、0 偏差等）；数量/百分比均来自接口或由接口数据计算。
- [x] 缺失数据使用空态或“—”占位，不使用常数样例。
- [x] 列表按唯一业务主键去重：项目 `key`、研究案 `id`、论点 `claim_id`、议案 `id`、授权 `id`、持仓 `symbol`、台账/事件 `id`。
- [x] `dedupeBy` 单测覆盖重复键、空键与空输入（`tests/instDedupe.test.ts`）。

### 3. 加载 / 空 / 错误

- [x] 每个数据页面有页面级加载态与错误态；错误信息来自接口。
- [x] 列表与详情区块均有空态：无项目、无议案、无授权、无持仓、无事件、无退出、无估值字段等。
- [x] 交叉质询无核验明细、估值无可用字段均显示明确空态，不渲染空容器。

### 4. 视觉硬约束

- [x] 字号仅出现 `11 / 12 / 16 / 22px`；≤10px 中文为 0。
- [x] 间距使用 4/8/12/16/24/32；卡片内边距 16px、圆角 10px、描边 1px。
- [x] 三栏 `align-items: stretch`；1280/1440/1920 下底部均为 **803px**。
- [x] 侧栏头部与顶栏均 56px、同一底色；Logo 盒 38×38 位于头部内，未裁切。
- [x] 全局 `tabular-nums`；表格数字右对齐。
- [x] 灰字 `--v3-muted #5f5766` / `--v3-faint #6b6370` 对浅底 ≥4.5:1；无 9px 灰字。
- [x] 三档视口横向/纵向溢出均为 0。

### 5. 本轮内容修复

- [x] 按反馈保留原有字体：正文 `Inter`、标题 `DM Sans`、数字 `JetBrains Mono`。
- [x] 估值复核字段全部中文标签：估值方法、每股价值、关键假设、股权/企业价值、净债务桥、口径说明；隐藏 `is_demo`、内部 error 与原始 JSON。
- [x] 交叉质询按 claim 分组，显示中文状态（已核验/部分核验/未核验/证据不足/证据矛盾）、证据编号与问题说明。
- [x] 除首页外，所有页面大标题下不再显示解释性小字。
- [x] 项目流水线卡片、各工作台大标题、左侧项目/议案/授权切换列表均显示“版本 N”，同一股票的不同研究版本可区分。
- [x] 同一股票只保留最近更新的研究案进入流水线/左侧列表，不再同时出现在多个环节。
- [x] 左上角 Logo 修复：品牌副标题样式不再覆盖印章，`旸` 字完整居中显示。
- [x] 右上角搜索支持按代码/名称检索全市场股票；无当前案时“进入研究”创建研究案，有当前案时打开当前流程。
