# 模拟盘使用说明

> 适用对象：想用已有策略跟踪每日模拟持仓、成交和权益的用户
> 入口：顶部导航「模拟盘」

## 1. 模拟盘是什么

模拟盘是**日终批量**模拟，不是实时行情驱动的模拟交易，也不接入券商：

- 每个交易日收盘后，系统用截至前一交易日的信息生成当天订单；
- 以当天成交额 ÷ 成交量（VWAP）作为成交价，以当天未复权收盘价估值；
- 账户、持仓、订单、成交、费用和每日权益持续保存，策略状态跨交易日延续。

它与回测的区别：回测一次性算完一段历史；模拟盘逐日向前推进，每天结算一次，账户状态会保留。

## 2. 创建模拟账户

1. 先在「策略」里准备好一个策略项目（事件或向量化均可）。
2. 打开「模拟盘」，点击「新建模拟账户」。
3. 选择策略项目，填写账户名称和初始资金；首个结算日可以留空：
   - 收盘前创建：从当天开始结算；
   - 收盘后或非交易日创建：从下一个工作日开始；
   - 也可以显式指定历史日期用于补算，但不能晚于今天。
4. 创建时会**快照**策略源码、执行模式、股票池、基准和费用。之后修改策略项目不会自动影响账户，需要点击「同步策略」。

## 3. 自动结算与数据就绪

- 系统会定期（默认每 5 分钟）检查行情数据。数据发布后，自动补结算所有到期账户，一次最多补 10 个交易日。
- 「概览」会显示：行情数据就绪至哪一天、已结算至哪一天、下次结算日。
- 当天数据通常在收盘后发布。发布前提示“行情数据尚未就绪”属于正常等待，发布后会自动结算。
- 也可以点击「立即结算」手动触发；它只会结算已经就绪的交易日。

## 4. 结算口径

| 项目 | 规则 |
|---|---|
| 信号 | 事件策略和向量化策略都只使用截至前一交易日的数据，不含未来函数 |
| 成交价 | 当天 VWAP = 成交额 ÷ 成交量；成交量缺失或为 0 时不成交，不回退到收盘价 |
| 估值 | 当天未复权收盘价；缺失时回退到最近有效收盘价并提示 `MARK_PRICE_FALLBACK` |
| 交易规则 | 现金多头、100 股整手、T+1、停牌和涨跌停拒单 |
| 费用 | 佣金（含最低佣金）、卖出印花税；不模拟滑点 |
| 状态 | 策略状态跨日保存；事件策略的 `context.state` 会在下一交易日恢复 |

## 5. 页面操作

- **概览**：总资产、收益率、行情就绪日、已结算/下次结算日、最近一次结算尝试和错误提示。
- **持仓 / 成交 / 订单**：逐日明细，成交价格和费用可以逐笔核对。
- **结算记录**：每个结算日的现金、持仓市值、总权益、费用和行情版本；最新一笔可以「回滚并重算」，用于修正异常后重跑。
- **暂停 / 恢复**：暂停后不再自动结算，已有账本保留；恢复后从下一个未结算交易日继续补算。
- **同步策略**：把策略项目的最新代码和参数同步到账户。代码变化会清空策略状态，建议先在回测里确认新版本可运行。

## 6. 常见状态与处理

| 页面提示 | 含义 | 怎么处理 |
|---|---|---|
| 行情数据尚未就绪 | 目标交易日的数据还没发布 | 等待即可，发布后自动补结算 |
| 策略代码执行失败 | 策略运行时报错（如字段名写错） | 修正代码 →「同步策略」→ 把账户从“需处理”恢复为运行 |
| 策略代码与账户快照不一致 | 账户里的策略和当前项目不一致 | 确认版本后「同步策略」 |
| 策略状态与账户记录不一致 | 跨日状态对不上 | 在结算记录里回滚并重算，或同步策略重置状态 |
| 结算服务超时 / 繁忙 / 内部错误 | 结算暂时失败，不是账户数据错误 | 系统会自动退避重试；持续出现请查看「最近结算尝试」或联系管理员 |

账户显示“需处理”（红色）时，先按提示修正问题，再点击「暂停」→「恢复」，系统会从下一个未结算交易日继续。

## 7. 当前限制

- 只做日频、收盘后结算，不支持盘中、分钟或 Tick 行情。
- 不支持做空、融资融券、保证金、部分成交、成交量约束、滑点和市场冲击。
- 不自动处理分红、送转、配股等公司行为，跨这些日期区间的结果不作准确性保证。
- 不接入券商实盘，也不产生真实订单。
