# 监控指标

SVQuant 后端在进程内聚合 HTTP 指标，不引入额外依赖。

## 抓取

`GET /api/metrics` 返回 Prometheus 文本格式。鉴权规则：

- 设置 `METRICS_TOKEN`：请求头 `X-Metrics-Token: <token>` 或 `Authorization: Bearer <token>`；
- 未设置：仅允许回环地址（`127.0.0.1` / `::1`）。容器/反代场景请显式设置 token。

## 指标

- `svquant_http_requests_total{method,route,status}`：请求数，`route` 为路由模板（如 `/api/inst/cases/{case_id}`），不记录原始 ID；
- `svquant_http_request_duration_seconds_{bucket,sum,count}`：按路由的耗时直方图；
- `svquant_http_in_flight`：当前处理中请求数；
- `svquant_users` / `svquant_posts` / `svquant_news_items` / `svquant_strategy_runs` / `svquant_ai_usage_rows` / `svquant_audit_rows` / `svquant_open_community_reports`：库表聚合计数。

`/api/metrics` 自身不计入，避免抓取噪声。多副本部署时每个实例各自暴露，采集端按 `instance` 聚合。

`scripts/ops/check_alerts.py` 抓取时如设置了 `METRICS_TOKEN`，会自动带 `X-Metrics-Token`。
