## 边界

- 本仓库只定义 SVQuant 产品前后端的本地开发启动方式。
- PostgreSQL 与 ResearchEngine 是独立依赖，需先部署并可访问。
- 生产环境的反向代理、进程守护、容器编排、高可用与自动回滚不在本仓库范围内，按实际运维方案执行。
