## 边界

- 本仓库只定义 SVQuant 产品前后端的本地开发启动方式与容器编排（`deploy/compose.yml`）。
- PostgreSQL 与 ResearchEngine 是独立依赖，需先部署并可访问；RE 的流水线模板在 [`deploy/re-template/`](../../deploy/re-template/README.md)，落点在 RE 自己的仓库。
- 高可用、多可用区、蓝绿/金丝雀发布不在本仓库范围内，按实际运维方案执行。
- 旧版部署文档已归档到 [`../归档/2026-10-文档整理/07-部署文档/`](../归档/2026-10-文档整理/07-部署文档/)，其中可能含更细的历史命令，仅供排查参考。
