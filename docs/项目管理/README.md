# 项目管理

本目录承载“怎么开发上线可用”：迭代与项目计划、风险、技术债、项目状态快照和会议记录。

## 目录索引

| 目录/文件 | 用途 |
|-----------|------|
| `master-project-plan.md` | 项目总计划：阶段、里程碑和当前主线 |
| `迭代计划/` | 当前迭代的目标、任务清单和风险 |
| `项目计划/` | 各 Initiative 的实施计划 |
| `risks.md` | 风险登记 |
| `technical-debt.md` | 技术债登记 |
| `历史迭代/`、`版本发布/` | 历史迭代与发布记录（只读追溯） |
| [`项目状态/`](项目状态/) | 项目级当前状态快照和已交付事实 |
| [`会议记录/`](会议记录/) | 会议纪要和需要追溯的讨论结论 |

Feature 的验收证据和交付记录在对应功能包内维护（`功能包/FEAT-*/`），本目录只保存项目级管理事实。会议或实现产生的新结论必须在一个工作周期内回写到对应文档。
