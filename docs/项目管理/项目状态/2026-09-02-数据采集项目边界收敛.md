# 2026-09-02：数据采集项目边界收敛

FEAT-031 与 ADR-032 已落地。iFinD、AkShare、共享质量/候选发布工具、源数据、历史 release 和备份均归 `D:\project\IFind`；SVQuant 的 `MarketData` 根目录直接保存活动数据，ResearchEngine 只读消费，不再负责数据如何获得。

验收事实：IFind 67 项测试、ResearchEngine 533 项全量测试通过；实际 Provider 从扁平 `MarketData` 识别 5,916 个标的。原始/候选数据 119,790 个文件、13,446,498,383 字节，备份 10 个文件、642,171,558 字节，活动数据 14 个文件、2,706,782,340 字节，均与迁移前一致；SVQuant 变更数为 0。

旧 `MarketData/DataIngestion` 空目录已在终端释放工作目录后迁出。SVQuant `MarketData` 当前只包含活动数据目录、清单、质量报告和仓库说明文件。

详细证据见 [`FEAT-031 交付记录`](../../功能包/FEAT-031-iFinD采集项目拆分/交付记录.md)。
