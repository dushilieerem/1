## 布局检查

默认桌面实际内容宽度约1016 px，表单与Agent并排，无整页横向溢出。

浏览器实际390 / 1280 / 1440 px内容容器复核：390 px容器内（滚动条后375 px）总览、五模块、审查、Agent管理的scrollWidth等于clientWidth；导航抽屉可进入各模块。1280与1440 px容器内宽度分别1265与1425 px，无整页横向溢出；1280 px因子表单/Agent分栏659 / 310 px。

内置浏览器viewport控制未改变既有标签页实际尺寸，故使用自包含srcdoc验收夹具检查真实断点。普通iframe首次被服务器防嵌入策略拦截后改用srcdoc；未降低服务器安全设置。此工具/夹具问题不作为应用错误。
