## 策略研究的设计（重新设计，替代 GPT 稿的界面）

- 与因子工厂同一套研究框架：课题 → 研究树 → 台账 K → 校正门槛 → 封存验证 → 独立复核 → 入库。S0 复用 F0 的决策引擎，只换动作白名单。
- 每个节点是一个**冻结的配方**：因子与方向、等权合成、前 N 只、调仓周期、缓冲区；股票池、基准、区间、成本由课题固定。
- 门槛：扣费后超额、信息比率（随 K 提高）、相对回撤、换手、**2 倍成本下仍有超额**、**参数邻域 3×3 至少 6 格达标**。后两项用来防止挑中孤立的好参数。
- 同一配方重算不计 K；稳健性检验不另计 K。
- 入库只授予“可用于模拟组合”。

## 演示路径（约 8 分钟）

1. 驾驶舱：看待办和链路，组合与风险显示需要处理。
2. 策略研究：S1 在自主推进（换手过高 → 修订 → 回测 → 邻域 → 分支 → 封存 → 提交 SC2）。点检验标签看报告（净值、分年、邻域热力图、成本敏感性）。
3. 切到复核人：策略审查里勾选确认，入库 SC1，策略库出现 ST-03。
4. 组合与执行：版本与审批里批准 PF-1 v3；切到负责人在组合方案里把 ST-02 改成 100%，提交被拦截。
5. 运行与风险：负责人确认 E-31，填写复测证据后恢复；归因里创建改进任务。
6. 回到驾驶舱：数字和动态都已更新。
