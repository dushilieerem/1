# 因子工厂 V5：因子库分类对齐

版本：UX104 · 2026-11-10。范围：机构量化因子库，沿用 SVQuant 已有分类；不改变因子定义、指标、可用权限或研究准入。

## 用户问题与决策

原始 331 个因子具有真实的单因子分类，但机构页面额外合并为“量价／基本面与规模／风险与波动”，导致用户只能筛选少数大类。删除这个人为合并层，直接显示原库分类名称和顺序。分类采用可换行筛选按钮，搜索另起一行；机构端的整体布局、导航和组件风格保留。

分类显示名称来自逐因子 category_label/category 或原目录 libraryLabel，不以 SV01 等内部分类编号代替名称。复用已有 factorCatalog 分类排序逻辑，不另建冲突的固定分类体系。未来出现的真实分类追加显示；没有归属时显示“未分类”，不猜测。

## 数据与交互

1. 导入记录与原目录同一 library + factor_name 只显示一次；真实的新研究资产保留独立版本。复现验证不计成新因子。
2. 分类与搜索取交集。搜索涵盖名称、代码、定义及真实标签；切换分类不清除用户搜索词。全部分类清除分类限制，不清除其他筛选。
3. 分类计数按可访问、去重后的目录计算，搜索结果数另计；未命中显示空结果，不显示成接口故障或目录为空。
4. 这 331 条记录的 tags 当前均为同一组全库分类目录清单，并非单因子标签，不渲染为逐因子标签，也不参与标签搜索。真实研究资产的逐项 tags 保留。
5. 分类对齐不等于已按本机构范围验证，不重写旧参考指标和审批状态。新资产如有历史分类名称，照实保留；后续新增资产的分类输入应复用统一目录，需单独覆盖审批表单兼容后实施。
6. 原型仍为明确标注的场景数据，只显示少量样例；分类结构对齐 12 类，样例数量不冒充线上 331 条。样例标签用于交互设计，不充当原始因子的真实标签。
