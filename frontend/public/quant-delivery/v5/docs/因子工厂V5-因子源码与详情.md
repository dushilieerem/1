# 因子工厂 V5：因子源码与详情

版本：UX105 · 2026-11-10。用户要求查看导入因子的真实实现。本规格增量接在 UX104 原库分类之上，保留列表筛选、机构权限、原计算引用、既有报告和研究准入。

## 已确认事实与问题

- 私有 ResearchEngine 的 factor_library.db 包含主因子库331项，331项factor_code均非空。机构导入按库与稳定因子ID逐项对应，无缺失。
- 原RE目录接口只输出元数据；前端导入行body固定为空，详情错误地统一写“源码不可见”。SVQuant旧file接口只读本地Python文件，不能用文件路径拼接去读取这批SQLite定义。
- 稳定因子ID与Python函数入口不同，例如SV01_0001对应alpha158_cntd，SV02_0001对应bias。读取代码不意味着应把它转换为本机构自定义实现。

## 页面

因子名称／详情点击打开右侧详情面板，保留原列表筛选、滚动与选中位置；不把详情放在331行之后。宽度min(760px,视口-32px)，距边16px，窄屏仍可关闭，无整页横溢出。沿已有公司配色与对话框/侧栏规范实现。

- 标题显示因子名称、稳定编号与业务分类，右上角关闭。
- 三个页签：概览、实现代码、验证记录。默认概览，代码入口始终可见。
- 概览：定义、分类、真实标签及来源；没有逐项标签显示未标注。状态用面向用户的词语，不展示“未经V5复核”等内部版本词。
- 实现代码：Python只读代码区、复制按钮、真实函数入口；代码保持原字符与换行，长代码在代码区滚动。首次打开按需加载，切换因子立即清除旧代码；迟到响应不得串到另一个因子。
- 来源与版本折叠展示实际库、稳定ID、函数名、源码SHA-256、包含公共工具/适配器的执行指纹（若接口提供），各字段名称不得混用。默认说明为“定义依赖计算引擎提供的数据与公共工具；历史报告以报告保存的版本为准”。
- 验证记录：本机构复现记录与原始历史参考结果分开；没有记录明确为空，参考指标仍显示适用范围与口径，不用缺失显著性或当前源码冒充历史验证。
- 底部保留“基于此因子建立研究”，沿原库+稳定ID引用，不因查看/复制源码而填入draftFactor.body或自动调用计算。关闭／Esc返回触发位置；对话框内保持键盘焦点。

实现代码页区分读取中、已取得、未提供、读取失败。失败有重试；不存在的因子不展示上一项代码。不是所有非200都显示“源码不可见”。普通列表请求不加载331份源码。

## 后端契约

1. RE增加单因子只读源码DTO，复用SQLiteFactorRepository与参数化查询，选择库+稳定ID。返回真实原文、规范身份、函数入口和指纹。不得exec/compile源码来查询，不允许文件路径参数。
2. 机构BFF按当前用户机构读取授权导入记录，再用该行的库与稳定ID调用已配置机构RE。客户端不能随意指定RE地址、数据库路径或绕过机构过滤。返回身份与请求记录核对不一致时明确失败。
3. 原始源码SHA=源码UTF-8内容摘要；RE执行指纹包含稳定ID、适配器版本及公共工具，不将两者互相替代。当前源码接口不是历史报告快照API。
4. 新研究资产仍从既有授权冻结版本接口读源码，不被基础库接口覆盖。用户私有自定义库及其他机构资产不得借此暴露。
5. 超时、404、服务错误、身份错配各有可测试结果，错误不泄露本机路径、凭证或堆栈。GET不改变导入状态、研究台账、审批或目录快照。
6. 不重导入、不全库计算、不回写历史definition_source。本次仅改只读查询与展示；后续新导入可以采用准确的定义来源描述。
