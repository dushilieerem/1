# 因子工厂 V5 · 工作面板布局
版本 UX-103 v1.2 · 2026-11-10 · Codex 产品经理
状态：用户已授权的界面增量；实际实现与浏览器验收另记。

## 设计结论
用户连续指出两种问题：固定等高使审批卡大片空白；左卡决定等高又使右侧Agent记录只有很小可视区。最终不再把两个不同用途的卡片强行绑成相同高度，采用“业务工作区＋独立运行栏”。本版本替代v1/v1.1等高条款；其他业务流程和真实运行规则不变。

## 桌面 >1250px
- 原有左业务内容与右240px Agent栏的位置和公司样式保留，顶部对齐，底部不强制对齐。
- 左工作区：当前环节卡片按内容自然收紧，其下接原“研究历程与全部试验”，保持默认折叠和用户已展开状态，不新增占位块来填空。
- 仅长业务内容设上限 clamp(420px,62dvh,640px)，不是固定高度或最低420px。标题/主要操作固定，中间定义、实现和检验信息可滚动；短审批卡按内容显示。
- 右Agent运行栏使用自己的 clamp(420px,62dvh,560px) 高度，不受左卡内容长短影响。标题与当前状态、事件和建议滚动区、需要处理及操作区三段。上下padding约16px，状态不重复占空行；无操作时不渲染空actions块。
- 右侧日志区至少能完整读多条常规事件，默认保持最近事件可见；手动阅读旧事件或编辑建议时不因刷新强制滚回顶端。长日志/建议在栏内滚动。
- 右栏可sticky top84px随左侧历史阅读保留观察窗口；不能覆盖页头或超出容器。代码展开复用左主内容滚动区，不套第二个纵向滚动框。
- 独立未达标/人工接力提示位于工作区上方；不以其长度决定右栏高度。

## 窄屏 <=1250px
顺序为当前业务内容→Agent状态→研究历程。取消两栏固定/最大高度与sticky，内容自然展开；所有操作和证据仍可访问，无整页横向溢出。任务列表与四环节自身响应式设计保留。

## 实现映射
原型 ff-work-panels 下放 ff-work-main（ff-stage-main + ff-history）与ff-live。正式React复用相同层次，不复制模拟内容、不重建台账或改变事件回调。内容可滚动区有键盘焦点与可访问名称；Tab可正常离开。

## 验收
1. 1366x768、默认1536附近：审批卡无被撑出的大片空白，右Agent日志不会被压成约68px小窗。切换四环节右栏可读高度稳定。
2. 研究准备长内容、研发展开实现、审批短内容、右侧多条事件均可正常查看；标题/操作不被滚走或截掉。
3. 提取footer后“查看待审批”“打开因子库”、人工研究、所选报告和复盘原条件与链接完整保留；不得只删除原按钮。
4. 1024/760无横溢出，按业务→Agent→历史堆叠；展开历史仍有原树、试验和入口。
5. 此次是界面增量：不启动研究/计算，不改API/额度/审批/数据库。真实运行质量和正式准入需另外验收。
