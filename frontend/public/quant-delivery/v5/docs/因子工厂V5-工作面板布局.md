# 因子工厂 V5 · 工作面板布局
版本 UX-103 · 2026-11-10 · Codex 产品经理
状态：用户已授权的界面增量；设计与正式实现、浏览器验收分别记录。

## 目的和范围
用户反馈：任务详情左侧业务内容卡与右侧 Agent 状态卡各自随内容撑高，尤其审批入库左短右长。沿四环节及既有品牌优化，不重排任务导航、不改变自动研究/人工操作/审查契约。仅作用于挖掘任务四环节详情的双面板，不泛化影响复核页面、报告或其他业务模块。

## 布局
- 桌面宽度 >1250px：左业务内容、右 Agent 状态保持现有列宽；两张卡片顶边与底边一致。共享高度 clamp(420px,62dvh,640px)，vh 作兼容回退；切换四环节不因长短内容跳高。
- 标题与当前状态保留在卡片顶部；业务主操作与“需要你处理”保留在卡片底部。中间内容 flex:1/min-height:0，溢出出现纵向滚动条，长文本正常换行，不截断决定性内容。
- 左卡：标题 / 可滚动内容（含定义、实现与检验信息）/ 该环节操作。代码展开使用主内容滚动区，不叠加第二个纵向滚动容器。
- 右卡：当前工作标题与状态 / 可滚动的真实事件、人工建议与处理记录 / 需要你处理及主要操作。内联建议编辑器可放中间区，滚动后仍能完整编辑/提交；不能被固定高度裁掉或因后台刷新丢草稿。
- 研究未达标、人工接力等独立提示放双面板上方，不作为左侧高度的一部分。研究历程仍在下方默认折叠。
- 宽度 <=1250px：按业务内容、Agent 状态上下排列，取消固定高度与整卡内部纵向滚动，内容自然展开；保留所有入口。任务列表和四环节自身响应式约定不变。
- 可滚动内容区可键盘聚焦、有简明可访问名称；Tab 可离开。短内容不强造空白文案、假日志或示例进度。

## 验收
1. 正式页面与更新后的 factor-factory 原型对照；1366x768、1536x864 下四环节两卡高度差 <=1px，长内容仍可访问。
2. 研究准备长目标、因子研发展开实现、审批入库短内容、右侧多条事件，均无卡片溢出/互相覆盖/整页横向滚动。
3. 内容滚动时标题/底部操作位置稳定；无需滚至整页末尾才能找到主要操作。内联建议已有幂等/草稿行为不退化。
4. 1024与窄屏自然堆叠，操作与文字完整；切换环节、查看报告只读，不由验收触发模型或计算。
5. 状态、试验、人工建议均保留真实记录；本批不改 API、迁移、额度或后台运行。页面展示通过不代表研究质量/正式入库已完成。
