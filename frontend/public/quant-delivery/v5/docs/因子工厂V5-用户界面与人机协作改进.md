## 3. 排版与文案

- 沿公司浅色背景、紫色主操作、深色正文、轻边框卡片；保留现有导航和品牌。
- 普通正文 14px 左右，辅助文字至少 12px；任务标题 22px 左右、区块标题 16–18px。不能把决定性状态缩成 9–10px。
- 内容行高约 1.65–1.8，卡片内边距约 20px；长名称换行，代码和表格局部滚动，不产生整页横向滚动。
- 同一个数据只突出一次。当前工作与研发主卡分别回答“正在做什么”和“得到了什么”，不重复堆放同一日志或同一技术状态。
- 从未委托 Agent 的纯人工任务显示“继续人工研究 / 交给 Agent 研究”，只有实际自动运行失败才显示“重试启动”；不要用 Agent 运行标题误指人工操作。环境角标可保留“研究环境”，不要常驻“接入中”等研发进度描述。
- 主操作围绕当前状态：运行中可暂停/建议，暂停后可接手/交回，失败结束可查看报告/提交复盘，合格候选进入正式复核。
- 内部 development_failed 显示“未通过研发检验”；novelty deferred 显示“尚未进行因子库对照”，不能显示“查重完成”；manual 的创建来源不冒充实际执行者。
- 报告样本从冻结的 universe_snapshot 等实际证据读取；没有固定证券清单时才显示获授权股票池。不能默认猜成中证500。
- 错误提示解释本次操作是否生效，以及用户可以做什么。完整异常栈移到诊断，不吞成空数据。

## 4. 人机协作契约

### 4.1 提建议

人可以根据研发证据给建议。建议带目标分支、版本与提交时间，Agent 在下一次可用决策点读取，界面显示待处理/已采用/未采用及可核验理由。建议不得改预算、门槛、数据授权或封存规则。

### 4.2 人工接手

查看历史分支、试验和报告必须只读，禁止进入页面即激活分支。

显式接手时先暂停新的自动动作；对仍在运行的计算说明是等待当前计算结束还是已取消。以用户选择的 E/H 冻结实现为起点创建人工修订，标明继承来源，不从“最新草稿”偷换。原候选、代码、报告与消耗保留。

暂停或接手后迟到的模型返回不得覆盖人工工程。可保留为未采用建议，不能只靠前端禁按钮解决竞态。服务器以控制版本、输入身份和任务状态作原子校验。

### 4.3 交回 Agent

用户保存后明确选择“交回 Agent”，显示将使用的人工分支、版本与剩余预算。服务器绑定保存后的快照与控制版本，排队记录与状态恢复原子提交。

第一步使用这个人工版本进行检验；若同一冻结快照已有匹配有效检验，复用对应证据，不重复计算。之后 Agent 才决定继续修订或结束。整个往返延续原任务 K、已有证据和预算，不新建空任务来清零。

## 真实接力后的界面补项（2026-11-10）

- 任务级暂停放在任务标题操作区，各环节可访问；生成、计算、已停和历史失败要区别显示，不用一条笼统“正在检验”覆盖F3代码生成。
- 首次启动提示“已启动挖掘”；人工交回提示已保存版本及剩余额度。交回成功后展示当前运行，避免仍以旧F3失败作为当前状态；运行时阻止再次交回，保存遵守现有暂停/接管规则。
- 失败候选的留档和复盘属于该冻结候选的证据动作，不要求另起修订分支。F6只有源码/计划编辑需要先接手；选择/核对候选不能在父子effect之间循环清空重挂。
- 报告“返回研究任务”保持candidate与branch；仅显示H1a不能使候选再次隐式换成H1。
- 去掉普通工作区的“查看鱼骨图”设计链接；计划UUID放技术详情。“示例政策”改成明确本任务筛选条件；无封存证据时直接说明“尚未进行独立验证”，不使用“跨接口封存权限”等内部术语。冻结门槛字段按实际编辑权限显示只读/变更申请。
- 额度用完时显示已检验2/2与结束理由，不默认展示不存在授权的第3次操作。后台仍可保存精确nextK数学值供后续经授权的研究使用。

本补项保留现有四环节、侧栏、研究历程与报告结构，仅修正状态/证据/可读性；后端和前端必须按实际动作区分研究留档、失败复盘与正式准入。


## 复核结果页收口（2026-11-10，PM正式页面实查）

正式 /quant/reviews/factors 在已决定状态仍重复显示三次“未完成全库对照”，底部还并列一个无关的空“策略候选”区块，影响用户阅读。此次仅调整因子审查页面，不删除策略模块或其已有审查能力。

- 当前事项先展示“研究复盘 / 正式准入”类型及“待领取 / 处理中 / 已完成”状态。已决定页用一个结果卡显示决定、复核人、时间和意见；缺少某字段时不猜填。
- 对照证据保留一次准确的主结论，以及比较数量、最高相关、完整范围入口。重复的未完成句子合并，统计口径说明与技术追溯收起；未取得的数据仍明确为未取得，不能显示通过或0相关。
- 正在决定时，将真正的批准阻断条件集中在操作区一处；已决定后呈现当时的复核依据，不再堆叠像待操作的重复警告。功能限制继续由后端执行。
- “平台内置目录”在用户范围说明中统一叫“标准因子目录”，实际对应范围不变；可展开具体来源与版本，不编造分类。
- 因子专用审查页不拼接无关空策略审查区域；策略入口与原有路由保留。
- 意见按段落换行，正文大小/行高与报告一致；默认不罗列内部错误码、长UUID/哈希或研发操作说明。

验收补项 UX99-10：同一个已决定因子复盘在页面中只有一个主决定、一处对应未完成对照结论；正式准入的证据和批准权限没有因此放宽。研究员只读与复核员决定路径仍需保留。
